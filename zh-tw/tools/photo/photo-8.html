🔮 Image File Size Estimator

Estimate image file size from resolution, bit depth and compression ratio before shooting or exporting.

📐 計算公式與說明

未壓縮大小 = 畫素數 × 位深 / 8
壓縮後 ≈ 未壓縮 / 壓縮比

實際大小因影像內容而異。

📚 深度解析：未壓縮/壓縮圖片大小

💡 常見使用場景

  • 由畫素與位深算單張未壓縮大小。
  • 按壓縮比估實際檔案。
  • 儲存與傳輸規劃。
24MP 14bit
24MP、14bit：未壓縮 = 24e6×14/8/1e6 ≈ 42MB；壓縮比 4 → 約 10.5MB/張，連拍 100 張約 1GB。
位深影響
同 24MP 改 12bit：未壓縮 = 24×12/8 = 36MB，降 6MB；高位深保留更多後期空間但更佔卡。

❓ 常見問題（FAQ）

未壓縮大小怎麼算？
畫素數×位深(bit)÷8 = 位元組，再轉 MB；RAW 多含後設資料與冗餘略大於此。
壓縮比可信嗎？
無失真壓縮約 1.2–1.5×，有損 JPEG 可達 5–10×；估儲存用典型比並留餘量。
