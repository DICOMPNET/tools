🔮 Image File Size Estimator

Estimate image file size from resolution, bit depth and compression ratio before shooting or exporting.

📐 計算公式與說明

照片檔案大小估算（本頁程式碼口徑）：未壓縮大小=畫素數×位深÷8（B），換算 MB 再除 1024×1024，畫素數=百萬畫素×10⁶；壓縮後≈未壓縮÷壓縮比（1=不壓縮、約 3=RAW、約 10=JPEG；真實無失真壓縮約 1.2–1.5 倍，需按實際編碼器取係數）；聯動量：每畫素 bit=位深。校驗：三欄位經輸入守衛必填且須為合法數值，否則提示並中止。判據：無固定分級，壓縮比越大檔案越小，估算不含後設資料與容器開銷。

實際大小因影像內容而異。

⚠️ Unit-basis notice: this page uses 1 MB = 1024×1024 bytes (binary, MiB), while storage-card vendors label capacity as 1 GB = 1000 MB (decimal) — about 7.4% apart. When cross-checking "shots × file size" against card capacity, pair this with the card-capacity estimator (decimal basis) to avoid mixing bases.

📚 深度解析：未壓縮/壓縮圖片大小

💡 常見使用場景

  • 由畫素與位深算單張未壓縮大小。
  • 按壓縮比估實際檔案。
  • 儲存與傳輸規劃。
24MP 14bit
24MP、14bit：未壓縮 = 24e6×14/8/1e6 ≈ 42MB；壓縮比 4 → 約 10.5MB/張，連拍 100 張約 1GB。
位深影響
同 24MP 改 12bit：未壓縮 = 24×12/8 = 36MB，降 6MB；高位深保留更多後期空間但更佔卡。

❓ 常見問題（FAQ）

未壓縮大小怎麼算？
畫素數×位深(bit)÷8 = 位元組，再轉 MB；RAW 多含後設資料與冗餘略大於此。
壓縮比可信嗎？
無失真壓縮約 1.2–1.5×，有損 JPEG 可達 5–10×；估儲存用典型比並留餘量。

Item Formula / Rule Source / Standard
Uncompressed size Bytes = pixels × bit depth ÷ 8 × channel count ISO 12234-2:2001 Electronic still-picture imaging — TIFF/EP
Compression factor Lossless 14-bit RAW lands at 0.5 to 0.7 of raw size, while JPEG at quality 90 is near 0.1 ISO/IEC 10918-1 JPEG standard
Metadata overhead Thumbnails, XMP and maker notes add another 0.2 to 2 MB ISO 12234-2:2001 Electronic still-picture imaging — TIFF/EP
