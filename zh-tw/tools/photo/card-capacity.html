📷 Memory Card Shot Capacity Estimator

Estimate how many photos a memory card can hold from card capacity, image resolution and file format.

📐 計算公式與說明

可拍張數 = 卡容量(GB) × 1000 ÷ 單張大小(MB)（1GB 按 1000MB 計），RAW 與 JPEG 按各自單張大小分別計算；可錄分鐘數 = RAW張數 ÷ 10（按 10fps 連拍估算）。校驗：卡容量、RAW 單張、JPEG 單張均為必填有效數值（必填校驗殼攔截）。判據：單張檔案越小可拍張數與可錄時長越多，兩者均與卡容量成線性正比。

RAW 通常 20–50 MB，JPEG 較小。

⚠️ Unit-basis notice: this page uses the card-vendor basis of 1 GB = 1000 MB (decimal), while photo file sizes estimated on a binary basis (1 MB = 1024×1024 bytes, MiB) differ by about 7.4%. When cross-checking "file size × shots" against card capacity across pages, convert to the same basis first.

📚 深度解析：儲存卡容量與張數估算

💡 常見使用場景

  • 按卡容量與單張大小算可拍 RAW/JPEG 張數。
  • 估算延時/影片錄製時長。
  • 出行備卡規劃。
64GB 卡
64GB 卡、RAW 約 25MB/張：張數 = 64×1000÷25 ≈ 2560 張；JPEG 約 8MB → 8000 張；按 10fps 錄製約可存 64×1000÷(25×10×60) ≈ 4.3 分鐘。
容量換算
單張 30MB、拍 1000 張需 30GB；14bit RAW 比壓縮 JPEG 大數倍，連拍前先估峰值佔用避免寫滿。

❓ 常見問題（FAQ）

RAW 和 JPEG 差多少？
未壓縮 RAW 約 12–30MB、JPEG 高畫質 3–10MB，RAW 含全部資料利於後期但佔空間大。
影片為什麼更吃容量？
影片是連續碼流，4K 100Mbps 一分鐘約 750MB，遠快於單張；延時按幀率折算。
