📣 Exposure Value (EV) Reference

Reference common exposure values (EV) for typical lighting scenes and map them to aperture, shutter speed and ISO combinations.

📐 計算公式與說明

EV = log₂(N² / t) − log₂(ISO/100)
N 為光圈值，t 為快門時間

EV 越低畫面越亮。

📚 深度解析：曝光值 EV 計算

💡 常見使用場景

  • 由光圈、快門、ISO 求 EV 判斷曝光量。
  • 對比不同引數組合的等效曝光。
  • 測光表讀數核對。
EV 計算
f/8、1/125s、ISO100：EV100 = log2(N²/t) = log2(64×125) = log2(8000) ≈ 12.97；按 EV₁₀₀ 場景分檔落在「陰天/明亮陰影」，晴天正午約為 EV 14–15。
等效互換
EV 相同則曝光量等：f/8·1/125 等效 f/11·1/60（各變一檔），可換引數保亮度調虛化。

❓ 常見問題（FAQ）

EV 是什麼？
曝光值，每 +1 EV 曝光量翻倍；EV100 以 ISO100 為基準，公式 EV = log2(N²/t×100/ISO)。
EV 高低代表什麼？
EV 高=亮環境（如晴日 EV14+），低=暗環境（室內 EV4–7）；相機自動曝光即追目標 EV。
EV 分檔怎麼對應場景？
EV₁₀₀（ISO 100）常用分檔：≥16 雪地/沙灘正午、≥14 明亮日光（陽光 16 法則）、≥12 陰天/明亮陰影、≥10 室內明亮、≥8 室內一般/黃昏、≥6 日落、≤2 夜景。本頁與「曝光三角計算」頁共用同一套分檔。
