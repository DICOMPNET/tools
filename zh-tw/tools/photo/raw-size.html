🔮 RAW File Size Estimator

Estimate RAW file size from sensor resolution and bit depth, with typical compression ratios for common camera formats.

📐 計算公式與說明

RAW 資料量估算（本頁程式碼口徑）：單幀大小=百萬畫素×10⁶×位深÷8÷10⁶（MB，即畫素數×bit÷8 再折 MB）；每分鐘資料量=單幀 MB×幀率 fps×60÷1000（GB，按輸入幀率計算而非固定 10fps，頁面「分鐘@10幀」文案僅為預設值示例口徑）。校驗：無強校驗，空值按 0 兜底。判據：無固定分級，資料量與位深、幀率均成正比，8bit 折半、16bit 翻倍。

未計壓縮與後設資料開銷。

📚 深度解析：RAW 檔案大小與錄製

💡 常見使用場景

  • 由畫素與位深算單張 RAW MB。
  • 估影片/連拍緩衝佔用。
  • 儲存卡選型。
單張大小
24MP、14bit：RAW = 24e6×14/8/1e6 ≈ 42MB/張；連拍 10fps 緩衝每秒約 420MB，需高速卡。
錄製佔用
同參數 @10fps 錄 60s：42×10×60/1000 ≈ 25.2GB，RAW 影片極吃儲存，一般用壓縮代理。

❓ 常見問題（FAQ）

RAW 比 JPEG 大多少？
約 3–8 倍，因含全部拜耳資料與後設資料；位深 14bit 比 12bit 多 17%。
為什麼連拍看卡速？
每秒數百 MB 寫入，低速卡迅速填滿緩衝停拍，需 V90/UHS-II 級。
