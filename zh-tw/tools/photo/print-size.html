⚖️ Pixel to Print Size Reference

Reference how pixel dimensions map to physical print sizes at common resolutions such as 300 and 150 DPI.

📐 計算公式

列印尺寸 = 畫素數 / DPI × 單位換算（in=1、cm=2.54、mm=25.4）；百萬畫素 MP = W×H/10⁶；寬高比 = W/H；300DPI 所需畫素 = 列印尺寸(in)×300

W×H 為畫素數，DPI 為列印解析度。同一張圖 DPI 越高，可列印的物理尺寸越小；300 DPI 為高質量印刷基準，150 DPI 適合大幅海報。寬高比決定照片比例（3:2、4:3、1:1 等）。

常見照片列印尺寸（300 DPI）

DPI 與 PPI： DPI（每英寸點數）決定列印精度。300 DPI 適合高質量照片，150 DPI 適合一般列印。列印尺寸 = 畫素 ÷ DPI。

📚 深度解析：列印尺寸與畫素需求

💡 常見使用場景

  • 由畫素與 DPI 求列印寬高。
  • 反推清晰列印所需百萬畫素。
  • 放大輸出評估。
列印尺寸
6000×4000（24MP）@300dpi：寬 = 6000/300 = 20in ≈ 50.8cm，高 = 4000/300 ≈ 13.3in，即約 A3 滿解析度。
所需 MP
印 30×20cm @300dpi：需 3543×2362 ≈ 8.4MP；低於則發虛，故 24MP 綽綽有餘。

❓ 常見問題（FAQ）

列印尺寸受 DPI 約束嗎？
是，尺寸=畫素÷DPI；同畫素 DPI 越低印越大但越糊，視觀看距離定 DPI。
多少 MP 夠用？
常見 24MP 可印 A3，大幅海報需 50MP+ 或遠距離觀看降 DPI。
