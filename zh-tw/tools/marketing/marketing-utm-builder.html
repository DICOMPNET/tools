📢 UTM Parameter Builder

Build tracked UTM links for campaign analytics.

📐 計算公式 / 說明
UTM 構建：在網址後拼接 ?utm_source=&utm_medium=&utm_campaign=&utm_term=&utm_content=（後兩項可選），生成標準化追蹤連結；批次模式按行拆分網址，逐行套用同一組引數。
已有同名 utm_* 引數會先被刪除再寫入，引數插在 # 錨點之前；中文、空格與特殊字元由 URLSearchParams 自動編碼。URL 與來源 utm_source 必填；medium/campaign 建議填寫，缺失時結果區會提示歸因可能不完整；term 與 content 為空則不出現在連結中。

📚 深度解析：UTM 引數構建器

💡 常見使用場景

  • 為不同渠道/活動生成帶 UTM 的追蹤連結。
  • 規範 utm_source/medium/campaign 命名便於歸因。
  • 批次生成多活動連結匯入投放後臺。
單條連結
來源 wechat、媒介 cpc、活動 spring_sale → 原連結後接 ?utm_source=wechat&utm_medium=cpc&utm_campaign=spring_sale，可在 GA 按渠道拆分。
命名規範
utm_source 用平臺名（wechat/toutiao）、utm_medium 用型別（cpc/organic）、utm_campaign 用活動代號（含日期），避免中文與空格。
錨點落地頁
https://a.example/p#top + utm_source=wechat → https://a.example/p?utm_source=wechat#top；引數寫在 # 之前才能被服務端讀到，原有同名 utm_* 會被替換而不是追加。

❓ 常見問題（FAQ）

UTM 中文會有問題嗎？
會。中文與空格需 URL 編碼，部分後臺解析異常，建議全小寫英文+下劃線。
哪些引數必填？
utm_source 必填；medium/campaign 強烈建議，缺失時結果區會提示「GA 歸因可能不完整」，content/term 用於 A/B 或搜尋詞細分。
