本對照表按書體演變與代表書家梳理書法風格特徵，供書法鑑賞、臨帖選帖與藝術史學習參考。風格判斷需結合筆法、結字與傳世作品綜合研判。

📋 書體演變簡史

書體演變：甲骨文(商) → 金文(周) → 大篆(春秋戰國) → 小篆(秦) → 隸書(漢) → 楷/行/草(魏晉定型) → 沿用至今。

筆法演變：篆書圓轉中鋒 → 隸書方折波磔 → 楷書提按頓挫 → 行書流暢連帶 → 草書簡練奔放。

時代風格："晉人尚韻、唐人尚法、宋人尚意、明人尚態、清人尚碑"。每個時代的書法審美取向不同，是斷代的重要依據。

鑑定要點：紙張/絹帛材質、墨色、印章、題跋、著錄等輔助斷代。筆法、結體、氣韻需與傳世標準件比對。本表供學習參考，真偽鑑定需專業機構。

💡 常見使用場景

  • 書法學習者按書體（篆隸草楷行）與代表書家選帖，對照筆法特徵確定臨習方向。
  • 碑帖收藏者比對某名家（如顏真卿、柳公權）用筆結字，判斷拓本或臨本的流派歸屬。
  • 藝術史教學梳理"晉韻—唐法—宋意—元明覆古"的演變主線。
以"用筆+結字"區分顏體與柳體
顏真卿（顏體）用筆豐腴雄渾、外拓開張，結字寬博端莊（如《多寶塔》《顏勤禮碑》）；柳公權（柳體）用筆瘦硬挺勁、內擫收斂，結字中心收緊（如《玄秘塔碑》）。所謂"顏筋柳骨"，正指二者一豐一瘦的用筆差異，可據此區分唐楷兩大宗。

❓ 常見問題（FAQ）

如何從筆法判斷一件作品更接近晉人還是唐人？
晉人（如王羲之）重韻致、用筆靈動使轉多、結字欹側自然；唐人重法度、用筆規範、結字嚴謹勻稱。一件強調提按頓挫與規範間架的楷書更近唐法，而流暢連帶、蕭散自然的行書更近晉韻。
"碑學"與"帖學"在風格鑑定上如何區分？
帖學以墨跡法帖為宗，用筆細膩、風格妍美（二王一脈）；碑學尊碑版石刻，取方峻、生拙、金石氣（如北魏墓誌、摩崖）。清中葉後碑學興起，作品多顯厚重蒼茫，與帖學的流美秀潤形成對照。
