📐 工作原理與說明
營養評分取各維度最高檔：BMI(<17→3/<18.5→2/<20.5→1)、體重下降(>10%→3/5-10%→2/<5%→1)、攝入減少(>75%→3/50-75%→2/25-50%→1)、白蛋白(<30加2/30-35加1)疾病嚴重度：活動度(輕1/中2/重3)，範圍(廣泛≥1、全結腸/全小腸≥2)，併發症(有→≥2、瘻/膿腫→3)年齡≥70加1。總分 = 營養分 + 疾病分 + 年齡分：≥5重度、≥3中度、<3低度營養風險。

Key formulas: max(diseaseScore,1); max(diseaseScore,2); max(nutriScore,2)

📋 NRS-2002 評分標準

評分營養狀態疾病嚴重度
1分（輕）BMI 18.5-20.5 + 一般情況差 / 攝入減少25-50%慢性病急性加重
2分（中）BMI 17-18.5 / 3個月體重下降5% / 攝入減少50-75%腹部大手術 / 重症肺炎
3分（重）BMI＜17 / 3個月體重下降＞10% / 攝入減少＞75%頭部損傷 / 重症監護

總分≥3分提示存在營養風險，需制定營養支援計劃。年齡≥70歲加1分。

📊 IBD營養不良特點

  • CD營養不良發生率高於UC（30-50% vs 5-10%）
  • 常見缺乏：鐵、維生素B12、葉酸、鋅、維生素D
  • CD小腸受累者更易發生吸收不良和微營養素缺乏
  • 生長遲緩是兒童和青少年IBD的重要表現
  • 營養不良增加手術併發症風險和感染風險

📊 營養支援策略

  • 輕度營養不良：飲食指導+口服營養補充（ONS）
  • 中度營養不良：ONS為主，必要時腸內營養（EN）
  • 重度營養不良：腸內營養（EN）為首選，必要時聯合PN
  • CD活動期：獨家腸內營養（EEN）可誘導緩解（尤其兒童/青少年）
  • 圍手術期：術前7-14天營養支援降低併發症
提示：IBD患者應常規進行營養篩查。CD患者、病變廣泛者、活動期患者營養風險更高。鐵缺乏和維生素B12缺乏需定期監測和補充。腸內營養優於腸外營養。僅供臨床參考。

  • 營養篩查：IBD 活動期/圍手術期評估營養風險等級
  • 支援計劃：中重度風險制定 ONS/EN/PN 方案
  • 微營養糾正：補鐵、B12、葉酸、維生素 D
方法
演算法：營養狀態取最高項 — BMI <17→3、17~18.5→2、18.5~20.5→1 分；體重下降 >10%→3、5~10%→2、<5%→1 分；攝入減少 >75%→3、50~75%→2、25~50%→1 分；白蛋白 <30→+2、30~35→+1 分。疾病嚴重度（活動度 1~3 + 範圍 + 併發症）0~3 分；年齡 ≥70 加 1 分。總分 ≥5 重度、≥3 中度、<3 低度營養風險。
算例
例：BMI 18.5、體重下降 8%、白蛋白 32g/L、攝入減少 25~50%、活動度輕度、病變侷限、無併發症、年齡 45 → 營養 2（體重下降）+疾病 1+年齡 0 = 3 分，中度營養風險，建議 ONS 為主。若 BMI 16、體重下降 12%、白蛋白 28、攝入減少 >75%、重度活動、全結腸、併發症 2 項、年齡 45 → 營養 3+疾病 3+年齡 0 = 6 分，重度營養風險，建議儘早 EN（必要時 PN）、CD 考慮 EEN 誘導緩解。

❓ 常見問題（FAQ）

IBD 患者要低纖維飲食嗎？
緩解期無需嚴格限纖維；活動期或狹窄/穿透性病變者需低渣飲食減少殘渣刺激。營養支援優先保證能量 25~30 kcal/kg/d 與蛋白 1.0~1.5 g/kg/d，而非盲目禁食。
為什麼活動期要查白蛋白？
白蛋白反映炎症與營養雙重狀態，IBD 活動期因炎症消耗與腸道丟失常下降；<30g/L 提示中重度營養風險，需積極補充並控制炎症才能根本改善。
