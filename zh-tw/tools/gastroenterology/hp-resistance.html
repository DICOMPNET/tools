📊 常用根除方案

一線方案

  • 鉍劑四聯（推薦）：PPI bid + 鉍劑 bid + 阿莫西林 1g bid + 克拉黴素 0.5g bid，14天
  • 大劑量二聯：PPI bid/qid + 阿莫西林 1g tid/bid，14天
  • 伴同療法：PPI bid + 阿莫西林 1g bid + 克拉黴素 0.5g bid + 甲硝唑 0.4g bid/tid，14天

二線/補救方案

  • 含左氧氟沙星四聯：PPI + 鉍劑 + 阿莫西林 + 左氧氟沙星，14天
  • 含呋喃唑酮四聯：PPI + 鉍劑 + 阿莫西林 + 呋喃唑酮，14天
  • 含四環素四聯：PPI + 鉍劑 + 四環素 + 甲硝唑/呋喃唑酮，14天
提示：克拉黴素耐藥是根除失敗的主要原因。藥敏檢測指導下的個體化治療可提高根除率。多次根除失敗者建議行藥敏試驗或全基因組耐藥檢測。僅供臨床參考。

💡 常見使用場景

  • 藥敏導向：結合克拉黴素/甲硝唑/左氧氟沙星耐藥狀態與青黴素過敏選方案
  • 初次治療：優先含鉍劑四聯 14 天，避開耐藥藥
  • 難治病例：多次失敗者行藥敏試驗指導個體化治療
方法
演算法：先按藥敏/過敏結果建立禁用藥物集合（青黴素過敏→阿莫西林；克拉黴素/甲硝唑/左氧氟沙星耐藥→對應藥物），再從候選方案池中剔除所有含禁用藥物的組合，按治療史優先順序取前 2~3 個：初次治療優先含鉍劑四聯（阿莫西林+克拉黴素、阿莫西林+甲硝唑或四環素+甲硝唑）；既往失敗 1 次優先含左氧四聯或呋喃唑酮四聯；失敗 ≥2 次優先四環素+甲硝唑、呋喃唑酮四聯並建議藥敏。若過濾後無可用方案 → 提示藥敏指導/專科會診，不強行推薦。療程均 14 天（需臨床複核）。
算例
例：青黴素過敏、鉍劑可用、克拉黴素敏感、甲硝唑敏感 → 輸出鉍劑四聯（PPI+鉍劑+四環素 500mg qid+甲硝唑 0.4g tid）14 天。若初次治療、克拉黴素耐藥、甲硝唑敏感、鉍劑不可用 → 剔除含克拉黴素及需鉍劑的方案，僅保留大劑量二聯（艾司奧美拉唑 40mg qid+阿莫西林 1g tid）14 天，並建議補做藥敏。

❓ 常見問題（FAQ）

大劑量二聯為什麼現在受重視？
大劑量二聯（雙倍 PPI + 高劑量阿莫西林，常 qid/tid）通過持續抑酸提升胃內阿莫西林濃度，根除率可達 90% 左右，且抗生素種類少、副作用小，適合不能使用鉍劑或耐藥複雜者。
呋喃唑酮有什麼特別注意事項？
呋喃唑酮可致雙硫侖樣反應（服藥期間禁酒），長期使用有周圍神經病變風險，劑量多為 0.1g bid、療程 14 天，肝腎功能異常者慎用，需在醫師指導下使用。
