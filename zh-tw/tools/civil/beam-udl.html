📐 計算公式
簡支梁均布荷載：最大彎矩 M = qL² ÷ 8（kN·m）、最大剪力 V = qL ÷ 2（kN）、跨中撓度 δ = 5qL⁴ ÷ 384EI（彈性；q 先由 kN/m 化 N/m，E 按 GPa×1e9 化 Pa；I 由 b×h 自動取 I = bh³ ÷ 12，cm⁴ 經 ×1e−8 化 m⁴，結果 ×1000 折 mm）；截面模量 W = bh² ÷ 6（mm³），彎曲應力 σ = M×1e6 ÷ W（MPa，M 由 kN·m 化 N·mm）。校驗：L、E、b、h 須 >0 且 q ≥0，否則提示「請輸入有效的梁引數」。說明：I 只讀，與應力所用同一截面，避免兩套截面口徑矛盾。荷載組合：q_k 為標準組合均布荷載（標準值，僅用於 M_k 對照，不參與撓度計算），q_q 為準永久組合均布荷載（準永久值，不是荷載分項係數後的設計值）；M_k = q_k·L² ÷ 8、M_q = q_q·L² ÷ 8。正常使用極限狀態（GB 50010-2010 3.4.3 / 7.2.1 / 7.2.2 / 7.2.3）：鋼筋混凝土受彎構件的最大撓度按準永久組合計算並考慮長期作用，σ_s、ψ、B_s 同按準永久組合（7.1.1-3 / 7.1.4 / 7.2.3）。h₀ = h − a_s（a_s 為受拉鋼筋合力點至受拉邊緣距離，不是保護層 c）；ρ = A_s ÷ (b·h₀)、ρ_te = A_s ÷ (0.5·b·h)（<0.01 取 0.01）、α_E = E_s ÷ E_c（E_s=2×10⁵MPa）；σ_s = M_q ÷ (0.87·h₀·A_s)；ψ = 1.1 − 0.65·f_tk ÷ (ρ_te·σ_s)（夾取 0.2~1.0）；B_s = E_s·A_s·h₀² ÷ [1.15ψ + 0.2 + 6α_Eρ ÷ (1+3.5γ_f')]；準永久組合的長期剛度 B = B_s ÷ θ（式 7.2.2-2）；θ 按 7.2.5-1 由 ρ′/ρ 自動計算（ρ′=0 取 2.0、ρ′=ρ 取 1.6、中間線性內插；受拉區翼緣的倒 T 形 ×1.2），可手改，手改值與自動值不符時提示；δ_lt = 5·M_q·L² ÷ (48·B)（7.2.1 結構力學方法）；限值按計算跨度 l₀ 分檔（l₀<7m 取 l₀/200、7m≤l₀≤9m 取 l₀/250、l₀>9m 取 l₀/300，表 3.4.3），δ_lt ≤ 限值判滿足（等號算滿足）。標準組合的長期剛度 B = M_k ÷ [M_q(θ−1)+M_k]·B_s（式 7.2.2-1）僅適用於預應力混凝土構件（3.4.3 規定其撓度按標準組合）；本頁為鋼筋混凝土，不採用該路徑，M_k 僅作參考顯示。開裂判定：先按 GB 50010-2010 7.1.1 算 M_cr = f_tk·W_0（W_0 = b·h²/6，未計塑性影響係數 γ，偏安全），M_q ≤ M_cr 時構件未開裂，取 B_s = E_c·I_0、ψ 與 σ_s 不適用（長期剛度仍按 B = B_s/θ 折減）；M_q > M_cr 才走上式的裂後 ψ → B_s → B。

計算受均布荷載簡支梁的最大彎矩、剪力、跨中撓度與跨中彎曲應力。

📌 計算說明
  • 最大彎矩 Mmax = qL²/8（跨中）
  • 最大剪力 Vmax = qL/2（支座處）
  • 跨中撓度 δ = 5qL⁴/(384EI)（單位統一為 N、m）
  • 彎曲應力 σ = M/W，W = bh²/6 為截面模量
  • h₀ = h − a_s；a_s 為受拉鋼筋合力點至受拉邊緣距離（單排常取 35、雙排 60），不是保護層厚度 c
  • 強度等級 C25–C40 聯動 f_tk 與 E_c，可手動覆蓋；手動值與等級不匹配時頁面給出提示，避免「C25 強度、C40 剛度」混配
  • q_k 為標準組合均布荷載（標準值），q_q 為準永久組合均布荷載（可變荷載準永久值係數 ψ_q 與標準值組合後再計入永久荷載標準值）；q_q 不是荷載分項係數後的設計值，也不是標準值簡單打折；頁內 M_k = q_kL²/8、M_q = q_qL²/8；q_k 僅用於 M_k 對照與「q_q 不應大於 q_k」合理性提示，不進入 σ_s、ψ、B_s、B 與 δ 的任何計算（改 q_k 只改 M_k 顯示，δ 不變）
  • 撓度按準永久組合：GB 50010-2010 3.4.3 規定鋼筋混凝土受彎構件的最大撓度按荷載準永久組合並考慮長期作用，故 σ_s、ψ、B_s 均用 M_q（7.1.1-3 / 7.1.4 / 7.2.3），長期剛度 B = B_s/θ（7.2.2-2），δ_lt = 5M_qL²/(48B)；標準組合的 B 公式（7.2.2-1）僅用於預應力構件，本頁不採用
  • 開裂判定：先按 GB 50010-2010 7.1.1 算 M_cr = f_tk·W_0（W_0 = b·h²/6，未計塑性影響係數 γ，偏安全）；M_q ≤ M_cr 時構件未開裂，取 B_s = E_c·I_0（長期折減 B = B_s/θ 保留），σ_s 與 ψ 不適用；M_q > M_cr 才按上式走裂後 ψ → B_s → B
  • θ 按 7.2.5-1 取用：ρ′ = 0 取 2.0、ρ′ = ρ 取 1.6、中間線性內插；翼緣位於受拉區的倒 T 形截面 θ 增加 20%。頁面由輸入的 ρ′ 與 A_s、b、h₀ 自動算出 θ 並回填輸入框（改 ρ′ 或截面型別即重算），仍可手改；手改值與自動值相差 >0.01 時給出提示，按手改值計算。ρ′ 單位為 %，ρ = A_s/(b·h₀) 為無量綱比值，程式內先統一量綱再內插
  • 撓度限值按計算跨度 l₀ 分檔（表 3.4.3）：l₀<7m → l₀/200、7m≤l₀≤9m → l₀/250、l₀>9m → l₀/300；δ_lt ≤ 限值判滿足，等號算滿足

💡 常見使用場景

  • 樓板、次梁按簡支估算跨中彎矩 Mmax=wL²/8 與剪力 Vmax=wL/2，作為配筋與連線設計的控制內力。
  • 校核變形：跨中撓度 f=5wL⁴/(384EI)，用於樓蓋舒適度與淨高控制。
  • 對比不同跨度 L、線荷載 w 對彎矩的敏感度，最佳化梁高與材料用量。
4m 簡支次梁均布荷載
跨度 L=4m、線荷載 w=10kN/m：Mmax=wL²/8=10×16/8=20kN·m；Vmax=wL/2=20kN；若 EI=2.4×10¹¹N·mm²，則跨中撓度 f≈5wL⁴/(384EI)（按單位換算後評估）。

❓ 常見問題（FAQ）

均布荷載與點荷載結果差多少？
同總荷載下，跨中彎矩點荷（PL/4）約為均布（wL²/8=PL/8）的 2 倍，故荷載形式直接影響配筋，不可混用。
撓度超限怎麼調？
增大截面高度 h（撓度∝1/h³ 量級）、提高剛度 EI 或減小跨度；也可加反拱或改用連續梁降低跨中彎矩。
連續梁能按簡支估算嗎？
不能。連續梁支座負彎矩顯著大於簡支跨中彎矩，簡支結果會低估支座區配筋，需按連續梁係數或有限元複核。
