📐 工作原理與說明
震害綜合評估（建築+生命線+地質災害）
建築震害指數 = (0.1×輕微 + 0.3×中等 + 0.5×嚴重 + 0.7×區域性倒塌 + 1.0×倒塌) ÷ 建築總數（上限 1）
生命線評分 = (供水處數÷10 + 供電 + 燃氣÷5 + 道路 + 通訊) ÷ 5（各自上限 100%）
地質災害評分 = (滑坡萬m²÷20 + 崩塌處÷50 + 裂縫km÷10 + 液化萬m²÷10) ÷ 4（各自上限 100）
綜合震害指數 = 建築×0.40 + 生命線×0.35 + 地質災害×0.25
等級：≥0.7 毀滅性｜≥0.5 特大｜≥0.3 嚴重｜≥0.1 中等｜<0.1 輕微
倒塌率 = (區域性倒塌+倒塌) ÷ 建築總數 × 100%
需安置人口比例粗估 = 倒塌率×5 + 嚴重破壞率×2

Key formulas: (minor×0.1+moderate×0.3+severe×0.5+partial×0.7+total×1.0)÷totalBldg; bldgScore÷100×0.40+lifelineScore÷100×0.35+geoScore÷100×0.25; (waterScore+powerScore+gasScore+roadScore+commScore)÷5

📚 深度解析：地震震害綜合評估

💡 常見使用場景

  • 建築震害核算：輸入各類建築數量（輕微/中等/嚴重/區域性倒塌/全部倒塌）與總棟數，算建築震害指數（加權 0.1/0.3/0.5/0.7/1.0 並歸一），量化建築破壞程度。
  • 生命線與地質評分：分別評估供水/供電/燃氣/交通/通訊中斷程度與滑坡/崩塌/地裂/液化等地質災害規模，轉化為 0-100 評分。
  • 綜合定級：按 建築40% + 生命線35% + 地質25% 加權得綜合震害指數，劃分 輕微/中等/嚴重/特大/毀滅性 五級，支撐應急響應等級啟動。
算例：某鎮震害綜合評估
1000 棟建築中輕微200/中等100/嚴重50/區域性倒塌20/全部倒塌10；生命線中斷 供水30/供電40/燃氣2/交通50/通訊60；地質災害 滑坡20/崩塌10/地裂5/液化3。建築震害指數=(200×0.1+100×0.3+50×0.5+20×0.7+10×1.0)/1000=0.099→9.9分；生命線=(100+40+40+50+60)/5=58.0；地質=(100+20+50+30)/4=50.0；綜合指數=9.9%×0.40+58%×0.35+50%×0.25=0.3676 → 評定為「嚴重震害」，應啟動 II 級響應組織搶險。值得注意的是建築倒塌少，但生命線/地質受損拉高了綜合等級。

❓ 常見問題（FAQ）

綜合震害指數怎麼加權？
綜合指數 = 建築得分×0.40 + 生命線得分×0.35 + 地質災害得分×0.25（各得分均歸一到 0-100）。權重體現「建築破壞為主、生命線與地質並重」的災後評估思路。
等級劃分的閾值是什麼？
綜合指數 ≥0.7 毀滅性、≥0.5 特大、≥0.3 嚴重、≥0.1 中等、其餘為輕微；對應啟動 I 級（毀滅性/特大）或 II~IV 級應急響應，閾值可在工具內按地方標準微調。
