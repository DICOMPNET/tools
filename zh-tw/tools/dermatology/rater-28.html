Rater 28

VSS

瘢痕評估 = 厚度 + 血管分佈 + 柔韌性 + 顏色（各 0 至 3）之和；不超過3 輕度、不超過7 中度、大於7 重度（溫哥華瘢痕量表 VSS）。

VSS溫哥華疤痕量表（4維度，總分0-14，分數越高疤痕越嚴重）

📚 深度解析：疤痕（VSS）溫哥華評分

💡 常見使用場景

  • 多維評估：錄入瘢痕的色澤（血管性/色素）、柔韌性（柔軟→硬固）、厚度（0–3）、疼痛與瘙癢（各 0–3），工具加權彙總 VSS。
  • 療效對比：雷射、注射或手術前後複評，分值下降反映瘢痕軟化、褪色與症狀緩解，輔助隨訪。
  • 重點項識別：定位最重維度（如厚度或疼痛），指導區域性治療（如點陣雷射、瘢痕內注射）的重點。
使用示例
示例：瘢痕色紅（血管性 2）、質硬（柔韌性 3）、增厚 2mm（厚度 2）、偶癢（1）→ VSS 彙總偏高，提示以軟化褪色為主的綜合治療。

❓ 常見問題（FAQ）

VSS 分數越低越好嗎？
是的，VSS 各維度分值越低代表瘢痕越接近正常皮膚、症狀越輕，常用於科研與療效隨訪。結果僅供皮膚健康科普與初篩參考，不能替代皮膚科醫生的面診、皮膚鏡或活檢等檢查與專業診斷；皮損短期內增大、出血、破潰或伴發熱等全身症狀時請及時就診。
新舊瘢痕評法一樣嗎？
早期紅硬癢明顯、分值高，成熟後趨於平軟褪色；動態評估更能反映轉歸。結果僅供皮膚健康科普與初篩參考，不能替代皮膚科醫生的面診、皮膚鏡或活檢等檢查與專業診斷；皮損短期內增大、出血、破潰或伴發熱等全身症狀時請及時就診。
瘢痕能消平嗎？
多數可改善（軟化、褪色、變平），完全消除較難；具體以雷射/注射/手術等綜合方案由醫生定。結果僅供皮膚健康科普與初篩參考，不能替代皮膚科醫生的面診、皮膚鏡或活檢等檢查與專業診斷；皮損短期內增大、出血、破潰或伴發熱等全身症狀時請及時就診。
