Capacitive Reactance

Calculate the capacitive reactance from capacitance and frequency using X_C = 1/(2π·f·C) for AC circuit analysis.

📐 計算公式
電容先由 µF 換算為法拉 C_F = C ÷ 1e6；容抗 X_C = 1 ÷ (2π×f×C_F)（Ω）；另輸出阻抗虛部 −X_C、導納 = 1 ÷ X_C（S）與角頻率 = 2πf。校驗：頻率 f 與電容 C 均為必填有效數值（必填校驗殼攔截）。判據：容抗與頻率和電容均成反比，f 或 C 越大 X_C 越小（高頻近似短路、直流開路）。

電容對交流電的阻礙作用隨頻率升高而降低。

❓ 常見問題（FAQ）

容抗隨頻率怎麼變？
Xc∝1/f；高頻時電容"短路"（阻抗極低），直流時相當於開路（僅漏電）。本工具為電磁學/電路基礎輔助計算，結果僅供教學與方案預研參考，不替代正式工程設計、電磁相容標準與持證工程師的判定。
容抗與電阻有何不同？
Xc 不消耗有功功率（理想電容無損耗），電流相位超前電壓 90°，僅在 RC 網路中消耗能量。本工具為電磁學/電路基礎輔助計算，結果僅供教學與方案預研參考，不替代正式工程設計、電磁相容標準與持證工程師的判定。
為何實際電容有 ESR？
介質損耗、引線電感、極板電阻合成等效串聯電阻 ESR；高頻/電源濾波選低 ESR 電容（如鉭電容/MLCC）。本工具為電磁學/電路基礎輔助計算，結果僅供教學與方案預研參考，不替代正式工程設計、電磁相容標準與持證工程師的判定。
