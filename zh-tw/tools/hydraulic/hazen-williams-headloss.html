Hazen-Williams Head Loss Calculator

Compute head loss h_f = 10.67*L*Q^1.852/(C^1.852*D^4.87) from flow, pipe length, roughness coefficient C and diameter (SI units).

📐 計算公式
Hazen-Williams 沿程水頭損失（本頁程式碼口徑）：h_f=10.67×L×Q^1.852÷(C^1.852×D^4.87)（m，Q 流量 m³/s、L 管長 m、C 粗糙係數、D 管徑 m）。聯動量：無其它派生項，結果保留 3 位小數。校驗：四欄位經輸入守衛必填且須為合法數值，否則提示並中止。判據：無固定分級，h_f 與流量 1.852 次方成正比、與管徑 4.87 次方成反比、與管長線性相關。

由流量、管長、粗糙係數 C 與管徑，按 h_f = 10.67·L·Q^1.852/(C^1.852·D^4.87) 計算水頭損失（SI）。

📌 計算說明
  • 適用於水溫約 4–25℃ 的給水管道；C 值：新鋼管≈120–140，舊管≈80–100。
  • 單位為 SI（Q: m³/s，D: m，結果 m）。

💡 常見使用場景

  • 給水管網按經驗式估沿程損失。
  • 不同 C 值（管材）對比能耗。
  • 長距離配水校核末端壓力。
標準算例
Q=0.01 m³/s、L=100 m、C=120、d=0.1 → h_f=10.67×100×0.01^1.852/(120^1.85×0.1^4.87)≈0.25 m。
C 值影響
C 從 120 降到 100（舊管），同條件損失增約 40%，結垢顯著抬升能耗。

❓ 常見問題（FAQ）

C 是什麼？
海曾-威廉粗糙係數，新鋼管 130~140、舊管或水泥管更低，材質越光滑越大。
和達西比？
海曾為給水經驗式，含 C 不直接顯 f；達西更通用但需 f(Re,ε)。
