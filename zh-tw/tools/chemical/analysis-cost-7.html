💰 Budget Line-item Summary

Sum budget line items, show total, max/min, each item's share and top-N cumulative share, with variance vs reference budget.

📐 工作原理與說明
合計 = Σ各分項金額；各分項佔比 = 金額 / 合計 × 100%；前 N 大項累計佔比 = 金額前 N 大之和 / 合計 × 100%；偏差 = (合計 − 參考預算) / 參考預算 × 100%。
預算編制與成本控制中，先彙總各分項得到總投資或年運營成本，再用佔比結構識別主要成本驅動項（前 N 大項），並對照參考預算判斷超支或節餘。結果隨口徑與價格假設變化，正式預算以內部核算制度為準。

📚 深度解析：預算分項彙總分析

💡 常見使用場景

  • 專案預算編制：彙總裝置、安裝、原料、能耗等分項，得總投資與年運營成本，支撐立項與比選。
  • 成本結構分析：用各分項佔比與前 N 大項累計佔比識別主要成本驅動，聚焦降本重點。
  • 偏差監控：對照參考預算量化超支或節餘及偏差率，輔助預算執行跟蹤。
算例（6 個分項，參考預算 2500）
分項金額（元）：800、200、1200、300、500、150。合計 3150.00；最大分項 1200.00、最小 150.00；各分項佔比最高 38.10%（1200）；前 3 大項（1200、800、500）累計佔比 79.37%；對比參考預算 2500 超支 650.00（偏差 26.00%）。

❓ 常見問題（FAQ）

前 N 大項累計佔比有什麼用？
它快速指出貢獻最大的少數分項。例如前 3 大項累計佔比接近 80% 時，意味著降本重點應放在這幾個核心分項上，而非平均用力。
偏差率正負怎麼看？
合計大於參考預算時顯示「超支」與正偏差率，小於時顯示「節餘」與負偏差率；偏差率絕對值越大，預算執行偏離越多，需核查口徑與價格假設。
