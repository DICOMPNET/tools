Pulmonary Function

Pulmonary Function

📐 工作原理與說明
肺功能判讀（阻塞/限制/GOLD 分級）
一秒率 = FEV1 ÷ FVC × 100%
阻塞性：一秒率 < 閾值（預設 0.70；可留空用下拉，或填 0.50–0.90 的 LLN 值如 GLI 表）
限制性：FVC 佔預計值 < 80%
混合性：兩者同時成立
正常：三者均不成立且 FEV1 佔預計值 ≥80%（ATS/ERS 2019 口徑，三引數均不低於正常下限）
GOLD 分級（按 FEV1 佔預計值）：≥80% GOLD 1 輕度
　≥50% GOLD 2 中度｜≥30% GOLD 3 重度｜<30% GOLD 4 極重度
阻塞+限制組合時按 FEV1 分級並提示查 TLC/DLCO
臨床建議隨分級輸出（戒菸/支擴劑/聯合吸入/氧療評估）

Key formulas: ratio×100

📋 通氣功能障礙判讀邏輯

型別條件說明
正常FEV1/FVC ≥ 閾值 且 FVC ≥ 80%預計 且 FEV1 ≥ 80%預計通氣功能正常
阻塞性FEV1/FVC < 閾值氣流受限，常見於COPD/哮喘
限制性FEV1/FVC ≥ 閾值 且 FVC < 80%預計需TLC確認，見於肺纖維化/胸壁疾病
混合性FEV1/FVC < 閾值 且 FVC < 80%預計同時存在阻塞與限制

📊 GOLD 阻塞性氣流受限嚴重度（基於 FEV1%預計值）

分級嚴重度FEV1 %預計值
GOLD 1輕度≥80%
GOLD 2中度50–79%
GOLD 3重度30–49%
GOLD 4極重度<30%
提示：FEV1/FVC 正常值隨年齡下降，固定閾值 0.70 對年輕人可能低估、對老年人可能高估阻塞性疾病（老年易過度診斷）；建議結合 LLN(正常下限) 綜合判讀。限制性障礙需肺總量(TLC)確認。支氣管舒張試驗後 FEV1/FVC<0.70 提示不完全可逆氣流受限(COPD)。僅供臨床參考。

FEV₁ 1.5 / FVC 3.0
比值=1.5/3.0=50%<0.7→阻塞性；FVC%pred≥80 不支援限制。
限制性
比值正常但 FVC%pred<80→限制性通氣障礙，查 TLC。

❓ 常見問題（FAQ）

切點可調？
預設 0.70/0.75 固定閾值，也可在「自定義閾值 / LLN」填 0.50–0.90 的 LLN 值（如 GLI 表）後優先使用；老年建議按 LLN。
阻塞性+限制？
比值低且 FVC 低為混合性，需 TLC/DLCO 確認。
