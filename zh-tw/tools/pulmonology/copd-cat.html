COPD ( CAT Score ) Questionnaire

COPD ( CAT Score ) Questionnaire

COPD 評估測試 CAT 總分 = 8 個問題（每項 0 至 5）之和，滿分 40；不超過10 輕度影響、不超過20 中度、不超過30 重度、超過30 極重度影響。

📋 CAT 評分臨床意義

總分影響程度臨床建議
0–10輕度影響輕微，維持治療，關注急性加重
11–20中度影響中等，最佳化治療，加強肺康復
21–30重度影響嚴重，強化藥物與支援治療
31–40極重度影響極重，全面評估，多學科管理
提示：CAT 是評估COPD健康狀態的簡明工具，建議每次隨訪複測。CAT變化≥2分視為有臨床意義的改變。GOLD 推薦結合 CAT、mMRC 及急性加重史進行 ABE 分組以指導治療。僅供臨床參考。

💡 常見使用場景

  • 慢阻肺症狀負荷評估
  • 指導藥物強度
  • 隨訪療效比較
8 題各 2 分
總分=8×2=16 分：10–20 為中度影響，建議含長效支擴劑治療。
重度影響
總分≥20：症狀重度，考慮 LAMA+LABA 或聯合 ICS。

❓ 常見問題（FAQ）

CAT 與 mMRC 區別？
CAT 全面評估症狀/活動/心理，mMRC 僅呼吸困難；二者互補。
多少分需隨訪？
每 3 月複評，變化≥2 分有臨床意義。
