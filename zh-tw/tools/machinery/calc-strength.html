📐 計算公式
軸強度校核（彎扭合成，第三強度理論口徑）：彎曲應力 σ = M×1000 ÷ W、扭轉剪應力 τ = T×1000 ÷ Wp（MPa）；當量應力 σe = √(σ²+3τ²)；安全係數 n = 屈服強度 σs ÷ σe。截面係數：實心 W = π·d_eff³/32、Wp = π·d_eff³/16（帶鍵槽時 d_eff = d×0.95 折減）；空心軸 k = 1−(d₀/d)⁴，W = π·d³/32·k、Wp = π·d³/16·k；剛度校核：扭轉角 φ = T·L ÷ (G·Ip)×180/π（°/m，G=81000 MPa 鋼、L 按 1000mm 計）。校驗：軸徑須 >0，空心時 0≤d₀<d（內徑須小於外徑）。判據：n≥1.5 安全、≥1.2 基本安全、≥1.0 臨界、<1 不安全；扭轉角 >0.5°/m 判剛度不足。

按第四強度理論計算實心圓軸的應力與安全係數

💡 第四強度理論：σe=√(σ²+3τ²)。抗彎截面係數 W=πd³/32，抗扭截面係數 Wp=πd³/16。安全係數 n=σs/σe。

安全係數評定標準

  • n ≥ 1.5：安全（靜強度足夠）
  • 1.2 ≤ n < 1.5：基本安全（一般用途）
  • 1.0 ≤ n < 1.2：臨界（需進一步校核疲勞）
  • n < 1.0：不安全（需增大軸徑或換材料）

💡 常見使用場景

  • 按第三強度理論（當量應力）校核轉軸危險截面。
  • 彎曲應力 σ=M/W、扭轉剪應力 τ=T/Wp、σe=√(σ²+3τ²)。
  • 鍵槽應力集中導致有效直徑折減的修正。
d=20,T=100 N·m,M=200 N·m
W=πd³/32=785.4 mm³、Wp=πd³/16=1570.8 mm³；σ=M·1000/W=200000/785.4=254.6 MPa；τ=T·1000/Wp=100000/1570.8=63.7 MPa；σe=√(254.6²+3×63.7²)=√(64829+12174)=√77003≈277.5 MPa。
許用校核
材料 σb=500 MPa、安全係數 2 → [σe]=250 MPa。上例 σe=277.5>[σe]，強度不足，需加大直徑或降載。

❓ 常見問題（FAQ）

為什麼用 σ²+3τ²？
第三強度理論（最大剪應力）對塑性材料，當量應力 σe=√(σ²+3τ²)，保守且工程常用。
鍵槽為何折減有效直徑？
鍵槽產生應力集中並削弱截面，按經驗取有效直徑 dEff≈d−槽深影響，疲勞設計需查應力集中係數。
