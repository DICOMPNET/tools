📐 計算公式
螺紋車削引數（本頁程式碼口徑，以實算口徑為準）：螺紋牙深=0.5413×螺距（實際牙高，理論全高 0.866×P 僅作參考、不參與計算）；總切入量=牙深×1.3、切削次數=⌈螺距÷0.3⌉+2，逐刀深度=min(1.2×均分步距, 剩餘)、末刀清剩餘；轉速 n=Vc×1000÷(π×直徑)（rpm，取材料 Vc 區間中值：碳鋼 60–80、不鏽鋼 30–50、鋁合金 120–200、黃銅 80–120、鑄鐵 70–100 m/min）；進給量=螺距（mm/r）、進給速度=中值轉速×螺距。校驗：規格須形如 M10×1.5 或 M10（無螺距自動查粗牙螺距表），無法解析即提示並中止。判據：中值轉速>2000 提示「轉速較高，注意安全」、<100 提示「轉速偏低，效率較低」，否則「轉速適中」。
基於 ISO 公制 60° 螺紋基本牙型：理論三角形高度 H=0.866P，實際牙高 H₁≈0.5413P（約為 H 的 5/8）；用於螺紋加工切削深度確定。
💡 主軸轉速 n = Vc×1000 / (π×D)；進給量 f = 螺距 P (mm/r)；切削次數根據螺距遞減分配

💡 常見使用場景

  • 車削程式設計：由螺紋規格與材料算主軸轉速與進給速度
  • 攻絲/車螺紋工藝：確定切削次數與每次進刀深度
  • 材料適配：比較碳鋼、不鏽鋼、鋁合金等的切削速度區間
方法
演算法：按材料取切削速度區間（碳鋼 60~80、不鏽鋼 30~50、鋁合金 120~200、黃銅 80~120、鑄鐵 70~100 m/min）；中值 Vc = (Vc_min+Vc_max)/2；主軸轉速 n = Vc×1000/(π×公稱直徑)；每轉進給 = 螺距 P；螺紋牙深 = 0.5413×P；總進刀量 = 牙深×1.3；切削次數 = ⌈P/0.3⌉+2；各次進刀按遞減分配，前幾次為平均量×1.2，最後一刀取剩餘量；進給速度 = 中值轉速×P（mm/min）。轉速 >2000rpm 提示注意安全，<100rpm 提示效率低。
算例
例：M10×1.5 碳鋼 → Vc 70m/min、轉速 2228rpm（範圍 1910~2546）、進給 1.5mm/r、進給速度 3342mm/min、牙深 0.812mm、切削 7 次，各次進刀 0.181→0.181→0.181→0.181→0.181→0.151→0.000mm，提示「轉速較高，注意安全」。若改 M20×2.5 不鏽鋼 → Vc 40m/min、轉速 637rpm、進給 2.5mm/r、進給速度 1593mm/min、牙深 1.353mm、切削 11 次，各次進刀 0.192mm×9 →0.032→0.000mm，提示「轉速適中」。若改 M20×2.5 鋁合金 → Vc 160m/min、轉速 2546rpm、進給速度 6366mm/min。

❓ 常見問題（FAQ）

牙深 0.5413P 是什麼？
0.5413×P 是 ISO 公制 60° 螺紋的基本牙型高度 H₁（理論三角形高為 0.866P，實際牙高約為其 5/8 = 0.5413P）。車削時徑向進刀量按此牙高控制，再乘 1.3 的係數是為了計入刀尖圓弧與讓刀，保證牙底清根。
最後一刀為什麼顯示 0.000？
本工具採用「前幾刀取平均量×1.2、最後一刀取剩餘量」的遞減分配，當前幾刀已把總餘量吃完後，最後一刀剩餘量為 0，實際加工中即為空走刀（光整刀）。這符合實際工藝——末刀常作為無切深的光整行程，用於消除讓刀、提高牙面質量。
