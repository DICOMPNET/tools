Compute standard gear parameters such as module, pitch diameter, addendum and whole depth.

📐 計算公式
標準圓柱齒輪幾何（雙分支）：直齒 d = m·z、db = d·cosα、ha = ha*·m、hf = (ha*+c*)·m、da = d+2ha、df = d−2hf、p = πm、s = p÷2、pb = p·cosα、zmin = 2ha* ÷ sin²α；斜齒 mt = mn ÷ cosβ、d = mt·z、αt = atan(tanα ÷ cosβ)、ha/hf 按 mn、p = π·mt（端面）、s = π·mn ÷ 2（法向）、zmin = 2ha*·cosβ ÷ sin²αt。校驗：6 項非空守衛，m>0 且齒數 ≥4，壓力角須在 (0,90) 否則標紅，斜齒 |cosβ|<0.001 報「螺旋角無效」。判據：z < zmin 提示根切、建議採用變位齒輪。

支援直齒/斜齒標準圓柱齒輪基本引數計算（GB/T 1356）

💡 公式：分度圓 d=mz；基圓 db=d·cosα；齒頂圓 da=d+2ha；齒根圓 df=d-2hf；周節 p=πm。斜齒輪按法向模數 mn 計算。

⚠️ 使用說明
  • 本工具適用於標準漸開線圓柱齒輪（正常齒制 ha*=1, c*=0.25）
  • 斜齒輪輸入法向模數 mn，螺旋角 β 不可為 0
  • 標準齒輪不發生根切的最少齒數：直齒 zmin=17，斜齒 zmin≈17·cosβ
  • 計算結果僅供參考，實際設計請查閱 GB/T 1356 標準

❓ 常見問題（FAQ）

基節 pb 與周節 p 關係？
pb=p·cosα，是相鄰齒同側齒廓在基圓上的法向距離，等於重合度計算的齒距投影。
預設模組/壓力角？
本工具預設 m=2、α=20°（最常用），可改；斜齒需額外輸入螺旋角。
