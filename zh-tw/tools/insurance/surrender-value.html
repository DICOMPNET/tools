Cash Value (Reserve x Surrender Ratio)

Derive cash value as reserve multiplied by the surrender ratio.

📐 計算公式
退保現金價值（本頁程式碼口徑）：現金價值=準備金×退保比例（比例按小數輸入，80% 填 0.8）；聯動量：退保費用扣減額=準備金−現金價值、退保損失率=1−退保比例、現金價值率=現金價值÷準備金（準備金為 0 時無定義，顯示「—」，不再用 10⁻⁹ 兜底）。校驗：兩個欄位都必須填寫，留空不再按 0 兜底；準備金須 ≥0（負數會把「現金價值為負、扣減額為正」算成結論）、退保比例須在 0–1 之間（超過 1 會算出現金價值高於準備金），不滿足即提示並中止。判據：無固定分級，退保損失率恆等於 1−比例，比例越低退保扣費越重；比例為 0 / 100% 與準備金為 0 三種邊界單獨說明。本頁為簡化模型（現金價值 = 準備金 × 比例），與真實保險合同的現金價值表不同。

📚 深度解析：現金價值（準備金×退保比例）

💡 常見使用場景

  • 退保時按準備金乘退保比例給現金價值。
  • 看不同年度退保能拿回多少。
準備金 5 萬、退保比例 80%
現金價值 = 50000×0.8 = 40000 元。即退保到手 4 萬。

❓ 常見問題（FAQ）

和 estimate-20 區別？
同公式同口徑，estimate-20 偏客戶視角(退保金)、本工具偏精算視角(準備金×比例)，計算一致。
退保比例和退保率是一回事嗎？
不是。退保比例是準備金中實際返還給客戶的比例（受最小現金價值監管約束），退保率是退保件數除以有效件數的業務指標，二者分母不同。
