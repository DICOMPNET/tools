n = c / v

Compute the refractive index of a medium from the speed of light in it, n = c/v.

📐 計算公式
折射率與光速：n = 真空光速 c ÷ 介質光速 v（無量綱，透明介質 n>1）；聯動量：速度比 = v ÷ c、速度差 = c − v（m/s）、比值 = c ÷ max(c−v,10⁻⁹)。校驗：介質光速、真空光速兩項必填守衛，v 作為分母不得為 0。判據：無固定分級，n 越大光在該介質中傳播越慢（真空中 n=1 為上限速度）。

由光在介質中的速度求折射率。

📚 深度解析：由光速求折射率

💡 常見使用場景

  • 已知光在介質中的傳播速度，反推該介質的折射率。
  • 比較不同光學材料對光的減速能力，用於材料選型。
  • 校核實驗測得的光速資料是否落在合理折射率區間。
水中光速 v=2.25e8 m/s
n=c/v=3e8/2.25e8=1.3333，與水在可見光波段的折射率約 1.33 一致。
玻璃中光速 v=1.5e8 m/s
n=c/v=3e8/1.5e8=2.0000。該值對應高折射率光學玻璃（普通冕牌玻璃約 1.5，對應 v≈2.0e8 m/s）。

❓ 常見問題（FAQ）

折射率可以小於 1 嗎？
按 n=c/v，若算得 n<1 說明介質中光速大於真空光速，這違背狹義相對論，通常意味著輸入有誤（如單位寫錯或把群速度/相速度混用）。常規透明介質 n≥1。
折射率與波長有關嗎？
有關，這就是色散。同一材料對短波（藍紫光）的折射率通常更大，因此稜鏡能把白光分解成光譜。計算時應註明所用波長，常見參考值是鈉黃光 589 nm 下的 n_D。
