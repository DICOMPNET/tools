Thin-Film Constructive Interference Calculator (2nt = mλ)

Compute the wavelength that interferes constructively at normal incidence from film index n, thickness t in nanometres and order m. For thin-film optics and reflection enhancement.

📐 計算公式
薄膜相長干涉波長（本頁程式碼口徑）：λ=2×n×t÷m（nm，n 膜折射率、t 膜厚 nm、m 干涉級次）；聯動量：光程差=2×n×t（nm）、下一級相長波長=2×n×t÷(m+1)（nm）。校驗：n、t、m 空值即提示並中止。判據：無固定分級，級次越大相長波長越短，相鄰級次波長逐級遞縮。

輸入膜折射率 n、厚度 t（奈米）與級次 m，求相長干涉波長。

Formula Reference

Item Formula / Note Source / Standard
Constructive interference (normal incidence)2 n t = m λ, λ = 2 n t / m (convention here: net interface phase shifts cancel)Standard thin-film interference (Hecht, Optics, §9.8)
Optical path differenceOPD = 2 n t, n = film index, t = film thicknessStandard geometrical optics

  • n=1.33,t=500,m=1 → 1330 nm。

💡 常見使用場景

  • 增透/增反膜波長設計。
  • 肥皂膜、油膜彩虹成因。
  • 干涉濾光片中心波長。
水膜 n=1.33、厚 500nm、m=1
λ=2nt/m=2×1.33×500/1=1330nm（紅外相長）。若取 m=2 則 λ=665nm（可見紅）。
空氣膜 250nm、m=1
λ=2×1.0×250=500nm，膜呈綠色增強。

❓ 常見問題（FAQ）

相長還是相消看相位跳變
一介面有半波損失時條件互換；本式按 2nt=mλ 相長計。
為什麼膜厚多取 λ/4？
單層減反膜取光學厚 n t=λ/4，使兩反射相消。
