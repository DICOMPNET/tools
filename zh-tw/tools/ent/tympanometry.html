Tympanometry

📐 工作原理與說明
鼓室導抗圖 Jerger 分型（峰壓 TPP / 聲順 SC / 外耳道容積 ECV）
A 型（正常）：−100 ≤ TPP ≤ 100 daPa 且 0.3 < SC < 1.6 mL
As 淺峰型：SC < 0.3（提示聽骨鏈固定/耳硬化）｜Ad 深峰型：SC > 1.6（提示聽骨鏈中斷）
C 負壓型：TPP < −100（C1：−100~−200 輕度；C2：< −200 重度）
B 平坦型：SC < 0.1 或 TPP=0 且 SC < 0.2；ECV > 2.0 mL 提示鼓膜穿孔，ECV 正常提示中耳積液/粘連

Tympanometry: computes and outputs results from the input parameters.

Jerger 鼓室圖分型標準

型別峰壓(dPa)聲順(mL)臨床意義
A型-100~+1000.3-1.6正常鼓室圖
As型-100~+100<0.3聲順低：耳硬化症、聽骨鏈固定
Ad型-100~+100>1.6聲順高：聽骨鏈中斷、鼓膜鬆弛
B型無峰極低平坦型：中耳積液、鼓膜穿孔

臨床要點：B型鼓室圖伴ECV異常增大提示鼓膜穿孔；C型鼓室圖峰壓-100~-200daPa為C1型（輕度負壓），<-200daPa為C2型（重度負壓）。聲導抗是中耳功能篩查的重要工具，結合純音測聽可鑑別傳導性與感音神經性聾。

💡 常見使用場景

  • 兒童中耳炎（積液）篩查。
  • 咽鼓管功能障礙評估。
  • 聽力損失性質鑑別（傳導性）。
B 型鼓室圖
鼓室圖平坦無峰（B 型），聲順低，提示中耳積液（分泌性中耳炎），結合純音測聽確診。

❓ 常見問題（FAQ）

A 型都正常嗎？
A 型峰值正常多為正常，但 As（低峰）提示僵硬、Ad（高峰）提示鬆弛，需結合聲反射判斷。
C 型說明什麼？
峰壓負移提示中耳負壓（咽鼓管阻塞早期），可發展為積液，建議處理鼻腔/咽鼓管。
