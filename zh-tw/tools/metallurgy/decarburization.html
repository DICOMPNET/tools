Decarburization

Decarburization

📐 工作原理與說明
擴散係數 D = D₀·exp(−Q/(R·T))，D₀ = 2.0×10⁻⁵ m²/s、Q = 142 kJ/mol；有效 D = D × 氣氛係數；脫碳層深 x = 2·√(D·t)·erf⁻¹(脫碳比)

Key formulas: 2×√(effD×t×3600)×erfInv(ratio); D0×Math.exp(-Q÷(R×Tk)); 2.0e-5

📋 模型說明

擴散模型：表面碳濃度服從半無限體擴散方程，碳濃度 C(x,t)/C0 = erf(x/(2√(D·t)))。
脫碳層深度：x = 2·√(D·t)·erf⁻¹(Cs/C0)，D 為碳在奧氏體中擴散係數。
擴散係數 (Arrhenius)：D = D0·exp(−Q/RT)，D0≈2.0×10⁻⁵ m²/s，Q≈142 kJ/mol。
氣氛修正：空氣取滿脫碳(表面C≈0)，弱脫碳折減0.6，保護氣氛折減0.1。
注：為工程估算，實際脫碳受合金元素、晶粒、氧分壓等多因素影響。

📚 深度解析：脫碳層估算

💡 常見使用場景

  • 按加熱溫度、保溫時間與氣氛估算鋼材表面脫碳層深度，判定加工餘量是否足夠。
  • 用擴散方程定量給出 C(x,t)/C0 沿層深分佈，定位碳含量跌至某閾值的深度。
  • 對比空氣/弱氧化/保護氣氛的修正係數，最佳化加熱制度。
擴散模型
表層碳濃度分佈 C(x,t)/C0 = erf( x / (2√(D·t)) )，深度 x = 2√(D·t)·erf⁻¹(Cs/C0)。擴散係數 D = D0·exp(−Q/(R·T))，D0=2.0×10⁻⁵ m²/s，Q=142 kJ/mol，R=8.314。氣氛修正係數：空氣 1.0、弱氧化性 0.6、中性/保護 0.1。
算例
1000℃（T=1273 K）保溫 2 小時、空氣：D=2e-5×exp(−142000/(8.314×1273))≈3.0×10⁻¹¹ m²/s；Cs/C0=0.5 時 x=2×√(3.0e-11×7200)×0.477≈2×√(2.16e-7)×0.477≈2×4.65e-4×0.477≈4.4×10⁻⁴ m≈0.44 mm。改用保護氣氛（×0.1）深度降至約 0.04 mm。

❓ 常見問題（FAQ）

脫碳層多深要留餘量？
以最終硬度/滲層要求定；若脫碳 0.4 mm，粗加工留量應大於該值並在精加工去除，否則表面軟層影響耐磨與疲勞。
溫度影響為何這麼大？
D 隨溫度指數增長，溫度每升約 50–100℃ 擴散係數可成倍增加，故控制加熱溫度與停留時間是抑制脫碳的核心。
