📚 深度解析：爐料配比計算

💡 常見使用場景

  • 配料計算按各爐料成分與配比求加權平均成分，再扣燒損得最終熔體成分。
  • 對照牌號目標成分（如 HT250、QT500）反向求生鐵/廢鋼/回爐料配比。
  • 用交叉法快速求兩種爐料的配比，複雜多料再迭代修正。
配料與燒損
配料成分 = Σ(爐料成分 × 配比%) / 配比總和；最終成分 = 配料成分 × (1 − 燒損%)。牌號目標示例：灰鑄鐵 HT250 C 3.2/Si 2.0/Mn 0.6；球鐵 QT500 C 3.6/Si 2.5/Mn 0.4；可鍛 KTH350 C 2.6/Si 1.3/Mn 0.5；鑄鋼 ZG270 C 0.35/Si 0.4/Mn 0.6。燒損：C 5%/Si 15%/Mn 20%。
交叉法算例
生鐵 C 4.3%、廢鋼 C 0.2%，目標 HT250 的 C 3.2%（暫忽略燒損）：配比 = (4.3−3.2):(3.2−0.2) = 1.1:3.0 → 生鐵佔 3.0/(1.1+3.0)=23.4%、廢鋼佔 76.6%。再計入 Si/Mn 燒損與鐵合金補加，迭代至全成分達標。

❓ 常見問題（FAQ）

為什麼先算配料再扣燒損？
爐料帶入的是配料成分，熔煉中易氧化元素（Si、Mn、C）會燒損，最終熔體成分 = 配料×(1−燒損)，順序不能顛倒。
回爐料怎麼處理？
回爐料成分接近牌號，可按其已知成分計入配料加權平均；比例過高需關注雜質累積，配比計算時一併參與加權。
