⚖️ Steel Profile Weight Calculator

Calculate weight per meter and total weight for steel sections from dimensions and density.

📐 工作原理與說明
型鋼理論重量（碳鋼密度 7.85 g/cm³ 口徑）：米重按型材下拉——圓鋼 = a²×0.00617、圓管（外徑 a、壁厚 t）= π·t·(a−t)×0.00785、方鋼 = a²×0.00785、扁鋼 = a×b×0.00785、等邊角鋼 = (2a−t)×t×0.00785、槽鋼 = (a+2b−2t)×t×0.00785（kg/m，按兩翼緣+腹板截面近似）；總重量 = 米重 × 長度 L(m)。校驗：主尺寸 a ≤0 或長度 L ≤0 提示「請輸入有效的主尺寸與長度」；圓管需 0<t<a/2，角鋼/槽鋼需 t>0，槽鋼還需 b>t。判據：無固定分級，另附常用規格理論重量參考表供結果對照。

💡 常見使用場景

  • 採購備料：按型材理論米重 × 長度估算單根/整批重量，快速核對外購噸位與運費，避免按根數盲目報價。
  • 運輸與吊裝：理論重量用於貨車載重、吊具額定與堆場承載力校核，尤其在多規格混裝時統一按重量彙總。
  • 下料最佳化：已知每米重量後，可把套裁方案折算成餘料重量，對比哪種排料更省料、廢重更少。
五型別材預設引數對比（a=20mm / b=10mm / t=3mm / L=6m）
按碳鋼密度 7.85 g/cm³ 推導的經驗係數（圓鋼 0.00617、方鋼/扁鋼/角鋼 0.00785）： 圓鋼 a²×0.00617 = 20²×0.00617 = 2.468 kg/m，總重 2.468×6 ≈ 14.81 kg； 圓管 π·t·(a−t)×0.00785 = 3.1416×3×17×0.00785 = 1.258 kg/m，總重 7.55 kg； 方鋼 a²×0.00785 = 3.14 kg/m，總重 18.84 kg； 扁鋼 a×b×0.00785 = 20×10×0.00785 = 1.57 kg/m，總重 9.42 kg； 等邊角鋼 (2a−t)×t×0.00785 = (40−3)×3×0.00785 = 0.871 kg/m，總重 5.23 kg； 槽鋼 (a+2b−2t)×t×0.00785 = (20+20−6)×3×0.00785 = 0.801 kg/m，總重 4.80 kg（兩翼緣+腹板近似）。

❓ 常見問題（FAQ）

經驗係數 0.00617 / 0.00785 是怎麼來的？
由密度 7.85 g/cm³ 推導：把尺寸單位 mm 換成 cm、長度 m 換成 cm 後，單位體積質量 7.85 g/cm³ 折算成「kg/m·mm²」即約 0.00785；圓鋼按截面積 π(d/2)² 與圓 (d/2)² 的面積比 π/4≈0.785 再乘 0.00785 得到 0.00617。係數是近似值，含軋製圓角與負偏差，結算以過磅為準。
理論重量和過磅重量差很多正常嗎？
正常。理論重量按公稱尺寸計算，實際允許 ±5% 左右公差，且表面鏽蝕、塗層、負偏差會讓實重低於理論；大批次採購建議以過磅或理論重量上限（加公差）作為結算與運力校核依據，本工具結果僅作估算參考。
