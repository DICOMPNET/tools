🛰️ NDVI Vegetation Analyzer

NDVI = (NIR − RED) / (NIR + RED). Enter band reflectances to estimate vegetation cover.

📐 工作原理與公式
NDVI = (近紅外 NIR − 紅光 RED) ÷ (NIR + RED)，兩者為非法數或之和為 0 時無法計算；分級：小於 0 為水體 / 雲 / 雪，小於 0.1 為裸土 / 岩石 / 建築，小於 0.2 為稀疏植被 / 荒地，小於 0.4 為中等植被 / 灌木草地，小於 0.6 為較茂密植被 / 農作物，其餘為茂密植被 / 森林；批次模式按行讀「NIR,RED」逐行計算
NDVI（歸一化植被指數）利用綠色植被在近紅外波段強反射、紅光波段強吸收的光譜特性來量化植被覆蓋：NDVI =（NIR − RED）/（NIR + RED）。取值範圍 −1 ～ 1：水體、雲、雪為負值，裸土與岩石接近 0，植被越茂密越接近 1。輸入可為反射率（0–1）或原始 DN 值，只要兩波段量綱一致，相除後量綱約去，結果相同。純前端本地計算，資料不上傳。
NDVI 區間覆蓋型別
< 0水體 / 雲 / 雪
0 ～ 0.1裸土 / 岩石 / 建築
0.1 ～ 0.2稀疏植被 / 荒地
0.2 ～ 0.4中等植被 / 灌木草地
0.4 ～ 0.6較茂密植被 / 農作物
> 0.6茂密植被 / 森林

💡 常見使用場景

  • 遙感影像的植被覆蓋度快速評估
  • 農田作物長勢監測與地塊間差異對比
  • 生態修復工程的前後期覆蓋變化分析
單點算例
NIR=0.35、RED=0.10：NDVI=(0.35−0.10)/(0.35+0.10)=0.25/0.45≈0.5556，落在 0.4–0.6 區間，屬“較茂密植被 / 農作物”。
多期對比
同一地塊三期 NDVI 為 0.20 → 0.35 → 0.55，可直觀看出植被由稀疏恢復到較茂密。

❓ 常見問題（FAQ）

NDVI 的取值範圍和含義？
範圍 −1 ～ 1。負值多為水體、雲、雪；裸土與建築接近 0；值越大表示綠色植被越茂密。
輸入反射率還是 DN 值？
兩者皆可，只要近紅外與紅光量綱一致，相除後量綱約去，結果相同。反射率通常取 0–1。
為什麼兩波段之和不能為 0？
分母為 0 時 NDVI 無定義；當 NIR+RED=0（如全黑像元）時應剔除該像元或改用其他植被指數。
