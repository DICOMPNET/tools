加密說明

🔒 加密原理

本工具使用基於密碼的異或（XOR）流加密演算法，結合鹽值（Salt）增強安全性：

  • 每個條目使用獨立隨機鹽值，防止相同明文產生相同密文
  • 密碼經多輪雜湊擴充套件後生成金鑰流
  • 明文與金鑰流異或生成密文，儲存於 localStorage
  • 無密碼無法解密，密碼不儲存在本地
📚 Standard basis: NIST SP 800-63B requires server-side password storage with slow hashes + salt (Argon2id/bcrypt/PBKDF2); OWASP recommends Argon2id first. This tool's XOR stream cipher is an educational demo and does not meet production standards — do not store real sensitive credentials here.
注意：這是教學級簡化加密，適合日常備忘保護，不適合儲存高敏感資訊。如需高強度加密請使用專業密碼管理器（如 KeePass、1Password）。忘記密碼將無法恢復資料。
資料儲存位置：瀏覽器 localStorage，清除瀏覽器資料會導致保險箱內容丟失；匯出的備份僅含條目密文，不含主鹽，不能作為清空後的完整恢復。

虛擬保險箱使用密碼加密技術，將你的私密文本資訊安全地儲存在本地瀏覽器中。

✨ 功能特點

  • 密碼加密本地儲存
  • 獨立鹽值增強安全
  • 密碼強度即時檢測
  • 支援條目管理
  • 可匯出條目密文備份（不含主鹽）
  • 資料不上傳伺服器

📋 使用場景

  • 臨時儲存敏感文本
  • 個人密碼備忘
  • 加密筆記

📚 深度解析：虛擬保險箱

💡 常見使用場景

  • 臨時保管不常用的賬號密碼、序列號或私密備忘，避免明文散落在便籤或文件中。
  • 在瀏覽器本地儲存一段私密筆記，僅在輸入正確口令時可「解鎖」檢視。
  • 教學演示：直觀展示口令 + 鹽值經雜湊後儲存、驗證時比對雜湊值的過程。
以「儲存一段私密文本」為例
工具使用 FNV-1a 雜湊演算法（seed=0x811c9dc5）對「password + salt」進行雜湊，再將文本與雜湊值存入瀏覽器 localStorage。驗證時，對輸入口令重新計算 hashStr(pwd + storedSalt) 並與儲存的 pwdHash 比對：一致則解鎖，不一致則拒絕。由於雜湊不可逆，原文不會被還原儲存——這也是它「教學級」的體現：即便拿到本地資料也無法反推口令和原文。

❓ 常見問題（FAQ）

存在本地安全嗎？適合存銀行卡密碼嗎？
資料僅存本機 localStorage、不上傳，但本機被入侵、清快取或重灌會丟失；且它是教學級簡化加密（雜湊 + 固定鹽值），並不適合儲存銀行卡、主密碼等高敏感資訊。高敏感場景請使用 KeePass、1Password 等專業密碼管理器。
忘了口令能找回嗎？
不能。雜湊不可逆且無任何後端服務，系統既不儲存原文也不提供找回通道；口令遺忘即永久無法解鎖該條資料，使用前請務必牢記或另行備份明文。
