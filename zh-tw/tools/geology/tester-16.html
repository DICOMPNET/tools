📐 計算公式
岩石三引數試驗（本頁程式碼口徑，三子計算器）：單軸抗壓 A=π×d²÷4（mm²）、σc=P×1000÷A（MPa，P 破壞荷載 kN、d 直徑 mm）；密度 ρd=乾重÷(飽和重−水中重)、ρs=飽和重÷(飽和重−水中重)（g/cm³）、吸水率 Wa=(飽和重−乾重)÷乾重×100（%）；軟化係數 K=飽和抗壓÷乾燥抗壓。校驗：輸入非數值或關鍵分母 ≤0 提示「請輸入有效資料」。判據：σc≥120 堅硬 / ≥60 較硬 / ≥30 較軟 / ≥5 軟 / <5 極軟；Wa<1 緻密 / <3 中等孔隙 / ≥3 高孔隙；K≥0.75 非軟化 / ≥0.5 弱軟化 / <0.5 軟化。

計算岩石單軸抗壓強度（力學）、幹密度（物理）、吸水率與軟化係數（水理）等引數，輸入實驗資料自動計算並給出岩石質量評價。

公式：σc = P / A，A = π×d²/4

幹密度 ρd = m₁/(m₂-m₃)×ρw；吸水率 Wa = (m₂-m₁)/m₁×100%

軟化係數 K = σcw / σcd，K<0.75 為軟化岩石

⚠️ 使用說明與注意事項
  • 單軸抗壓強度：σc = P/A，A 為受壓面積，試樣高徑比建議 2:1
  • 幹密度採用水中稱量法：ρd = m₁/(m₂-m₃)×ρw（ρw=1.0 g/cm³）
  • 吸水率反映岩石孔隙率，一般 Wa<1% 為緻密岩石
  • 軟化係數 K<0.75 為軟化岩石（遇水強度顯著降低），工程中需特別注意
  • 純前端執行，資料不會上傳到伺服器

📚 深度解析：岩石力學三引數（抗壓/密度/軟化）計算

💡 常見使用場景

  • 抗壓強度：由破壞荷載與試件直徑算單軸抗壓強度 σc 並判堅硬程度
  • 物理引數：由幹/飽和/溼質量算幹密度、飽和密度與吸水率，評孔隙特徵
  • 水理引數：由幹/飽和抗壓強度算軟化係數，判遇水強度折減
方法
公式：①單軸抗壓 σc=P×1000/A，A=πd²/4（P 破壞荷載 N、d 直徑 mm，σc 單位 MPa）；堅硬分級 σc≥120 堅硬、60–120 較硬、30–60 較軟、5–30 軟、<5 極軟。②幹密度 ρd=md/(ms−mw)、吸水率 Wa=(ms−md)/md×100%（md 乾重、ms 飽和重、mw 溼重 g）。③軟化係數 K=σcw/σcd（本地計算，單位統一 g、mm）。
算例
例：P=120kN、d=50mm → A=1963.5 mm²、σc=120000/1963.5=61.11 MPa（較硬岩石）；md=250、ms=255、mw=158 → ρd=2.577 g/cm³、ρs=2.629 g/cm³、Wa=2.00%（中等孔隙）；幹/飽和抗壓 cd=85、cw=55 → K=0.647（弱軟化，遇水強度降低約 35.3%）。

❓ 常見問題（FAQ）

軟化係數低於多少不能用？
一般 K<0.75 視為軟化岩石，水利工程等飽水環境須按飽和強度設計；K≥0.75 耐水性較好。具體閾值按工程型別與規範（如壩基、邊坡）調整，結果僅供參考。
試件直徑影響 σc 嗎？
σc 已用 A=πd²/4 歸一化，理論上與直徑無關；但高徑比須滿足規範（通常≥2），否則端部效應會偏低。本工具只算強度，形狀修正須按試驗規範執行。
