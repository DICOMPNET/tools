🪨 Geological Logging Record Sheet

Generate geological logging records from hole, run and stratum depth.

📐 計算公式
地質編錄表分層計算：層厚 = 終止深度 dTo − 起始深度 dFrom（m）；編錄記錄按 孔號/回次/分層區間 [dFrom~dTo]/巖性/顏色/結構/描述/日期 拼接生成，可逐層存入 localStorage。校驗：dFrom 或 dTo 非數字、或 dTo <dFrom 時報「請輸入有效深度（終止深度 ≥ 起始深度）」。判據：無固定分級，層厚恆非負。

輸入鑽孔分層資訊，生成標準化地質編錄記錄，支援多層累積與匯出

💡 本層厚度 = 終孔深度 − 起始深度；生成記錄含孔號、回次、分層、巖性、描述等標準編錄欄位。

⚠️ 注意事項
  • 分層深度應連續，避免層位重疊或漏編
  • 巖性描述應包含顏色、礦物成分、結構構造、風化程度
  • 加入層位後可一鍵複製完整編錄表
  • 編錄資料儲存在瀏覽器本地，不上傳伺服器

📚 深度解析：鑽孔地質編錄記錄表生成

💡 常見使用場景

  • 分層編錄：錄入每回次起止深度、巖性、顏色、結構構造，自動算層厚
  • 資料歸檔：多分層累積生成標準化編錄表，匯出用於勘察報告
  • 現場校核：即時核對分層厚度合計與鑽探進尺是否一致
方法
演算法：單層厚度 = 終止深度 dTo − 起始深度 dFrom（要求 dTo≥dFrom）；逐回次錄入孔號、回次、巖性、顏色、結構構造與描述，工具累積為分層表並自動生成「孔號 / 起止深度 / 厚度 / 巖性 / 顏色 / 結構 / 描述」的標準化記錄，可複製或匯出（深度精確到 0.01m）。
算例
例：孔號 ZK101、回次 3、dFrom=12.50m、dTo=15.80m、巖性=強風化花崗岩 → 層厚=15.80−12.50=3.30m，記錄含顏色「灰黃褐色」、結構「中粒結構，塊狀構造」。連續錄入多個分層後，複製得到帶製表符的分層彙總表，便於貼入 Excel 或報告。

❓ 常見問題（FAQ）

分層厚度合計必須等於鑽探進尺嗎？
原則上各回次分層厚度之和應等於該回次進尺；若出現缺口或重疊，說明漏記或深度錄入有誤，需在現場及時補正，否則影響資源量估算與剖面連續性。
編錄表能直接當勘察報告嗎？
編錄表是原始資料，報告還需附巖芯照片、取樣位置、試驗結果與綜合解釋。本工具僅規範記錄格式與厚度計算，不作地質結論。
