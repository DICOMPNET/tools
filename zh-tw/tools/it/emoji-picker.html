💻 Emoji Picker

Emoji Picker - Search emojis by keyword (Chinese or English), filter and click to copy. Built-in dataset, free, browser-only.

📐 工作原理與說明
表情表每條為「字元 + 英文拼音名 + 中文關鍵詞串」。篩選：關鍵字為空時返回全部；否則保留英文拼音名轉小寫後包含關鍵字、中文關鍵詞串轉小寫後包含關鍵字、或表情字元與關鍵字完全相等的條目。命中結果逐條渲染為可點選卡片，點選複製該表情
內建 Unicode Emoji 資料集（含 CLDR 分組與多語言關鍵詞），前端按關鍵詞或分類即時過濾，點選即複製 Emoji 字元或其碼點（如 U+1F600）。複雜 Emoji 可由 ZWJ（零寬連線符 U+200D） 序列組合（如家庭、職業組合）。
  • 資料隨 Unicode 版本更新（15.x 已超 3000 個 Emoji）。
  • 純前端本地檢索，不上傳；複製結果依賴系統字型回退渲染。

⚠️ 使用說明與注意事項
  • 支援中英文關鍵詞，按 emoji 名稱與中文釋義模糊匹配；留空顯示全部。
  • 點選任意 emoji 即複製到剪貼簿（相容無 HTTPS/剪貼簿 API 的環境，使用 execCommand 兜底）。
  • 內建約 180 個常用 emoji；更多字元建議用系統輸入法的 emoji 面板。

❓ 常見問題（FAQ）

Emoji 跨平臺一致嗎？
碼點一致，但各平臺繪圖形狀不同。
該不該在正式文本里用 emoji？
視場景而定。社媒與社群內容用 emoji 能提升親和力；但合同、報錯資訊、技術文件應慎用——不同平臺渲染不同、螢幕閱讀器會逐個朗讀，且部分符號存在歧義。正式文本建議把關鍵資訊完全交給文字表達。
