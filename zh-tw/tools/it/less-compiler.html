📐 工作原理與說明
讀取 LESS 原始碼，原始碼為空時顯示空狀態提示並隱藏統計；未載入 less.js 時提示尚未載入完成請稍後重試。呼叫 less.render 並傳入壓縮、嚴格數學、嚴格單位三個編譯選項，同時記錄起始時間。編譯成功後取輸出 CSS：統計編譯耗時（當前時間減起始時間，四捨五入取整）、輸出行數（按換行切分的行數）與輸出位元組數（按 UTF-8 位元組長度，千分位展示），並把 CSS 寫入輸出區、狀態置為編譯成功。編譯失敗時拼接錯誤資訊，並依次附加行號、列號與檔名（若存在），狀態置為錯誤並清空上一次編譯結果
把 Less 編譯為標準 CSS。
  • 特性：變數 @var、巢狀規則、混合（mixin）、運算與內建函式。
  • 編譯：變數求值、mixin 內聯展開、巢狀選擇器展開為後代選擇器。
  • & 符號：代表父選擇器，用於偽類與拼接（如 &:hover）。
  • 注意：過度巢狀會生成過長的選擇器鏈，導致優先順序過高難以覆蓋。

📖 使用說明

功能說明

  • 即時編譯：輸入 Less 程式碼時自動延遲編譯，無需手動點選
  • 變數 Variables：@width: 10px; 定義變數，可在全域性複用
  • 混合 Mixins：.bordered(); 引用一組屬性集合
  • 巢狀 Nesting：支援選擇器層級巢狀，結構更清晰
  • 運算 Operations：支援加減乘除等數學運算
  • 函式 Functions：darken()、lighten()、fade() 等顏色與數學函式

編譯選項

  • 壓縮模式：移除註釋和多餘空白，輸出最小體積 CSS
  • 嚴格數學：僅在括號內執行數學運算，避免 font: 12px/1.5 被計算
  • 嚴格單位：單位不一致時報錯，而非自動轉換
  • Tab 縮排：輸入框中按 Tab 鍵可插入兩個空格縮排

❓ 常見問題（FAQ）

Less 變數與 CSS 變數區別？
Less 編譯期替換，CSS 變數執行時生效。
變數沒替換是什麼原因？
Less 變數是編譯期替換，作用域遵循「就近優先、延遲求值」：變數可在定義之後被修改，最終取最後一次賦值，因此寫在使用之後也會生效，這點與直覺不同。另外 @import 順序、變數插值（@{name}）與轉義（~"..."）都會影響替換結果。

  • 支援運算與內建函式
  • 壓縮模式輸出最小體積
  • 嚴格數學/嚴格單位模式
  • 編譯耗時與輸出統計
  • 詳細錯誤資訊提示

  • 支援深色模式
