🔄 CSS Unit Converter (px / em / rem / pt / %)

Convert between CSS length units.

📐 工作原理與說明
基準字號取輸入值（非法時取 16）；px 值須為有效數字、非負且基準字號大於 0，否則提示請輸入有效的正數並把預覽字號固定為 16px。換算：em = px ÷ 基準字號；rem = px ÷ 16；pt = px × 0.75；百分比 = px ÷ 基準字號 × 100。逐項以表格輸出單位、數值與對應的 CSS 寫法（font-size 宣告），並把預覽文字的字號設為該 px 值、內容改為「示例文字（px 值 + px）」
在 px、em、rem 等 CSS 長度單位之間換算，相對單位依賴基準字號。
  • px：CSS 參考畫素，約等於 1/96 英寸，是絕對基準。
  • em：相對父元素的 font-size，巢狀層級深時會產生複合放大。
  • rem：相對根元素（html）的 font-size，預設 16px 時 1rem = 16px，避免複合問題。
  • 其他：% 相對父級，vw/vh 相對視口的 1%，ch 為字元 0 的寬度，ex 為小寫 x 的高度。

📌 換算關係
  • em / rem：目標 px ÷ 基準 px（例如 16px / 16px = 1rem）。
  • pt：1px = 0.75pt，因此 16px = 12pt。
  • 百分比（%）：以基準字號為 100%，16px 對應 100%。
  • 瀏覽器預設根字號通常為 16px。

💡 常見使用場景

  • 按根字號把 rem 轉 px，或按父字號把 em 轉 px。
  • 響應式改造：把設計稿裡的固定 px 按根字號換算成 rem，使用者調整瀏覽器預設字號時整站才會跟著縮放，兼顧可訪問性。
換算
根字號 16px：2rem=32px；父字號 14px：1.5em=21px；12pt≈16px。

❓ 常見問題（FAQ）

em 與 rem 區別？
em 相對父元素字號，rem 相對根(html)字號。
em 和 rem 有什麼坑？
rem 恆等於根元素字號，可預測；em 相對父元素字號，巢狀多層會逐級相乘——三層巢狀且每層 1.2em 時，實際是 1.728 倍而非 1.6 倍。因此字號建議統一用 rem，只有需要跟隨區域性上下文縮放的屬性（如按鈕內邊距）才用 em。

📊 結果解讀

單位關係

CSS 長度：px 絕對畫素；em 相對父字型大小；rem 相對根（html）字型大小；pt 印刷點（1pt=1/72in）；% 相對父尺寸。無父上下文時 % 可能無效。

用途

響應式排版優先用 rem/em 實現可縮放；px 適合固定邊框。1rem 預設 = 16px。

注意

em 會層層累積，巢狀深時需謹慎；結果以當前根/父字型設定為準。
