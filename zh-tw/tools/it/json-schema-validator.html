📄 JSON Schema Verifier

Validate JSON against a JSON Schema in your browser — catch structural errors fast.

📐 工作原理與說明
分別解析模式與資料兩處 JSON，模式解析失敗或資料為 null 時提示 JSON 格式錯誤。隨後從根節點遞迴校驗：先判斷值是否符合模式宣告的型別，不符合即記為「型別不匹配 + 路徑 + 期望型別」並停止下探；型別為物件時要求值確實是非陣列的物件（否則記為不是物件），逐項檢查必填欄位列表中每個鍵是否存在於資料中（缺失記為缺少必填欄位），再對屬性表中同時存在於資料中的鍵繼續遞迴校驗。收集到任何問題時逐條列出並標註未通過，全部通過則提示校驗通過
JSON Schema 是一種用 JSON 描述資料結構的規範：用 type 約束欄位型別、required 標記必填、properties 定義子欄位、additionalProperties 控制是否允許額外欄位。本工具在瀏覽器內解析 Schema 與待校驗 JSON，逐條比對約束並定位首個錯誤位置，資料不出本地。
行列號從 1 開始（首個字元 = 第 1 行第 1 列）；本頁深度上限 64 層（超出即停止校驗並報錯）；輸入上限 不設上限。

❓ 常見問題（FAQ）

Schema 用哪個規範？
常用 draft-07 或 2020-12，注意版本差異。
校驗通過了就安全嗎？
只說明結構合規，不代表業務合法。Schema 能約束型別、必填與範圍，但無法表達「結束時間必須晚於開始時間」這類跨欄位規則，也不做許可權判斷。校驗通過後仍需按輸出上下文做轉義與引數化查詢，防止注入。
