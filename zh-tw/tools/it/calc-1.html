🔄 File Size Unit Converter

Convert file sizes between decimal (SI) and binary (IEC) units.

📐 工作原理與說明
輸入須為有效的非負數值，否則提示請輸入有效的非負數值。位元組數 = 輸入值 × 所選單位的換算因子；隨後用同一套因子表把位元組數換算為其它各單位的數值並逐一展示，數值按中文地區千分位格式輸出，同時給出原始大小與等價位元組數
在儲存與傳輸的單位之間換算，需區分十進位制與二進位制兩套字首。
  • 兩套標準：SI 十進位制按 10³ 遞進（KB/MB/GB），IEC 二進位制按 2¹⁰ 遞進（KiB/MiB/GiB）。
  • 差異：1 KB = 1000 B，而 1 KiB = 1024 B；硬碟廠商標稱用十進位制，作業系統顯示常用二進位制。
  • 位與位元組：1 B = 8 bit；頻寬常用 bit/s（Mbps），下載速度常用 B/s，相差 8 倍。
  • 影響：同一容量用兩種標準表示約差 7%（如 1 GB 與 1 GiB），換算時須明確口徑。

📌 單位說明
  • SI 十進位制：1 KB = 1,000 B，1 MB = 1,000 KB（硬碟廠商常用）。
  • IEC 二進位制：1 KiB = 1,024 B，1 MiB = 1,024 KiB（作業系統常用）。
  • Windows 顯示的“GB”實際為 GiB，Mac 顯示的“GB”通常為十進位制 GB。

💡 常見使用場景

  • KB/MB/GB 與 KiB/MiB 混用時換算。
  • 核對硬碟容量：廠商標稱 1 TB 按十進位制（10¹² 位元組），作業系統按二進位制顯示（÷ 1024⁴ ≈ 0.909 TiB），兩者差約 9% 屬正常，不是縮水。
換算
1 GB=1000 MB（十進位制）；1 GiB=1024 MiB（二進位制）。100 MiB×1024²≈104.9 MB。

❓ 常見問題（FAQ）

KB 與 KiB 區別？
KB=10³ 位元組，KiB=2¹⁰ 位元組，儲存廠商標十進位制、系統常顯二進位制。
MB 和 MiB 到底差多少？
1 MB = 1,000,000 位元組，1 MiB = 1,048,576 位元組，相差 4.86%。單級差別不大，但逐級累積：1 GB 與 1 GiB 差 7.4%，1 TB 與 1 TiB 差約 10%。傳輸速率同理——100 Mbps 寬頻的理論下載速度是 12.5 MB/s 而非 12.5 MiB/s。

📊 結果解讀

換算口徑

檔案大小按 1 KB=1024 B（二進位制，KiB）或 1 KB=1000 B（十進位制，SI）換算；系統/廠商口徑不一常致"標稱 vs 顯示"差異。

用途

儲存、頻寬與傳輸量估算；注意 GiB/GB、MiB/MB 區分以對賬準確。

注意

磁碟/流量常標十進位制，作業系統常顯二進位制，差額約 7% 量級。
