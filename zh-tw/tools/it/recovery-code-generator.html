恢復碼（備份碼）是雙因素認證失效時的兜底憑證，要求「離線可存、一次性有效、不可猜測」。本工具用密碼學安全隨機源生成高熵字串，按固定長度分組便於抄寫。安全要點有三：一是每碼只用一次，服務端使用後立即失效；二是必須以雜湊形式儲存，明文洩露等同於繞過 2FA；三是提示使用者列印或離線儲存，而非存在同一臺裝置的明文檔案裡。生成數量通常 8–10 個即可覆蓋絕大多數找回場景。

❓ 常見問題（FAQ）

恢復碼怎麼存？
服務端雜湊儲存，使用者離線保管。
用掉一個之後要重新生成嗎？
不必立即重新生成，但應關注剩餘數量：多數平臺會在剩餘較少時提示補充。若懷疑恢復碼已洩露，應立即作廢全部舊碼並重新生成——這會讓之前儲存的副本全部失效。建議定期核對還能用幾次，而不是等到真需要時才發現用光了。
