📄 TOML Format

📐 工作原理與說明
TOML 配置檔案的格式化與校驗。
  • 語法：[table] 表示表，key = value 表示鍵值，陣列用 []，內聯表用 {}。
  • 字串：基礎字串用雙引號、字面字串用單引號、多行用三引號。
  • 格式化：統一縮排與空行，保持語義不變，便於閱讀與 diff。
  • 用途：整理 Cargo.toml、pyproject.toml 等配置檔案。

Format and beautify TOML in your browser — consistent, readable configuration files.

📖 使用說明

TOML 語法簡介

  • 鍵值對：key = "value"
  • 字串：用引號包裹，支援多行字串 """
  • 數字：整數、浮點數、科學計數法
  • 布林值：true / false
  • 陣列：[1, 2, 3]
  • 表(section)：[table] 表示一個物件
  • 陣列表：[[array_of_tables]]
  • 註釋：# 開頭

❓ 常見問題（FAQ）

TOML 與 YAML 比？
TOML 對配置更直觀，型別明確。
為什麼格式化後鍵的順序變了？
TOML 要求「表必須位於所有普通鍵之後」，格式化器會把根級標量提到前面、再按層級排列表頭，所以看起來順序被重排。這是格式約束而非資料丟失。若需要人眼可讀的固定順序，可在原始檔中就按層級組織，或用註釋分段標記。
