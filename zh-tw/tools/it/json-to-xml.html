❓ 常見問題（FAQ）

陣列怎麼轉 XML？
通常重複元素或加索引，如 <item>1</item><item>2</item>。
為什麼屬性和資料分不清？
因為 JSON 只有鍵值、沒有「屬性」概念，轉換器必須靠約定來區分（常見做法是把以 @ 開頭的鍵當作屬性、#text 當作文本內容）。不同庫約定不同，跨系統對接時要先用樣例驗證，必要時手工調整生成的 XML。
