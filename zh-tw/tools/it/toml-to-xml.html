📄 TOML to XML Converter

📐 工作原理與說明
TOML 解析：去回車後逐行處理，跳過空行與 # 開頭註釋（# 判定避開成對雙引號內部）；[節名] 按 . 逐級建巢狀物件，[[陣列名]] 向同名數組追加一個新元素；其餘行取第一個 = 分隔鍵與值，值先剝掉行尾 # 註釋再解析——雙引號串按 \n \t \" 反轉義，true/false 轉布林，純整數轉 parseInt，純小數轉 parseFloat，[ ] 內按逗號遞迴解析為陣列。轉 XML：值為物件時以 @ 字首鍵還原屬性、#text 還原文本、陣列按同名元素逐個序列化；頂層鍵不止一個時外面包 <root>，並對 & < > 與屬性值雙引號做轉義
把 TOML 轉換為 XML。
  • 對映：TOML 的表對映為 XML 元素，鍵成為子元素或屬性（依具體約定）。
  • 轉義：XML 中的 & < > 等保留字元必須轉義。
  • 限制：XML 元素名不能以數字開頭或含空格，非法名稱需做轉換。
  • 用途：與僅支援 XML 輸入的系統對接。

Convert TOML configuration into XML, mapping tables to nested elements for systems that require XML.

⚠️ 使用說明與注意事項
  • TOML 中以 @ 開頭的鍵會轉為 XML 屬性；陣列展開為多個同名元素。
  • 轉換按約定進行，複雜結構建議人工核對。

為什麼生成的結構和預期不一樣？
因為兩種模型的表達能力不對等：TOML 有表、表陣列與內聯表，XML 有元素與屬性，沒有統一對映規則。多數轉換器把表對映為元素、標量對映為文本或屬性。跨系統對接時應先用小樣例驗證結構，必要時調整源配置的層級。
