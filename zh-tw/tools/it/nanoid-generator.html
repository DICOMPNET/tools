🔐 NanoID Generator

Create secure, URL-friendly NanoIDs in your browser using a cryptography-grade random generator.

📐 工作原理與說明
生成短小且 URL 安全的唯一識別符號。
  • 特點：預設 21 個字元，比 UUID 更短，字母表為 A-Za-z0-9_-，可直接用於 URL。
  • 隨機源：使用密碼學安全的隨機數生成器，而非 Math.random。
  • 碰撞：21 字元的碰撞機率與 UUID v4 相當，可安全用於分散式 ID。
  • 用途：資料庫主鍵、短鏈、前端臨時標識與冪等鍵。

📖 NanoID 說明

• 預設長度 21 字元，比 UUID 短但碰撞率極低

• 使用 Web Crypto API 的 getRandomValues 保證密碼學安全

• 預設字母表：A-Za-z0-9_- (URL 安全，64 字元)

• 21 字元長度提供約 122 位熵，約 4 年後才有 1% 碰撞機率（350M ID/s）

❓ 常見問題（FAQ）

NanoID 與 UUID 比？
更短、URL 友好、可定製字元集。
預設長度夠安全嗎？
NanoID 預設 21 個字元、使用 64 個字元表，約 126 位熵，與 UUID v4 的 122 位相當，碰撞機率可忽略。若縮短長度，熵會線性下降：14 個字元約 84 位，仍足夠大多數場景；但要避免用 Math.random 作為隨機源——那會讓它完全可預測。
