📄 TOML to YAML Converter

📐 工作原理與說明
TOML 解析：逐行去空白，跳過空行與 # 註釋（# 的判定需避開成對雙引號內的內容）；[節名] 按 . 逐級建立巢狀物件並設為當前表，[[陣列名]] 同名數組追加一個新元素並設為當前表（路徑中若碰到陣列表則下鑽到它的最後一個元素，子表才不會丟）；其餘行取第一個 = 分隔鍵與值，鍵按 . 形成點號路徑，值先剝掉行尾 # 註釋再解析；值以 [ 或 { 開頭且括號未閉合時繼續吞併後續行，支援多行陣列。值解析：雙引號串單遍反轉義（\\ \n \t \r \" 一次對映，避免 \\temp 被拆成反斜槓+製表符），true/false 轉布林，純整數轉 parseInt，純小數轉 parseFloat，[ ] 內按頂層逗號（跳過引號與巢狀括號內的逗號）遞迴解析為陣列，{ } 內聯表按 a=1 遞迴解析為對映。輸出：鍵名匹配 ^[A-Za-z0-9_-]+$ 時原樣寫，否則加雙引號並轉義反斜槓與引號；字串含反斜槓、換行、製表符或 YAML 特殊字元時加雙引號並轉義，陣列元素是對映時按 - 鍵: 值 逐行展開（子表/子陣列繼續縮排遞迴），同一表內先寫標量鍵再寫子表，可選按鍵名字典序排序
把 TOML 轉換為 YAML。
  • 對映：TOML 的表與鍵值分別轉為 YAML 的對映與標量，陣列轉為序列。
  • 縮排：YAML 以縮排表達層級，只能使用空格，不能使用 Tab。
  • 型別：形如 true、0123 的值需加引號，避免被 YAML 誤推斷型別。
  • 用途：配置檔案在兩種格式之間遷移。

⚠️ 使用說明與注意事項
  • TOML 的 [section] 錶轉為 YAML 巢狀對映；[[陣列表]] 轉為 YAML 列表，每個元素是一個對映。
  • TOML 的陣列（[1,2,3]）轉為 YAML 行內或塊列表。
  • 時間戳等 TOML 專有型別會按字串保留，避免資訊丟失。

❓ 常見問題（FAQ）

兩者都支援註釋嗎？
都支援，但轉換需約定註釋去留。
轉換後註釋沒了怎麼辦？
這是常見現象：多數轉換器基於解析後的資料結構再序列化，註釋在解析階段就被丟棄了。若註釋承載重要說明，應在轉換後手工補回，或保留 TOML 作為唯一資料來源、把 YAML 當作生成產物（並在 CI 中自動重新生成，禁止手改）。
