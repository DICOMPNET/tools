🔗 URL Slug Generator

📐 工作原理與說明
生成流程：可選移除中文或中文轉拼音 → 可選剝離符號（先於 Unicode 轉義執行，避免轉義後的 % 被符號過濾剔除）→ Unicode 模式按碼點轉義 → 可選轉小寫 → 可選剔除停用詞 → 空白與分隔符歸一為所選分隔符（預設 -）→ 壓縮重複分隔符並去首尾；四種預覽：標準 slug、全小寫、按所選分隔符轉下劃線、按分隔符切分後首字母大寫拼接的駝峰式
把標題或文本轉換為 URL Slug。
  • 步驟：小寫化 → 去除重音符號 → 空格與標點統一替換為連字元 → 去除首尾連字元。
  • 目的：讓 URL 中不含空格、中文與特殊字元，避免轉義與傳輸問題。
  • 示例：Hello World! 2024 → hello-world-2024。
  • 用途：生成可讀、穩定且對搜尋引擎友好的連結地址。

❓ 常見問題（FAQ）

保留大寫嗎？
一般轉小寫並去標點。
為什麼 URL 裡要避免大寫和空格？
空格在 URL 中會被編碼成 %20，可讀性差且部分系統處理不一致；大小寫則可能造成重複內容（/About 與 /about 在部分伺服器上指向不同資源，被搜尋引擎視為兩個頁面）。因此約定統一用小寫、連字元分詞、去掉標點，並在釋出後保持穩定。
