🔀 Text Deduplicate Sort

📐 工作原理與說明
分隔符取值：換行時按 \r\n / \r / \n 拆行，其餘按字面分隔符（逗號、分號、製表符或自定義串）拆分且不保留換行。變換管線按順序為：去重（保留首次出現，累計去重條數）、去空行（過濾 trim 後為空的行）、去首尾空白（^\s+|\s+$ 替換為空）、排序（升序/降序直接比較字串；自然排序用 Intl.Collator 的 numeric + base 靈敏度比較，不可用時按「數字塊與文本塊」交替拆分後逐段比較，數字段按數值比、文本段按字串比，最後比段數；按長度排序先比 length 再比字典序）、反轉、加序號（padStart 補零到指定位數後接 ". "）與去序號（^\s*\d+[.)、\]:\s]+ 替換為空）。統計：原始條數（與實際參與處理的資料同源）、當前條數、累計去重數
對文本行去重並排序。
  • 去重：移除重複行，保留首次出現項，可選擇忽略大小寫與首尾空白。
  • 排序方式：字典序、按長度、按數值，或自然排序（natural sort）。
  • 自然序：能正確處理 a2 < a10，而純字典序會得到 a10 < a2。
  • 用途：整理清單、生成唯一值列表、資料清洗前置處理。

❓ 常見問題（FAQ）

大小寫敏感？
可選敏感/忽略。
為什麼去重後還是有幾行看起來一樣？
多半是行尾空白或不可見字元不同（如一行帶 \r 另一行沒有、或含零寬空格），肉眼無法分辨但字串並不相等。應先清理（去首尾空白、統一換行符、移除控制字元）再去重；若需按語義去重，還要統一大小寫與全半形。
