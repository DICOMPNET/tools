Design CSS box-shadows with a live preview in your browser — tweak offset, blur, spread and color.

📐 工作原理與說明
CSS 語法：box-shadow: [inset] Xpx Ypx 模糊px 擴散px rgba(顏色, 透明度%)；inset 為內陰影，省略為外陰影，透明度 0–100% 對映到 alpha 通道
生成 CSS 盒陰影程式碼並即時預覽，支援內外陰影與多層疊加。
  • 語法：box-shadow: [inset] <offset-x> <offset-y> <blur> <spread> <color>。
  • 引數：offset-x/y 控制偏移；blur 為模糊半徑（0 為硬邊）；spread 控制擴張或收縮。
  • inset：加 inset 關鍵字把外陰影變為內陰影；多層用逗號分隔，先宣告的在上層。
  • 效能：大面積高模糊陰影會觸發重繪，列表中建議減小 blur 或改用偽元素承載。

💡 常見使用場景

  • 視覺化調出元素投影：偏移/模糊/擴散/顏色。
  • 做擬態（Neumorphism）按鈕：疊加一深一淺兩層陰影，深色偏右下、淺色偏左上，配合與背景同色的填充，可得到凸起的立體感。

❓ 常見問題（FAQ）

inset 是什麼？
加 inset 變為內陰影，用於凹陷效果。
陰影會影響效能嗎？
box-shadow 的模糊半徑越大，重繪成本越高，在滾動或動畫中大量使用會掉幀。建議：給做動畫的元素加 will-change 或改用 transform 動畫；用較小的模糊半徑疊加多層代替單層大模糊，通常更快也更好看。
