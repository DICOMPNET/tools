❓ 常見問題（FAQ）

== 與 equals？
== 比引用，equals 比值（物件）。
String 拼接該用 + 還是 StringBuilder？
編譯期常量或單行拼接用 + 即可，現代編譯器會自動最佳化；但在迴圈裡反覆用 + 會生成大量中間物件，應顯式使用 StringBuilder。另外從 Java 9 起字串拼接改用 invokedynamic 實現，效能特性又有變化，但迴圈場景仍建議顯式使用。
