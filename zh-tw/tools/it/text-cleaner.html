💻 Text Cleaner

📐 工作原理與說明
清理管線按勾選順序執行：全形轉半形把 \uFF01-\uFF5E 區間的字元碼減 0xFEE0，並把全形空格 \u3000 換成半形空格；半形轉全形反過來加 0xFEE0 並把空格換成 \u3000；HTML 實體解碼借 textarea 的 innerHTML 賦值再取 value；去掉 HTML 標籤、去掉不可見字元、統一換行為 \n、製表符轉空格（按指定個數，預設 4）、空格轉製表符（按指定個數）、每行去首尾空白、刪除所有空格、多個空格摺疊為一個、刪除空行、多個空行摺疊為一個。統計：原始字元數即 length，行數為按 \n 切分的段數，減少量 = 輸出長度 − 輸入長度（負號表示減少）
清理文本中的多餘與不可見字元。
  • 清理項：多餘空格、連續空行、行尾空白、製表符、不可見控制字元與零寬字元。
  • 零寬字元：如 U+200B、U+200C 肉眼不可見，卻會破壞搜尋匹配與程式解析。
  • 可選處理：去除 HTML 標籤、刪除重複行、統一換行符為 LF 或 CRLF。
  • 場景：整理從 PDF、網頁、表格或聊天記錄中複製出來的文本。

❓ 常見問題（FAQ）

會刪換行嗎？
可選保留段落或全壓成一行。
為什麼清理後中文標點變了？
因為輸入裡可能混入了全形/半形標點、不間斷空格（U+00A0）或零寬字元，它們看起來與普通空格標點一樣，但編碼不同，會影響搜尋與排版。清理工具會按規則歸一化；若希望保留原始形態，請先確認清理選項，避免誤改正文。
