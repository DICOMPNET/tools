🎲 Random String Generator

📐 工作原理與說明
安全隨機字串生成
隨機源：crypto.getRandomValues（密碼學安全），降級 Math.random
生成方式：每字元取隨機數 mod 字元集大小 索引
字元集可選：大寫 26｜小寫 26｜數字 10｜符號 25 類
理論熵(bits) = 長度 × log₂(字元集大小)
強度評級：<40 弱｜<60 中｜<120 強｜≥120 極強
約束：長度 1~128，條數 1~50
生成指定字元集的隨機字串。
  • 字元集：大小寫字母、數字、符號可自由組合，並支援排除易混字元（如 0/O、l/1）。
  • 安全：用於口令或令牌時必須用 crypto.getRandomValues，而非 Math.random。
  • 強度：熵 ≈ 長度 × log₂(字元集大小)，熵越高越難被猜到。
  • 用途：臨時口令、API 令牌、驗證碼與前端臨時標識。

⚠️ 使用說明與注意事項
  • 使用瀏覽器 crypto.getRandomValues 生成密碼學安全的隨機值；不支援時回退到 Math.random。
  • 長度上限 128、數量上限 50，避免一次性生成過多造成卡頓。
  • 符號集含常見安全符號；如需自定義可手動編輯結果。

❓ 常見問題（FAQ）

用 crypto 隨機嗎？
安全場景應使用密碼學安全隨機數。
為什麼不能用 Math.random 生成？
因為 Math.random 用的是可預測的偽隨機演算法，攻擊者觀測到若干輸出後可反推內部狀態，進而預測後續所有值。憑證、口令、令牌這類場景必須使用 crypto.getRandomValues（瀏覽器）或 secrets 模組（Python）等密碼學安全隨機源。
