🔤 Java String Escape

📐 工作原理與說明
逐字元處理並把結果放在一對雙引號內：反斜槓轉為兩個反斜槓；雙引號與單引號轉為反斜槓加該字元；換行轉反斜槓 n，回車轉反斜槓 r，製表符轉反斜槓 t，退格轉反斜槓 b，換頁轉反斜槓 f；其餘字元在碼點小於 0x20 時，開啟 Unicode 選項則輸出反斜槓 u 加四位十六進位制（不足補前導 0），否則輸出對應簡寫形式。開啟包裹選項時在首尾補上引號
Java 字串字面量的轉義與反轉義。
  • 轉義序列：\n \t \r \" \\ \b \f \' \uXXXX \OOO。
  • 特性：\uXXXX 在編譯期即被解析，即便出現在註釋中也會生效。
  • 文本塊：Java 15+ 支援 """ 文本塊，可多行書寫並減少轉義。
  • 要求：\u 必須恰好四位十六進位制，不足需補前導 0。
  • 非法序列：反斜槓 u 之後不足四位十六進位制或含非法字元時顯示錯誤並清空舊結果。

轉義
輸入 `a b` → 輸出 `"a\tb"`（製表符變 \t）。

❓ 常見問題（FAQ）

Java 文本塊 """ 能省轉義嗎？
JDK 15+ 文本塊可免多數轉義，但仍需處理 `"""` 本身。
Java 屬性檔案裡的轉義規則一樣嗎？
不一樣。.properties 有自己的規則：鍵名中的空格、冒號與等號需要反斜槓轉義；非 Latin-1 字元通常按 \uXXXX 表示（Java 9 起預設按 UTF-8 讀取，情況有所變化）。不要直接把 Java 字面量的轉義結果複製進屬性檔案。
