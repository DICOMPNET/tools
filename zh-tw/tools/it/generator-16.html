Generate .env format environment variables in your browser — quick configuration scaffolding.

📐 工作原理與說明
生成條數保證在 1 到 50 之間（非法時取 5）。把內建的環境變數鍵值對陣列隨機打亂後按條數迴圈取用（取完一輪迴到開頭繼續），逐條按「鍵 = 值」拼行，整體作為 .env 配置片段輸出
生成 .env 格式的環境變數配置。
  • 格式：每行 KEY=VALUE，支援 # 註釋與引號包裹的值。
  • 轉義：值中的引號、反斜槓與換行需按目標解析規則轉義。
  • 規範：鍵名建議大寫加下劃線，避免使用保留字。
  • 安全：金鑰類變數不應入庫，生產環境應由金鑰管理服務下發。

❓ 常見問題（FAQ）

註釋支援嗎？
支援 `#` 註釋行。
生成的 .env 能直接提交嗎？
只提交不含真實機密的 .env.example。真實 .env 必須寫進 .gitignore；若已提交過機密，僅刪除檔案無效——Git 歷史裡仍有記錄，應立即輪換金鑰，並用 git filter-repo 之類工具清理歷史後再推送。
