📝 Markdown to HTML

Render Markdown to clean HTML in your browser with live preview — no upload, no server.

📐 工作原理與說明
先把圍欄程式碼塊（```lang 起、``` 止）整體取出，轉義後包成 <pre><code>，原位置換成佔位標記，避免塊內內容被行內規則誤處理。隨後逐行匹配：佔位行直接回填程式碼塊；空行收尾當前列表與表格；^(#{1,6})\s+(.*)$ 按井號個數輸出 h1–h6；^---+$ 輸出 <hr>；^>\s?(.*)$ 輸出引用塊；^[-*+]\s+(.*)$ 歸入同一 <ul> 列表；以 | 開頭且下一行是分隔行時進入表格，表頭與各行都按 | 切分並去掉首尾豎線。行內規則在 & < > 轉義之後依次處理反引號程式碼、**粗體**、*斜體*、[文本](連結) 與 ![圖片說明](圖片地址)，連結與圖片地址只允許 http/https/mailto 或相對路徑，並做屬性轉義。文本為空時提示輸入 Markdown
按 CommonMark 規則將 Markdown 解析為 HTML：# 標題、** 粗體、* 斜體、[]() 連結、- 列表、` 行內程式碼、| 表格等。前端解析器（如 marked）生成帶語義標籤的 HTML，可即時預覽。
  • 直接插入 DOM 需防 XSS（對不可信輸入做消毒/沙箱）。
  • 純前端轉換，貼上內容不離開瀏覽器。

💡 常見使用場景

  • 預覽/釋出 Markdown 為網頁。
  • 把文件轉成靜態頁釋出：先轉 HTML 再套模板，適合要自定義樣式的專案文件站。
轉換
`# 標題 - a - b` → `<h1>標題</h1><ul><li>a</li><li>b</li></ul>`。

❓ 常見問題（FAQ）

原始 HTML 會保留嗎？
取決於是否允許 HTML 透傳，預設常轉義。
轉換結果能直接放進頁面嗎？
結構可以，但要注意兩點：若 Markdown 來自使用者輸入，必須過濾（停用原始 HTML 或用白名單消毒），否則等於開放 XSS；另外 Markdown 不產生任何樣式，表格、程式碼塊與引用都需要你自己寫 CSS 才能正常顯示。

Formula & Standard References

Block structure paragraphs, headings, lists, quotes and code blocks map to tags CommonMark specification

Raw HTML inline HTML is allowed by default; sanitize before display CommonMark specification
⚠️ 使用說明與注意事項
  • 支援：#1-6 標題、**粗體**、*斜體*、`行內程式碼`
  • 支援：- 無序列表、數字列表、> 引用、--- 分割線
  • 支援：``` 程式碼塊、| 表格、[連結](url)
  • 轉換純本地進行，文本不會上傳
