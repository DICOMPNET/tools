📄 TOML to JSON Converter

📐 工作原理與說明
TOML 解析：去回車後逐行處理，跳過空行與 # 註釋（# 判定避開成對雙引號內部）；[節名] 按 . 逐級建立巢狀物件，[[陣列名]] 向同名數組追加一個新元素；其餘行取第一個 = 分隔鍵與值，值先剝掉行尾 # 註釋再解析——雙引號串按 \n \t \" 反轉義，true/false 轉布林，純整數轉 parseInt，純小數轉 parseFloat，[ ] 內按逗號遞迴解析為陣列。輸出 JSON 時縮排取 tab 或指定個數的空格（預設 2），勾選排序時按鍵名字典序遞迴重排所有層級的鍵
把 TOML 轉換為 JSON。
  • 對映：TOML 的表與陣列分別轉換為 JSON 物件與陣列。
  • 型別：字串、整數、浮點、布林按對應型別轉換。
  • 日期：TOML 原生支援日期時間型別，而 JSON 沒有，通常序列化為字串。
  • 用途：配置遷移、跨語言資料交換與工具鏈對接。

TOML to JSON Converter - Paste TOML text and convert it to formatted JSON, including [section] and [[array of tables]]. Free, browser-only.

⚠️ 使用說明與注意事項
  • TOML [section] 轉為巢狀 JSON 物件；[[陣列表]] 轉為 JSON 陣列。
  • 字串、整數、浮點、布林、陣列、內聯表都會被正確解析。
  • 結果縮排可選 2/4 空格或 Tab。

❓ 常見問題（FAQ）

日期型別保留嗎？
TOML 的日期時間會轉為字串或對應型別。
為什麼數字變成了字串？
多半是型別資訊在轉換中被保守處理：TOML 有原生日期時間型別，JSON 沒有對應型別，通常會被轉成 ISO 8601 字串；此外超大整數為避免精度丟失也可能以字串輸出。消費端需按欄位自行解析，尤其是日期與 64 位整數。
