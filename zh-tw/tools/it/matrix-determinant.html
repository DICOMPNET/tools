📐 工作原理與說明
矩陣行列式 |A|
二階：|A| = a·d − b·c（主對角積 − 副對角積）
三階（Sarrus 法則）：複製前兩列，主對角方向三積之和 − 副對角方向三積之和
四階及以上：按第一行餘子式遞迴展開 |A| = Σⱼ (−1)^(1+j)·a₁ⱼ·M₁ⱼ
|A| = 0 表示矩陣奇異（不可逆）
行列式是與方陣關聯的一個標量，反映對應線性變換對面積（或體積）的縮放比例。
  • 二階：det = ad − bc。
  • 幾何意義：|det| 是變換後面積（三維為體積）的放大倍數；為 0 說明矩陣奇異、不可逆。
  • 計算：高階矩陣用餘子式展開，或用高斯消元化為上三角後取對角線元素之積。
  • 用途：判斷矩陣是否可逆、求解線性方程組、計算特徵值。

📚 深度解析：矩陣行列式

💡 常見使用場景

  • 判斷方陣可逆性、解線性方程組（克拉默法則）。
  • 判斷線性方程組是否有唯一解：先算係數矩陣的行列式，為 0 則方程相關或無解，不必再往後求逆。
2x2
矩陣 [[a,b],[c,d]] 行列式 = ad−bc；如 [[3,2],[5,7]] → 3·7−2·5=11。

❓ 常見問題（FAQ）

行列式為 0 說明？
矩陣奇異、不可逆，方程組可能無解或無窮解。
大矩陣手工算容易錯怎麼辦？
手算高階行列式確實容易出錯，通常用「初等行變換化成上三角、再取對角線乘積」的辦法，比按行展開省事得多；計算時注意每交換兩行要變號、某行乘以 k 則行列式也乘 k。工程上直接交給數值庫，但要注意接近 0 的行列式可能只是浮點誤差。
