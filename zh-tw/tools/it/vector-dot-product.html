📐 工作原理與說明
向量點積（數量積）
A · B = Σᵢ aᵢ × bᵢ = a₁b₁ + a₂b₂ + … + aₙbₙ（結果為標量）
夾角公式：cos θ = (A·B) ÷ (|A|·|B|)，θ = arccos(…)×180/π
投影長度：|proj_B A| = (A·B) ÷ |B|
幾何判讀：A·B = 0 正交（垂直）｜>0 銳角｜<0 鈍角
計算兩個向量的點積（內積）。
點積按 1e-10 精度顯示；絕對值小於 1e-12 的浮點殘差按 0 顯示（正交相消殘差屬數值噪聲，不代表真實小量）。
  • 代數定義：a·b = Σ aᵢbᵢ，即對應分量相乘後求和。
  • 幾何定義：a·b = |a||b|cosθ，θ 為兩向量夾角。
  • 判定：結果 >0 為銳角、=0 為垂直、<0 為鈍角。
  • 應用：餘弦相似度、物理中功的計算、圖形學光照與投影。

💡 常見使用場景

  • 判斷向量夾角、投影、相似度計算。
  • 做推薦或檢索時衡量相似度：把兩個特徵向量做點積（或歸一化後的餘弦），判斷它們方向上是否接近。
點積
(1,2,3)·(4,5,6)=1·4+2·5+3·6=32。

❓ 常見問題（FAQ）

點積為 0 含義？
兩向量正交（垂直）。
點積和餘弦相似度是一回事嗎？
不完全。點積 = |a||b|cosθ，會受向量長度影響；餘弦相似度再除以兩個模長，只保留方向資訊。因此比較「方向是否接近」時應用餘弦（如文本相似度），而點積同時含長度與方向，適合需要兼顧強度的場景（如注意力權重）。
