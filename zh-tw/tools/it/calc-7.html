🔎 JSON Path Extractor

Extract values from JSON by dot-path (e.g. user.name).

📐 工作原理與說明
JSONPath 求值：把路徑按 . 與 [n] 切分為鍵或下標序列，從根物件 $ 起逐級下鑽。當前值不是物件或陣列時提示該路徑無法繼續訪問；陣列時下標必須是非負整數且不越界（越界提示陣列下標越界）；物件時鍵必須存在（不存在提示鍵不存在）。每步把已走過的路徑拼成可讀軌跡（數字下標寫作 [n]、字串鍵寫作 .key）。結果按所選格式輸出為美化縮排的 JSON 或緊湊形式；輸入 JSON 解析失敗時顯示解析錯誤
用路徑表示式從 JSON 中快速定位並提取欄位。
  • 語法：$ 表示根，點號取屬性（$.a.b），方括號取下標（$.list[0]）。
  • 萬用字元：* 遍歷陣列全部元素或物件全部成員，配合下標可批次取值。
  • 求值：從根物件逐段下鑽，任一段缺失即返回 undefined（可配置嚴格或寬鬆模式）。
  • 用途：在大型 API 響應中定位欄位、做資料抽樣與介面除錯。

📌 路徑語法
  • 點號路徑：user.name 等價於 user['name']。
  • 陣列下標：tags[0]、items[1].id。
  • 根路徑：直接留空可檢視完整 JSON。
  • 僅支援簡單點號與方括號路徑，不支援萬用字元或過濾表示式。

💡 常見使用場景

  • 從巢狀 JSON 中按路徑提取欄位。
  • 從介面響應裡批次取值：用 $.data.list[*].id 一次取出全部 id，比手寫迴圈更省事，也方便在文件裡說明欄位位置。
提取
對 `{"user":{"name":"Tom","age":20}}` 用 `$.user.name` → `Tom`。

❓ 常見問題（FAQ）

$ 表示什麼？
$ 代表根物件，後續用 . 或 [] 下鑽。
鍵名裡有特殊字元怎麼辦？
用方括號加引號：$['user-name']、$['a.b']。點號語法只支援合法識別符號（字母、數字、下劃線且不以數字開頭），遇到連字元、空格、點號或以數字開頭的鍵名必須改用方括號形式，否則會被當作層級解析而取不到值。
