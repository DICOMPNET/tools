🔄 Integer Base Converter

Switch integers across bases (2–36) in your browser for programming, debugging and bitwise work.

📐 工作原理與說明
進位制範圍 2–36，越界自動鉗制；BigInt 按源進位制解析後同時輸出 2 / 8 / 10 / 16 / 32 / 36 進位制結果；支援正負號（如 -255）；不接受 0x/0b/0o 字首；解析失敗時主輸出置 ❌ 並顯示錯誤原因
在 2–36 進位制之間轉換整數。
  • 字母表：0–9 之後用 a–z 表示 10–35，故最高支援 36 進位制；輸出統一小寫，輸入大小寫不敏感。
  • 演算法：任意進位制按權展開求和轉十進位制，再用除基取餘轉目標進位制。
  • 邊界：正負號先行剝離再解析（-255 十進位制等價於 -ff 十六進位制）；本頁只做整數，小數請用浮點轉換工具。
  • 大數：全程 BigInt，超出 2⁵³−1 的整數逐位精確，不經過 Number。

💡 常見使用場景

  • 在 2–36 進位制間互轉大整數。
  • 處理超大整數：把超過 Number.MAX_SAFE_INTEGER 的 ID 在十進位制與十六進位制間轉換，避免用浮點數導致精度丟失。
轉換
255 轉 36 進位制 = `73`（字元 0-9A-Z）；`Z`(36進位制)=35(10)。

❓ 常見問題（FAQ）

超過 36 進位制怎麼表示？
需自定義符號表，標準僅到 36（0-9A-Z）。
為什麼大整數轉出來末尾不對？
多半是用浮點數算的。JS 的 Number 只能精確表示到 2⁵³−1，超過後低位會被舍入，表現為末尾變成 0 或隨機數字。處理大整數應使用 BigInt（或 Python 的任意精度整數），並確認中途沒被 JSON.parse 之類步驟轉回 Number。
