🔤 C / C ++ String Escape

📐 工作原理與說明
先去掉首尾空白，存在成對外層雙引號或單引號時去掉外層引號。逐字元掃描：遇到反斜槓且後面還有字元時，按後隨字元轉義——n 轉換行、r 轉回車、t 轉製表符、b 轉退格、f 轉換頁、v 轉縱向製表符、0 轉空字元、a 轉響鈴、反斜槓與單雙引號與問號轉其自身；x 後連續取最多 2 位十六進位制數字按 16 進位制解析為碼點；後隨字元是八進位制數字時，連續取最多 3 位八進位制數字按 8 進位制解析為碼點；其餘情況取後隨字元本身。不是轉義序列的字元原樣保留
在 C/C++ 字串字面量的轉義形式與真實字元之間雙向轉換。
  • 常見轉義：\n 換行、\t 製表、\r 回車、\\ 反斜槓、\" 雙引號、\0 空字元。
  • 數值表示：八進位制 \nnn（1–3 位）與十六進位制 \xhh；C11/C++ 還支援 \uXXXX。
  • 原始字串：C++11 的 R"(…)" 不做任何轉義，適合寫正則與 Windows 路徑。
  • 陷阱：\x 會貪婪吞掉後續十六進位制字元，超出範圍的值行為由實現定義。

❓ 常見問題（FAQ）

\0 有什麼特殊含義？
\0 是空字元，常用於標記 C 字串結尾。
\x41 和 \101 都能表示 'A' 嗎？
都能。\x41 是十六進位制轉義，\101 是八進位制轉義（101 八進位制 = 65 十進位制 = 'A'）。區別在於十六進位制轉義會一直吃到非十六進位制字元為止，後面緊跟數字或字母 a–f 時容易連讀出錯；八進位制固定最多三位，邊界更明確。
