✨ Basic Auth Generator

Build HTTP Basic Auth headers (user:pass → Base64) in your browser for quick API testing.

📐 工作原理與說明
令牌 = Base64(使用者名稱 + 冒號 + 密碼)；請求頭 = Authorization: Basic + 空格 + 令牌；URL 內嵌形式 = https:// + encodeURIComponent(使用者名稱) + 冒號 + encodeURIComponent(密碼) + @example.com/；使用者名稱與密碼同時為空時清空三項輸出；狀態列顯示令牌字元數
生成 HTTP Basic 認證的 Authorization 頭憑證。
  • 構造：把 用户名:密码 按 UTF-8 編碼後做 Base64，得到憑證串。
  • 請求頭：Authorization: Basic <凭证串>。
  • 安全：Base64 不是加密，憑證等同明文，必須配合 HTTPS，否則等同裸奔。
  • 侷限：無過期與吊銷機制，洩露即長期有效；生產環境優先用可撤銷的 Token / OAuth。

💡 常見使用場景

  • 把 user:pass 編碼為 Authorization 頭。
  • 給內網工具或測試環境快速生成 Authorization 頭，直接貼進 curl -H 或 Postman 的 Header 裡，省去手工拼接與 Base64 編碼。
生成
`user:pass` → `Basic dXNlcjpwYXNz`（Base64，非加密）。

❓ 常見問題（FAQ）

Basic Auth 安全嗎？
須配合 HTTPS，否則明文可被截。
Basic Auth 安全嗎？
只有在 HTTPS 下才算勉強可用。Base64 編碼不等於加密，任何抓包者都能還原出明文使用者名稱與密碼，因此必須配合 TLS；且它沒有登出機制、憑據每次請求都重複傳送，面向公網的系統應改用 OAuth 2.0 或會話令牌。
