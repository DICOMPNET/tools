🔄 IPv6 Address Converter

IPv6 Address Converter - Switch between compressed (::) and full 8-group IPv6 forms. Free, browser-only.

📐 工作原理與說明
地址轉小寫並去空白後按冒號切分。含雙冒號時以第一個空串為界分為左段與右段（各自過濾掉空串），需要補的段數 = 8 − 左段數 − 右段數，結果為負則判為非法；補入相應數量的全零段後按「左段 + 補零段 + 右段」拼成 8 段。不含雙冒號時直接取切分結果。段數不為 8 或任一段不是 1 到 4 位十六進位制數字時判為非法地址。每段前面補 0 到 4 位。輸出完整形式（8 段以冒號連線）、以原始輸入作為壓縮形式，並逐段列出序號與該段內容
IPv6 地址的展開、壓縮與格式轉換。
  • 結構：128 位，寫作 8 組 4 位十六進位制，以冒號分隔。
  • 壓縮：連續的全 0 組可用 :: 代替（全地址中只能出現一次），每組前導 0 可省略。
  • 特殊地址：::1 環回、:: 未指定、fe80::/10 鏈路本地、fc00::/7 唯一本地。
  • 內嵌 IPv4：末 32 位可寫作點分十進位制，如 ::ffff:192.0.2.1。
⚠️ 使用說明與注意事項
  • IPv6 共 128 位，寫成 8 組、每組 4 個十六進位制數字，組間用冒號分隔。
  • 壓縮規則：連續的全 0 段可替換為 ::（一個地址只能壓縮一次），如 2001:db8:0:0:0:0:0:1 → 2001:db8::1。
  • 每組前導 0 可省略（1:0:0:0 寫作 1::），但 :: 只能出現一次，否則無法唯一還原。

壓縮完整
::10000:0000:0000:0000:0000:0000:0000:0001
2001:db8::12001:0db8:0000:0000:0000:0000:0000:0001

❓ 常見問題（FAQ）

:: 代表什麼？
一段或多段全零的壓縮寫法，一個地址中只能用一次。
IPv4 對映地址長什麼樣？
有兩種常見形式：::ffff:192.0.2.1（IPv4 對映的 IPv6 地址，用於雙棧 socket）與 64:ff9b::192.0.2.1（NAT64 的知名字首）。壓縮表示時最後 32 位常寫成點分十進位制，展開成純十六進位制時容易看漏，核對規則時要特別留意。
