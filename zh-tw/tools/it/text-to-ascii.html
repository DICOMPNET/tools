💻 Text to ASCII Converter

Text to ASCII Converter - Show decimal, hex and 8-bit binary for each character. Free, instant, browser-only.

📐 工作原理與說明
按 Unicode 碼點逐字元遍歷（保留完整代理對），大於 127 的字元跳過並累計跳過個數。保留的字元分別輸出十進位制、十六進位制（0x 加兩位大寫十六進位制）與二進位制（轉 2 進位制後前面補 0 到 8 位），空格字元以中點加括號註明。以表格逐行展示字元、十進位制、十六進位制與二進位制；存在跳過的非 ASCII 字元時提示已跳過多少個非 ASCII 字元，並說明本表僅顯示 ASCII 字元
把文本轉換為 ASCII 碼或二進位制表示。
  • 原理：取每個字元的碼點或位元組值，以十進位制或二進位制形式輸出。
  • 範圍：標準 ASCII 為 0–127；超出部分需按 UTF-8 位元組序列或 Unicode 碼點處理。
  • 等價：與十六進位制、八進位制表示資訊量相同，只是進位制不同。
  • 用途：排查字元編碼問題、教學演示與協議分析。

⚠️ 使用說明與注意事項
  • 標準 ASCII 僅定義 0–127；128–255 為擴充套件 ASCII（依賴編碼頁），Unicode 漢字等不在此表。
  • 空格顯示為「·(空格)」便於核對；換行/製表符會顯示其控制字元碼點。
  • 二進位制固定為 8 位（1 位元組）表示。

❓ 常見問題（FAQ）

小寫字母碼點比大寫大多少？
相差 32，如 a=97、A=65。
為什麼有些字元顯示成問號？
因為該字元不在當前字型或編碼範圍內：ASCII 只定義 0–127，超出部分需按 Unicode 處理；若終端或編輯器按單位元組編碼（如 ISO-8859-1）解釋 UTF-8 位元組，多位元組字元就會顯示成亂碼或問號。應先確認檔案編碼，再檢查字型是否包含對應字形。
