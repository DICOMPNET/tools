🗣️ Language Code Query

📐 工作原理與說明
輸入轉小寫後先按 ISO 639-1 兩字母程式碼精確查表；未命中則遍歷語種庫，命中中文名子串、英文名子串（忽略大小寫）或 ISO 639-3 三字母碼三者之一即收錄；結果唯一時輸出 639-1 / 639-3 程式碼、中英名稱、語系與書寫系統，多個時列出全部匹配項
語言程式碼用於標識自然語言，是國際化與本地化的基礎。
  • ISO 639-1：兩位小寫字母程式碼，如 zh、en、ja；ISO 639-2 為三位程式碼（如 zho、eng）。
  • BCP 47：可組合語言、文字與地區，如 zh-Hans-CN、en-US、pt-BR。
  • 回退：找不到精確匹配時逐級回退，如 zh-CN → zh。
  • 用途：決定翻譯選擇、日期與數字格式、以及排序規則。

❓ 常見問題（FAQ）

zh-CN 與 zh？
zh 為語言，zh-CN 含地區變體。
zh-CN、zh-Hans、zh-Hans-CN 該用哪個？
按 BCP 47：語言子標籤（zh）+ 可選書寫系統（Hans/Hant）+ 可選地區（CN/TW）。只關心簡繁體用 zh-Hans；需要區分地區習慣用 zh-CN。服務端匹配應做逐級回退（zh-Hans-CN → zh-Hans → zh），否則使用者會意外落到預設語言。
