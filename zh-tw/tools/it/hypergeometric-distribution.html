🎰 Hypergeometric Distribution

📐 工作原理與說明
超幾何分佈（無放回抽樣）
P(X = k) = C(K,k) · C(N−K, n−k) ÷ C(N, n)
N 總體大小，K 總體中目標物數，n 抽取數，k 抽中目標數
累積概率同二項/泊松：P(X ≤ k) = Σ P(X=i)；P(X ≥ k) = 1 − P(X ≤ k−1)
均值 = n·K/N；方差 = n·(K/N)·[(N−K)/N]·[(N−n)/(N−1)]
描述不放回抽樣中成功次數的機率分佈。
  • 機率：P(X=k) = C(K,k)·C(N−K, n−k) / C(N,n)，N 為總數、K 為成功總數、n 為抽取數。
  • 期望：E[X] = n·K/N；方差含有限總體校正因子 (N−n)/(N−1)。
  • 與二項分佈：超幾何為不放回，二項為有放回；當 N 遠大於 n 時可用二項近似。
  • 場景：抽檢合格數、抽樣調查、卡牌抽牌機率。

📋 超幾何分佈公式

P(X = k) = C(K, k) × C(N−K, n−k) / C(N, n)
性質：
• 均值 E[X] = n × K / N
• 方差 Var[X] = n × (K/N) × ((N−K)/N) × ((N−n)/(N−1))
• 適用場景：無放回抽樣（如撲克牌、批次質檢）
• 與二項分佈區別：每次試驗不獨立（無放回）

📚 深度解析：超幾何分佈計算器

💡 常見使用場景

  • 不放回抽樣（如從 N 件含 K 件次品中抽 n 件）的成功次數。
  • 質檢抽檢：從 1000 件（含 30 件次品）中抽 50 件，算「一件次品都沒抽到」的機率，評估該抽檢方案能否發現問題。
質檢抽樣
N=50,K=5,n=10,k=1：P(X=1)=C(5,1)C(45,9)/C(50,10)≈0.431（約 43.1%）。

❓ 常見問題（FAQ）

超幾何與二項區別？
超幾何不放回、機率隨抽樣變化；二項放回、機率恆定。
什麼時候可以當作二項分佈算？
當總體 N 遠大於抽樣量 n（通常 n/N < 0.05）時，不放回與放回的差異可忽略，用二項分佈近似即可，計算更簡單。抽樣比例較高時必須用超幾何分佈，否則會高估方差、低估抽到次品的機率。
