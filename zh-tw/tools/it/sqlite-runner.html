🗄️ SQLite Runner

📐 工作原理與說明
瀏覽器內用 sql.js 建立記憶體資料庫（new SQL.Database()），按分號切分語句逐條執行並跳過空語句；單條耗時 = performance.now() 前後差值（保留兩位小數 ms），總耗時為各條之和；結果集渲染為表格，異常時按錯誤類別提示。歷史最多保留 10 條
在瀏覽器中直接執行 SQL 語句。
  • 實現：基於編譯為 WebAssembly 的 SQLite 引擎，完全在瀏覽器內執行。
  • 隱私：資料只存在於本地記憶體，不會上傳到任何伺服器。
  • 能力：支援標準 SQL 語法與 SQLite 內建函式，可建表、插入與查詢。
  • 注意：頁面重新整理後資料即丟失，重要結果需及時匯出儲存。

❓ 常見問題（FAQ）




能建表嗎？
可，運行於記憶體庫，重新整理即清空。


資料會儲存嗎？
不會。執行在瀏覽器記憶體（或臨時庫）中，重新整理頁面即丟失，且不上傳任何內容——這是它適合臨時驗證與教學演示的原因，也意味著不能當作持久化儲存使用。需要保留結果請手動匯出 SQL 或 CSV。

📝工具簡介

      
SQLite 線上執行工具基於 sql.js（將 SQLite 編譯為 WebAssembly）實現，在瀏覽器記憶體中執行完整的 SQLite 資料庫引擎。無需安裝任何軟體、無需註冊賬號，開啟網頁即可編寫並執行 SQL 語句，即時檢視查詢結果。所有資料均在瀏覽器本地處理，不會上傳到任何伺服器。

      
✨功能特點

      
    
        
  • 基於 WebAssembly 的完整 SQLite 引擎
    • 
        
  • 支援多條 SQL 語句一次性執行
    • 
        
  • SELECT 結果以表格形式展示
    • 
        
  • 顯示執行耗時與影響行數
    • 
        
  • SQL 關鍵字語法高亮
    • 
        
  • 執行歷史記錄（本地儲存最近 10 條）
    • 
        
  • 一鍵匯出 .sqlite 資料庫檔案
    • 
        
  • 支援深色模式與響應式佈局
    • 
        
  • 純前端執行，資料不上傳
