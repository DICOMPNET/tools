📈 Standard Deviation Calculator

📐 工作原理與說明
標準差計算（總體/樣本）
均值 x̄ = (x₁+x₂+…+xₙ) ÷ n
離差平方和 SS = Σ(xᵢ − x̄)²
總體方差 σ² = SS ÷ n；樣本方差 s² = SS ÷ (n−1)（貝塞爾校正）
標準差 = √方差；樣本標準差需至少 2 個數據
衡量一組資料的離散程度。
  • 總體標準差：σ = √(Σ(xᵢ−μ)² / N)，μ 為總體均值。
  • 樣本標準差：s = √(Σ(xᵢ−x̄)² / (n−1))，分母用 n−1 做貝塞爾校正。
  • 校正原因：用樣本均值 x̄ 代替真實 μ 會低估離散程度，除以 n−1 可得無偏估計。
  • 關係：方差為標準差的平方；標準差越大說明資料越分散。

❓ 常見問題（FAQ）

樣本與總體標準差區別？
樣本除以 n−1（無偏），總體除以 n。
標準差大一定不好嗎？
取決於場景。製造業追求一致性，標準差越小越好；但投資與創新類場景波動本身是特性。判斷時應結合分佈形態：若存在長尾（少數極慢請求），標準差會被放大，此時看 P95/P99 比看標準差更直觀，也更容易與使用者體驗對應。
