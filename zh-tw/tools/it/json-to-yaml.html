📄 JSON to YAML

📐 工作原理與說明
解析 JSON 後遞迴轉 YAML：空值輸出 null；布林直接轉字串；數字按十進位制輸出，指數形態補 .0（1e+21 → 1.0e+21，避免 YAML 1.1 解析器把它當字串）；字串與鍵在空串、純數字、YAML 布林/空值字面量（true/false/null/yes/no/on/off/~/y/n）、.inf/.nan、日期形態、以 - ? : , [ ] { } # & * ! | > ' " % @ ` 開頭、含冒號或空格加井號、含控制字元、首尾帶空白時用雙引號包裹並轉義，否則原樣輸出；空陣列輸出成對的方括號，非空陣列每項以「縮排 + 短橫線 + 空格」開頭並遞迴；空物件輸出成對的花括號，非空物件按鍵逐行輸出「鍵: 值」並對值遞迴縮排；「壓縮」只刪除空行與行尾空白，保留前導縮排，因此層級結構與完整結果等價
本開發工具在前端本地完成解析、轉換與處理，程式碼不離開瀏覽器，遵循對應語法與格式規範。 工具名稱：JSON 轉 YAML - 免費開發工具，線上JSON 轉 YAML，免費使用。

轉換

❓ 常見問題（FAQ）

YAML 對縮排敏感嗎？
是，必須用空格且層級一致。
為什麼轉出來多了引號？
因為該字串在 YAML 中存在歧義：形如 123 的數字串、yes/no/true/false、null、以 * 或 & 開頭、含冒號空格的值，不加引號就會被解析成對應型別或錨點。加引號正是為了保證往返一致；不需要時可手工刪除，但要確認刪後仍能正確解析。
