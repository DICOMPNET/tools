🖥️ Docker Run to Compose Converter

Paste a docker run command and parse the image, ports, volumes, environment and restart policy into a docker-compose.yml snippet. Runs locally.

📐 工作原理與說明
先用 docker run 開頭的正則截取出引數串，再按空白切詞逐項解析：-d 或 --detach 標記後臺執行、--name 取其後為容器名、-p 或 --publish 收集埠對映、-v 或 --volume 收集掛載、-e 或 --env 收集環境變數、--restart 取重啟策略、其餘以 - 開頭的項跳過；首個不以 - 開頭且尚未賦值的詞作為映象名；解析完成後轉換為 compose 配置
把 docker run 命令轉換為 docker-compose 配置。
  • 對映：-p→ports、-v→volumes、-e→environment、--name→container_name、--network→networks。
  • 其他：映象名→image、命令→command、--restart→restart、--link→depends_on/links。
  • 解析：需處理引號包裹與反斜槓續行的多行命令。
  • 輸出：生成 YAML 時注意縮排一致與含特殊字元值的引號包裹。

Formula & Standard References

Item Formula / Note Source / Standard
Flag mapping -p maps to ports, -v to volumes, -e to environment Docker Compose specification
Networks and dependencies --network maps to networks; --link is superseded by depends_on Docker Compose specification
Restart policy --restart takes no, on-failure, always or unless-stopped Docker Compose specification
⚠️ 使用說明與注意事項
  • 支援引數：-d/--detach、-p/--publish、-v/--volume、-e/--env、--name、--restart；其餘未知 - 引數在解析時跳過，可按需手動補到 compose。
  • compose 預設以後臺執行，原 -d 無需對應欄位；restart 策略沿用 unless-stopped / always / no 等原值。
  • 本解析為輕量級：不支援 --network、--link、多值 -e 合併等複雜寫法，生成後請在本地 docker compose config 校驗。

💡 常見使用場景

  • 把 docker run 命令轉 docker-compose。
  • 把線上正在用的 docker run 命令轉成 compose 檔案，固化到倉庫裡，便於團隊復現環境而不是靠口頭傳參。
轉換
`docker run -p 80:80 nginx` → compose `services.web.image=nginx ports=["80:80"]`。

❓ 常見問題（FAQ）

卷怎麼轉？
`-v` 轉為 volumes 對映。
哪些引數轉不了？
compose 與 run 的表達能力不完全對等：複雜網路配置、--security-opt 的細粒度項，以及 shell 裡的變數與管道都需要手工調整。轉換後務必用 docker compose config 校驗結構，並在測試環境實際啟動一次確認行為一致。
