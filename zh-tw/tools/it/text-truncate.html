💻 Text Truncate

📐 工作原理與說明
截斷模式分四種：按字元數取前 limit 個字元，開啟單詞邊界時從第 limit 個字元往前找到最近的空白字元作為終點，一直找不到則回退到 limit；按詞數先按空白切分為詞陣列，取前 limit 個再以空格連線；按行數先按換行切分，取前 limit 行再以換行連線；按位元組數逐字元累加位元組數（中日韓統一表意文字與全形區字元記 2 位元組，其餘記 1 位元組），累加會超過 limit 時停止。開啟從末尾截斷時改為取末尾對應數量的字元、詞或行。發生截斷且設定了省略符時，從末尾截斷把省略符加在前面，否則加在後面。開啟逐行處理且模式不是按行時，先按換行切分再對每一行單獨執行上述截斷
按長度截斷文本並新增省略標記。
  • 處理：達到指定長度後截斷，並在末尾追加省略號或自定義字尾。
  • 字素簇：應按字素簇截斷，避免切在代理對中間產生半個 emoji 或亂碼。
  • 詞邊界：可選擇在詞邊界處截斷，避免把單詞切成兩半。
  • 用途：列表摘要、卡片描述、控制 SEO description 長度。

❓ 常見問題（FAQ）

按位元組還是字元？
可選，中文按字元更友好。
為什麼截斷後出現了半個字？
因為按位元組截斷時切在了多位元組字元中間：UTF-8 下一個漢字佔 3 位元組，從中間切斷會得到無法解碼的位元組序列，顯示為問號或方塊。正確做法是按字元（或字素簇）計數後再截斷；若必須按位元組限制（如簡訊、資料庫欄位），應在字元邊界處回退。
