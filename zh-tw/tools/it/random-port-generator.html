🎲 Random Port Generator - Batch Generate 1024-65535 Random TCP / UDP

Pick a random port number in your browser — handy for local dev and containers.

📐 工作原理與說明
生成個數取輸入值並保證在 1 到 20 之間。迴圈直到湊夠數量或嘗試次數達到 1000 次：每次用加密級隨機數填充一個無符號 32 位整數，埠號 = 1024 + 隨機數對「65535 − 1024 + 1」取餘，即落在 1024 到 65535 之間；開啟避開常用保留埠且命中保留表時跳過；與已生成的埠重複時跳過。最後逐個列出埠並標註協議，同時提示生成個數與是否避開常用保留埠；本工具不檢測埠是否被實際佔用
在 1024–65535 範圍內生成隨機埠號，不檢測埠是否被佔用。
  • 範圍：埠號 0–65535，分公認埠（0–1023）、註冊埠（1024–49151）與動態埠（49152–65535）。
  • 建議：從動態埠段選取，可最大程度避免與已知服務衝突。
  • 許可權：0–1023 為特權埠，繫結需要管理員/root 許可權。
  • 實踐：使用前應實際檢測端口占用情況，避免啟動失敗。

💡 常見使用場景

  • 為本地服務挑一個高位埠（本工具取值 1024–65535，不保證未被佔用）。
  • 本地起多個測試服務時挑一個未被佔用的動態埠，避免寫死 8080 導致並行任務互相搶佔。
生成
隨機 `52341`（落在 1024–65535 範圍內）。

❓ 常見問題（FAQ）

為什麼用高位埠？
1024 以下需特權，動態埠段衝突少。
生成的埠一定沒被佔用嗎？
不一定。本工具在 1024–65535 範圍內隨機取值（含註冊埠段 1024–49151），無法即時感知你機器上哪些埠已被佔用——瀏覽器出於安全限制也不能掃描本機埠。使用前應用 netstat/lsof 確認，或讓程式繫結埠 0 由系統自動分配；若只想要動態埠段，可自行過濾 49152 以上的結果。
