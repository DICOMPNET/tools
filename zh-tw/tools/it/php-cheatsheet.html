❓ 常見問題（FAQ）

PHP 8 型別宣告？
支援引數/返回型別宣告與聯合型別。
為什麼要用預處理語句？
預處理把 SQL 結構與資料分開發給資料庫，資料不會被當作程式碼解析，從根本上避免 SQL 注入；同一語句多次執行時還能複用執行計劃。注意預處理並不覆蓋所有場景——表名、欄位名等識別符號無法引數化，必須走白名單校驗。
