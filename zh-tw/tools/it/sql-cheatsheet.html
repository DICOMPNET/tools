CTE

❓ 常見問題（FAQ）

CTE 與子查詢？
CTE 可讀性好，遞迴 CTE 可處理層級。
為什麼同樣的查詢換個庫就報錯？
因為 SQL 只是標準，各家實現差異很大：日期函式、字串拼接（|| vs CONCAT）、分頁語法（LIMIT vs TOP vs ROWNUM），以及視窗函式的支援程度都不同。跨庫時應儘量用最基礎的語法，並把差異部分隔離在應用層或遷移腳本里。
