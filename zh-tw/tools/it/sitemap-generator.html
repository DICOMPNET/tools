✨ Sitemap Generator

Sitemap Generator - Paste one URL per line to build a standard sitemap.xml with lastmod for search engines. Free, browser-only.

📐 工作原理與說明
生成供搜尋引擎抓取的 XML Sitemap。
  • 欄位：每個 URL 含 loc（地址）、lastmod（最後修改）、changefreq（更新頻率）、priority（優先順序）。
  • 限制：單個 sitemap 最多 5 萬條 URL、未壓縮不超過 50MB；超出需用 sitemap index 分片。
  • 提交：在 robots.txt 中宣告 Sitemap 地址，或通過搜尋引擎站長平臺提交。
  • 說明：sitemap 只是抓取線索，不保證收錄；priority 僅供搜尋引擎參考。
⚠️ 使用說明與注意事項
  • 單 sitemap 最多 50000 條 URL 且檔案不超過 50MB；超限需用 sitemap 索引檔案拆分。
  • URL 必須是絕對地址且可被爬蟲訪問；含非 ASCII 需做百分號編碼。
  • 生成後放到站點根目錄並在 robots.txt 宣告 Sitemap 路徑，再到搜尋引擎後臺提交。

📋 結構

<urlset xmlns=".../0.9">
  <url><loc>https://x/</loc></url>
</urlset>

❓ 常見問題（FAQ）

上限多少？
單檔案 5 萬 URL / 50MB，超出需索引。
生成的 sitemap 一定能被收錄嗎？
不能保證。sitemap 只是「告知」而非「命令」——搜尋引擎會自行判斷是否抓取與收錄；被 robots 遮蔽、返回非 200 或質量過低的頁面即便寫進 sitemap 也不會被收錄。因此應先確保頁面可訪問、內容有獨特價值，並保持 sitemap 與實際狀態一致。
