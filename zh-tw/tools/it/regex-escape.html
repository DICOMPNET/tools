🔤 Regex Expression Character Escape

Escape special regex metacharacters in your browser — turn literal text into a safe pattern.

📐 工作原理與說明
逐字元處理：字元屬於所選風格（基礎或寬鬆）的元字元集合時在其前面加反斜槓；開啟轉義斜槓時斜槓字元同樣加反斜槓；換行輸出為反斜槓 n，回車輸出為反斜槓 r，製表符輸出為反斜槓 t；其餘字元原樣保留
把字串中的正則元字元轉義為字面量。
  • 需要轉義：. * + ? ^ $ { } ( ) | [ ] \ 等。
  • 用途：把使用者輸入安全地拼進正則，避免語法錯誤與正則注入（ReDoS）。
  • 等價函式：各語言內建工具，如 Python 的 re.escape。
  • 注意：不同引擎對 / 與 - 的處理略有差異。

📚 深度解析：正規表示式字元轉義

💡 常見使用場景

  • 把使用者輸入當作字面量匹配時，對其中的 . * + ? 等轉義。
  • 把使用者輸入的關鍵詞當作字面量去搜索：先轉義再拼進正則，否則輸入裡的 . * ( 會被當成元字元導致匹配錯誤甚至崩潰。
轉義 "a.b"
輸入 `a.b` → 輸出 `a\.b`（點號被轉義為字面量）。

❓ 常見問題（FAQ）

為什麼要轉義？
不轉義時 . 會匹配任意字元，導致誤匹配。
手工替換反斜槓為什麼不行？
因為需要處理十幾個元字元（. * + ? ^ $ { } ( ) | [ ] \），以及字元類內部不同的規則，手工替換極易遺漏；不同引擎的元字元集合還略有差異。應使用語言內建函式（如 Python 的 re.escape、JS 的轉義輔助函式）來保證完整覆蓋。
