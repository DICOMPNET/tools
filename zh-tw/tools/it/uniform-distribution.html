📏 Uniform Distribution

📐 工作原理與說明
均勻分佈 X ~ U(a, b)
機率密度 PDF：f(x) = 1/(b−a)（a ≤ x ≤ b），區間外為 0
分佈函式 CDF：F(x) = 0（x < a）｜(x−a)/(b−a)（a ≤ x ≤ b）｜1（x > b）
區間機率 P(c ≤ X ≤ d) = [min(d,b) − max(c,a)] ÷ (b−a)
均值 = (a+b)/2；方差 = (b−a)²/12；中位數 = 均值 = (a+b)/2
計算均勻分佈的機率與數字特徵。
  • 連續型：在區間 [a,b] 上機率密度恆為 1/(b−a)，區間外為 0。
  • 機率：P(c < X < d) = (d−c)/(b−a)，僅與區間長度有關。
  • 數字特徵：期望 E[X] = (a+b)/2，方差 Var = (b−a)²/12。
  • 離散型：有限個取值機率相等，如擲均勻骰子每面機率均為 1/6。

📋 均勻分佈公式

f(x) = 1/(b−a) 當 a ≤ x ≤ b，否則 0  |  F(x) = (x−a)/(b−a)
性質：
• 均值 E[X] = (a+b)/2
• 方差 Var[X] = (b−a)²/12
• 適用場景：等可能性事件，如擲骰子、隨機抽樣、四捨五入誤差

💡 常見使用場景

  • 區間 [a,b] 內等可能取值的機率與期望。
  • 估算排隊或輪詢等待：若在 [a,b] 區間內均勻到達，平均等待為 (a+b)/2，據此設定超時與容量。

❓ 常見問題（FAQ）

均勻分佈的密度？
區間內恆為 1/(b−a)，區間外為 0。
現實中真的有均勻分佈嗎？
真正的均勻分佈不多，它更多是「對未知的最保守假設」（最大熵假設）。實際資料常是正態、指數或偏態的：比如使用者到達常是泊松過程（間隔服從指數分佈），而非均勻。用錯分佈會導致容量估算偏差，因此應先用真實資料擬合再選模型。
