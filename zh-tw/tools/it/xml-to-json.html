轉換
`<name>Tom</name>` → `{"name":"Tom"}`。

❓ 常見問題（FAQ）

屬性怎麼轉？
常加 @ 字首，如 `<a id="1">` → `{"a":{"@id":"1"}}`。
為什麼單個元素有時是物件有時是陣列？
這是 XML 轉 JSON 的經典問題：XML 無法表達「陣列」概念，轉換器只能按出現次數推斷，導致同一欄位在只有一項時是物件、多項時是陣列，消費端程式碼容易出錯。解決辦法是在轉換時顯式宣告哪些路徑強制為陣列，或在消費端統一做歸一化處理。
