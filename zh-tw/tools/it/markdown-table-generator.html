📝 Markdown Table Generator

Generate Markdown table syntax from rows, columns, and content.

📐 工作原理與說明
行數取輸入值並保證在 1 到 50 之間（非法時取 1），列數取輸入值並保證在 1 到 20 之間（非法時取 1）。表頭與正文種子均按 CSV 規則切分：英文逗號分隔，單元格可用雙引號包裹以容納逗號（"" 表示一個字面引號）；未加引號的欄位去首尾空白，引號內的首尾空格會保留並以   在 Markdown 中明示。未閉合雙引號會報錯並停止生成。填充單元格時按順序取種子值，取不到時用「C 加列序號」佔位，並對內容做 Markdown 轉義：先把反斜槓轉義為雙反斜槓，再把豎線轉義為反斜槓加豎線，最後把換行換成空格。分隔行按對齊方式生成標記。正文每行在種子值後追加行序號。CSV 匯出預設對 = + - @ 開頭的非數值單元格加單引號防公式注入，並可選 UTF-8 BOM。
生成 Markdown 格式的表格。
  • 結構：表頭行 + 分隔行（| --- | --- |）+ 資料行。
  • 對齊：分隔行寫 :--- 左對齊、---: 右對齊、:---: 居中。
  • 轉義：單元格內的豎線需寫作 \|，否則會被當作列分隔。
  • 用途：在 README 與文件中清晰呈現引數、對照表與結果資料。
  • CSV 匯出：預設中和 = + - @ 開頭的非數值內容（防公式注入），可選 Excel 相容 BOM；負數與普通文本保持原樣。

❓ 常見問題（FAQ）

對齊怎麼設？
`:---` 左、`:--:` 中、`---:` 右。
單元格里有豎線怎麼辦？
需要轉義成 \|，否則會被當作列分隔符破壞整行結構，這是 Markdown 表格最常見的坑。另外單元格內換行在標準 Markdown 裡無法直接表達，通常改用 <br> 標籤（但部分平臺會轉義 HTML），或拆成多行記錄。
