📄 JSON to CSV

Convert JSON arrays or objects into CSV-ready tables right in your browser — no upload, no server round-trip.

📐 工作原理與說明

將 JSON 物件陣列展平為二維表格的邏輯:

  • 巢狀物件或陣列會被序列化為 JSON 字串填入對應單元格（例如 {"a":1} 顯示為 {"a":1}），不展開為多列。
  • 每個陣列元素輸出一行;值轉為字串(布林、數字、日期原樣)。
  • null / 缺失欄位留空;巢狀陣列同樣序列化為 JSON 字串填入單元格（不按索引展開為多列）。

匯出建議帶 UTF-8 BOM,以便 Excel 正確識別中文不亂碼。全程純前端解析,資料不上傳。

複製 / 下載的 CSV 會給以 = + - @ 開頭的單元格自動加單引號字首，防止 Excel / WPS 將其當作公式執行；頁面預覽保持原始資料。

💡 常見使用場景

  • 把物件陣列匯出為表格便於 Excel 開啟。
  • 給運營匯出資料：把介面返回的物件陣列轉成 CSV，讓同事可以直接用 Excel 開啟篩選。
轉換
`[{"a":1,"b":2},{"a":3,"b":4}]` → 表頭 a,b 兩行資料。

❓ 常見問題（FAQ）

巢狀欄位怎麼處理？
巢狀物件或陣列會被序列化為 JSON 字串填入對應單元格（例如 {"a":1} 顯示為 {"a":1}），不會展平成多列。
為什麼 Excel 開啟是亂碼？
因為編碼不匹配：中文 CSV 存成 UTF-8 時，Excel 預設按本地編碼（GBK）開啟就會亂碼。解決辦法是匯出時加 UTF-8 BOM，或在 Excel 裡用「資料 → 自文本」手動指定編碼。另外以 0 開頭的編號與長數字串被自動轉成數字，也需設為文本格式。
