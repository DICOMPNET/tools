📖 什麼是 TSV？

TSV（Tab-Separated Values，製表符分隔值）是一種簡單的文本檔案格式，用製表符（Tab）分隔各列資料。與 CSV 相比，TSV 更少出現分隔符衝突問題，因為資料中很少包含 Tab 字元。

💡 使用場景

• 資料匯出匯入：Excel、Google Sheets 等電子表格軟體支援 TSV 格式

• API 資料處理：將 JSON 介面資料轉為 TSV 方便分析

• 日誌分析：將結構化日誌轉成表格形式檢視

• 資料遷移：不同系統之間的資料交換

• 資料庫匯出：將查詢結果匯出為 TSV 方便分享

📝 JSON → TSV 示例

輸入 JSON 陣列：

[
  {
    "name": "张三",
    "age": 25,
    "city": "北京"
  },
  {
    "name": "李四",
    "age": 30,
    "city": "上海"
  }
]

輸出 TSV（Tab 分隔）：

name	age	city
张三	25	北京
李四	30	上海

⚠️ 注意事項

• JSON 必須是合法的陣列格式，每個元素為物件

• TSV 中如果值包含 Tab 字元，會被自動替換為空格

• 巢狀物件或陣列會被轉為 JSON 字串形式

• 所有處理都在瀏覽器本地完成，資料不會上傳到伺服器

❓ 常見問題（FAQ）

TSV 與 CSV 區別？
TSV 用 分隔，欄位內逗號無需轉義。
欄位裡有製表符怎麼辦？
TSV 的弱點正在於此：分隔符是製表符，而它不像 CSV 有普遍遵循的引號轉義約定，不同解析器行為不一。穩妥做法是在轉換前把值裡的製表符與換行替換成空格，或乾脆改用 CSV（有 RFC 4180 明確定義的轉義規則）。
