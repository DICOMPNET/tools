📄 YAML to JSON Converter

📐 工作原理與說明
YAML 解析由本地 js-yaml 4.1.1 完成：完整支援引號鍵、錨點/別名、塊標量與行內註釋，複雜鍵不再被靜默丟棄；僅支援單文件，檢測到 --- 多文件時直接報錯。輸出 JSON 縮排可選 tab 或 2/4 空格；勾選排序時按鍵名字典序遞迴重排所有層級的鍵
把 YAML 轉換為 JSON。
  • 對映：YAML 的對映與序列分別轉為 JSON 物件與陣列。
  • 型別：YAML 的布林、數字與 null 會被轉為對應的 JSON 型別。
  • 錨點：YAML 的錨點（&）與別名（*）在轉換時展開為實際內容。
  • 限制：複雜鍵、多文件等 YAML 特性無法直接對映為單一 JSON，需預先處理。

⚠️ 使用說明與注意事項
  • 轉換結果可直接貼上進 JSON 配置、REST 請求體或程式碼。
  • 支援常見 YAML 子集：對映、列表、標量（字串/數字/布林/null）、塊標量（| / >）與行尾註釋；不支援錨點、多文件等高階特性。
  • 縮排可選 2/4 空格或 Tab，便於對接不同程式碼風格。

❓ 常見問題（FAQ）

YAML 註釋會保留嗎？
JSON 無註釋，轉換後註釋丟失。
為什麼鍵的順序或型別變了？
順序上，YAML 對映解析後通常保持插入順序，但部分庫會按字典序重排，若下游依賴順序需留意。型別上，YAML 的 yes/no、on/off、~ 會被解析為布林與 null，轉成 JSON 後就是 true/false/null 而非字串；若期望字串，應在 YAML 中加引號。
