🗜️ JS Minifier

JS Minifier - Remove comments and extra whitespace from JavaScript for a quick size reduction, without renaming variables. Free, browser-only.

📐 工作原理與說明
依次執行：刪除塊註釋；刪除行註釋；把連續空白壓縮為單個空格；去掉等號、加號、減號、乘號、除號、取餘、尖括號、花括號、逗號、分號、冒號、圓括號與方括號等符號兩側的空白；再次壓縮空白並去掉首尾空白
壓縮 JS 程式碼以減小體積。
  • 手段：去空白與註釋、縮短識別符號、刪除不可達程式碼、合併常量。
  • 驗證：壓縮後必須做功能迴歸，確認行為未改變。
  • 疊加：與 gzip/brotli 傳輸壓縮疊加使用，收益更明顯。
  • 許可：保留 /*! … */ 形式的許可宣告，滿足開源協議要求。

⚠️ 使用說明與注意事項
  • 本壓縮為「安全型」：只去註釋與空白，不重新命名變數、不改作用域，幾乎不改變行為。
  • 真正的生產壓縮應交給 Terser/esbuild：會做變數重新命名、死程式碼消除、常量摺疊，體積更小但不可讀。
  • 壓縮會刪除版權/許可證註釋，若需保留請用 /*! 開頭的重要註釋（本工具一併移除，釋出前請確認）。

📋 建議

僅做快速瘦身可用本工具；CI 流水線裡推薦整合 Terser 以獲得更優壓縮率與 tree-shaking。

❓ 常見問題（FAQ）

ESM 能壓縮嗎？
能，現代壓縮器支援 ESM 語法。
壓縮會破壞 ES Module 的 tree-shaking 嗎？
順序很關鍵：應先由打包器（Rollup/esbuild）做模組解析與 tree-shaking，再對最終產物壓縮。若先把每個模組單獨壓縮，副作用標記與匯出資訊可能丟失，導致本可剔除的程式碼被保留。壓縮器一般只做區域性等價變換，不做跨模組分析。
