❓ 常見問題（FAQ）

格式化改變含義嗎？
不改變結構，但可能改變混合內容的空白。
為什麼格式化後多了或少了空格？
因為 XML 中混合內容（元素裡既有文本又有子元素）時，空白是否有意義取決於具體語義：對純資料型 XML，縮排空白通常無意義；但對含文本段落的文件，空白會影響渲染。因此格式化純配置檔案安全，格式化含文本的文件需謹慎，或使用 xml:space 宣告。
