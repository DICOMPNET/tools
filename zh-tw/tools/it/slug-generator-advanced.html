📐 工作原理與說明
處理鏈：先規範化變音符號；中文拼音模式使用本地拼音庫按上下文轉寫，音節之間新增分隔符，無法轉寫的漢字以 Unicode 編碼保留並提示。可選轉為 X 或移除中文；再按設定處理大小寫、停用詞、符號、分隔符、長度與隨機 ID。拼音可能受多音字影響，使用前請核對。
生成 URL 友好的 Slug 標識。
  • 處理流程：轉小寫 → 去除變音符號（如 é→e）→ 非字母數字替換為連字元 → 合併連續連字元 → 去除首尾連字元。
  • 中文：可轉為拼音或 X；兩個選項均未啟用時會移除中文。
  • 引數：可指定分隔符、最大長度、是否保留數字與停用詞。
  • 用途：生成可讀且利於 SEO 的文章、商品與分類連結。

❓ 常見問題（FAQ）

中文怎麼 slug？
通常拼音化或保留 Unicode，視 SEO 策略。
為什麼不要把中文轉成拼音？
取決於場景：拼音可讀但存在多音字歧義，且部分使用者更習慣在 URL 裡看到原文（瀏覽器會顯示為百分比編碼，實際可讀性尚可）。更重要的是「穩定性」——一旦釋出就不要再改 slug，否則會產生死鏈。因此應先確定規則並保持一致，而不是中途切換策略。
