📐 工作原理與說明
向量模長（範數）
|v| = √(v₁² + v₂² + … + vₙ²)
單位向量（方向不變、模長為 1）：v̂ = v ÷ |v|
二維方向角：θ = atan2(y, x) × 180/π
三維方向餘弦：cos α = v₁/|v|、cos β = v₂/|v|、cos γ = v₃/|v|
零向量（|v|=0）無單位向量
向量模長（範數）表示向量的長度。
結果按 1e-10 精度顯示；絕對值小於 1e-12 的浮點殘差按 0 顯示（該殘差屬數值噪聲，不代表真實小量）。
  • 公式：|v| = √(v₁² + v₂² + … + vₙ²)，即各分量平方和再開方。
  • 低維：二維即勾股定理 √(x²+y²)，三維為 √(x²+y²+z²)。
  • 歸一化：v/|v| 把向量縮放到長度 1，只保留方向資訊。
  • 用途：計算距離、向量歸一化、比較向量相似度。

💡 常見使用場景

  • 求向量長度/距離，歸一化前先算模。
  • 計算兩點距離或做向量歸一化前的準備：先算出模長，再把向量除以它得到單位方向向量。

‖(3,4)‖=√(3²+4²)=5。

❓ 常見問題（FAQ）

歸一化怎麼做？
向量除以其模長得到單位長度。
為什麼要歸一化？
因為很多運算只關心方向不關心長度：光照計算中的法向量、相似度比較中的特徵向量、梯度下降中的方向都需要單位長度，否則數值會被模長干擾、不同樣本之間也不可比。歸一化就是把向量除以自身模長，得到長度為 1 的同向向量。
