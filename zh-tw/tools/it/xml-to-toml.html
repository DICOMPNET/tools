📄 XML to TOML Converter

📐 工作原理與說明
XML 側：剔除註釋、處理指令並把 CDATA 還原為文本，逐元素取頭部標籤名與屬性（([\w:-]+)\s*=\s*"([^"]*)"），屬性值與文本統一做實體解碼（&amp; &lt; &gt; &quot; &apos; 與 &#NN; / &#xNN;，只解一層），按標籤名分組，同名單個取單值、多個取陣列，屬性以 @ 字首、文本以 #text 存放。TOML 側輸出：鍵名匹配 ^[A-Za-z0-9_-]+$ 時原樣寫，否則加雙引號並轉義反斜槓與引號；值為空寫 ""，布林寫 true/false，數字直接寫字串，陣列寫 [a, b]，其餘加雙引號轉義；表頭路徑逐段轉義後以點號拼接，表陣列寫 [[父表.子鍵]]；同一表先寫標量鍵再寫子表，可選按鍵名字典序排序
把 XML 轉換為 TOML。
  • 對映：XML 元素名成為 TOML 的鍵，巢狀元素成為子表。
  • 陣列：重複的兄弟元素通常轉換為 TOML 陣列。
  • 屬性：元素屬性可作為鍵值，或用字首區分以避免與子元素重名。
  • 用途：配置格式遷移與系統間資料對接。

Convert XML documents into TOML, mapping nested elements to tables for configuration workflows.

Formula & Standard References

Item Formula / Note Source / Standard
Hierarchy mapping parent-child elements become tables; leaves become keys W3C XML 1.0 / TOML v1.0.0
Repeated children repeated siblings map to arrays of tables TOML v1.0.0
Attributes attributes have no native form; demote to keys or drop TOML v1.0.0
⚠️ 使用說明與注意事項
  • XML 屬性轉為 TOML 中以 @ 開頭的鍵；重複同名子元素轉為 TOML 陣列。
  • TOML 不支援 XML 的屬性和混合內容的全部語義，轉換按約定歸一化。
  • 極複雜 XML 建議人工核對。

❓ 常見問題（FAQ）

深層巢狀怎麼轉？
用 [section] 表層級表示。
為什麼轉換結果不完整？
因為兩種模型不對等：XML 有屬性與混合內容、允許同名元素重複出現，TOML 只有表、陣列與標量。屬性與重複元素需靠約定對映（如屬性轉欄位、重複元素轉陣列），不同工具約定不同。跨系統使用時應先用小樣例驗證，並在遷移後做一次回讀校驗。
