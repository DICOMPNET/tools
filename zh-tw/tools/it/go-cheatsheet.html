❓ 常見問題（FAQ）

defer 何時執行？
函式返回前按後進先出執行。
goroutine 洩漏怎麼避免？
核心是保證每個 goroutine 都有退出路徑：用 context 傳遞取消訊號、給 channel 操作加 select + ctx.Done() 分支、並確保傳送方最終會關閉 channel。常見於等待一個永遠沒人寫入的 channel——可用 pprof 觀察 goroutine 數量是否持續增長。
