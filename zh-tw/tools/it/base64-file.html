🔤 Base64 File Converter

📐 工作原理與說明
按逗號切分輸入，第一段若形如「data: 型別 ; 後續內容」則取其中的媒體型別，否則按通用二進位制流型別處理；資料部分為逗號之後的所有內容（沒有逗號時取整串）。對資料做 Base64 解碼得到二進位制字串，逐字元取字元編碼填入無符號 8 位陣列，再按解析出的媒體型別構造二進位制大物件，據此生成臨時下載連結；下載檔名以「decoded.」加按媒體型別查表得到的標準副檔名（text/plain→txt、image/jpeg→jpg、image/svg+xml→svg、vnd.openxmlformats 系列→docx/xlsx/pptx），未收錄的型別先去掉 + 語法字尾與 x-/vnd. 字首再取末段，仍取不到時用 bin；隨後釋放該連結。輸出還原後的位元組數（按易讀大小格式化）、媒體型別與實際檔名；解碼失敗時提示 Base64 無效
把本地檔案與 Base64 文本互相轉換，可產出可直接嵌入頁面的 Data URL。
  • 讀取：用 FileReader 讀為 ArrayBuffer 或 DataURL，再按 Base64 規則編碼位元組流。
  • Data URL：格式為 data:<MIME>;base64,<编码内容>，可直接作為 img/src 或下載連結。
  • 體積：編碼後膨脹約 33%，大檔案建議分片並放在 Worker 中處理，避免阻塞主執行緒。
  • 解碼：剝離 Data URL 字首後按 Base64 還原位元組，再構造 Blob 觸發下載。

📚 深度解析：檔案轉 Base64（Data URI）

💡 常見使用場景

  • 把小圖示 / 圖片內聯為 data URI，嵌入郵件或單檔案 HTML，避免額外請求。
  • 上傳前在瀏覽器本地預覽檔案內容，不把檔案發到伺服器。
  • 把證書、字型等二進位制資源轉成可貼上的文本形式。
圖片轉 Data URI
選擇一個 PNG 檔案，工具在本地讀取並輸出 data:image/png;base64,iVBORw0KGgo... 形式字串，可直接放入 <img src="..."> 或 CSS background。

❓ 常見問題（FAQ）

Data URI 有大小限制嗎？
瀏覽器和郵件系統對 URL / data URI 長度有限制（常見幾 MB 到幾十 MB 不等），大檔案應改用普通檔案連結而非內聯，否則可能截斷或拖慢頁面。
內聯圖片會影響效能嗎？
Data URI 省了一次請求，但無法被瀏覽器單獨快取、且體積比原檔案大約 33%，適合小圖示；大圖仍建議用獨立檔案 + 快取。
