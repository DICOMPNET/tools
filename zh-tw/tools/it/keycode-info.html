📚 Keyboard Key Code Inspector

Look up keyboard key codes (key, code, keyCode) in your browser — handy for event handlers.

📐 工作原理與說明
監聽全域性按鍵按下事件：按鍵名為空格時按 Space 展示，為製表符時按 Tab 展示，其餘取按鍵名本身。分別展示按鍵名、物理鍵位編碼、原始按鍵值與傳統鍵碼（已廢棄）。修飾鍵狀態按 Ctrl、Shift、Alt、Meta 的順序收集並以加號連線，一個都沒有時顯示無。不攔截任何按鍵的預設行為，Tab 焦點切換、空格與方向鍵滾動、F12 等瀏覽器快捷鍵均保持原生可用；結果區文案按當前語言輸出
查詢鍵盤按鍵的編碼標識。
  • 三套標識：event.key（字元或鍵名）、event.code（物理鍵位）、keyCode（已廢棄的數字）。
  • 推薦：新程式碼應使用 key 與 code；keyCode 已廢棄且受鍵盤佈局影響。
  • code 示例：KeyA、Digit1、Space、Enter、ArrowUp，不隨輸入法與佈局改變。
  • 組合鍵：配合 shiftKey、ctrlKey、altKey、metaKey 判定。

📚 深度解析：按鍵碼 Keycode 查詢

💡 常見使用場景

  • 查鍵盤事件的 keyCode/code/key。
  • 寫快捷鍵時確認鍵值：查清 event.code（物理按鍵）與 event.key（實際字元）的區別，避免在不同鍵盤佈局下失效。
查
回車 Enter → key="Enter"、code="Enter"、keyCode=13。

❓ 常見問題（FAQ）

keyCode 棄用了嗎？
是，建議用 code/key。
為什麼在不同鍵盤上結果不一樣？
因為 keyCode 反映的是按鍵產生的字元碼，會受佈局、輸入法與修飾鍵影響；code 反映的是物理鍵位（如 KeyQ 永遠是 Q 那個位置）。做遊戲或全域性快捷鍵應用 code，做文本輸入判斷用 key。另外 Mac 上 meta 與 ctrl 的語義與 Windows 不同。

📊 結果解讀

結果含義

按鍵碼查詢返回按鍵對應的 event.key（字元）、event.code（物理鍵位）與舊式 keyCode 值，用於鍵盤事件除錯。

用途

前端監聽 keydown/keyup 時核對按鍵標識；注意 keyCode 已廢棄，新程式碼優先用 code/key。

注意

不同鍵盤佈局/輸入法下 key 值可能變化；code 反映物理位置更穩定。
