📐 工作原理與說明
先去掉首尾空白；以單引號開頭時判為單引號字串，否則判為雙引號字串，存在成對外層引號時去掉外層引號。單引號模式直接把「反斜槓 + 任意字元」替換為該字元本身。雙引號模式逐字元掃描：遇到反斜槓且後面還有字元時，按後隨字元轉義——n 轉換行、r 轉回車、t 轉製表符、v 轉縱向製表符、f 轉換頁、e 轉 ESC 字元、反斜槓與雙引號與美元符號轉其自身；x 取後隨 2 位十六進位制解析為碼點；u 後隨左花括號時取到右花括號之間的十六進位制解析為碼點並跳到右花括號之後，否則取後隨 4 位十六進位制；後隨字元是八進位制數字時，連續取最多 3 位八進位制數字按 8 進位制解析為碼點；其餘情況取後隨字元本身。不是轉義序列的字元原樣保留
PHP 字串字面量的轉義與反轉義。
  • 轉義序列：\n \t \r \" \\ \$ \xHH \OOO \u{XXXX}。
  • 引號差異：雙引號解析變數與轉義序列，單引號只識別 \\ 與 \'。
  • 陷阱：雙引號中的 $ 會被當作變數起始，需寫作 \$。
  • 安全：輸出到 HTML 用 htmlspecialchars，寫入資料庫應使用預處理語句。

❓ 常見問題（FAQ）

單引號字串轉義規則不同嗎？
是，單引號只轉義 \ 和 ' 自身。
雙引號裡 $ 會怎樣？
雙引號字串會解析變數：$name 會被替換成變數值，\$ 才表示字面量的美元符號。因此來自使用者的文本若含 $，直接放進雙引號可能導致意外解析甚至資訊洩露。穩妥做法是優先用單引號字串，或用 nowdoc 避免解析。
