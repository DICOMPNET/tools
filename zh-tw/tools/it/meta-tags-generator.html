✨ Meta Tags Generator

Meta Tags Generator - Generate SEO and social share (Open Graph / Twitter Card) meta tags from title, description, URL and image. Free, browser-only.

📐 工作原理與說明
讀取標題、描述、網址、圖片地址四項輸入。按固定順序拼裝標籤：頁面標題標籤、頁面描述元資訊，以及開放圖譜協議的標題、描述、型別（固定為 website）、網址、圖片，再拼裝推特卡片型別（固定為大圖摘要）、推特標題、推特描述與推特圖片。輸出時對整段 HTML 做轉義後在程式碼塊中展示
生成頁面頭部 meta 與社交分享標籤。
  • 基礎：title、description、keywords、viewport、robots、charset。
  • 社交：Open Graph 的 og:title/og:description/og:image/og:url，以及 Twitter Card 的 twitter:card 等。
  • 建議：description 控制在 150–160 字元，過長會被搜尋結果截斷。
  • 必需：viewport 是移動端正確適配的前提，缺失會觸發桌面版縮放。

⚠️ 使用說明與注意事項
  • OG 圖片建議 1200×630 畫素、小於 1MB，過小的圖在部分平臺不展示大卡。
  • og:type 文章用 article、影片用 video.other；本工具預設 website。
  • 改完可用社交平臺偵錯程式（如 Facebook Sharing Debugger）預覽卡片抓取效果。

❓ 常見問題（FAQ）

og 與 twitter 區別？
og 為 Open Graph（Facebook 等），twitter 為卡片。
description 會影響排名嗎？
通常不直接影響排名，但會顯著影響點選率——搜尋結果裡展示的很可能就是這段描述。寫得具體、能回答使用者意圖的描述會提升點選；留空則由搜尋引擎自行摘取正文，往往不理想。注意不同頁面的 description 應各不相同，重複描述會被視為低質量訊號。
