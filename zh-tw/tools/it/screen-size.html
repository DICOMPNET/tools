Screen Size

📐 計算公式
對角線畫素 = √(寬畫素² + 高畫素²)；PPI 畫素密度 = 對角線畫素 ÷ 對角線英寸（1920 × 1080、24 英寸約 92 PPI）；物理寬 = 對角線 × 寬畫素 ÷ 對角線畫素，物理高同理；PPI 只是密度；是否覺得細膩需結合實際觀看距離、視力與內容判斷；螢幕面積 = 物理寬 × 物理高，長寬比 = 寬畫素 ÷ 高畫素。

Screen Size

Viewing distance is used only to estimate angular pixel density (pixels per degree), assuming the eye is centered on the screen. Whether it is “sharp enough” also depends on vision, content and context; this tool gives no sharp/not-sharp verdict.

📐 計算公式

對角線畫素 = √(寬² + 高²)

PPI = 對角線畫素 ÷ 對角線英寸

每英寸物理寬 = 解析度寬 ÷ PPI

長寬比 = 寬 : 高（化簡）

點距 = 25.4 ÷ PPI（mm）

提示：PPI 越高畫素越密；是否「夠清晰」取決於觀看距離、視力與內容，不能用 300/200 的統一閾值斷言。可在上方填寫觀看距離估算畫素/度。長寬比化簡使用最大公約數。

💡 常見使用場景

  • 選購顯示器/手機/投影時由解析度與對角線算 PPI，判斷清晰度是否夠用。
  • 對比同分辨率不同尺寸（如 24 寸 1080p vs 27 寸 1080p）的畫素密度差異。
  • 換算實際顯示寬高（英寸/釐米）與寬高比，確認桌面或壁掛適配。
以「解析度 1920×1080、對角線 23.8 英寸」為例
對角線畫素=√(1920²+1080²)≈2202.9，PPI=2202.9/23.8≈92.56；實際顯示寬=1920/92.56≈20.74 英寸、高≈11.67 英寸；寬高比=1920:1080 化簡 16:9；點距=25.4/92.56≈0.274mm。若換 27 寸 2560×1440，PPI 升至 108.79，文字更細膩。

❓ 常見問題（FAQ）

PPI 多高算清晰？
約 90–110 PPI 為常見桌面舒適區間；手機因觀看距離近常 400+ PPI。同分辨率尺寸越小 PPI 越高（畫素越密），但過小傷眼；投影或電視因觀看距離遠，PPI 低也夠清晰。
寬高比怎麼從解析度得到？
對寬高求最大公約數化簡，如 1920/1080 的 gcd=120→16:9；超寬 3440×1440→43:18（約 21:9）。它決定畫面形狀，影響電影黑邊與多窗口布局。
