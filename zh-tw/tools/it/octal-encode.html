🔤 Octal Encode

Encode text as octal values and decode octal back to text, entirely in your browser.

📐 工作原理與說明
把文本按 UTF-8 編碼為位元組序列，逐位元組轉 8 進位制並在前面補 0 到 3 位；開啟字首選項時在每段前加反斜槓；最後用所選分隔符依次連線輸出
把文本轉換為八進位制表示。
  • 原理：每個位元組用 3 位八進位制數表示，取值範圍 000–377。
  • 常見場景：Unix 檔案許可權、C/Go 語言的字元轉義、早期系統的字元表示。
  • 編碼：取字元碼點或 UTF-8 位元組值轉八進位制，常用空格或反斜槓分隔。
  • 解碼：按分隔符切分後逐段還原為字元。

💡 常見使用場景

  • Unix 檔案許可權（如 0644）、早期系統轉義常用八進位制。
  • 閱讀 chmod 數字或 C 語言 \ooo 轉義時用到。
編碼 "A"
輸入 `A` → 輸出 `101`（八進位制 0101 = 十進位制 65）。

❓ 常見問題（FAQ）

八進位制和許可權位如何對應？
644 即 owner 讀4+寫2=6、group 讀4、other 讀4。
為什麼許可權用三位八進位制？
因為 Unix 許可權正好分三組（屬主、屬組、其他），每組用 rwx 三個位表示，正好一個八進位制數字（0–7）：4=讀、2=寫、1=執行，相加組合。因此 0644 表示屬主可讀寫（6=4+2）、屬組與其他只讀（4）。前面的 0 是八進位制字面量字首，不是許可權位。
