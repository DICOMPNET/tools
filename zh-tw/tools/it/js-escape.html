🔤 JavaScript String Escape

Escape and unescape JavaScript string literals in your browser — embed strings in code safely.

📐 工作原理與說明
按所選引號（單引號或雙引號）包裹輸出。逐字元處理：反斜槓轉為兩個反斜槓；與所選引號相同的字元前加反斜槓；換行、回車、製表符、退格、換頁、縱向製表符與空字元分別轉為對應的反斜槓簡寫；其餘字元在碼點小於 0x20，或開啟 Unicode 選項且碼點大於 0x7E 時，輸出反斜槓 u 形式的轉義；其餘字元原樣保留
JavaScript 字串字面量的轉義與反轉義。
  • 轉義序列：\n \t \r \" \' \\ \b \f \v \0 \xHH \uXXXX。
  • 碼點：ES6 起可用 \u{XXXXX} 表示超出 BMP 的字元（如 emoji）。
  • 模板串：反引號字串支援多行與 ${} 插值，其中的反引號與 ${ 需轉義。
  • 用途：把文本安全嵌入 JS 字面量，避免語法錯誤與注入風險。

💡 常見使用場景

  • 把含引號、換行、Unicode 的文本安全嵌入 JS 字面量。
  • 生成內聯指令碼時把使用者輸入轉義成字面量，避免字串裡的引號提前閉合造成語法錯誤或注入。
轉義含引號文本
輸入 `He said "Hi"` → 輸出 `He said "Hi"`（雙引號前加反斜槓）。

❓ 常見問題（FAQ）

模板字串還需要轉義嗎？
用反引號可避免雙引號轉義，但反引號與 ${} 仍需處理。
為什麼還要防 </script>？
因為內聯 <script> 的內容由 HTML 解析器先掃描：只要出現 </script> 序列，指令碼塊就會被提前結束，後面的內容被當作 HTML 輸出，攻擊者可藉此注入標籤。因此內聯 JSON 時除 JS 轉義外，還應把 < 轉成 \u003C，避免任何位置出現該序列。
