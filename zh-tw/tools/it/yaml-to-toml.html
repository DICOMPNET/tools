YAML to TOML Converter - Paste YAML text and convert it to TOML with nested tables, arrays and common scalars. Free, browser-only.

📐 工作原理與說明
縮排層級 → [table] / [[array of tables]]（表陣列元素內的子錶帶父字首，如 [items.meta]）
型別對映：mapping→表、sequence→陣列表/陣列（含 [a, b] 流式寫法）、標量→字串/整數/浮點/布林/日期（行尾 # 註釋在引號外剝離）
兩種格式都表達「鍵值 + 巢狀」的配置樹，但語法差異顯著：YAML 依賴縮排與 - 列表，TOML 則用 [table] 宣告表、[[table]] 宣告表陣列、鍵用點號或表頭表達層級。轉換時的關鍵約束是 TOML 要求「表必須寫在所有普通鍵之後」，因此轉換器需先輸出根級標量鍵，再按層級輸出表頭；YAML 的 null 在 TOML 中無對應型別，通常被丟棄或轉為空串；多行字串、錨點與別名（&/*）無法直接對映，需先展開。轉換後建議用 TOML 解析器回讀校驗。

⚠️ 使用說明與注意事項
  • 轉換按結構等價進行：YAML 對映→TOML 表，YAML 列表→TOML 陣列；巢狀對映會展開為 [section] 小節。
  • TOML 不支援 YAML 的錨點/合併（&anchor、*alias）與多行摺疊，這類高階語法會被忽略或報錯。
  • 字串中含特殊字元（冒號、#、方括號等）會自動加引號以保證 TOML 合法。

❓ 常見問題（FAQ）

YAML 錨點怎麼處理？
需展開錨點引用後再轉。
為什麼轉換後結構變得很囉嗦？
因為 TOML 需要為每個層級顯式寫表頭（[a.b.c]），而 YAML 用縮排隱式表達，層級越深表頭越多，這是格式差異導致的正常現象。若原始檔大量使用錨點（&/*）或多文件（---），轉換前應先展開——多數轉換器不會自動處理這些特性。
