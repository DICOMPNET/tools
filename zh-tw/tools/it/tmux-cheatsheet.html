🖥️ tmux Command Quick Reference

📐 工作原理與說明
按分組統計各分類命令條數，繪製柱狀圖（高度 300）並生成 序號 / 分類 / 數量 / 代表命令 四列明細表；分類名與表頭在英文態下走對應對映
tmux 是終端複用器，可在單個視窗中管理多個會話、視窗與面板。
  • 層級：會話（session）→ 視窗（window）→ 面板（pane）。
  • 字首鍵：預設 Ctrl+b，鬆開後再按命令鍵；% 左右分屏、" 上下分屏。
  • 常用：c 新建視窗、n/p 切換、d 分離會話、tmux attach 重連。
  • 優勢：會話在後臺保持，SSH 斷開後其中的任務仍繼續執行。

Quick reference for tmux sessions, windows, panes and key bindings.

💡 常見使用場景

  • 分屏/會話管理。
  • 遠端開發時保持會話：斷線後重新 attach 即可回到原來的視窗與程序，避免長任務隨 SSH 斷開而中斷。
分屏
`Ctrl-b %` 豎分；`Ctrl-b "` 橫分。

❓ 常見問題（FAQ）

detach 是什麼？
`Ctrl-b d` 脫離會話，後臺繼續執行。
為什麼我建的視窗別人看不到？
tmux 會話預設是獨立的：每個會話有自己的視窗與程序，除非主動共享（如用 tmux -S 指定同一 socket 並用相同使用者），否則互不干擾。這也是它的設計——多人協作時需顯式共享 socket 並設定許可權，而不是期待自動同步。
