線上程式碼執行器

📐 工作原理與說明
載入時寫入預設的 HTML / CSS / JS 三段樣例程式碼，繫結自動執行監聽，並在 100 毫秒後執行一次執行；執行時取三個編輯框的當前內容，拼裝成完整文件後交給隔離 iframe 執行，實現即時預覽
在瀏覽器沙箱中執行程式碼片段並檢視輸出。
  • 執行方式：new Function、Web Worker 或 iframe sandbox，隔離程度依次增強。
  • 安全：執行不可信程式碼必須隔離，防止訪問主頁面 DOM、Cookie 與同源資料。
  • 限制：預覽 iframe 不含 allow-same-origin，不能讀取父頁或本地檔案；sandbox 本身不阻斷網路，因此本工具在預覽文件內注入 CSP default-src 'none'，預設禁止外部 fetch/圖片/字型等出站請求，也沒有提供“允許網路”開關。如程式碼需要外部資源，請自行在本地環境驗證。
  • 超時：本工具無超時終止，死迴圈會凍結當前標籤頁，請勿執行不可信或無限迴圈程式碼。
  • 用途：片段驗證與教學演示，切勿執行來源不明的指令碼。

▶️ 工具介紹 ▼

線上程式碼執行器是一款純前端程式碼編輯與預覽工具，支援 HTML、CSS、JavaScript 三種語言的即時編輯和執行。

🔥 功能特點

  • 三欄程式碼編輯（HTML / CSS / JS）
  • iframe 沙箱隔離 + CSP 預設禁網
  • console.log / warn / error 輸出捕獲
  • 即時預覽模式（300ms 防抖）
  • 5 套內建示例程式碼，切換前保留可撤銷草稿
  • 編輯內容本地自動儲存，重新整理不丟失；可一鍵清除
  • 多行 Tab / Shift+Tab 縮排與反縮排
  • 一鍵複製 / 清空程式碼
  • 深色模式支援
  • 移動端自適應佈局

🏠 使用場景

  • 快速測試 HTML/CSS/JS 程式碼片段
  • 前端學習與教學演示
  • 除錯 UI 元件和動畫效果
  • 程式碼面試線上手寫驗證

📚 深度解析：線上程式碼執行器

💡 常見使用場景

  • 臨時跑片段驗證邏輯（沙箱、無網路）。
  • 與他人討論演算法時貼一段可執行片段，讓對方直接看到輸出，比截圖或文字描述更省溝通成本。
執行
`print(2**10)` → 輸出 `1024`。注意：本工具用 iframe 沙箱即時預覽，沒有超時終止機制；`while(true)` 等死迴圈會凍結當前標籤頁，請勿執行不可信或無限迴圈程式碼。

❓ 常見問題（FAQ）

能訪問網路/檔案嗎？
不能，沙箱隔離，僅純計算。
輸出結果穩定可復現嗎？
取決於程式碼本身。執行環境已固定語言版本，但涉及隨機數、當前時間、浮點精度或物件遍歷順序的邏輯，不同時刻或不同引擎可能給出不同結果。需要可復現時，應顯式設定隨機種子、固定時間與排序規則。
