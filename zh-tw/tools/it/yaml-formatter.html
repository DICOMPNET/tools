📄 YAML Format

📐 工作原理與說明
先用基於縮排棧的解析器把 YAML 文本解析為物件：跳過空行與以井號開頭的註釋行，取每行首個非空白字元的位置作為縮排量；縮排量小於等於棧頂縮排時不斷出棧。以「- 」開頭的行作為陣列項——父級該鍵還不是陣列時先建立陣列；項內容含「: 」時解析為鍵值對物件併入棧，以冒號結尾時壓入一個新物件，否則作為標量值推入陣列。以冒號結尾的行建立新物件並壓棧。含「: 」的行按鍵值對寫入當前父級（父級是陣列時新建物件再推入）。格式化時把解析結果遞迴序列化為文本，再把每兩個空格替換為所選縮排寬度的空格；壓縮模式直接輸出物件的緊湊 JSON 序列化結果
YAML 配置檔案的格式化與校驗。
  • 語法：key: value 為對映，- 開頭為序列，# 為註釋，| 與 > 處理多行文本。
  • 縮排：YAML 用縮排表示層級，只能使用空格，禁止使用 Tab。
  • 格式化：統一縮排寬度與空行，不改變資料內容。
  • 校驗：縮排錯誤會改變結構，格式化後應重新解析確認語義未變。

📖 使用說明

功能說明

  • 格式化：自動調整縮排、對齊，使YAML結構清晰易讀
  • 壓縮：移除多餘空白和註釋，生成緊湊YAML
  • 驗證：檢查YAML語法錯誤，定位錯誤位置
  • YAML↔JSON互轉：一鍵在兩種格式間轉換

YAML 語法要點

  • 使用縮排表示層級關係（空格，不能用Tab）
  • 鍵值對用冒號分隔: key: value
  • 列表用短橫線: - item
  • 註釋以 # 開頭
  • 字串通常不需要引號，特殊字元需要

❓ 常見問題（FAQ）

Tab 能縮排 YAML 嗎？
不能，YAML 僅允許空格縮排。
為什麼格式化後引號沒了？
因為該值不加引號也不會產生歧義（如普通單詞），格式化器按 YAML 規範去掉了冗餘引號，語義上等價。但要注意：形如 123、yes/no、null 的值去掉引號會改變型別——規範的格式化器會保留它們的引號；若發現型別被改，應手工加回。
