📄 CSV to YAML Converter

CSV to YAML Converter - Paste CSV text and convert to YAML lists (first row as header) or plain arrays. Supports quoted fields. Free, browser-only.

📐 工作原理與說明
先去掉回車符再按換行切分並過濾空行。逐行做引號感知的切分：遇到引號時，若其後緊跟另一個引號則寫入一個引號字元並跳過，否則切換引號狀態；不在引號內且遇到逗號時切分欄位；其餘字元累加到當前欄位。無表頭模式時每行輸出為一個短橫線加方括號包裹的列表項，各欄位以 JSON 字串形式逗號分隔。有表頭模式時首行作為鍵名，其餘每行輸出為「短橫線 + 空格」開頭、各鍵與對應值按 JSON 字串逐行縮排排列，鍵值之間以冒號加空格連線
把 CSV 資料轉換為 YAML 格式。
  • 流程：先按 CSV 解析為二維表，再按 YAML 縮排規則序列化為列表與對映。
  • 縮排：YAML 依賴縮排表達層級，不能用 Tab，同層級必須嚴格對齊。
  • 型別：形如 no、0123 的值會被推斷為布林或數字，需加引號保留字串。
  • 用途：配置檔案生成、資料遷移與人工編輯場景。

⚠️ 使用說明與注意事項
  • 逗號、換行、雙引號會被自動按 RFC 4180 處理；包含逗號/換行的欄位請用雙引號包裹。
  • 無表頭模式輸出為巢狀陣列，有表頭模式輸出為鍵值對列表。
  • 值為空時輸出空字串；如需 null 可後續手動替換。

❓ 常見問題（FAQ）

大 CSV 轉 YAML 慢嗎？
行數很大時 YAML 體積與解析都較重。
轉換後縮排亂了怎麼辦？
YAML 依賴縮排表達層級，常見問題是值裡含冒號、前導空格或製表符，導致被當作巢狀結構或非法字元。轉換時應給含特殊字元的欄位加引號；另外確保用空格而非 Tab 縮排——YAML 規範不允許 Tab。
