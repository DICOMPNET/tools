🔤 Python String Escape

📐 工作原理與說明
先去掉首尾空白；以 r 或 R 開頭時判為原始字串並去掉該字首。隨後去掉成對的三雙引號，或成對的外層雙引號與單引號。原始字串模式直接把「反斜槓 + 任意字元」替換為該字元本身。否則逐字元掃描：遇到反斜槓且後面還有字元時，按後隨字元轉義——n 轉換行、r 轉回車、t 轉製表符、b 轉退格、f 轉換頁、v 轉縱向製表符、a 轉響鈴、0 轉空字元、反斜槓與單雙引號轉其自身；x 取後隨 2 位十六進位制、u 取後隨 4 位、U 取後隨 8 位，按 16 進位制解析為碼點並生成字元；後隨字元是八進位制數字時，連續取最多 3 位八進位制數字按 8 進位制解析為碼點；其餘情況取後隨字元本身。不是轉義序列的字元原樣保留
Python 字串字面量的轉義與反轉義。
  • 轉義序列：\n \t \r \" \' \\ \xHH \uXXXX \UXXXXXXXX \OOO。
  • 原始字串：r"…" 不做轉義處理，常用於正規表示式與 Windows 路徑。
  • 字首：b 位元組串、f 格式化串、r 原始串，可組合為 rf"…"。
  • 多行：三引號字串可直接跨行，其中的換行會被原樣保留。

❓ 常見問題（FAQ）

raw 字串 r"..." 還要轉義嗎？
r 字首下反斜槓不轉義，但不能以奇數個反斜槓結尾。
\n 和 \\n 有什麼區別？
\n 是原始碼裡的轉義序列，表示真正的換行符（1 個字元）；\\n 表示反斜槓加字母 n（2 個字元）。混淆二者會導致日誌裡出現字面 \n 或字串被意外截斷。判斷方法很簡單：print 出來看是換行還是兩個字元。
