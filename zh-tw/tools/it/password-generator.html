🔑 Password Generator

Create strong random passwords with customizable length and character sets.

📐 工作原理與說明
已生成多條密碼時，逐條計算其強度並取其中的熵值（保留 1 位小數），以「密碼 + 序號」為橫軸畫柱狀圖（圖高 260），展示本次生成各密碼的熵。僅生成單條時降級展示：讀取當前長度與四類字元集（小寫、大寫、數字、符號）的大小，按 小寫、加 大寫、加 數字、加 符號 的順序逐類累加字元池大小，每一檔的熵 = 長度 × log₂(當前累計字元池大小)，保留 1 位小數（累計字元池為 0 時取 0），同樣以柱狀圖展示該長度下逐類開啟字元集的熵
使用密碼學安全隨機源（crypto.getRandomValues）生成，可配長度與字元集（大小寫字母、數字、符號）。密碼強度用資訊熵衡量：熵(bit) = 長度 × log₂(字元池大小)。
  • 建議長度 ≥12、熵 ≥80 bit；含符號可顯著提升抗暴力破解。
  • 避免詞典詞與個人資訊；生成後妥善儲存，前端不留存。
  • 純瀏覽器生成，不離開本地。

❓ 常見問題（FAQ）

多長夠安全？
隨機含四類字元 12+ 位可抗線上爆破，離線需更長。
為什麼有的網站不接受我生成的口令？
通常是字元限制：部分系統不允許某些符號、限制長度上限，或要求必須包含（或禁止包含）特定字元類別。另有少數系統在傳輸或儲存時錯誤處理了特殊字元。遇到這種情況應在允許的字元集內重新生成，而不是把口令改短來遷就規則。
