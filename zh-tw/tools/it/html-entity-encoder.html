🔤 HTML Entity Encoder

Encode and decode HTML entities (named and numeric) in your browser for safe markup and text.

📐 工作原理與說明
按順序依次替換：與號替換為對應實體，小於號替換為對應實體，大於號替換為對應實體，雙引號替換為對應實體，單引號替換為數字實體形式。替換後的結果寫入輸出框
HTML 實體的編碼與解碼。
  • 安全輸出：把使用者內容插入 HTML 時必須轉義 & < > " '。
  • 屬性上下文：屬性值需額外注意引號處理，單引號包裹的屬性也要轉義單引號。
  • 侷限：實體轉義不能替代富文本淨化，應配合白名單過濾（如 DOMPurify）。
  • 上下文：HTML 文本、屬性、JS、CSS、URL 各有不同的轉義規則，不可混用。

❓ 常見問題（FAQ）

命名實體和十進位制實體能混用嗎？
可以，瀏覽器都能解析。
空格和換行需要轉成實體嗎？
通常不需要。普通空格在 HTML 中會被摺疊為一個，只有需保留連續空格時才用 &nbsp;；換行需用 <br> 或 CSS 的 white-space 控制，轉成 &#10; 並不會產生換行效果。批次轉義時應只處理危險字元與確實需要保形的空白。
