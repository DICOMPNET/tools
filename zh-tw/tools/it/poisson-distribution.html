📡 Poisson Distribution

📐 工作原理與說明
泊松分佈 X ~ P(λ)
P(X = k) = λ^k · e^(−λ) ÷ k!
累積機率：P(X ≤ k) = Σ_{i=0..k} P(X=i)；P(X ≥ k) = 1 − P(X ≤ k−1)
P(X > k) = 1 − P(X ≤ k)
均值 E[X] = λ；方差 Var[X] = λ；標準差 = √λ（均值方差相等是泊松分佈特徵）
泊松分佈描述固定時間或空間內隨機事件發生次數的機率。
  • 機率：P(X=k) = λ^k·e^(−λ)/k!，λ 為單位時間（或空間）內的平均發生次數。
  • 特徵：期望與方差都等於 λ。
  • 適用條件：事件相互獨立、發生率恆定，且不會同時發生兩次（如每分鐘接到的呼叫數）。
  • 與二項分佈：當 n 很大、p 很小時，可用 λ=np 的泊松分佈近似二項分佈。

📋 泊松分佈公式

P(X = k) = (λk × e−λ) / k!
性質：
• 均值 E[X] = λ
• 方差 Var[X] = λ（均值=方差）
• 適用場景：單位時間內獨立稀有事件計數
• 例子：呼叫中心來電數、放射性衰變、網站訪問量

❓ 常見問題（FAQ）

泊松與二項關係？
n 大 p 小時二項逼近泊松。
什麼時候不能用泊松分佈？
當事件之間不獨立或發生率不恆定時不適用。例如有突發流量的場景（方差遠大於均值，稱過離散），此時泊松會嚴重低估極端值，應改用負二項分佈；若事件有固定的最小間隔（如定時輪詢），也不滿足「獨立隨機到達」的假設。
