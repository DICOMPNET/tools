👀 Rich Text Editor

Rich Text Editor - Compose and format text with headings, lists, bold, italic and links, with live HTML preview and one-click copy. Runs in your browser.

📐 工作原理與說明
遞迴遍歷節點生成 Markdown：文本節點直接取文本內容；元素節點按標籤轉換——pre 且帶程式碼塊標記時輸出程式碼佔位塊；h1 到 h6 按級別數字輸出對應數量的井號加標題；p 輸出段落；br 輸出兩個空格加換行；strong 與 b 用雙星號包裹；em 與 i 用單星號包裹；s、del、strike 用雙波浪號包裹；code 用反引號包裹；a 輸出「方括號包裹文字（文字為空時用連結地址）+ 圓括號包裹連結地址」；blockquote 每行前加引用符號；li 前加「- 」；ul 與 ol 直接取內部內容；hr 輸出分隔線；img 輸出「感嘆號 + 方括號包裹替代文字 + 圓括號包裹圖片地址」；table 轉為 Markdown 表格；其餘標籤取其內部內容。標題與段落前後補空行
所見即所得的富文本編輯器。
  • 實現：基於 contenteditable 或自維護文件模型（如 ProseMirror、Slate）。
  • 命令：加粗、斜體、標題、列表、連結、程式碼塊等，通過命令系統操作選區內容。
  • 安全：貼上內容必須淨化，輸出 HTML 前必須過濾，否則極易引入 XSS。
  • 難點：各瀏覽器的選區、輸入法與撤銷棧行為差異較大。

❓ 常見問題（FAQ）

貼上會帶樣式嗎？
通常做淨化防止 XSS。
生成的內容能直接存進資料庫嗎？
可以存，但必須在服務端做消毒（sanitize）：富文本的 HTML 來自不可信輸入，直接渲染等於開放 XSS。應使用白名單策略只保留必要的標籤與屬性（去掉 script、iframe、on* 事件與 style），並在入庫與渲染前各做一次，避免只做前端過濾。

⚠️ 使用說明與注意事項
  • 本工具純前端執行，編輯內容不會上傳到伺服器，重新整理頁面會丟失，請先匯出儲存
  • 建議在主流瀏覽器（Chrome/Safari/Firefox/Edge）中使用，快捷鍵 Ctrl+B / Ctrl+I / Ctrl+U 可用
  • Markdown 匯出為常用語法的近似轉換（標題、列表、加粗、斜體、連結、引用、程式碼），複雜表格可能需手工微調
  • 貼上外部內容時若帶入冗餘樣式，可用「🧹 清格式」按鈕清除
