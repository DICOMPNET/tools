📊 Code39 Barcode

📐 工作原理與說明
每字元 = 9 元素（5 條 4 空），其中 3 寬 6 窄
格式：* + 資料 + *（* 為起止符）
Code 39 是最早的字母數字條碼之一：每個字元用 9 個元素（5 條 4 空）表示，其中恰有 3 個寬元素、6 個窄元素，故得名「三九碼」。寬窄比通常為 2:1 至 3:1，比例越大越易讀。字元集含 A–Z、0–9、空格與 - . $ / + %，用 * 同時作起始與終止符。標準 Code 39 不強制校驗位，需要時可用 Mod 43 校驗。因密度較低（每字元約 9–16 模組），適合標籤空間充裕的工業與物流場景。

📚 深度解析：CODE39 條形碼

💡 常見使用場景

  • 工業與資產標籤：Code 39 支援大寫字母與數字、無需校驗位即可列印，廣泛用於裝置資產牌、倉庫貨架與軍工（LOGMARS）標籤。
  • 需要 Mod 43 校驗的場景：標籤內容較長或列印質量不穩定時，可開啟 Mod 43 校驗位——把每個字元的值求和後除以 43 取餘，把餘數對應字元追加到末尾，能攔住大部分誤讀。

❓ 常見問題（FAQ）

Code 39 一定要加 * 號嗎？
標準 Code 39 不強制校驗位；需要時可用 Mod 43。與 EAN/UPC 不同，它的校驗位是可選的，由應用方決定是否啟用——這也是同一串資料在兩個系統里長度可能差一位的原因。
能編碼小寫字母嗎？
標準 Code 39 只有大寫 A–Z、0–9、空格與 - . $ / + % 共 43 個字元；小寫需藉助擴充套件 Code 39（用兩個字元組合表示一個 ASCII 字元），條碼長度會明顯增加。若必須支援小寫，建議改用 Code 128。
