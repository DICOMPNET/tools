🎯 Binomial Distribution

📐 工作原理與說明
二項分佈 X ~ B(n, p)
P(X = k) = C(n,k) · p^k · (1−p)^(n−k)，C(n,k) = n! / [k!(n−k)!]
累積機率：P(X ≤ k) = Σ_{i=0..k} P(X=i)；P(X ≥ k) = 1 − P(X ≤ k−1)
P(X < k) = P(X ≤ k−1)；P(X > k) = 1 − P(X ≤ k)
均值 = n·p；方差 = n·p·(1−p)；標準差 = √[n·p·(1−p)]
描述 n 次獨立伯努利試驗中成功次數的機率分佈。
  • 機率：P(X=k) = C(n,k)·p^k·(1−p)^(n−k)，X ~ B(n, p)。
  • 數字特徵：期望 E[X]=np，方差 Var=n·p·(1−p)，標準差為方差開方。
  • 累積：P(X≤k) 逐項累加；P(X≥k) = 1 − P(X≤k−1)。
  • 近似：當 np 與 n(1−p) 均 ≥5 時，可用正態分佈 N(np, np(1−p)) 近似。

📋 二項分佈公式

P(X = k) = C(n, k) × pk × (1−p)n−k
前提：n 次獨立試驗，每次成功機率 p，X 為成功次數。
均值：μ = np
方差：σ² = np(1−p)
當 np≥5 且 n(1−p)≥5 時，可正態近似：X ~ N(np, np(1−p))

📚 深度解析：二項分佈計算器

💡 常見使用場景

  • n 次獨立試驗、單次成功機率 p 時算恰好/至多 k 次成功。
  • 抽檢方案評估：一批產品不良率 2%，抽 100 件，用該分佈算出「檢出 0 件不良」的機率僅約 13%，說明這個抽樣量並不能可靠保證批質量。
拋硬幣
n=10,p=0.5,k=5：P(X=5)=C(10,5)·0.5^10≈0.246（約 24.6%）。

❓ 常見問題（FAQ）

二項與伯努利關係？
單次伯努利是 n=1 的二項分佈。
n 很大時還算得動嗎？
n 較大時組合數 C(n,k) 會非常大，但 p 很小時可用泊松分佈近似（λ = np），n 大且 p 不極端時可用正態近似（均值 np、方差 np(1−p)）。近似能大幅降低計算量，但要注意適用條件：通常要求 np ≥ 5 且 n(1−p) ≥ 5。
