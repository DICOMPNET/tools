✨ ASCII Directory Tree Generator

Generate ASCII directory trees from a path list in your browser — great for docs and READMEs.

📐 工作原理與說明
按行讀取路徑並以 / 切分為層級，末段標記為檔案、其餘為目錄，合併同名節點構建成樹；繪製時每層取當前層鍵序，末項用 └──、其餘用 ├──，根節點不加連線符；子節點字首在父級為末項時補 4 個空格、否則補 │ 加 3 空格；目錄名末尾追加 /，輸出總行數即樹節點總數
把層級資料渲染成終端風格的目錄樹，用縮排與連線符表達父子關係。
  • 連線符：非末級子項用 ├──，同層最後一項用 └──，用 │ 延續父級豎線。
  • 規則：某節點是其父的最後一項時，其子樹字首補空格而非 │，保證視覺閉合。
  • 輸入：顯式選擇「路徑列表」「縮排樹」或「自動識別」。路徑列表按行去除首尾空白、按 / 切分，單行偶然帶前導空格不會改變整份輸入的解析方式；縮排樹保留行首空白，按 ├──/└──/│ 字首與最小非零縮排推斷層級。
  • 輸出：純文本，可直接貼上進 README、介面文件或終端說明。

❓ 常見問題（FAQ）

與 tree 命令區別？
本工具線上生成，無需 shell。
├── 和 └── 的區別是什麼？
├── 表示該節點後面還有同級兄弟，└── 表示它是父節點的最後一個子項。父級是否繼續畫豎線 │ 也由此決定：最後一個子項之後不再延續，整棵樹才不會多出斷線。
