🔄 JSON to Code

📐 工作原理與說明
由 JSON 樣本生成目標語言的型別定義。
  • 輸出：TypeScript 的 interface、Go 的 struct（帶 json tag）、Python 的 dataclass/TypedDict 等。
  • 巢狀：巢狀物件生成子型別，陣列生成元素型別。
  • 命名：按目標語言慣例轉換命名風格（如 snake_case → camelCase）。
  • 後續：生成結果為基礎骨架，校驗規則與註釋需補充。
 
 
 
 

  









📚 深度解析：JSON 轉程式碼


💡 常見使用場景


    

  • 把 JSON 轉成 TS 介面/Python dict/Go struct 等。
    • 

  • 對接新介面時先生成型別定義：把響應 JSON 轉成 TS interface 或 Go struct，避免手寫時漏欄位或寫錯型別。
    • 



轉 TS
`{"name":"Tom"}` → `interface Root { name: string }`。


❓ 常見問題（FAQ）




巢狀物件怎麼轉？
遞迴生成巢狀介面/結構體。


生成的欄位名不符合規範怎麼辦？
多數生成器支援注入命名規則：TS 通常保留原樣或轉 camelCase，Go 需要轉 PascalCase 並加 json tag，Python 的 dataclass 則要注意保留字衝突。生成後應統一跑一次格式化與 lint，並對 nullable 欄位確認用的是指標還是值型別。
