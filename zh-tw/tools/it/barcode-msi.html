📊 MSI Barcode

📐 工作原理與說明
每位數字 = 8 個單元（0→窄空寬條，1→寬條窄空，其餘按二進位制展開）
校驗：Mod 10（Luhn）/ Mod 11 / Mod 1010 可選
MSI（Modified Plessey）是脈衝調變型條碼，每位數字用 8 個單元表示：0 編碼為「窄空寬條」，1 編碼為「寬條窄空」，其餘數字按二進位制位展開為 8 個寬窄交替的單元。它只含數字、無字母，密度中等，主要用在零售貨架標籤與倉庫庫位標識。MSI 本身不校驗，實踐中常追加 Mod 10（即 Luhn 演算法）、Mod 11 或雙重 Mod 1010 校驗位，以防止掃描誤讀。

💡 常見使用場景

  • 貨架與庫位標籤：MSI 常見於零售貨架價籤與倉庫庫位標識，只有數字、可用點陣或熱敏印表機輸出，成本低、易識別。
  • 追加校驗位：MSI 本身無校驗，實際使用常追加 Mod 10（Luhn）、Mod 11 或兩輪 Mod 1010；對接老系統前要先確認對方用哪一種，否則掃描結果會多出 1–2 位。
生成
輸入數字串（如 `123456789`）→ 渲染 MSI 條碼圖形；請按規範長度與校驗位填寫。

❓ 常見問題（FAQ）

MSI 預設有校驗位嗎？
沒有。MSI 是脈衝調變型碼，任一位被誤讀都會產生另一個合法字元，因此必須靠應用層追加校驗位。選擇上：Mod 10（Luhn）最普遍，Mod 11 多一位校驗、檢出率更高，Mod 1010 則是連續兩輪 Mod 10。
MSI 能編碼字母嗎？
不能。MSI 只定義了 0–9 十個數字，任何字母或符號都無法編碼。若標籤需要含字母（如庫位 A-01-03），應改用 Code 39 或 Code 128。
