📊 MSI Barcode

📐 工作原理與說明
每位數字 = 4 位二進位制 → 12 個模組（位 1 → 110：2 模組條 + 1 模組空；位 0 → 100：1 模組條 + 2 模組空）
起始 110、結束 1001；校驗：Mod 10 / Mod 11 可選
MSI（Modified Plessey）是脈衝寬度調變型條碼，每位數字按 4 位二進位制展開：位 1 編碼為 110（2 模組條 + 1 模組空），位 0 編碼為 100（1 模組條 + 2 模組空），即每位 12 個模組；起始為 110、結束為 1001。它只含數字、無字母，密度中等，主要用在零售貨架標籤與倉庫庫位標識。MSI 本身不校驗，實踐中常追加 Mod 10（Luhn 類演算法）、Mod 11 校驗位，以防止掃描誤讀。

💡 常見使用場景

  • 貨架與庫位標籤：MSI 常見於零售貨架價籤與倉庫庫位標識，只有數字、可用點陣或熱敏印表機輸出，成本低、易識別。
  • 追加校驗位：MSI 本身無校驗，實際使用常追加 Mod 10（Luhn）、Mod 11 或兩輪 Mod 1010；對接老系統前要先確認對方用哪一種，否則掃描結果會多出 1–2 位。
生成
輸入至少一位純數字（如 `1234567`）→ 渲染 MSI 條碼圖形；MSI 碼制本身不含校驗位，校驗位按所選模式（無 / Mod 10 / Mod 11 / Mod 1010）由工具追加到資料末尾，無需手工填寫。

❓ 常見問題（FAQ）

MSI 預設有校驗位嗎？
沒有。MSI 是脈衝調變型碼，任一位被誤讀都會產生另一個合法字元，因此必須靠應用層追加校驗位。選擇上：Mod 10（Luhn）最普遍，Mod 11 多一位校驗、檢出率更高，Mod 1010 則是連續兩輪 Mod 10。
MSI 能編碼字母嗎？
不能。MSI 只定義了 0–9 十個數字，任何字母或符號都無法編碼。若標籤需要含字母（如庫位 A-01-03），應改用 Code 39 或 Code 128。
