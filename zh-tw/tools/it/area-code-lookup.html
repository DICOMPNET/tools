🗺️ Area Code Lookup

📐 工作原理與說明
先剔除全部非數字；11 位且首位為 1 時剝離 NANP 國家碼 +1；區號取前 3 位 NPA，按首位 2–9、排除 N11 服務碼 / N99 保留碼 / Reserved 非地理碼校驗後查表得地區；完整 10 位號碼再校驗 NXX 結構並按 (NPA) NXX-XXXX 格式化，區號未收錄時只給結構結論、不判標準有效；僅輸入 3 位時同樣先過 NPA 規則再判區號有效性
按北美編號計劃（NANP）規則，用區號反查所屬州/城市並校驗號碼格式。
  • 結構：NANP 號碼為 NPA-NXX-XXXX 共 10 位，NPA 即 3 位區號。
  • 規則：區號首位為 2–9；第二、三位不得同為 1（避免與 N11 服務碼衝突）。
  • 覆蓋：NANP 含美國、加拿大及部分加勒比地區，同一區號可能跨州（overlay）。
  • 用途：識別來電歸屬地、校驗錄入號碼是否合法。

❓ 常見問題（FAQ）

區號會新增嗎？
會，號碼資源緊張時新增區號。
查不到某個區號是怎麼回事？
可能原因有三：該區號屬於新啟用的疊加區號（overlay）尚未收錄；號碼來自加拿大、加勒比等其他 NANP 成員（NANP 不只覆蓋美國）；或輸入的是 800/888 等免費號碼、900 付費號碼這類非地理區號。
