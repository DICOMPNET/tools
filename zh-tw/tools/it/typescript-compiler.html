TypeScript轉JavaScript編譯器

💻 TypeScript Compiler

📐 工作原理與說明
呼叫 ts.transpileModule(原始碼, 選項) 做單檔案轉譯——僅移除型別註解，不做完整型別檢查；target 對映 ts.ScriptTarget（ES3 / ES5 / ES2015 / ES2017 / ES2020 / ESNext），module 對映 ts.ModuleKind（None / CommonJS / AMD / UMD / ESNext）；編譯耗時 = performance.now() 前後差值（無 performance 時退回 Date.now()）；異常時診斷面板報編譯異常並清空輸出
把 TypeScript 編譯為 JavaScript。
  • 流程：先做型別檢查，再擦除型別註解，並按 target 降級語法（如轉為 ES5）。
  • 型別擦除：型別資訊只在編譯期存在，執行時不可見，因此無法用於執行時校驗。
  • 配置：tsconfig.json 控制 target、module、strict、lib 與輸出目錄。
  • 提醒：編譯不校驗外部資料，介面返回值等仍需做執行時校驗。

⚠️ 使用說明與注意事項
  • 本工具使用 ts.transpileModule 進行單檔案轉譯，會移除型別註解但不做完整型別檢查
  • 型別錯誤（如賦值型別不匹配）不會被檢測，僅語法錯誤和部分語義錯誤會出現在診斷面板
  • 需要完整型別檢查請使用本地 tsc 或 IDE
  • 所有編譯在瀏覽器本地完成，程式碼不會上傳到伺服器
  • 建議在主流瀏覽器（Chrome/Safari/Firefox/Edge）中使用

❓ 常見問題（FAQ）

型別檢查在編譯時做嗎？
是，tsc 編譯同時做型別檢查，瀏覽器只跑 JS。
為什麼編譯通過了執行時仍然報錯？
因為 TypeScript 的型別只在編譯期起作用，執行時型別資訊被完全擦除；來自介面響應、JSON.parse 或使用者輸入的資料，編譯器無從校驗。因此關鍵邊界必須用執行時校驗（如 schema 校驗庫）守住，型別是第二道防線而不是唯一防線。

📝工具簡介

TypeScript 轉 JavaScript 編譯器是一款基於官方 TypeScript 5.3 編譯器的線上工具。它在瀏覽器本地呼叫 ts.transpileModule API，將 TypeScript 程式碼即時轉譯為 JavaScript，支援選擇 ES3 到 ESNext 的目標版本與 None、CommonJS、AMD、ESNext 模組系統，並提供編譯診斷資訊。所有程式碼處理都在瀏覽器中完成，不會上傳到任何伺服器，保障隱私安全。

✨功能特點

  • 基於官方 TypeScript 5.3 編譯器
  • 左右分欄即時編輯與輸出
  • 支援 ES3/ES5/ES6/ES2017/ES2020/ESNext 目標
  • 支援 None/CommonJS/AMD/ESNext 模組系統
  • 移除註釋、嚴格模式、isolatedModules 選項
  • 300ms 防抖即時編譯
  • 編譯診斷資訊（錯誤/警告/位置）
  • 顯示編譯耗時與輸出行數
  • Tab 鍵縮排支援
  • 一鍵複製 / 下載 JS 檔案
  • 深色模式與移動端響應式

🎯使用場景

  • 學習 TypeScript 語法與型別系統
  • 驗證 TS 程式碼降級為不同 ES 版本的效果
  • 將含型別註解、介面、泛型的 TS 轉為 JS
  • 快速檢視列舉、可選鏈等特性的編譯產物
  • 線上除錯 TS 語法錯誤
  • 老專案降級到 ES5 相容舊瀏覽器
