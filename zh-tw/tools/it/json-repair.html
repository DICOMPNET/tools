📄 JSON Repairer

JSON Repairer - Fix broken JSON (trailing commas, single quotes, comments) and validate it locally. Free, browser-only.

📐 工作原理與說明
修復格式不規範的近似 JSON 文本。
  • 常見錯誤：尾隨逗號、單引號、未加引號的鍵、混入註釋、缺少逗號或括號。
  • 策略：補齊缺失的引號/逗號/括號，去除註釋，把單引號轉為雙引號。
  • 風險：修復是啟發式的，可能改變原意，重要資料必須人工複核。
  • 場景：處理從日誌、LLM 輸出或非嚴格配置中貼上的內容。
⚠️ 使用說明與注意事項
  • 修復器會移除 /* */ 與 // 註釋、把單引號鍵/值轉成雙引號、刪除物件/陣列尾隨的逗號，覆蓋大多數複製貼上造成的錯誤。
  • 修復是啟發式的：若結構本身嚴重損壞（缺括號、鍵名無引號且非數字），仍可能失敗，請對照錯誤提示手動修正。
  • 處理敏感資料時請在本地完成，不要上傳到第三方修復網站。

💡 常見使用場景

  • 修復缺引號、尾逗號等非法 JSON。
  • 救回一段粘錯的不完整 JSON：補齊缺失的引號與花括號，先從日誌裡恢復出可讀結構，再確認內容是否可信。
修復
`{a:1,}` → 修復為 `{"a":1}`（補鍵引號、去尾逗號）。

❓ 常見問題（FAQ）

自動修復會改語義嗎？
僅修語法錯誤，不改變欄位與值。
修復後的資料能直接用嗎？
不能盲信。修復器只能按啟發式規則猜測缺失部分——多一個逗號是筆誤還是少了一個元素，工具無從判斷。正確做法是把修復結果當作「可讀性恢復」用於排查，之後回源頭重新獲取完整資料；若必須消費，務必再做一次 Schema 校驗。
