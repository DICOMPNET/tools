📐 工作原理與說明
ASCII 用 7 位二進位制表示 128 個字元，是早期計算機與通訊中最基礎的字元編碼。
  • 分割槽：0–31 與 127 為控制字元（如 LF=10、CR=13、ESC=27），32–126 為可列印字元。
  • 規律：數字 0–9 為 48–57，大寫 A–Z 為 65–90，小寫 a–z 為 97–122。
  • 大小寫：同一字母的大小寫碼點相差 32（如 A=65、a=97）。
  • 侷限：ASCII 僅覆蓋英文與基本符號，中文等字元需 UTF-8 等多位元組編碼。

❓ 常見問題（FAQ）

可列印範圍？
32–126 為可列印，其餘為控制字元。
為什麼 128 之後的字元查不到？
標準 ASCII 只定義 0–127 共 128 個字元。128–255 屬於擴充套件 ASCII（ISO-8859-1、Windows-1252 等各家互不相容），中文與 emoji 則用 Unicode 表示，需查 Unicode 碼錶而非 ASCII 表。
