🔄 List Converter

Convert between list formats (lines, CSV, JSON) in your browser — reshape data quickly.

📐 工作原理與說明
在不同格式的列表之間轉換並做清洗。
  • 格式：逗號分隔、換行分隔、空格分隔、分號分隔、JSON 陣列。
  • 清洗：支援去重、去空項、去首尾空白、排序與引號剝離。
  • 轉義：值內若含分隔符，需引號包裹或轉義，否則切分會出錯。
  • 用途：批次資料處理、生成 SQL IN 子句、整理配置項。

💡 常見使用場景

  • 分隔符/CSV/陣列互轉。
  • 把資料庫匯出的一列 ID 轉成 SQL 的 IN 子句：先轉成逗號分隔並加引號，直接粘進查詢裡。
轉換
`a,b,c` → 每行一項或 `["a","b","c"]`。

❓ 常見問題（FAQ）

引號怎麼處理？
CSV 模式按需加引號。
欄位本身含分隔符怎麼辦？
需要轉義或用引號包裹，規則與 CSV 一致：含分隔符、引號或換行的欄位用雙引號包圍，欄位內的雙引號寫成兩個雙引號。若源資料分隔符不統一（混用中英文逗號、分號），應先統一再轉換，否則列會被切錯。
