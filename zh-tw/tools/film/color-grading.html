Color Palette LUT Reference

Color Palette LUT Reference focuses on common LUT types, working color spaces, and grading parameters used in film post-production, with client-side filtering and search for fast decision support.

📐 工作原理與說明
LUT 預設把 3d / tech / creative / monitor 對映為「3D / 技術 / 創意 / 監視器」寫入篩選框並清空關鍵詞；篩選逐行判斷：關鍵詞與篩選值均轉小寫，行文本 indexOf 命中兩者才保留，否則隱藏該行

本表彙總 1D/3D LUT 的典型分工：1D LUT 處理灰階對映（如監視器校正、基礎色彩變換），3D LUT 處理三維色彩對映（如 Log 轉 Rec.709 或創意風格化）。通過篩選與搜尋，可快速查詢適配鏡頭來源與交付規格的參考項，輔助色彩決策。

💡 常見使用場景

  • 剪輯前按型別篩選常見 LUT（如電影感、日系、膠片模擬），快速縮小選擇範圍。
  • 按適用色彩空間（Rec.709 / Log / HDR）篩選，確認手裡的素材該配哪一類。
  • 給客戶講解風格方向時，用速查表上的典型引數作為溝通參照。
怎麼用這張速查表
先按型別下拉篩選（如"膠片模擬"），再在搜尋框輸入關鍵詞（如"柯達""富士""青橙"）縮小範圍，表格會列出 LUT 名稱、適用色彩空間與典型調色引數（對比度、飽和度、色溫偏移等）。例如 Log 素材通常要先套還原 LUT 回到 Rec.709，再疊加風格 LUT，順序反了會出現色偏。

❓ 常見問題（FAQ）

表裡的引數能直接照搬嗎？
只能作為起點。不同攝影機的 Log 曲線、色溫與曝光基準都不同，實際調色要以示波器與監看為準，把引數當作參考區間而非固定值。
為什麼套完 LUT 畫面發灰？
多半是把風格 LUT 直接套在了 Log 素材上。Log 素材需要先做色彩空間轉換（還原 LUT 或 CST）回到顯示空間，再疊加風格 LUT。
