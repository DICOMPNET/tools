買入總成本 = 買入價 x 數量 + 買入佣金 + 買入過戶費

賣出總收入 = 賣出價 x 數量 - 賣出印花稅 - 賣出佣金 - 賣出過戶費

盈虧金額 = 賣出總收入 - 買入總成本

盈虧百分比 = 盈虧金額 / 買入總成本 x 100%

印花稅：賣出時收取，費率 0.05%（2023年8月28日起減半）

佣金：買賣雙向收取，預設 0.025%，最低 5 元/筆

過戶費：買賣雙向收取，費率 0.001%（滬市為主，深市2023年起統一）

保本賣出價 = (買入總成本 + 賣出綜合費率 x 數量 x 保本價) / 數量

即：保本價 ≈ 買入總成本 / (數量 x (1 - 賣出綜合費率))

注：本計算器基於 A 股通用費率，實際費率以券商公告為準。計算結果僅供參考，不構成投資建議。

❓ 常見問題（FAQ）

A 股賣出要交哪些費用？
通常含印花稅（賣出單邊）、券商佣金（雙向，常有最低 5 元）與過戶費；具體以券商實際收費為準。
為什麼盈虧和券商顯示不同？
各家傭金費率、最低收費與過戶費口徑可能不同，請以交割單為準。
計算含分紅嗎？
本頁只算買賣價差與交易費用，不含分紅派息與股息稅。
