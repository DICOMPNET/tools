💰 Cost Accounting & Allocation Model

Allocate a cost pool across cost objects with one base, showing the allocation rate, each share and the resulting unit cost.

📐 計算公式
分攤率 = 待分攤總成本 ÷ Σ分攤基數　　分攤額ᵢ = 分攤率 × 基數ᵢ　　佔比ᵢ = 基數ᵢ ÷ Σ分攤基數　　單位成本ᵢ = 分攤額ᵢ ÷ 產量ᵢ

先歸集待分攤成本（製造費用、共同成本、間接人工等），選定一個與耗用最相關的分攤基數（產量、工時、面積、銷售額、人數），算出「每單位基數應承擔多少成本」的分攤率，再按各成本物件的基數份額分配。分攤基數之和必須大於 0；若某物件基數為負（如退貨衝減產量），頁面照常計算但會提示核對。單位成本只在填寫的產量條數與物件條數一致且產量大於 0 時給出，否則該列顯示「—」。

📚 深度解析：成本分攤與單位成本測算

💡 常見使用場景

  • 製造費用按產量或機器工時分攤到各產品線，算出單位成本
  • 集團共同費用按銷售額分攤到各子公司
  • 報價前測算綜合單位成本，確定價格底線
方法
分攤率 = 待分攤總成本 ÷ Σ分攤基數；各物件分攤額 = 該物件基數 × 分攤率；佔比 = 該物件基數 ÷ Σ基數；單位成本 = 分攤額 ÷ 該物件產量。成本物件按「名稱,基數」每行一條填寫，產量按順序用逗號分隔一一對應；分攤基數名稱可自定義（產量 / 工時 / 面積 / 銷售額 / 人數），綜合單位成本 = 待分攤總成本 ÷ 產量合計。
算例
待分攤總成本 100,000 元，A 產品基數 300、B 產品基數 200，產量各 1,000 件 → Σ基數 500.00，分攤率 200.00 元 / 單位基數；A 產品分攤 60,000.00 元（佔 60.00%），單位成本 60.00 元；B 產品分攤 40,000.00 元（佔 40.00%），單位成本 40.00 元；合計 100,000.00 元，綜合單位成本 = 100,000.00 ÷ 2,000.00 = 50.00 元 / 件。

❓ 常見問題（FAQ）

分攤基數為負會怎樣？
頁面會提示存在負基數並照常計算，結果取決於分母：只要 Σ基數仍為正，分攤率就有意義，負基數物件會分到負的分攤額（相當於衝減）。若 Σ基數 ≤ 0，分攤率無法定義，頁面會直接報錯要求調整基數。
產量條數和成本物件條數不一致怎麼辦？
單位成本列會顯示「—」並給出提示，因為無法一一對應。分攤率、分攤額與佔比仍會照常輸出——它們只依賴基數；只有需要折算單位成本的場合才必須補齊產量。
為什麼換一種分攤基數，單位成本會差這麼多？
分攤基數是成本動因的代理變數，選錯動因會把成本推給不該承擔的物件。製造業常用機器工時，多品種小批次可用批次或訂單數，集團共同費用常用銷售額或人數。選定的動因應與消耗資源的真正原因一致，否則定價會被扭曲。

⚠️ 使用說明與注意事項
  • 分攤基數要與成本動因相關：機器折舊按機器工時、倉儲費用按面積或數量，選錯基數會讓成本失真。
  • 同一次分攤只能用一個基數；不同性質的費用應分組、分別選擇基數後再彙總。
  • 分攤率 = 待分攤總成本 ÷ Σ分攤基數，基數合計為 0 或負數時無法分攤，請先核對輸入。
  • 單位成本需要「各物件產量」的條數與物件條數一致且產量大於 0，否則該列顯示「—」。
  • 本工具純前端執行，輸入資料不會上傳到伺服器；結果僅為測算口徑，不作為賬務或稅務依據。
