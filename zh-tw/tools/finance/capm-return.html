CAPM Expected Return Calculator

Capital Asset Pricing Model: required return from the risk-free rate, beta and market return, with a security market line reference table and an alpha verdict.

📐 計算公式
E(R) = Rf + β × (Rm − Rf)　　α = R實際 − E(R)

Rf 為無風險利率（通常取國債到期收益率），Rm 為市場組合預期收益率，β 衡量該資產對市場波動的敏感度（β = 1 與市場同步、β > 1 放大波動、β < 0 反向）。括號內的 (Rm − Rf) 是市場風險溢價，也是證券市場線的斜率；乘以 β 得到該資產應得的風險補償。若同時填入實際（觀測）收益率，則 α = 實際 − 要求：α > 0 表示實際收益高於同等風險下的必要回報，α < 0 表示承擔了風險卻沒拿夠補償。下方按 β 從 0 到 2 給出對應必要收益率，用於快速定位標的在 SML 上的位置。

📌 計算說明
  • β 衡量系統性風險：β = 1.2 表示市場每變動 1%，該資產預期同向變動 1.2%。
  • 市場風險溢價 (Rm − Rf) 是 SML 的斜率，斜率為負時風險越大要求回報反而越低，屬異常輸入。
  • Rm < Rf 現實中僅短期出現，頁面給出提示但仍照公式計算，便於對照檢查。
  • α 是事後指標，只有在填入真實觀測收益率後才有意義；不填時只輸出必要收益率與 SML 對照。
  • β 為負的資產（避險資產、反向頭寸）用 CAPM 估計可靠性偏低，結論需謹慎。
  • 本工具純前端執行，輸入資料不會上傳到伺服器。

💡 常見使用場景

  • 估值取折現率：用無風險利率、β 與市場收益率求出權益資本成本
  • 橫向比較：把不同 β 的標的統一到「同等風險下的必要回報」量綱上
  • 事後復盤：填入實際收益率算 α，判斷是跑贏還是跑輸
  • 口徑核對：支援小數（0.03）與百分數（3）兩種輸入，避免量級填錯
方法
E(R) = Rf + β×(Rm − Rf)。先算市場風險溢價 Rm − Rf，再乘 β 得風險補償，加上無風險利率即必要收益率；α = 實際收益率 − E(R)。輸入口徑由「單位」下拉決定：選小數時 0.03 表示 3%，選百分數時直接填 3，四個輸入項要用同一種單位，否則量級會差出 100 倍。SML 對照表按 β 從 0 到 2、步長 0.25 列出 9 檔必要收益率，當前 β 所在行會加底色高亮。
算例
Rf = 3%、β = 1.2、Rm = 8% → 市場風險溢價 5.000%，風險補償 1.2 × 5.000% = 6.000%，E(R) = 3.000% + 6.000% = 9.0000%。SML 上 β = 0 對應 3.000%（無風險資產）、β = 1 對應 8.000%（與市場同步）、β = 2 對應 13.000%。若同時填入實際收益率 10.000%，α = 10.000% − 9.000% = 1.000% > 0，說明實際收益高於同等風險下的必要回報。

❓ 常見問題（FAQ）

β 該填多少才合理？
β 是對系統性風險的度量，通常取可比公司或指數迴歸得到的區間中值：公用事業常在 0.5~0.8，科技與週期成長股常在 1.2~1.8。β 會隨迴歸視窗與頻率變化，穩妥做法是同時給出 0.8 / 1.2 等情景區間，而不是隻填一個點值。
市場風險溢價 Rm − Rf 為負說明什麼？
說明填入的市場收益率低於無風險利率，現實中只在短期或口徑異常時出現。頁面會給出提示但仍照公式計算：此時 SML 斜率為負，β 越大的資產必要收益率反而越低，屬異常結果，優先核對 Rm 是否為長期平均市場收益、Rf 是否用了同期國債收益率。
α 為負就一定該賣出嗎？
不一定。α 是事後指標，受樣本區間、基準選擇與運氣影響很大，單期 α 為負可能只是正常波動。更穩妥的做法是看 2~3 年滾動 α 是否持續為負，並結合換手成本、稅費與 β 的估計誤差一起判斷。

📝工具簡介

按資本資產定價模型（CAPM）由無風險利率、貝塔係數與市場收益率求必要收益率：先算市場風險溢價（Rm−Rf）與風險補償 β×(Rm−Rf)，再給出證券市場線（SML）上 9 檔 β 的對照值；填入實際收益率後還會算出阿爾法 α，判斷該資產被高估還是低估。

  • 必要收益率 E(R) = Rf + β×(Rm−Rf) 一次算全
  • 市場風險溢價與風險補償分步展示，便於核對口徑
  • SML 對照表覆蓋 β = 0 ~ 2（每 0.25 一檔），自動高亮當前 β 所在行
  • 支援百分數（填 3 表示 3%）與小數（填 0.03）兩種輸入口徑一鍵切換
  • 填入實際收益率即得 α，並給出高估 / 低估的文字判定
