📐 計算公式 / 說明
到期收益率(YTM) 使債券未來現金流現值等於價格的貼現率；當期收益率 = 年息 / 市價。
基於債券定價原理：YTM 為使未來現金流（票息 + 本金）現值等於買入價的貼現率；當期收益率 = 年票息/市價，持有期收益率還含資本利得，用於債券回報比較。

📈 現金流示意圖

🎯 到期收益率 (YTM)

定義：買入債券並持有至到期的年化收益率

公式（附息債券）：

P = C/(1+r) + C/(1+r)² + ... + (C+F)/(1+r)ⁿ

  • P = 債券價格
  • C = 每期利息
  • F = 面值
  • r = 到期收益率
  • n = 期數

零息債券：r = (F/P)^(1/n) - 1

特點：考慮了利息再投資收益，是最常用的債券收益率指標

📊 當期收益率

定義：債券年利息與當前市場價格的比率

公式：當期收益率 = 年利息 / 當前價格 × 100%

示例：面值1000元，票面利率5%，價格950元 → 50/950 = 5.26%

特點：簡單直觀，只反映利息收益，不考慮資本利得

📈 持有期收益率

定義：持有債券期間的總收益率

公式：

  • 總收益 = 賣出價 - 買入價 + 持有期間利息
  • 持有期收益率 = 總收益 / 買入價 × 100%
  • 年化收益率 = (1 + 持有期收益率)^(1/年數) - 1

特點：反映實際投資收益，適用於中途賣出的情況

💰 債券定價

原理：債券價格等於未來現金流的現值之和

公式：

  • 附息債券：P = Σ(C/(1+r)^t) + F/(1+r)^n
  • 零息債券：P = F/(1+r)^n

價格與利率關係：

  • 市場利率上升，債券價格下降
  • 市場利率下降，債券價格上升
  • 長期債券對利率更敏感

🏛️ 債券型別

  • 國債：國家發行，信用最高，風險最低
  • 地方政府債：地方政府發行，用於地方建設
  • 企業債：企業發行，風險高於國債
  • 公司債：上市公司發行，需核准
  • 可轉換債券：可轉換成股票的債券
  • 零息債券：不付息，折價發行，到期還本
  • 永續債券：無到期日，永久付息

📉 債券風險

  • 利率風險：利率上升導致債券價格下跌
  • 信用風險：發行人違約，無法還本付息
  • 流動性風險：無法及時變現
  • 再投資風險：利息再投資收益下降
  • 通脹風險：通脹侵蝕實際收益
  • 贖回風險：債券被提前贖回

📊 債券常用指標

  • 久期(Duration)：衡量債券利率風險，價格對利率的敏感度
  • 凸性(Convexity)：久期的二階導數，更精確衡量利率風險
  • 到期收益率(YTM)：持有到期的年化收益
  • 信用評級：評估違約風險，如AAA、AA、A等

💡 投資建議

  • 根據風險承受能力選擇債券信用等級
  • 利率上行期選短債，利率下行期選長債
  • 分散投資，降低單一債券違約風險
  • 關注債券基金，專業管理更省心
  • 國債逆回購也是現金管理好工具

當期收益率
當期收益率 = 年息 / 市價。面值 1000、票面利率 5%（年息 50）、市價 950，則當期收益率 = 50/950 ≈ 5.26%，高於票面因折價買入。
YTM 含義
到期收益率 YTM 是把未來票息與本金按當前價格貼現、使 NPV=0 的折現率，綜合考慮了折價/溢價與持有期，比當期收益率更全面。

❓ 常見問題（FAQ）

YTM 和票面利率區別？
票面利率是發行時固定的年息比例；YTM 是考慮當前市價後的實際年化回報。折價買入 YTM>票面，溢價買入則相反。
債券價格與收益率反向？
是。市價越低，相對票息與面值的回報越高，收益率上升；價格上漲則收益率下降，這是債券定價基本關係。
