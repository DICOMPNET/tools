📐 計算口徑（單位：萬元）
營業成本 = 營業收入 × 成本率；毛利 = 營業收入 − 營業成本；營業利潤 = 毛利 − 期間費用；所得稅 = 營業利潤 × 所得稅率（虧損為 0）；淨利潤 = 營業利潤 − 所得稅；負債 = 資產總額 × 資產負債率；所有者權益 = 資產總額 − 負債；經營現金流 = 淨利潤 + 折舊攤銷；現金淨增加額 = 經營 + 投資(−資本開支) + 籌資(−分紅)。
三張報表由同一組輸入派生，保證「資產 = 負債 + 所有者權益」與「經營現金流 = 淨利潤 + 折舊攤銷」兩項勾稽恆成立；結果為演示與教學用途，非審計報表。

  • 調整成本率、稅率、負債率觀察毛利、淨利與現金流的連鎖變化。
算例（預設引數，單位萬元）
營業收入 1000、成本率 65% → 營業成本 650、毛利 350；期間費用 150 → 營業利潤 200；稅率 25% → 所得稅 50、淨利潤 150。 資產 1200、負債率 45% → 負債 540、權益 660（1200 − 540 − 660 = 0）。 經營現金流 150 + 折舊 60 = 210；投資 −80、籌資 −30 → 現金淨增加 100，期末現金 300（期初 200）。

❓ 常見問題（FAQ）

結果會隨機變化嗎？
不會。三表完全由輸入引數決定，同一組引數重複生成結果一致，便於複核與課堂對照。
能直接用於正式報表嗎？
不能。模型省略了應收應付、存貨、其他損益等科目，僅用於演示與教學；正式報表需按會計準則編制並經審計。
