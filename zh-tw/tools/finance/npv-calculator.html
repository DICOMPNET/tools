📐 計算公式 / 說明
NPV = Σ CFₜ/(1+r)ᵗ；PI = 未來現金流現值 / 初始投資；IRR 使 NPV = 0
基於折現現金流法：NPV 為初始投資與各期現金流按折現率 r 折現之和；NPV > 0 專案可行；另給出盈利指數 PI、IRR 與回收期，用於資本預算。

📐 公式說明

NPV 淨現值 = Σ CFt / (1+r)^t - 初始投資

NPV > 0：專案可行；NPV < 0：專案不可行

IRR 內部收益率：使 NPV = 0 的折現率

PI 獲利指數 = 未來現金流現值 / 初始投資

PI > 1：可行；PI < 1：不可行

投資回收期：累計現金流轉正所需時間

靜態回收期 = 累計淨現金流量出現正值年份 - 1 + 上年累計絕對值 / 當年淨現金流量

❓ 常見問題（FAQ）

NPV 與 IRR 哪個更可靠？
NPV 以絕對金額反映價值增量、不受多解影響，通常更可靠；IRR 便於直觀比較收益率，但非常規現金流可能多解。
折現率怎麼選？
通常用資本成本或目標收益率（如 WACC、必要報酬率）；折現率越高，遠期現金流折現值越低。
NPV 為正就一定投資嗎？
不一定。還需考慮風險、資金約束與戰略因素，NPV 只是量化參考之一。
