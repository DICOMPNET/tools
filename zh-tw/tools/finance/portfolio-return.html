E(Rp) = Σ wᵢ·Rᵢ

Weighted-average expected return of a multi-asset portfolio.

📐 計算公式
兩資產組合預期收益 rp = 權重 w₁×收益 r₁ + 權重 w₂×收益 r₂（w 以百分比輸入，計算時 ÷100）。校驗：權重、收益為有效數；權重合計應≈100%。

按權重加總的組合期望收益。

📚 深度解析：組合預期收益（加權平均）

💡 常見使用場景

  • 由資產權重與預期收益求組合期望回報。
  • 做配置目標設定。
60%/40%：預期 12% 與 8%
E(Rp) = 0.6×12% + 0.4×8% = 10.4%。即組合預期年化約 10.4%。

❓ 常見問題（FAQ）

權重按市值還是成本？
用當前市值權重更反映實際敞口；再平衡時回到目標權重，收益隨之更新。
組合預期收益是加權平均，風險也是嗎？
預期收益是各資產預期收益按權重的線性加權；但風險不是——組合方差要計入兩兩資產的協方差。這正是分散化的來源：相關性越低，組合波動越小於各資產波動的加權平均。
