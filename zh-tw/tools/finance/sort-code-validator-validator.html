❓ 常見問題（FAQ）

Sort Code 的格式是什麼？
6 位數字，常寫作 XX-XX-XX，標識英國銀行的分行；無算術校驗位，頁面按長度與數字格式校驗。
Sort Code 和 IBAN 的關係？
英國 IBAN 由 GB+校驗位+4 位銀行碼+6 位 Sort Code+8 位賬號組成，Sort Code 是其中的分行標識段。
校驗通過就能到賬嗎？
不能保證。頁面只校驗格式，賬戶有效性須由銀行確認。
