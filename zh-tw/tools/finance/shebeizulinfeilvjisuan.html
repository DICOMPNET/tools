📐 計算公式
D = P×(1−s)/(Y×12)；月租金 R = D + P×r/(12×100) + P×m/(12×100)
基於裝置租賃定價模型：月折舊 D 按原值 P、殘值率 s、折舊年限 Y 直線計提；月租金 R 含折舊+維護(費率 r)+期望利潤(利潤率 m)；用於租賃報價與投資回報評估。
💡 公式：月折舊額 D = P×(1−s) / (Y×12)；月維護費 = P×r/(12×100)；月租金 R = D + 維護費 + P×m/(12×100)；投資回報率 ROI = (R×T − P×s) / (P×s) × 100%（殘值作為期末回收）。
⚠️ 使用說明與注意事項

  • 殘值率為裝置期末剩餘價值佔比，影響折舊額與 ROI

📚 深度解析：裝置租賃費率計算（租金/折舊/ROI）

💡 常見使用場景

  • 租賃定價：由裝置原值、折舊年限與費率算月租金
  • 收益評估：算租期內總租金、淨收益與投資回報率
  • 方案比選：調整租期、利潤率後對比回報水平
方法
演算法：殘值 = 原值×殘值率%；應計折舊總額 = 原值 − 殘值；月折舊 = 應計折舊/(折舊年限×12)；月維護費 = 原值×維護費率/(12×100)；月利潤 = 原值×利潤率/(12×100)；月租金 = 月折舊 + 月維護費 + 月利潤；總租金收入 = 月租金×租期月數；淨收益 = 總租金 + 殘值 − 原值；ROI = 淨收益/原值×100%。另給出日租金、年租金與月租費率。評級：ROI<0 虧損、<10% 低迴報、<30% 合理回報、否則高回報。
算例
例：原值 50 萬元、租期 24 個月、折舊 8 年、維護費率 3%、利潤率 8%、殘值率 5% → 殘值 25000 元、月折舊 4947.92 元、月維護 1250.00 元、月利潤 3333.33 元，月租金 9531.25 元（月租費率 1.906%、日租金 317.71 元），總租金 228750 元，淨收益 −246250 元、ROI −49.25%，評級「虧損」——因為只租 2 年卻按 8 年折舊計租，尚未收回折舊。若租期拉長到 96 個月（8 年）→ 總租金 915000 元、淨收益 440000 元、ROI 88.00%，評級「高回報」。另例：20 萬元、36 個月、折舊 5 年、維護 2.5%、利潤 10%、殘值 8% → 月租金 5150.00 元、總租金 185400 元、淨收益 1400 元、ROI 0.70%，評級「低迴報」。

❓ 常見問題（FAQ）

為什麼短期租約算出來是虧損？
本工具的 ROI 只統計租期內的租金收入，而月折舊按整個折舊年限分攤。租期短於折舊年限時，累計租金不足以覆蓋未折舊完的賬面價值，屬正常現象；評價長期收益應把後續租約或轉售殘值一併計入。
利潤率和維護費率怎麼定？
維護費率可按同類裝置的年均保養支出佔原值比例估算（工程機械常 2%~5%）；利潤率參考行業資金成本與競爭水平，通常 5%~15%。兩者均以年為單位輸入，工具按月攤分。
