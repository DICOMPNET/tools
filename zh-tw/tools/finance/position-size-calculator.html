📈 倉位模擬曲線

🎯 凱利公式 (Kelly Criterion)

公式：f = (bp - q) / b

  • f = 最優倉位比例
  • b = 盈虧比（平均盈利/平均虧損）
  • p = 勝率
  • q = 敗率 = 1 - p

簡化版：f = p - q/b = 勝率 - 敗率/盈虧比

示例：勝率55%，盈虧比2:1 → f = 0.55 - 0.45/2 = 0.325 = 32.5%

注意：實際應用中常用"半凱利"（乘以0.5），降低波動

📐 固定比例法

原理：每次買入固定比例的資金，不考慮勝率和盈虧比

  • 倉位金額 = 總資產 × 固定比例
  • 持股數量 = 倉位金額 ÷ 買入價格
  • 風險金額 = 持股數量 × (買入價 - 止損價)

優點：簡單易用，適合新手

常用比例：單票5%-15%，同時持有3-10只

🛡️ 風險預演算法

原理：根據單筆最大虧損比例反推倉位大小

  • 單筆最大虧損 = 總資產 × 單筆風險比例
  • 每股風險 = 買入價 - 止損價
  • 持股數量 = 單筆最大虧損 ÷ 每股風險
  • 倉位金額 = 持股數量 × 買入價

優點：風險可控，專業交易者常用

常用比例：單筆風險1%-3%

📈 馬丁格爾策略

原理：虧損後加倍下注，期望一次盈利彌補之前虧損

  • 第n次倉位 = 初始倉位 × 倍數^(n-1)
  • 累計倉位 = 初始倉位 × (倍數^n - 1) / (倍數 - 1)

優點：只要不一直加倉，最終盈利可回本盈利

風險：資金可能耗盡，需謹慎使用

📊 倉位管理原則

  • 分散投資：不要把雞蛋放在一個籃子裡
  • 止損紀律：每筆交易必須設止損，嚴格執行
  • 分批建倉：不要一次性滿倉
  • 順勢加倉：盈利時加倉，虧損時減倉
  • 現金儲備：保持一定現金，應對突發情況
  • 風險匹配：倉位大小與風險承受能力匹配

⚠️ 常見誤區

  • 越跌越買：虧損加倉可能導致深度套牢
  • 滿倉操作：沒有容錯空間
  • 頻繁交易：手續費侵蝕利潤
  • 不止損：小虧變大虧
  • 聽訊息炒股：沒有自己的交易系統
  • 追漲殺跌：情緒化交易

❓ 常見問題（FAQ）

凱利公式怎麼用？
最優比例 f=(bp-q)/b（b 為盈虧比、p 為勝率、q=1-p）；實務常用半凱利或 1/4 凱利以降低波動。
固定比例法與風險預演算法有什麼區別？
固定比例按總資金固定百分比開倉；風險預演算法先定單筆可承受虧損，再按止損幅度反推倉位，風險更可控。
按凱利滿倉操作安全嗎？
不安全。凱利假設引數準確，實際勝率與盈虧比難以精確估計，滿凱利回撤極大，建議只取分數凱利。
