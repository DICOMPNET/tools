屬性抽樣公式（泊松分佈法）
n = R / (TM - EP)
R：可信賴程度對應的可靠性因子
TM：可容忍誤差率，EP：預期誤差率
可靠性因子表：90%→2.31，95%→3.0，99%→4.61
變數抽樣公式（均值估計法）
n = (Z × σ × N / TM)² （放回抽樣）
n = n₀ / (1 + n₀/N) （不放回抽樣，有限總體修正）
Z：可靠性係數（95%→1.96，90%→1.645，99%→2.576）
提示：樣本量越大，審計結論越可靠但成本越高。實際工作中還需考慮總體變異性、分層抽樣等因素，本工具結果供參考。

📚 深度解析：審計抽樣樣本量確定

💡 常見使用場景

  • 財務報表審計中，針對內部控制測試（屬性抽樣）確定應抽取多少筆業務以評估偏差率是否可接受。
  • 實質性細節測試（變數抽樣）時，根據可容忍誤差與預計總體誤差計算樣本規模，控制推斷風險。
  • 年審工作量規劃與人員排期時，用樣本量倒推檢查工時，避免抽樣不足導致審計證據不充分。
屬性抽樣樣本量估算
設定信賴過度風險 5%、可容忍偏差率 5%、預計總體偏差率 1%。查屬性抽樣樣本規模表（風險係數法）：5% 風險對應風險係數約 3.0，樣本量 n=風險係數÷可容忍偏差率=3.0÷5%=60 筆；若預計偏差率升到 2%，風險係數升為 4.8，則 n=4.8÷5%≈96 筆。預計偏差越高，所需樣本量越大。

❓ 常見問題（FAQ）

屬性抽樣和變數抽樣怎麼選？
屬性抽樣關注「是否存在偏差」（如審批缺失、憑證不全），結果是偏差率，用於內部控制測試；變數抽樣關注「金額錯報多大」（如高估存貨成本），結果是錯報金額區間，用於實質性細節測試。兩者樣本量公式不同，應分別對應測試目標。
可容忍誤差設大了會怎樣？
可容忍誤差（或偏差率）設得越大，所需樣本量越小、檢查工作量越低，但審計結論的精確度隨之下降，可能漏掉重大錯報。它應低於財務報表重要性水平，並在審計風險模型下與檢查風險、重大錯報風險統籌設定，不能單純為省工而放寬。
