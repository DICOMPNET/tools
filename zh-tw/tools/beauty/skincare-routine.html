📋 你的專屬護膚流程

📌 護膚基本原則

  • 潔面：溫和清潔，避免過度清潔破壞屏障
  • 化妝水：二次清潔、補水、開啟吸收通道
  • 精華：功效性產品，分子小先塗
  • 眼霜：眼周肌膚薄，需要專門護理
  • 乳液/面霜：保溼鎖水，封住前面的營養
  • 防曬：白天最後一步，抗老的關鍵

🔄 正確順序口訣

水 → 精華 → 眼 → 乳 → 霜 → 防曬

質地從稀到稠，分子從小到大。先塗水質，再塗油質。

❌ 不能一起用的成分

酸類 + 酸類
水楊酸+果酸、水楊酸+維A醇 = 過度去角質，屏障受損
維A醇 + 高濃度酸
A醇+果酸/水楊酸 = 刺激性翻倍，容易泛紅脫皮
維C + 煙醯胺
高濃度原型VC（pH<3.5）+煙醯胺 = 可能轉化為煙酸刺激皮膚
銅肽 + 維C
藍銅胜肽遇到維C會被氧化失活
蛋白酶 + 強酸
酶類去角質成分在強酸環境下失活
✅ 安全搭配：
• 早C晚A（但需建立耐受）
• 煙醯胺 + A醇（黃金搭配）
• 神經醯胺 + 任何成分（修護+功效）
• 玻尿酸 + 任何成分（百搭補水）

💡 常見使用場景

幹皮晨晚流程算例
乾性 30 歲：晨間溫水潔面→保溼水→精華（玻尿酸）→面霜→防曬；夜間卸妝→潔面→水→精華→眼霜→面霜（封層）。原則：水質先於油質、分子由小到大、防曬為日間最後一步且不可替代。

❓ 常見問題（FAQ）

精華和麵霜順序能反嗎？
不建議。精華小分子先滲透，面霜大分子後鎖水；先霜後精華會阻礙吸收，且面霜油脂阻隔水溶性成分。
步驟越多越好嗎？
不是。步驟多易疊加刺激、增加成本；以清潔-保溼-防曬為基礎，功效精華按需求 1–2 種足矣，敏感肌做減法更安全。
