ΔOkun's Law

Apply Okun's law to relate the unemployment-rate gap to the output growth gap: Δu ≈ −½(growth gap).

📐 計算公式
奧肯定律（本頁程式碼口徑）：Δu = −0.5×(g−g*)（百分點，g 實際 GDP 增速%、g* 潛在增速%、0.5 為奧肯係數）；聯動量：增長缺口 = g−g*、幅值 = |Δu|、相對增長缺口 = (g−g*)÷(|g*|||1)×100（%，g* 為 0 時分母按 1 兜底）。校驗：無強校驗，空值按 0 兜底。判據：無固定分級，實際增速低於潛在增速 2 個百分點失業率約升 1 個百分點。

實際 GDP 增長率與潛在增長率之差對失業率變化的影響。

Formula Reference

Item Formula / Note Source / Standard
Okun's lawΔu ≈ −β·(g − g*): empirical link between output gap and unemployment (β ≈ 2)Arthur Okun (1962)
📌 計算說明
  • 實際 4%、潛在 3% → 失業率下降約 0.5 點。
  • 係數為 −½（常用近似）。

💡 常見使用場景

  • 失業研判：錄入實際與潛在增速差，估失業率變化。
  • 缺口監測：看產出缺口方向判斷就業冷熱。
  • 教學演示：演示增速低於潛在時失業率上升。
使用示例
示例：實際增速 2%、潛在 3%，缺口 −1%，奧肯係數 2 時失業率約升 0.5 個百分點。

❓ 常見問題（FAQ）

係數固定嗎？
經典約 −2（每 1% 產出缺口對應 −0.5% 失業反差），各國估計不同。結果僅作經濟學教學與快速測算參考，不構成投資建議或政策依據，涉及預測與經驗估算的部分以權威統計與教材為準。
潛在增速？
由勞動力與全要素生產率趨勢估得，統計機構定期更新，非觀測值。結果僅作經濟學教學與快速測算參考，不構成投資建議或政策依據，涉及預測與經驗估算的部分以權威統計與教材為準。
是定律嗎？
經驗關係非嚴格定律，結構變化時會漂移，宜作近似研判。結果僅作經濟學教學與快速測算參考，不構成投資建議或政策依據，涉及預測與經驗估算的部分以權威統計與教材為準。
