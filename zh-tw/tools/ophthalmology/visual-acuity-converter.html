📐 計算公式
通用樞紐 logMAR = −log10(小數視力)：Snellen 20/6/5 制先按 分母基準÷分子 化小數，5 分記錄反演 logMAR = 5 − 記錄值，ETDRS 反演 logMAR = 1.10 − 字母數×0.02；反向小數視力 = 10^(−logMAR)，再換算 20/、6/、5/ 行、5 分記錄 = 5 − logMAR、ETDRS = (1.10 − logMAR) ÷ 0.02。校驗：非數提示輸入，logMAR 非有限值提示「數值無效，無法換算」。判據：logMAR ≤0 正常、≤0.3 輕度下降、≤1.0 中度、≤1.3 重度、>1.3 盲目/低視力。

✨換算公式

  • logMAR = −log10(小數視力)
  • 中國5分 = 5 − logMAR
  • ETDRS letters ≈ (1.10 − logMAR) / 0.02

💡 常見使用場景

  • 小數 = 基準/值；logMAR = −log10(小數)；5 分記錄 = 5 − logMAR。
  • Snellen 20/6/5 與 ETDRS 行號互換。
  • 科研與臨床統一視力單位。
20/20
小數 1.0、logMAR 0、5 分記錄 5.0、ETDRS 行號 55，對應正常視力。
20/200
小數 0.1、logMAR 1.0、5 分記錄 4.0、ETDRS 行號 (1.10−1.0)/0.02 = 5，屬低視力。

❓ 常見問題（FAQ）

logMAR 越大視力越差？
是，logMAR 與視力對數成反比，值越大越差；每 0.1 約一行。
ETDRS 行號怎麼得？
由 logMAR 線性對映（如 (1.10−logMAR)/0.02），用於閱讀視力表分級。

Formula & Standard References

Item Formula / Rule Source / Standard
ETDRS letters Five letters per row and 0.02 log unit per letter: logMAR = 1.10 − 0.02 × correct letters; score 0–70, with 20/20 = 55, 20/10 = 70, and worse than 20/200 scored 0 Ferris et al., New visual acuity charts, Am J Ophthalmol, 1982
Five-point notation Five-point score = 5 − logMAR, so decimal 1.0 equals 5.0 GB 11533-2011 Standard logarithmic visual acuity charts

📊 結果解讀

三種刻度

Snellen（20/20、6/6）、小數視力（1.0）、logMAR（0.0）三者等價表達同一視力：20/20=6/6=1.0=0.0 logMAR；分子越大（如 20/40）視力越差。

用途

不同國家視力表互轉；logMAR 便於統計與科研（數值越大越差）。

注意

換算為數學對應，實際視力受光照、距離、矯正狀態影響；以專業驗光為準。
