📐 計算公式
社保繳費測算（本頁程式碼口徑，城市×險種查表）：繳費基數=稅前工資按下限上限夾取——工資<下限按下限、>上限按上限、否則按實際工資；每險種單位月繳=基數×單位比例、個人月繳=基數×個人比例（如北京養老單位 16%、個人 8%，基數 6326–33891 元）；單位與個人月繳為養老/醫療/失業/工傷/生育五險逐行累加。校驗：無強校驗，空值按 0 兜底。判據：無固定分級，各城市各險種上下限與比例由城市配置表驅動，可切換城市對比。

💡 常見使用場景

  • 按當地上下限把工資「 clamp 」到繳費基數，估算單位與個人各險種繳費額。
  • 工資低於下限按下限、高於上限按上限繳納。
  • 對比不同城市費率與基數，輔助參保與薪酬規劃。
基數 1 萬、常見費率
養老單位 16% = 1600、個人 8% = 800；醫療單位約 8% = 800、個人 2% = 200；失業單位 0.5% = 50、個人 0.5% = 50；月繳單位合計約 2470、個人約 1050 元（費率以當地為準）。
工資越限處理
工資 3000 低於下限 4250 則按下限繳；工資 3 萬高於上限 21258 則按上限繳，超出部分不計入基數。

❓ 常見問題（FAQ）

繳費基數怎麼確定？
一般以上年度本人月平均工資為準，在當地公佈的上下限之間；新參保按起薪當月工資，後續年度調整。
單位和個人比例固定嗎？
全國框架統一但各省費率略有差異（如工傷按行業風險浮動、醫保單位比例不同），以參保地規定為準。
