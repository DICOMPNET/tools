a = g·(sinθ − μ·cosθ)

Enter the incline angle, static/kinetic friction coefficients, and initial state to decide whether the object starts from rest and compute the acceleration once sliding.

📐 計算公式
斜面臨界與下滑加速度：先比較 tanθ 與靜摩擦係數 μ_s 判斷能否由靜止起動；已滑動後用動摩擦係數 μ_k 計算 a = g × (sin θ − μ_k × cos θ)（m/s²）。校驗：θ 須在 0–90°、μ_s/μ_k 非負、g 為正，空值或非數值會提示並中止，不按 0 兜底。判據：由靜止釋放且 tanθ ≤ μ_s → 靜止（靜摩擦平衡）；tanθ > μ_s → 起動。已向下滑動時 a > 0 加速、a = 0 勻速、a < 0 減速，負加速度不代表靜止。

輸入斜面傾角、靜/動摩擦係數與初始狀態，判斷能否起動並計算已下滑時的加速度。

💡 常見使用場景

  • 斜面下滑：錄入傾角與摩擦係數，求加速度，判斷物體是否加速下滑（sinθ>μcosθ）。
  • 貨物輸送：對傳送帶/斜坡錄入引數，估算下滑或需施加的約束力。
  • 教學演示：演示傾角增大加速度增大、摩擦增大則減小。
使用示例
示例：θ=30°、μ=0.2、g=9.8，a=9.8×(0.5−0.2×0.866)=9.8×0.327≈3.2 m/s²。

❓ 常見問題（FAQ）

物體一定下滑嗎？
當 sinθ>μcosθ（即 tanθ>μ）才加速下滑；否則靜止或需外力。結果按標準力學公式即時計算，供物理學習、作業演算與工程估算參考；涉及安全或實際工程請以專業規範與實測資料為準。
無摩擦時呢？
μ=0 時 a=g sinθ，即沿斜面分量決定加速度，與質量無關。結果按標準力學公式即時計算，供物理學習、作業演算與工程估算參考；涉及安全或實際工程請以專業規範與實測資料為準。
質量影響加速度嗎？
理想斜面（無滾動）加速度與質量無關；若考慮轉動慣量（滾動）則略降。結果按標準力學公式即時計算，供物理學習、作業演算與工程估算參考；涉及安全或實際工程請以專業規範與實測資料為準。
