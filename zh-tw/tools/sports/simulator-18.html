💧 Bernoulli Trial Simulator

Run independent Bernoulli trials with a given number of trials and success probability, then report the observed frequency and deviation.

📐 工作原理與說明
伯努利試驗蒙特卡洛模擬：每次試驗獨立以機率 p 判定成功，進行 n 次；實際頻率 = 成功次數 / n；理論機率為 p；實際頻率與理論值之差即抽樣偏差，其標準誤為 sqrt(p*(1-p)/n)，隨 n 增大而減小。

📚 深度解析：高原（低氧）適應模擬

💡 常見使用場景

  • 模擬低氧訓練刺激。
  • 登山前模擬目標海拔血氧適應，預演何時需補氧與降速。
模擬
間歇低氧（IHT）設 FiO₂≈15% 模擬約 2500 m，刺激紅血球生成。

Formula & Standard References

Item Formula / Note Source / Standard
Single trial Each trial is independent with a constant success probability p Bernoulli trial definition
Successes The number of successes in n trials follows the binomial distribution B(n,p) Binomial distribution
Standard error Standard error of the frequency sqrt(p·(1−p)/n) Sampling theory
