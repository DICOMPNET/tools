📖 重音規則說明

規則一：以母音 / n / s 結尾

以母音 (a, e, i, o, u) 或子音 n、s 結尾的單詞，重音落在倒數第二音節。

casa → CA-saperro → PE-rrocantan → CAN-tanmeses → ME-ses

規則二：以其他子音結尾

以除 n、s 以外的子音結尾的單詞，重音落在倒數第一音節(末音節)。

papel → pa-PELfeliz → fe-LIZseñor → se-ÑORreloj → re-LOJ

規則三：重音符號 (´)

如果重音不落在上述預設位置，必須用重音符號標出。有重音符號的單詞，重音就是符號所在音節。

lápiz → LÁ-pizespárrago → es-PÁ-rra-gojamás → ja-MÁSestán → es-TÁN

規則四：二重母音和三重母音

二重母音 (ai, au, ei, eu, ia, ie, io, iu, ou, ua, ue, uo, ui) 中，強母音 (a, e, o) 與弱母音 (i, u) 組合算一個音節；兩個弱母音也算一個音節。兩個強母音相鄰則分屬不同音節。

ciudad → ciu-DADpais → pa-ÍSreal → re-AL

💡 常見使用場景

  • 查單詞該不該加重音符號（á/é/í/ó/ú/ñ）
  • 區分同形異義詞（如 el/él、si/sí）的標法
  • 拼寫檢查前先確認重音分類
同形異義
el（定冠詞，無重音）vs él（他，有重音）；si（如果）vs sí（是的/重音在末）；依賴重音區分語義。
標法判定
café 以子音結尾且重音在末 → 標 é；libro 以母音結尾重音在次末 → 不標；反覆練習可內化規則。

❓ 常見問題（FAQ）

重音符號只標母音？
是，西語重音符號只加在 a/e/i/o/u 上（ñ 是獨立字母非重音）；á 等表示該音節重讀。
疑問詞一定標重音？
是，疑問/感嘆詞（qué/cuándo/dónde）必標重音以區別於關係代詞（que/cuando），屬固定寫法。

結果含義

西班牙語重音規則：按單詞末尾音節分類——以母音/n/s 結尾為重音在倒數第二音節（llana，通常無符號），其他結尾在末音節（aguda，需重音符號）；倒數第三音節（esdrújula）必帶符號。

用途

結果標註該詞的重音位置與是否需加重音符號；疑問/感嘆詞（ qué/quién ）另加符號。規則為一般性，專有名詞除外。
