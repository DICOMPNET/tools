音節拆分
한 = 初聲 ㅎ + 中聲 ㅏ + 終聲 ㄴ；사 = ㅅ+ㅏ（無終聲）；랑 = ㄹ+ㅏ+ㅇ。每個方塊由三要素組合。
Unicode 編碼
諺文音節 = 0xAC00 + 初聲序號×588 + 中聲序號×28 + 終聲序號；如 한(0xD55C) 可反推三要素，便於程式化拆解。

❓ 常見問題（FAQ）

為什麼分初聲中聲終聲？
諺文是音素文字，方塊由子音(初)+母音(中)+可選子音(終)拼成；會拆就能懂任何生字的拼讀邏輯。
終聲一定是子音嗎？
終聲(받침)只能是 27 個合法收音之一（含 ㅇ 等），可空；母音不能作終聲，雙終聲按代表音歸一。
