📐 工作原理與說明
助行器與柺杖手柄高度適配計算
大轉子高度 = 身高 × 0.57（股骨大轉子約為身高 57%）
腋窩高度 = 身高 × 0.77；前臂套環（鷹嘴）高度 = 身高 × 0.74
手柄高度：優先取腕橫紋實測值 + 2cm，否則取大轉子高度
鞋底修正：鞋底 ≠ 2cm 時手柄 += 鞋底 − 2
場景修正：樓梯使用 −2cm；不平地面 +1cm
腋托高度 = 腋窩高度 − 5cm（腋窩下 5cm，防臂叢神經壓迫）
肘關節屈曲應在 20~30°
手柄高度/身高正常範圍 54%~60%
器具適配：標準助行器/前臂柺杖/腋拐/單拐手杖（用健側）
步態：助行器先推一步再患肢後健肢；四點步態 右拐→左腳→左拐→右腳
　三點步態 雙柺+患肢→健肢；兩點步態 右拐+左腳→左拐+右腳
年齡 >75 歲建議有輪助行器並增加平衡訓練

Key formulas: finalHandleHeight ÷ height × 100; height × 0.57; wristH + 2

📖 輔助器具高度標準

標準助行器（Walker）

  • 手柄高度 = 股骨大轉子高度（約身高的55-60%）
  • 或 = 地面至腕橫紋距離 + 2-3cm
  • 站立時肘關節屈曲20-30度
  • 使用時身體應在助行器後方，不要太前傾

前臂柺杖（Forearm Crutch）

  • 手柄高度同助行器（腕橫紋+2-3cm）
  • 前臂套環高度 = 鷹嘴上方2.5-3cm
  • 前臂套環鬆緊適中，能通過前臂但不滑脫

腋拐（Axillary Crutch）

  • 腋托高度 = 腋窩下方5cm（約身高的77%）
  • 手柄高度 = 腕橫紋+2-3cm（肘屈20-30°）
  • 腋窩不應直接承重，力量在手上
  • 腋托與腋窩保留2-3指寬度間隙

單拐/手杖（Cane）

  • 手柄高度 = 股骨大轉子高度
  • 或 = 地面至腕橫紋距離
  • 站立時肘關節屈曲20-30度
  • 應使用在健側（非患側）

❓ 常見問題（FAQ）

手柄多高合適？
站立時手柄齊腕橫紋（大轉子水平），肘屈曲 20-30°；過高聳肩、過低彎腰，均增加勞損。
肘屈多少度最好？
站立雙臂自然下垂，手柄高度約平股骨大轉子（或腕橫紋）水平，此時肘關節屈曲約 20–30°。屈曲過小（小於 15°）支撐時肩臂易疲勞、推起困難；過大（大於 40°）則重心前移、軀幹前傾，反而不穩且增加腰揹負擔。調節後讓患者實際行走觀察：若出現聳肩或身體前傾，需再微調 1–2 cm。
