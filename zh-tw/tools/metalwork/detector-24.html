🔍 Flaw Detection Setup (X-ray, Ultrasonic, Penetrant)

Configure flaw detection using X-ray, ultrasonic or penetrant testing and assess sensitivity and applicable defect types.

📐 工作原理與說明
焊縫探傷質量分級評定
射線探傷 RT（GB/T 3323）：按缺陷長/板厚比 + 數量
　≤3% 且 ≤3 個 → Ⅰ級｜≤6% 且 ≤6 → Ⅱ級
　≤10% 且 ≤10 → Ⅲ級（有條件）｜≤15% → Ⅳ級｜其他 Ⅴ級
超聲探傷 UT（GB/T 11345）：按指示長度
　≤6mm 且 ≤3 → Ⅰ｜≤12 且 ≤6 → Ⅱ｜≤20 且 ≤10 → Ⅲ｜其他 Ⅳ
滲透探傷 PT（JB/T 6062）：按痕跡尺寸
　≤1.5mm → Ⅰ｜≤3 → Ⅱ｜≤6 → Ⅲ｜其他 Ⅳ
不合格須返修後重新探傷
Ⅲ 級為有條件合格，結合工況綜合判定

依據 GB/T 3323（射線）、GB/T 11345（超聲焊縫）、GB/T 9443（滲透）等國家標準，對輸入的探傷方法、缺陷長度、母材厚度等引數進行質量等級評定；原理為缺陷尺寸與板厚比對照等級限值，結果即時輸出。純前端本地計算，資料不出瀏覽器。

💡 常見使用場景

  • 按缺陷型別選擇 X 光、超聲或滲透探傷。
  • 評估各方法的適用材料與靈敏度。
  • 制定無損檢測工藝卡。
內部氣孔/縮孔
鑄件內部缺陷優先用 X 光或超聲；X 光成像直觀，超聲對大厚度件穿透力更強。
表面裂紋
表面開口缺陷用滲透探傷靈敏、成本低；近表面缺陷可用磁粉（鐵磁材料）。

❓ 常見問題（FAQ）

超聲和射線哪個更好？
二者互補：射線適合體積型缺陷與成像，超聲對面積型缺陷（裂紋、未熔合）更敏感。
滲透探傷能查內部缺陷嗎？
不能。滲透只能檢出表面開口缺陷，內部缺陷需用射線或超聲。

📝工具簡介

鑄件無損探傷等級評定工具，支援射線(RT)、超聲(UT)、滲透(PT)三種探傷方法，輸入缺陷引數後自動對照國家標準評定質量等級。

✨功能特點

  • 支援RT/UT/PT三種探傷方法
  • 依據國家標準自動分級
  • 缺陷長度/板厚比自動計算
  • 生成專業檢測報告

🎯使用場景

  • 鑄件質量驗收檢測
  • 焊接接頭無損探傷
  • 壓力容器定期檢驗
  • 產品質量出廠檢驗

如何使用檢測（X光/超聲/滲透）探傷

  1. 在對應的輸入框或選項中填寫、選擇所需引數。
  2. 點選「計算」或「生成」按鈕執行。
  3. 在結果區檢視輸出，可複製結果或匯出使用。

引數說明

  • 探傷方法
  • 缺陷長度 (mm)
  • 母材厚度 (mm)
  • 缺陷數量（評定區內）

適用場景

射線探傷（RT）等級評定：輸入缺陷長度與母材厚度，對照 GB/T 3323 評定鑄鋼件或焊縫質量等級（Ⅰ–Ⅳ級），輸出是否合格及整改建議；超聲探傷（UT）焊縫檢測：對對接焊縫掃查，按 GB/T 11345 評定缺陷指示長度與等級，定位未熔合、未焊透等體積型缺陷。
