⚡ Cable Tray Sizing Calculator

Size cable trays and ladder racks from cable count, diameter and fill ratio to select a compliant tray width and height.

📐 計算公式

單根截面積 A₁ = π·D²/4；電纜總截面積 A = A₁·N；所需橋架面積 A_need = A / 填充率；推薦規格取滿足「寬×高 ≥ A_need」的最小規格；實際填充率 = A /(寬×高)×100%

D 為單根電纜外徑(mm)，N 為電纜根數；填充率按用途取 40%（動力）、50%（控制）等。按面積法選型可保證散熱餘量與施工空間。

❓ 常見問題（FAQ）

填充率取多少合適？
動力電纜常取 40%，控制電纜可放寬至 50%；高溫或需擴容場合宜更低。
為什麼按面積而不是按根數選型？
同樣根數不同直徑佔用空間差異大，按面積法能真實反映敷設所需空間。
⚠️ 使用說明與注意事項
  • 橋架面積 = 電纜截面積之和 ÷ 填充率
  • 填充率：電力 40%、控制 50%、擴容預留 60%
  • 選滿足面積的最小標準規格
  • 正式設計按 GB/T 29415 與散熱校核執行
