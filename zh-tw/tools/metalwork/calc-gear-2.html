📐 計算公式
端面模數 mt、齒數 z、螺旋角 β（β=0 即直齒）、法向壓力角 αn=20°：分度圓 d = mt×z；法向模數 mn = mt×cosβ；端面壓力角 αt = atan(tanαn ÷ cosβ)；齒頂圓 da = d + 2×mn；齒根圓 df = d − 2.5×mn；基圓 db = d×cosαt；端面齒距 pt = π×mt；軸向齒距 px = π×mt/tanβ（直齒時無軸向齒距）。滾齒：滾刀轉速 n刀 = 1000×Vc ÷ (π×滾刀外徑)，工件轉速 n工 = n刀 ÷ z（單頭滾刀），進給 Vf = n工×f；插齒：n = 1000×Vc ÷ (π×d)，Vf = n×f。校驗：端面模數須為有效正數、齒數至少 4、螺旋角 0–45°、切削速度與進給量須 >0，否則逐項提示。提示：滾齒滾刀轉速>500 rpm 或插齒 n>800 rpm 時提醒檢查刀具與機床（閾值為本頁提示線，非驗收標準），另按材料表給出推薦切削速度 Vc 參考值。
輸入端面模數、齒數、螺旋角（0 為直齒）與加工方法；斜齒時齒頂圓/齒根圓按法向模數 mn、基圓按端面壓力角 αt 修正，並計算切削加工引數。
💡 分度圓 d=mt×z；法向模數 mn=mt×cosβ；齒頂圓 da=d+2×mn、齒根圓 df=d−2.5×mn；基圓 db=d×cosαt（αt=atan(tan20°/cosβ)）；滾刀轉速 n=1000×Vc/(π×d)。

💡 常見使用場景

  • 設計齒輪時求分度圓、齒頂圓、齒根圓、基圓直徑。
  • 由模數 m、齒數 z 決定齒距與齧合尺寸。
  • 核算轉速與進給匹配滾齒/插齒。
標準直齒輪
m=2、z=24：分度圓 d = 2×24 = 48mm，齒頂圓 da = 2×(24+2) = 52mm，齒根圓 df = 2×(24−2.5) = 43mm，基圓 db = 48×cos20° ≈ 45.1mm，齒距 p = 2×π ≈ 6.283mm。
滾齒轉速
vc=40m/min：n = 1000×40÷(π×48) ≈ 265.3 rpm，進給速度按走刀量設定，保證齒面粗糙度。

❓ 常見問題（FAQ）

模數是什麼？
模數 m = 分度圓直徑÷齒數，是齒輪尺寸與強度的核心引數，必須成對齧合相同，單位 mm。
基圓有什麼用？
基圓決定漸開線齒廓形狀，db = d×cos(壓力角)；壓力角標準 20°，基圓越小齒根越瘦。
