Return on Assets (ROA) Calculator

Compute return on assets from net income and average total assets to measure the profit generated per unit of assets.

📐 計算公式
總資產收益率（本頁程式碼口徑）：ROA=淨利潤÷總資產×100（%）；聯動量：小數形式=淨利潤÷max(總資產,10⁻⁹)、資產淨利比=總資產÷max(淨利潤,10⁻⁹)、萬分比形式=淨利潤÷總資產×10000。校驗：兩欄位經輸入守衛必填且須為合法數值，否則提示並中止。判據：無固定分級，ROA 與淨利潤成正比、與總資產規模成反比，分母按 10⁻⁹ 兜底防除零。

ROA = 淨利潤 / 平均總資產。

📚 深度解析：淨利 / 總資產

💡 常見使用場景

  • 衡量企業運用全部資產創利的能力，評價管理層資源配置效率。
  • 對比同業 ROA，判斷資產擴張是否帶來相應回報。
  • 投資者結合 ROA 與槓桿，理解 ROE 的來源。
計算總資產收益率
某公司淨利潤 400 萬元、平均總資產 4000 萬元，ROA=400/4000=10%，即每 1 元資產年創淨利潤 0.1 元。

❓ 常見問題（FAQ）

ROA 和 ROE 的區別？
ROA 看全部資產（含負債形成）的回報，ROE 只看股東投入的回報；ROE 因槓桿會被放大，ROA 更反映資產本身的盈利能力。
ROA 偏低但 ROE 高說明什麼？
說明企業大量運用負債放大了股東回報，但同時也累積了財務風險，需警惕槓桿不可持續。
