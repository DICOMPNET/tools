API Gravity

API Gravity

📐 工作原理與說明
比重 SG = 141.5 ÷ (API 度 + 131.5)；密度(g/cm³) = SG × 同溫度水的密度，密度(kg/m³) = 前者 × 1000。合法性：未填提示輸入 API 度，≤ −131.5 時分母非正、提示應大於 −131.5。原油分類：API > 31.1 輕質原油、≥ 22.3 中質原油、≥ 10 重質原油、< 10 超重質/瀝青

API Gravity: computes and outputs results from the input parameters.

📋 原油分類與公式

API 度 = 141.5 / SG − 131.5

SG = 141.5 / (API + 131.5)

密度 = SG × 水密度（g/cm³）

API 度類別典型代表
> 31.1輕質原油布倫特、WTI
22.3 - 31.1中質原油迪拜原油
10 - 22.3重質原油瑪雅原油
< 10超重質/瀝青委內瑞拉重油

📚 深度解析：API 度與密度換算

💡 常見使用場景

  • 原油貿易與計價：不同產區原油以 API 度報價，需換算為比重(SG)與密度(g/cm³、kg/m³)才能計算質量、體積與船運配載；工具按 API↔SG 互算，輸入任一即可得另一量。
  • 煉廠裝置設計與混兌：原油調和時要按密度核算混合油比重，API 度越高表示越輕、經濟價值通常越高；用 classify 可快速判斷輕質/中質/重質/超重質。
  • 實驗室與計量交接：交接計量常以 60°F(15.6℃) 標準密度為準，本工具以 60°F 水相對密度 1.0 為基準折算密度，便於與計量單對照。
算例：API 度換算為相對密度與類別
API=30 時 SG = 141.5/(30+131.5) = 0.8762，密度(水=1.0) = 0.8762 g/cm³ = 876.2 kg/m³；classify(30)：22.3≤30≤31.1 → 中質原油。 API=35 時 SG = 141.5/166.5 = 0.8498，密度 0.8498 g/cm³，classify(35)>31.1 → 輕質原油。 反算：SG=0.85 → API = 141.5/0.85 - 131.5 = 34.97°API（輕質）。分類閾值：>31.1 輕質、≥22.3 中質、≥10 重質、<10 超重質/瀝青。

❓ 常見問題（FAQ）

API 度是怎麼定義的？
API 度是美國石油學會的相對密度標度：°API = 141.5/SG - 131.5（SG 為 60°F 相對密度）。數值越大油越輕；°API=10 時 SG=1.0（與水等重），大於 10 比水輕、小於 10 比水重。
原油輕重如何分類？
常用分界：API>31.1 為輕質原油、22.3~31.1 為中質、10~22.3 為重質、<10 為超重質/瀝青。輕質油更易提煉高附加值餾分，通常溢價。
