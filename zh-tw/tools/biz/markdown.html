❓ 常見問題（FAQ）

和標準 Markdown 有差異嗎？
本工具按 GitHub 風格 GFM 解析（支援表格、刪除線、任務列表）；若你用嚴格 CommonMark，部分擴充套件語法（如表格）在標準裡不定義，遷移時注意。
HTML 混寫安全嗎？
Markdown 允許內聯 HTML，但釋出到公網前需確認不過濾危險標籤；本工具僅本地渲染，不上傳內容。
