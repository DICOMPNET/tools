📚 深度解析：提取 HTML 標籤

💡 常見使用場景

  • 分析頁面結構：列出文件中所有標籤與不同標籤數，快速瞭解骨架。
  • 抽取特定標籤：在“指定標籤”填 a,img 等，勾選保留屬性，篩出對應標籤做資源盤點。
  • 模板審查：匯出開/閉標籤清單後人工比對，發現缺失的閉合標籤。
抽取並核對 a 標籤
貼上一段 HTML，在“指定標籤”填 a 並勾選“保留屬性”，結果逐條列出全部 <a ...> 開標籤，可檢查 href 是否為空或指向站外；取消保留屬性則只輸出 <a> 形式，便於計數。

❓ 常見問題（FAQ）

會處理巢狀嗎？
按文件順序列出標籤，巢狀關係需結合縮排/層級檢視；本工具偏「標籤清單」，結構性分析建議配合 DOM 工具。
腳本里的標籤也算嗎？
預設統計所有 <...> 形態；勾選“排除 script/style/註釋”後，會先剔除 <script>、<style> 與 <!-- --> 註釋塊，再統計正文標籤。
