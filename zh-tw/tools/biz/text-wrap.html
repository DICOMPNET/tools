📐 計算公式 / 原理
字元模式：行數 = ⌈文本長度 / 寬度⌉，第 i 行 = 文本[i×寬度 : (i+1)×寬度]（按碼點計數，emoji 不拆分）；詞模式：按空白切詞並保留原段落換行，累計長度超過寬度即換行；取消「不截斷單詞」時超長詞按寬度強制切分，勾選時整詞保留可超寬
字元模式嚴格按定長切分，會切斷英文單詞與中文詞語，適合固定寬度裝置（如小票、終端）。詞模式保持單詞完整，行數略多但可讀性好，是正文排版的預設選擇。兩種模式均按 Unicode 碼點計數，emoji 等代理對字元視為一個字元，不會被拆壞；視覺寬度仍以實際渲染為準（CJK 全形字元約佔兩列）。換行符可選 \n、\r\n 或

💡 常見使用場景

  • 固定寬度排版：把長段落按每行 N 字元斷行，適合終端/郵件正文。
  • 程式碼註釋換行：長說明按 80 列折行，符合規範。
  • 移動端預覽：窄屏按短行重排提升可讀。
按 40 字寬換行
一段 120 字說明設寬度 40，拆成 3 行各約 40 字，在等寬字型下整齊；注意不在單詞中間斷（除非開啟強制斷）。

❓ 常見問題（FAQ）

會在詞中斷開嗎？
預設在空格處斷行（不切斷英文詞）；中文無空格時可按字元寬斷，需開啟「按字元」模式避免超寬。
和文本分割區別？
分割按分隔符拆，換行按寬度智慧折行並保持語義完整，適合排版而非資料拆分。
