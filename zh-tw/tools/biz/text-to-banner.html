🎉 Text to Banner

📐 工作原理與說明
文本列寬 = Σ（半形字元 1 列 / 中文、全形標點、emoji 2 列）；內容寬 = 文本列寬 + 左右填充 × 2；邊框行 = 左上角字元 + 橫線條重複內容寬次 + 右上角字元；上下各插 縱向填充 行（豎線 + 填充符 × 內容寬 + 豎線）；文本行 = 豎線 + 填充符 × 左填充 + 文本 + 填充符 × 右填充 + 豎線；底邊同頂邊，用左下 / 右下角字元

Wrap text in a configurable ASCII/Unicode character frame, preview the column-aligned banner, then copy it or download it as a .txt file (no image or colour output).

生成「HI」橫幅
輸入「HI」、井號填充、左右內邊距 2 → 文本列寬 2、內容寬 6，輸出「╔════════╗ / ║##HI##║ / ╚════════╝」（實際為 3 行，上下填充為 0）；複製或下載後可直接粘進終端與 README。

❓ 常見問題（FAQ）

中文會錯位嗎？
不會。工具按顯示列寬計算：中文、全形標點與 emoji 各計 2 列，半形字元計 1 列，因此中英混排的邊框能對齊；但終端字型若非等寬，實際顯示仍可能輕微偏移。
有哪些樣式？
8 種字元邊框：井號填充、星號包圍、等號橫線、虛線框、雙線框、圓角框、愛心邊框、菱形邊框；再配合左右與上下內邊距控制留白。
能匯出圖片嗎？
不能。本工具只產出純文本字元橫幅，可複製或下載 .txt；需要圖片請用截圖或專門的圖片橫幅工具，頁面不再宣稱圖片匯出。
