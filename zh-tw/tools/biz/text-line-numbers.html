🔢 Line Number Adder

📐 工作原理與說明
行號 = 起始值 + 步進 × 行序；補零寬度 = 設定值或最大行號位數；九種格式：N. / N) / [N] / {N} / N: / N | / N- / ＞ N / 純數字；可跳過空行（保留空行）、編號後加分隔空格

Add continuous line numbers to every line with a configurable start value and separator, useful for pasting code, quoting manuscripts and numbering step lists.

📚 深度解析：加行號

💡 常見使用場景

  • 程式碼展示與引用：給片段加 1. 2. 行號，便於討論時定位「第 N 行」。
  • 教學與文件：標註步驟序號，讀者可對照。
  • 日誌對齊：給擷取日誌加行號便於回溯。
給 5 行加行號
貼上 5 行，設起始 1、格式「N. 」，輸出「1. …/2. …」；匯出後引用「見第 3 行」一目瞭然。

❓ 常見問題（FAQ）

能從指定數開始嗎？
可以設起始值（如從 10 開始），適合接在上一段之後連續編號。
加號還是點？
支援「N.」「N)」「[N]」等；純展示用，不影響原文本邏輯。
