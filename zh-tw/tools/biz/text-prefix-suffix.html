🏷️ Prefix & Suffix Adder

📐 工作原理與說明

Add a fixed prefix or suffix (such as numbering or symbols) to every line, with regex and separator support for batch list formatting.

設定

拼 SQL IN 列表
貼上「a/b/c」每行一個，加字首「'」字尾「',」得「'a',『b',『c',」，最後一項去掉尾逗號即得 ('a','b','c')，省去手敲。

❓ 常見問題（FAQ）

尾逗號怎麼處理？
可在選項去掉末行字尾，或用「末行不加」模式，避免 SQL 語法錯誤；也可生成後手動刪最後一個逗號。
內容含引號會衝突嗎？
會。若原文本已有單引號，再包單引號會破壞字串；此時改用雙引號或轉義，或選無衝突的分隔。
