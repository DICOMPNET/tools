❓ 常見問題（FAQ）

IPv6 能抽嗎？
可在選項開啟 IPv6 匹配（如 2001:db8::1）；預設多按 IPv4，避免把普通冒號數字誤判。
私網和公網怎麼區分？
抽得後按 RFC 1918（10/8、172.16/12、192.168/16）標註私網，便於區分內網與外網來源。

Item Formula / Note Source / Standard
IPv4 format IPv4 is four dotted decimal octets each ranging zero to two hundred fifty-five RFC 791, internet protocol
IPv6 format IPv6 is eight hexadecimal groups separated by colons with zero compression RFC 4291, IPv6 addressing
