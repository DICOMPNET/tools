🔁 Text Repeater

📐 工作原理與說明
重複次數 = 解析後的整數（預設 1）；分隔符為 custom 時取自定義串、為 \n 時取換行。逐次生成：勾選編號時正序取 i + 1、倒序取 次數 − i，勾選補零時按 padStart 補到「次數」的位數；每條拼成「編號 + 空格 + 原文」，最後用分隔符連線全部條目

Repeat a piece of text a set number of times, per block or per line, with prefix, suffix and separator options for test data, placeholders and bulk content.

💡 常見使用場景

  • 生成分隔線：重複「-」或「=」若干次做章節分隔。
  • 佔位與測試：生成指定長度的重複串，測試輸入框上限或排版。
  • 趣味/裝飾：重複字元做簡單圖案。
生成 40 個短橫線
輸入「-」重複 40 次得「----------------------------------------」，用作 Markdown 分隔或終端標題線；也可重複短語做填充。

❓ 常見問題（FAQ）

能按行重複嗎？
可設「整段重複 N 次」或「每行重複」，區別在是否換行；做分隔線用單行重複，做列表用按行重複。
超長會怎樣？
僅受記憶體與顯示限制，極長串在某些編輯器會卡；按需控制長度。
