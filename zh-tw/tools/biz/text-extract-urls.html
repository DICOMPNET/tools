🔗 URL Extractor

📐 工作原理與說明
URL 正則為 (https?://|ftp://|file://)? 開頭可選協議，主機支援含點域名 / localhost / IPv4 / [IPv6]（BS-N44，舊式強制點號會漏內網帶埠地址），接可選埠 :數字，再接可選的路徑（不含空白與 < > " ' ( ) [ ] { }）。缺協議時自動補 http://；只要 HTTP/HTTPS 時丟棄 ftp/file 開頭的項；去引數時先按 ? 截斷再按 # 截斷。之後按選項去重（保留首次出現）、字典序排序，輸出條數即結果條數，用所選分隔符連線（分隔符為 \n 時按換行連）

Extract every URL from long text or page source and deduplicate the list, handy for batch reference collection, backlink audits and link validation.

  • 從文本批次抽連結：得到可點選/可採集的 URL 清單。

  • 資料準備：把散落 URL 彙總去重，匯入爬蟲或書籤。
從公告抽連結
文本含「詳見 https://a.com/doc 與 http://b.cn/help」，工具抽得兩個 URL 並去重，可直接用於批次探測可達性。

❓ 常見問題（FAQ）

帶引數的長連結完整嗎？
完整保留 query（?id=1&t=2）；但末尾標點若緊貼會被誤含，建議抽取後 trim 或啟用「止於標點」模式。
相對路徑能抽嗎？
相對路徑（/doc/a）不以 http 開頭，預設不抽；需結合基址拼接時才算完整 URL。
