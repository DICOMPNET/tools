Angular Momentum (L = n·ℏ)

Compute the orbital angular momentum of an electron from the principal quantum number n using the simplified L = n·ℏ relation, useful for atomic-physics and quantum-mechanics exercises.

📐 計算公式
角動量 L = n·ħ（ħ = 1.054571817×10⁻³⁴ J·s）；軌道角動量 = √(n(n+1))·ħ；另輸出 n²ħ 與相鄰能級差 (n−1)·ħ。校驗：量子數數值輸入無強校驗。判據：L 隨量子數 n 線性增大，各量以 10⁻³⁴ J·s 量級（4 位小數）輸出。

輸入量子數 n，求軌道角動量。

📌 計算說明
  • L = n·ℏ。
  • n=3 → 3ℏ。

量子力學中角動量大小 L=√[l(l+1)]ħ，z 分量 m_lħ 才是 lħ 的整數倍。
ħ 是多少？

📊 結果解讀

公式與含義

軌道角動量大小 L=√(l(l+1))·ℏ，l 為角量子數（0,1,2,…）；其 z 分量取值 m_l·ℏ（m_l=−l…l）。量子化使角動量不取連續值。

用途

用於原子殼層、光譜項與磁量子數分析；l 決定亞殼層形狀（s/p/d/f）。

注意

結果為標準量子力學模型；具體體系還需結合自旋與耦合方案。
