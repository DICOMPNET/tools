CAL 計算
輸入：探診深度 PD=7mm，齦緣至 CEJ 距離 = 2mm（齦退縮） 計算：臨床附著喪失 CAL = PD + 齦退縮 = 7 + 2 = 9mm 說明：CAL 反映真實支援喪失，比 PD 更穩定，重度牙周炎 CAL≥6mm。

❓ 常見問題（FAQ）

PD 和 CAL 區別？
PD 是齦溝底到齦緣的軟組織深度，受牙齦腫脹/退縮影響；CAL 再加 CEJ 距離，反映真實附著支援喪失，更可靠。
牙周炎怎麼分級？
常按 CAL 與骨喪失；本頁採用簡化 CAL 分檔：正常 0–1mm、輕度 2–3mm、中度 4–5mm、重度 ≥6mm，結合探診出血與牙位綜合判斷。
出血、口臭是牙周炎嗎？
牙齦出血、紅腫、口臭、牙齒鬆動是牙周炎常見表現；確診與分期需牙周探診與 X 線，請到牙周科。
