Pell-Gregory 分類說明

水平分類（與升支關係）

• Class Ⅰ：升支前緣與第二磨牙遠中面間有足夠間隙容納智牙冠近遠中徑

• Class Ⅱ：間隙小於智牙冠近遠中徑

• Class Ⅲ：智牙全部位於升支前緣內側

深度分類（與咬合平面關係）

• Class A：智牙咬合面與第二磨牙咬合平面平齊（最高位）

• Class B：介於咬合平面與第二磨牙釉牙骨質界之間

• Class C：低於第二磨牙釉牙骨質界（最深位）

難度評分參考（Pederson難度指數）

水平：Class Ⅰ=1分，Ⅱ=2分，Ⅲ=3分

深度：A=1分，B=2分，C=3分

方向：垂直=1分，近中=2分，水平=3分，遠中=4分

💡 常見使用場景

  • 近中阻生智齒，輸入與升支前緣/咬合平面關係，工具給出 Pell-Gregory 分類與難度。
  • 水平阻生伴下頜神經管重疊，提示拔除風險高需 CBCT。
  • 垂直阻生間隙充足，提示難度相對低但仍需評估冠周。（結果僅供口腔健康科普與自我初篩參考，不替代口腔檢查、根尖片/CBCT 等影像學評估及口腔醫師、正畸科、牙周科等專業診斷與治療；如有牙痛、牙齦出血、潰瘍久不愈、口腔黏膜異常或咬合不適，請及時到正規醫院口腔科就診。）
Pell-Gregory 分類
輸入：智齒牙冠完全位於升支前緣前方（I 類），咬合平面以上（A 位），近中傾斜 45° 判定：I-A 類，空間相對充足、難度較低；若達 II/III 類或 B/C 位難度升高。

❓ 常見問題（FAQ）

Pell-Gregory 分幾類？
按智齒與升支前緣關係分 I/II/III 類（空間遞減），按與咬合平面關係分 A/B/C 位（位置遞減）；組合評估難度。
Winter 分類是什麼？
按阻生方向分垂直、近中、遠中、水平、頰舌向等；水平/近中阻生常難度更高，需結合影像。
什麼情況要拔智齒？
反覆冠周炎、齲壞、鄰牙壓迫吸收、囊腫或正畸需要；下頜神經管鄰近者需 CBCT，由頜面外科評估。
