📐 計算公式
圓的幾何量互算（知一推四、優先順序 半徑 → 直徑 → 面積 → 周長）：先反推半徑 r = 輸入半徑 或 直徑÷2 或 √(面積÷π) 或 周長÷2π，再統一正算 直徑 = 2r、面積 = πr²、周長 = 2πr。校驗：四項全空或非數提示「請至少輸入一個有效數值」，各分支要求輸入值 ≥0。判據：無固定分級，任一輸入來源均輸出 r/d/S/C 四卡。

輸入半徑、直徑、面積或周長中的任意一項，自動計算其餘三項。

公式：d = 2r，S = πr²，C = 2πr = πd。π 取 3.14159265359。

📚 深度解析：圓的面積/周長

💡 常見使用場景

  • 圓相關量（半徑、直徑、面積、周長）只要知道其一即可推導其餘，用於機械、UI 圓角、場地設計。
  • 由面積或周長反推半徑常用於已知用料求尺寸。
  • 務必統一單位（半徑與直徑不要混淆），面積與周長量綱不同不可比較。
算例：已知半徑 r=5
直徑 d = 2r = 10.0000；面積 S = πr² = 78.5398；周長 C = 2πr = 31.4159。
算例：已知面積 S=78.5398 反推
半徑 r = √(S/π) = √(78.5398/3.14159) = 5.0000；再由 r 得 d=10.0000、C=31.4159。

❓ 常見問題（FAQ）

計算時 π 取幾位？
一般取 3.14159（或 Math.PI）即可，結果保留 4 位小數足夠工程精度；面積/周長對 π 的小數位敏感，粗取 3.14 會引入約 0.05% 誤差。
直徑和半徑容易搞混怎麼辦？
直徑 d = 2r 是穿過圓心的全長，半徑 r 是圓心到邊緣。輸入時看清標註：直徑常標 ⌀ 或 d，半徑標 r。混用會使結果差一倍。
