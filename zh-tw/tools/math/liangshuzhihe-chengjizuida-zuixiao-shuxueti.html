🔢 Two-Number Sum/Product Min-Max

兩數之和/乘積最值演算器。輸入和 S 或積 P，按實數/整數/正整數三種限制求最大積與最小和，給出最優拆分與列舉對照表，並可代入任意兩數驗算是否已取到最值。

📐 核心公式與取等條件
兩數和定積最大 / 積定和最小（均值不等式）
和定積最大：ab ≤ ((a+b)÷2)² = (S÷2)²，a = b = S÷2 時取等
整數約束下取 ⌊S/2⌋ 與 ⌈S/2⌉ 的組合
積定和最小：a+b ≥ 2√(ab) = 2√P，a = b = √P 時取等
整數約束下取最接近 √P 的因數對
判定依據：a、b 越接近，和定時積越大、積定時和越小
參考不等式：a²+b² ≥ 2ab｜a²+b² ≥ (a+b)²/2｜1/a+1/b ≥ 4/(a+b)
列舉表（a+b=S 或 a×b=P）直觀驗證單調性，取等行高亮

和定積最大：當 a + b = S 為定值時，ab ≤ (S/2)²，當且僅當 a = b = S/2 時取等號，最大積 = S²/4。

積定和最小：當 ab = P（P > 0）為定值時，a + b ≥ 2√(ab) = 2√P，當且僅當 a = b = √P 時取等號，最小和 = 2√P。

整數解：限定 a、b 為整數時取不到 S/2 的等號點，改取最接近的兩數——和為 S 時取 ⌊S/2⌋ 與 ⌈S/2⌉（最大積 = ⌊S/2⌋×⌈S/2⌉）；積為 P 時取最接近 √P 的因數對（即從 ⌊√P⌋ 向下搜尋第一個能整除 P 的數）。

符號與邊界：S < 0 時 (S/2)² 仍為最大積，最優拆分為兩個負的相等數；P < 0 時兩數一正一負，和可以無限小（無下界），故「積定和最小」只在 P > 0 時有解。

📚 深度解析：兩數之和/乘積最值演算（和定積最大、積定和最小）

💡 常見使用場景

  • 作業驗算：手算最值題後核對最優拆分、最大積與最小和，避免粗心失分
  • 課堂演示：改數值觀察積隨兩數靠近而增大、和隨因數對靠近而減小
  • 整數約束辨析：理解「整數解取不到 S/2」帶來的最大積損耗與最小和的抬高
方法
和定積最大：a + b = S 時 ab ≤ (S/2)²，等號在 a = b = S/2 取得；限整數則在 a=⌊S/2⌋、b=⌈S/2⌉ 取得，最大積 = ⌊S/2⌋×⌈S/2⌉。積定和最小：ab = P（P>0）時 a + b ≥ 2√P，等號在 a = b = √P 取得；限整數則從 ⌊√P⌋ 向下找第一個能整除 P 的因數對。驗算模組用 |a−b| 判定兩數是否已靠到取等點。
算例
S=20 求最大積：實數解 a=b=10 → 10×10 = 100（上界 20²/4=100）；限整數解仍為 10 與 10，最大積 100。改 S=21：實數上界 21²/4 = 110.25，整數解只能取 10 與 11 → 110，比上界少 0.25。P=50 求最小和：實數下界 2√50 ≈ 14.14，整數因數對為 5 與 10 → 和 15，比下界多 0.86。代入 a=12、b=8（和 20、積 96）驗算：積 96 < 100，距最大積還差 4，因為 |12−8| = 4 ≠ 0。

❓ 常見問題（FAQ）

為什麼限定整數解後最大積會變小？
因為取等點 a = b = S/2 未必是整數。S 為偶數時 S/2 是整數，整數解照樣取到等號（如 S=20 → 10 與 10）；S 為奇數時只能取最接近的 ⌊S/2⌋ 與 ⌈S/2⌉（如 S=21 → 10 與 11），最大積變成 ⌊S/2⌋×⌈S/2⌉，比實數上界 S²/4 少 0.25。
積為負數時為什麼沒有最小和？
ab = P < 0 表示兩數一正一負。設 a 為很小的正數、b = P/a 為很大的負數，a + b 可以趨於負無窮，所以和沒有下界，談不上最小值。同理 P = 0 時其中一個數為 0、另一個可任意取，和也沒有最小值。
列舉表裡的高亮行怎麼看？
「和定積最大」列舉表中高亮行就是最大積組合，可以看到積隨兩數靠近而單調增大，在 ⌊S/2⌋ 處到達峰值；「積定和最小」列舉表中高亮行是最小和組合，因數對越接近 √P，兩數和越小。這就是均值不等式 a + b ≥ 2√(ab) 的直觀體現。
