Exponent Solver

Solve for the exponent from a known base and result using logarithms.

📐 計算公式
解指數方程 aˣ=b（本頁程式碼口徑）：x=ln(b)÷ln(a)；聯動量：回代校驗=aˣ、反推底數=b^(1÷x)、x 與 ln(a) 之比=x÷max(ln(max(a,1.000001)),10⁻¹²)。校驗：a≤0 或 b≤0 報「底數 a 與結果 b 都必須大於 0」；|a−1|<10⁻¹² 時 a 不能取 1（b=1 有無窮多解、否則無解）。判據：無固定分級，a>1 時 x 隨 b 單調增、0<a<1 時單調減。

輸入底數 a 與結果 b，求指數 x。

  • 2^x=8 → x=3。

📚 深度解析：由底數與結果求指數

💡 常見使用場景

  • 解指數方程 aˣ = b（求 x）用於半衰期、複利期數、pH/分貝反算。
  • 核心是對數換底：x = log(b) / log(a)，與底數選取無關。
  • 底數 a 必須 >0 且 ≠1，真數 b 必須 >0。
算例：2ˣ = 8
x = log(8)/log(2) = 3.0000（因 2³=8）。
算例：3ˣ = 81 與 10ˣ = 1000
x = log(81)/log(3) = 4.0000；x = log(1000)/log(10) = 3.0000。換底公式保證任意底數可算。

❓ 常見問題（FAQ）

換底公式是什麼？
logₐ(b) = ln(b)/ln(a) = log(b)/log(a)，即任意兩個同底對數之比。它把『非 10/非 e 底』的指數方程統一轉化為常用對數運算。
底數和真數有什麼限制？
底數 a>0 且 a≠1（a=1 時 1ˣ 恆為 1，無法反解），真數 b>0（對數定義域）。輸入 0 或負數會得到 NaN/非法，需提前校驗。
