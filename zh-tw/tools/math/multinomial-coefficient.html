Multinomial Coefficient Calculator

Compute the multinomial coefficient from the total and category counts.

📐 計算公式
多項式係數（本頁程式碼口徑，三組計數）：C=n!÷(k1!×k2!×k3!)，階乘按 2…k 累乘迭代計算。校驗：k1+k2+k3 必須等於 n，否則報錯並列出當前各組之和與 n；n 須為不超過 170 的非負整數且各組數量不能為負，否則報錯並中止（超 170 雙精度階乘溢位）。判據：無固定分級，主結果按整數輸出（保留 0 位小數）。

輸入總數 n 與三個類別數 k₁、k₂、k₃（和為 n），求多項式係數。

📚 深度解析：由總數與各類別數求多項式係數

💡 常見使用場景

  • 多項式係數 C(n; k₁,k₂,…,k_m) 出現在多項式展開 (x₁+…+x_m)ⁿ 的係數中。
  • 也用於把 n 個可區分物件分成指定大小的若干組（分配/分組計數）。
  • 約束 k₁+k₂+…+k_m = n，否則無意義。
算例：C(5; 2, 2, 1)
= 5! / (2!×2!×1!) = 120 / (2×2×1) = 30。即把 5 個不同元素分入 3 組（規模 2、2、1）的分法數。
算例：C(6; 3, 2, 1)
= 6! / (3!×2!×1!) = 720 / (6×2×1) = 60。

❓ 常見問題（FAQ）

多項式係數和二項式係數什麼關係？
二項式係數是 m=2 的特例：C(n;k,n−k) = n!/(k!(n−k)!) = C(n,k)。多項式係數是其在多類分組上的推廣。
什麼時候用多項式係數？
當展開式含多於兩項（如 (a+b+c)ⁿ）或要把 n 個物件按既定規模分到多個組時使用。組內順序不計、組間規模固定是其典型特徵。
