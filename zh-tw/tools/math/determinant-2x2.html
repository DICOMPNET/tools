2x2 Determinant Calculator

Compute the determinant of a 2x2 matrix from its four elements.

📐 計算公式
二階行列式：|A| = a·d − b·c；聯動量：跡 tr(A) = a + d。校驗：四項全空時提示輸入，部分留空按 0 參與計算。判據：|A| ≤ 1e-12·max(|a·d|,|b·c|) 視為奇異（不可逆），否則非奇異（可逆）——純 0 直接判奇異，ad 與 bc 數學相等時的浮點殘差（如 1.4e-17）同樣判奇異並在結果中標註殘差量級。例 1·4−2·3 = −2（非奇異）。

輸入二階矩陣元素 a、b、c、d，求行列式。

📌 計算說明
  • 行列式為零則矩陣奇異。
  • 1·4−2·3 → −2。

📚 深度解析：二階行列式

💡 常見使用場景

  • 判斷二元一次方程組是否有唯一解
  • 求二維線性變換的面積縮放因子
  • 矩陣可逆性初判（行列式非 0 才可逆）
計算
矩陣 [[a,b],[c,d]] 的行列式 = ad-bc。例 [[3,1],[2,4]] 行列式=3×4-1×2=10≠0，故該矩陣可逆、對應方程組有唯一解。
幾何意義
二階行列式的絕對值等於兩列向量張成的平行四邊形面積；為 0 表示兩向量共線（變換把平面壓成線）。

❓ 常見問題（FAQ）

行列式為 0 說明什麼？
矩陣不可逆（奇異），列向量線性相關，對應線性方程組要麼無解要麼無窮多解，線性變換降維。
二階行列式怎麼記？
主對角線乘積減副對角線乘積：ad-bc。高階用按行/列展開或化簡，但二階就這一條。
