🧮 Beta Coefficient Calculator

Compute a stock's beta from its returns relative to the market.

📋 計算說明

🔢 Beta計算公式

Beta = Cov(Ri, Rm) / Var(Rm)

其中 Cov 為協方差，Var 為方差，Ri 為個股收益，Rm 為市場收益

相關係數 = Cov(Ri, Rm) / (σi × σm)

📊 CAPM模型

預期收益 E(Ri) = Rf + β × (E(Rm) - Rf)

Rf 為無風險利率，E(Rm) 為市場預期收益

📈 Beta值解讀

Beta範圍風險特徵說明
β = 1同步與市場同幅波動
β > 1進攻型波動大於市場，漲幅跌幅更大
0 < β < 1防守型波動小於市場，相對穩健
β = 0無關與市場波動無關
β < 0反向與市場反向波動（罕見）

📐 計算公式

β = Cov(Rs, Rm) ÷ Var(Rm)（市場方差為 0 時記 0）；相關係數 ρ = Cov ÷ (σs×σm)；α = 個股均值 − β×市場均值；CAPM 預期收益 = 無風險利率 + β×(市場預期收益 − 無風險利率)。校驗：個股與市場收益率序列各至少 2 個且長度一致，否則分別提示報錯。判據：β >1 進攻型（高風險高收益）、β >0 防守型（相對穩健）、β <0 反向型、其餘與市場無關。

用個股與市場收益率序列求協方差，除以市場收益率方差；等價於 β = ρ(s,m)·σs / σm，衡量個股相對市場的系統性風險。

兩個序列長度需相同，建議至少12期資料以提高統計可靠性。Beta反映系統性風險，非總風險。

📚 深度解析：Beta 係數（迴歸法）

💡 常見使用場景

  • 給定個股與市場逐期收益率序列，計算個股相對市場的系統性風險 Beta。
  • 配合 CAPM 估算個股預期收益，或判斷進攻/防守屬性。
  • 多因子模型前，先用單因子 Beta 做初步風險分層。
示例資料算 Beta
個股收益 [1.5,-0.8,2.1,0.5,3.0,-1.5,0.8,1.9,-0.3,2.5]%、市場收益 [1.2,-1.0,1.8,0.3,2.6,-1.2,0.6,1.6,-0.5,2.2]%。Beta = cov(個股,市場)/var(市場)。cov≈0.00216、var(市場)≈0.00180 → Beta≈1.20。
CAPM 預期收益
無風險 3%、市場期望 8%、Beta=1.20：E(R)=3%+1.20×(8%−3%)=3%+6%=9%。Beta>1 為進攻型（高風險高收益）。

❓ 常見問題（FAQ）

Beta=1.2 意味著什麼？
市場漲 1%，該股歷史平均漲 1.2%；跌 1% 平均跌 1.2%。Beta 越高系統性風險越大，但非個股獨有風險（非系統性風險靠分散化消除）。
兩組資料長度不一致會怎樣？
本工具要求個股與市場收益率一一對應、長度相同，否則報錯。對齊日期後再算。
