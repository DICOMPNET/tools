Holding Period Return Calculator

Compute holding period return from buy and sell prices and dividends received.

📐 計算公式
股票持有期收益率（本頁程式碼口徑）：r=(賣出價−買入價+股息)÷買入價×100（%）；聯動量：資本利得率=(賣出價−買入價)÷買入價×100（%）、股息收益率=股息÷買入價×100（%，買入價為 0 時分母按 1 兜底）。校驗：三項空值即提示並中止。判據：無固定分級，總收益由資本利得與股息兩部分同向疊加構成。

輸入買入價、賣出價與期間股息，求持有期收益率。

📚 深度解析：股票持有期回報

💡 常見使用場景

  • 計算買入到賣出的總回報（含資本利得與股息）。
  • 多筆買賣合併算期回報。
  • 與年化回報換算（已知持有天數）。
買入 50、賣出 55、股息 2
持有期回報 = (賣出−買入+股息)/買入 = (55−50+2)/50 = 7/50 = 14%。
虧損
買入 50、賣出 45、股息 1：回報=(45−50+1)/50=−4/50=−8%。

❓ 常見問題（FAQ）

含分紅再投資嗎？
本工具紅利按現金計入；若分紅再投資，需用復權價計算總回報，結果通常略高。
怎麼年化？
年化 = (1+期回報)^(365/持有天數) − 1。持有 半年、回報 14% → 年化≈(1.14)^2−1≈29.96%。
