u = (u′ + v) / (1 + u′v/c²)

Combine velocities in the relativistic regime using (u+v)/(1+uv/c²), which never exceeds the speed of light.

📐 計算公式
u = (u′+v)/(1+u′v/c²)。 0.6c+0.6c → 0.882c（亞光速）。

高速參考系下的速度合成，永不超光速。

📌 計算說明
  • u = (u′+v)/(1+u′v/c²)。
  • 0.6c+0.6c → 0.882c（亞光速）。

📚 深度解析：相對論速度疊加

💡 常見使用場景

  • 接近光速時速度不能簡單相加。
  • 亞光速運動合成。
  • 高速情形下合成兩個速度，保證結果不超過光速。
0.6c + 0.6c
u = (0.6c+0.6c)/(1+0.6×0.6) = 1.2c/1.36 ≈ 0.882c。即兩 0.6c 疊加仍小於 c，不超光速。
兩個速度各為 0.5c，光速取 3×10⁸ m/s
u=(u′+v)/(1+u′v/c²)=(0.5+0.5)/(1+0.25)=0.800000 c，即約 2.400×10⁸ m/s。經典力學直接相加得 1.0c，明顯違背相對論。

❓ 常見問題（FAQ）

為什麼不超過 c？
經典相加得 1.2c 錯；相對論分母 1+u′v/c² 修正後結果恆 < c，光速不可超越。
日常速度為什麼感覺不到這個差別？
因為修正項 u′v/c² 極小。以兩列 350 km/h 的高鐵相向為例，uv/c² 只有約 10⁻¹² 量級，相對論結果與直接相加的差別遠小於任何儀器的測量誤差。只有當速度接近光速時修正才顯著。
