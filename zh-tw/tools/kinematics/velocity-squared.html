v² = v₀² + 2·a·Δx

Compute final velocity without time using v² = v₀² + 2ax from initial velocity, acceleration and displacement.

📐 計算公式
v² = v₀² + 2aΔx。 0 + 2×9.8×100 → v≈44.27 m/s。

不含時間的速度與位移關係。

📌 計算說明
  • v² = v₀² + 2aΔx。
  • 0 + 2×9.8×100 → v≈44.27 m/s。

📚 深度解析：速度位移關係（v²=v₀²+2aΔx）

💡 常見使用場景

  • 不知時間，由位移求末速。
  • 自由落體末速（已知高度）。
  • 不含時間地直接建立速度與位移的關係。
v₀=0、a=9.8、Δx=100
v = √(0+2×9.8×100) = √1960 ≈ 44.27 m/s。即自由下落 100 米末速約 44.3 m/s。
初速度 4 m/s，加速度 3 m/s²，位移 20 m
v=√(v₀²+2ax)=√(16+120)=√136=11.662 m/s。適用於只知道經過多遠、不知道花了多久的場景，如制動痕長度推算。

❓ 常見問題（FAQ）

和 free-fall-time 一致？
一致：由 h=½gt² 與 v=gt 消去 t 即 v²=2gh，是同一運動不同表達。
這個公式能反過來用嗎？
可以。交通事故鑑定中常測得制動痕長度 x，假定減速度 a 後反推初速 v₀=√(v²−2ax)；若車輛最終停住（v=0），則 v₀=√(−2ax)，a 取負值即可。
