📐 提示詞五要素與完整度評分
提示詞五要素完整度評分
五要素：角色 / 任務 / 上下文 / 輸出格式 / 約束
角色固定為「資深產品與設計領域專家」
任務要素需填寫任務動作；上下文需填寫目標物件
約束按中英文分號拆分為多條
完整度評分 = 已填要素數 ÷ 5 × 100
缺失項提示補齊建議，缺首項時說明模型只能按預設口徑回答
生成提示詞結構：【角色】【任務】【輸出格式】【約束】【自檢】【停用】
輸出條數限制 1~20 條
自檢項：條數是否等於設定值、是否滿足全部約束、是否給出可執行下一步
停用項：不輸出與目標物件無關的通用套話
五項齊備時建議在約束裡追加可量化條件（字數、條數、停用詞）

結構化提示詞 = 角色 + 任務 + 上下文 + 輸出格式 + 約束。五要素齊備時，模型輸出的一致性與可直接使用的比例最高；缺項對應的典型症狀：缺角色→用詞泛化，缺輸出格式→返回散文而非可複製列表，缺約束→字數與語氣失控。

完整度評分 = 已填寫要素數 ÷ 5 × 100（0~100）。本工具按五項逐項檢查並給出補寫建議。

要素作用：角色 → 決定專業深度與用詞；任務 → 決定動作（生成 / 最佳化 / 分析 / 改寫）；上下文 → 界定資訊邊界與受眾；輸出格式 → 決定可解析性；約束 → 字數、語氣、停用詞等硬性條件。

📚 深度解析：AI 提示詞構建（五要素拼裝與完整度自檢）

💡 常見使用場景

  • 文案與內容生成前先固定角色、約束與輸出格式，避免反覆返工
  • 把模糊需求（「寫得專業點」）翻譯成可校驗的提示詞要素
  • 團隊內統一提示詞寫法，減少同一任務在不同人手裡的結果波動
方法
五要素 = 角色 + 任務 + 上下文 + 輸出格式 + 約束。完整度只按「該要素是否填寫」計數：角色恆為已填，其餘四項每填一項加 20 分，故全空時為 20 分而非 0 分。約束用「；」分隔會自動拆成獨立約束項並寫入自檢清單；輸出條數被鉗制在 1~20 之間。生成結果是一段帶【角色】【任務】【輸出格式】【約束】【自檢】【停用】六段的可複製文本，不呼叫任何模型。
算例
任務 = 最佳化、目標物件 = 落地頁文案、輸出格式 = 分點列表、約束 = 「每條≤20字；不要感嘆號」、期望條數 = 5 → 完整度 100（5/5）、期望輸出條數 5；提示詞含「【任務】對「落地頁文案」執行最佳化」「按分點列表輸出 5 條」「每條≤20字；不要感嘆號。」與「條數是否等於 5」的自檢項。目標物件留空時完整度降為 80（缺上下文）；若任務與輸出格式也未選、且約束一併清空，則僅角色計入已填、降為 20。

❓ 常見問題（FAQ）

完整度評分是怎麼算的？
只按「要素是否填寫」計數，不判斷內容質量：角色恆為已填，任務、上下文、輸出格式、約束四項各佔 20 分。所以全部留空時是 20 分而不是 0 分，滿分 100 分表示五項齊備。
這個工具會呼叫 AI 生成內容嗎？
不會。它只把五要素拼裝成一段結構化提示詞文本並做完整度自檢，不聯網、不呼叫任何模型；拿到提示詞後需要自己複製到所用的 AI 工具裡執行。
輸出條數怎麼限制？
輸入框的值會被鉗制在 1~20 之間：填 0 或非法值回退為 1，填 99 也按 20 處理，避擴音示詞裡出現不切實際的條數要求。

⚠️ 使用說明與注意事項
  • 提示詞由五要素文本拼裝生成，輸出完全確定、可重複；本工具不呼叫任何線上模型
  • 完整度評分只衡量要素是否填寫，不代表生成質量；結果質量還取決於模型能力與上下文的真實程度
  • 約束條件建議寫成可校驗的硬指標（字數上限、停用詞、條數），避免「專業一點」這類主觀描述
  • 本工具純前端執行，資料不會上傳到伺服器
