📐 計算公式 / 原理
按當前分類取出字型配對列表，逐條渲染標題字型與正文字型（含各自字重）、預覽文本與風格標籤；收藏鍵由「標題字型-正文字型」拼接而成，與本機收藏列表比對決定是否點亮星標，點選卡片應用該配對，點選星標單獨切換收藏
從編排好的字型組合庫中選取標題 / 正文字型對，生成對應的 font-family 與引用宣告；組合按風格與可讀性篩選，用於網頁與海報的字型搭配。

❓ 常見問題（FAQ）

中文怎麼配？
中文多用同族字重區分層級，西文再配一種點綴即可。本頁匯出的 CSS 已採用中英雙字型棧：拉丁搭配字型在前，隨後回退到 Noto Sans SC、PingFang SC、Microsoft YaHei 等常見中文字型；預覽區也按同一棧渲染，輸入中文（可選用「中文標題 + 正文對比」預設）即可檢視中文效果。這些中文字型需本機或系統已安裝才會生效，未安裝時繼續回退到 sans-serif。結果以瀏覽器即時計算為準，純前端本地處理、資料不上傳；生成的樣式與程式碼僅作快速產出參考，正式專案請以設計系統、規範與瀏覽器實測為準。
