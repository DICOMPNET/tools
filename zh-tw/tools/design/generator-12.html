🎲 Particle Effect Generator

Batch-produce runnable CSS particle effects: set the particle count, animation period and colour per scheme (leave blank for random); each scheme ships ready-to-paste HTML particles plus CSS with the animation already bound, and renders a live preview.

📐 工作原理與說明
生成條數鉗制在 1–50（預設 5）；第 i 條按 i 對 4 取模迴圈選取 circle、square、diamond、star 四種形狀（用 clip-path 實現，不與 transform 動畫衝突）；每套的粒子數 20–200、顏色、尺寸 2–10 px、週期 0.3–3.0 s、擴散半徑 50–300 px、透明度 0.3–0.8 可指定或留空隨機。輸出為「HTML 粒子節點 + CSS」：.particles-N .p 繫結 animation: float-N var(--speed) linear infinite，--size / --color / --speed / --spread / --opacity 全部被引用，每個粒子另帶 left、animation-delay 與 --dx。關鍵幀：0% 下移一個擴散半徑、透明度 0；20% 升到設定透明度；100% 上移一個擴散半徑並橫向偏移 --dx、透明度回到 0
基於 CSS 關鍵幀的粒子系統：每個粒子是一個絕對定位的 span，靠 clip-path 決定形狀、靠 CSS 變數與 keyframes 完成上浮與淡入淡出，不依賴 JavaScript 執行時；輸出為可直接貼上執行的 HTML + CSS 兩段程式碼，並給出即時預覽。用於網頁背景與活動頁特效。
