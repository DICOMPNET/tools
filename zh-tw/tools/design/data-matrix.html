📊 Data Matrix Code Generator

📐 工作原理與說明
文本雜湊 hash = Σ 逐字元迭代 ((hash << 5) − hash + 字元碼) 並按 32 位取整；偽隨機序列 seed₀ = |hash| + 1，seedₙ = (seed × 9301 + 49297) mod 233280，取值 = seed ÷ 233280，大於 0.5 時該格填充；定點陣圖案按 Data Matrix 外觀繪製：左邊一列與下邊一行實心，上邊與右邊按 i 奇偶交替；畫布邊長 = 階數 × 18 px
生成「資料矩陣風格」的裝飾圖案：花紋由文本雜湊的偽隨機序列決定，不含真實資料編碼與 Reed-Solomon 糾錯，不可被掃碼裝置識別，僅用於視覺示意與排版佔位；如需可掃碼的 Data Matrix，請使用專業編碼庫生成。

❓ 常見問題（FAQ）

生成的圖案能當二維碼用嗎？
不能。本頁只生成 Data Matrix 外觀的裝飾圖案，不含資料編碼與糾錯、不能被掃碼識別；如需可掃碼的二維碼或 Data Matrix，請用對應的專業編碼工具。圖案在瀏覽器本地生成，資料不上傳。
生成的程式碼/圖片能直接用嗎？
可用於視覺示意與排版佔位，但圖案不含真實資料編碼，不能作為可掃碼的 Data Matrix 標籤使用；正式標識請用專業編碼庫生成。
會儲存或上傳我的內容嗎？
結果以瀏覽器即時計算為準，純前端本地處理、資料不上傳；生成的樣式與程式碼僅作快速產出參考，正式專案請以設計系統、規範與瀏覽器實測為準。
