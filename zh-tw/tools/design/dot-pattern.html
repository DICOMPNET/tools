⚫ Dot Pattern Generator

📐 工作原理與說明
點徑下限 2（預設 8）、間距下限 5（預設 30），漸變半徑 = 點徑 ÷ 2；方格排列 = 單層 radial-gradient(點色 半徑, transparent 半徑+1)，background-size = 間距 × 間距；錯位排列疊加兩層同參數漸變，第二層 background-position 偏移 (間距 ÷ 2, 間距 ÷ 2)；柔邊排列改用 radial-gradient(circle, 點色 半徑, transparent 點徑) 讓邊緣過渡
按固定間距在背景上重複繪製圓點（可用錯位排列形成六角感），點徑、間距與配色可調並複製 CSS 程式碼；用於包裝、網頁底紋與印刷稿。

Create an even or offset dot texture with adjustable dot size, spacing and colour, copyable as CSS code.
