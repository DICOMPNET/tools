🎨 Styled QR Code Generator

📐 工作原理與說明
畫布邊長 = size（下限 80，預設 240）；呼叫 QRCode.toCanvas 生成，引數 width = size、margin = 2、dark 取前景色、light 取背景色、errorCorrectionLevel 取所選糾錯等級；成功後匯出 PNG data URL 並插入畫布；二維碼庫未載入或生成報錯時提示對應錯誤
本工具為純前端線上工具，資料在瀏覽器本地處理、不上傳伺服器，依據對應領域標準與規範進行計算或處理，結果僅供參考。 工具名稱：樣式化二維碼 - 免費圖片處理工具，線上樣式化二維碼，免費使用。
