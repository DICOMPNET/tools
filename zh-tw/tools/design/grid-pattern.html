🔲 Grid Pattern Generator

📐 工作原理與說明
單元格邊長 = size（下限 5，預設 30），線寬 = lw（下限 1）；方格與虛線用橫豎兩層 linear-gradient 疊加、background-size = size × size，虛線額外把兩層背景分別偏移 −lw ÷ 2 製造斷續；點陣用 radial-gradient(線色 lw px, transparent lw+1 px)；斜線與十字改為 45° / −45° 的 linear-gradient 組合
按固定間距重複繪製方格或網格線（線寬與顏色可調）生成背景圖案並匯出圖片；用於工程圖底圖、網頁紋理與印刷稿。

Generate square or ruled grid backgrounds with adjustable spacing and line colour for engineering layouts, web textures and print.
