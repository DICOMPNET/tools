🔤 Typography Scale Generator

📐 工作原理與說明
字號 size(n) = base × rⁿ（r 為模數比，如 1.25 為大三度、1.618 為黃金比）
基於模數化排版比例：以基準字號按比例派生標題到正文的字號階梯，輸出字號表與 CSS，用於建立一致的排版層級。

Build a font-size ladder from a ratio such as 1.25 and export a heading-to-body scale table and CSS for a consistent hierarchy.

❓ 常見問題（FAQ）

比例選多大？
1.2 緊湊、1.25 通用、1.333 舒展；按氣質選。
基字號怎麼定？
正文通常 16px 起；過小傷可讀，按受眾與裝置調整。
會儲存或上傳我的內容嗎？
結果以瀏覽器即時計算為準，純前端本地處理、資料不上傳；生成的樣式與程式碼僅作快速產出參考，正式專案請以設計系統、規範與瀏覽器實測為準。
