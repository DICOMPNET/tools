🔤 Base64 to Image Converter

📐 工作原理與說明
輸入去首尾空白後，若不以 data: 開頭則按解碼出的前幾個位元組識別 PNG（89 50 4E 47）、JPEG（FF D8 FF）、GIF、WEBP 或 SVG，並自動補上對應 data:image/…;base64, 字首；交由 Image 載入校驗，載入成功則插入圖片並把該 data URL 記為結果地址，載入失敗提示無效的 Base64 資料並清空結果
本頁只做 Base64 / Data URL → 圖片的解碼：按位元組魔數補齊 MIME 字首後交由 Image 載入校驗，成功後預覽並支援複製 Data URL 或下載圖片；不提供圖片轉 Base64 的編碼入口，也不上傳任何資料。

Decode a Base64 string or data URL back into a viewable image and download it; this page only decodes and does not encode images to Base64.
