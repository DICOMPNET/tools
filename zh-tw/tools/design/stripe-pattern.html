🟰 Stripe Pattern Generator

📐 工作原理與說明
條紋紋理 = repeating-linear-gradient 按固定角度與週期重複雙色條紋；條紋寬度、角度與配色可調並匯出圖片，用於包裝、網頁與印刷底紋。

Generate horizontal, vertical or diagonal stripe textures with adjustable width and two-tone colours for packaging and web backgrounds.

❓ 常見問題（FAQ）

角度任意？
任意角度均可，密度越小越密。
能做雙色嗎？
可設雙色與底色，調對比度即可得到醒目或柔和條紋。
會儲存或上傳我的內容嗎？
結果以瀏覽器即時計算為準，純前端本地處理、資料不上傳；生成的樣式與程式碼僅作快速產出參考，正式專案請以設計系統、規範與瀏覽器實測為準。
⚠️ 使用說明與注意事項
  • 本工具純前端執行，資料不會上傳到伺服器
  • 建議在主流瀏覽器（Chrome/Safari/Firefox/Edge）中使用
  • 計算結果僅供參考，請以實際應用場景為準
