⭕ CSS Border Radius Generator

📐 工作原理與說明
四角共八個值：左上水平/垂直、右上水平/垂直、右下水平/垂直、左下水平/垂直。勾選「四角聯動」時統一圓角滑塊的值會寫入全部八項。輸出語法為 border-radius: 左上水平 右上水平 右下水平 左下水平 / 左上垂直 右上垂直 右下垂直 左下垂直，單位在簡單模式下取 px、高階模式下取 %，並把同一串即時應用到預覽元素
將各角半徑（支援 px 與百分比）拼裝為 CSS border-radius 宣告，即時預覽並複製；用於圓角容器、膠囊按鈕與卡片。
  • 單值=四角同；兩值=對角；三值=左上+右上左下+右下。
  • 橢圓角（/ 後值）可做“膠囊”“葉子”等形狀。
  • 純前端生成，複製即用。

Tweak the radius visually and generate the matching CSS border-radius, supporting per-corner values and percentages.
