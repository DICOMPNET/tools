🆔 Identicon Avatar Generator

📐 計算公式 / 原理
生成演算法：種子串按 Java 風格乘 31 雜湊（hash = hash×31 + 字元編碼，按 32 位整數迴繞）取絕對值，色相 = hash mod 360，前景色 = hsl(色相, 65%, 45%)；再以 LCG 偽隨機序列 s = (s×9301 + 49297) mod 233280 逐格判定，s÷233280 >0.5 即填色，左右列映象對稱。校驗：輸出尺寸夾取 ≥40，網格數夾取 3–9。判據：同一種子恒生成同一圖案，種子不同即得到不同圖案。
按雜湊演算法把任意字串確定性對映為對稱幾何圖案：同一輸入始終得到同一頭像，無需服務端儲存；用於無頭像使用者的預設標識。
