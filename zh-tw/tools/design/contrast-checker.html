🎨 Contrast Ratio Checker

Verify the WCAG contrast ratio between text and background in real time to keep copy readable for designers and developers.

📐 計算公式 / 原理
CR = (Llight + 0.05) / (Ldark + 0.05)，L = Σ(wᵢ·Cᵢ)，w = [0.2126, 0.7152, 0.0722]
依據 WCAG 2.1 計算前景色與背景色的對比度比值：相對亮度按 sRGB gamma 校正後加權求得；用於保證正文、按鈕與圖示在網頁上的可讀性。

⚖️ 對比度檢查器說明 ▼

WCAG（Web 內容無障礙指南）對比度檢查器，幫助設計師和開發者驗證文字顏色與背景顏色之間的對比度是否符合無障礙標準。

📌 WCAG 對比度標準

  • AA 級正常文字：對比度 ≥ 4.5:1
  • AA 級大文字（18px+ 或 14px 粗體+）：對比度 ≥ 3:1
  • AAA 級正常文字：對比度 ≥ 7:1
  • AAA 級大文字：對比度 ≥ 4.5:1

🎯 使用場景

  • UI 設計稿配色驗證
  • 網頁開發顏色可讀性檢查
  • 品牌色與文字色搭配最佳化
  • 無障礙合規性審查
