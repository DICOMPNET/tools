📐 計算公式 / 原理
色標按位置升序排列後拼為「色值 位置%」序列：線性 → linear-gradient(角度deg, …)；徑向 → radial-gradient(circle, …)；錐形 → conic-gradient(from 角度deg, …)；角度控制元件僅線上性/錐形下顯示；隨機漸變生成 2-4 個色標，位置 = ⌊i ÷ (色標數 − 1) × 100⌋，角度取 0-359 隨機整數。相鄰色標對比度按 WCAG 相對亮度計算：L = 0.2126R + 0.7152G + 0.0722B（通道值先線性化），對比度 = (L亮 + 0.05) ÷ (L暗 + 0.05)；該值僅衡量色標銜接強弱（≥4.5 清晰、≥3 可辨、<3 較弱），不適用 WCAG 文字等級判定。
把起止顏色、角度與顏色停靠點拼裝為 linear-gradient / radial-gradient 宣告，即時預覽並複製；用於網頁背景與按鈕配色。
