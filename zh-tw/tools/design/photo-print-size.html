🖼️ Photo Print Size Calculator

From pixel dimensions and print DPI, work out the best physical print size and compare it against standard paper formats.

📐 工作原理與說明
列印尺寸(英寸) = 畫素 / DPI；再對照常見相紙規格（3R/4R/5R/A4 等）取最接近者
基於列印解析度：給定 DPI 時由畫素尺寸求最佳列印物理尺寸並對照標準相紙規格；DPI 越高越精細但可印尺寸越小，用於避免沖印模糊或浪費相紙。

❓ 常見問題（FAQ）

DPI 低能印嗎？
低 DPI 近看有顆粒；牆面大圖可放寬，手持照片建議 ≥300。
英寸和畫素關係？
英寸×DPI=畫素；想清晰先定 DPI 再反推所需畫素。
會儲存或上傳我的內容嗎？
結果以瀏覽器即時計算為準，純前端本地處理、資料不上傳；生成的樣式與程式碼僅作快速產出參考，正式專案請以設計系統、規範與瀏覽器實測為準。
