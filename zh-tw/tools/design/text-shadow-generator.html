🌑 Text Shadow Generator

📐 計算公式 / 原理
基礎陰影 = 偏移X px 偏移Y px 模糊 px 陰影色；立體與復古預設生成 5 層，第 i 層偏移為 (偏移X × i) px (偏移Y × i) px、模糊不變，按逗號連線；霓虹與輝光預設為 0 0 模糊 / 2×模糊 / 3×模糊 三層同色；描邊預設為 (±1 px, ±1 px) 四個方向各一層；最終輸出 color 與 text-shadow 兩條宣告
按 offset / blur / color 拼裝 text-shadow（支援多層疊加）並即時預覽，用於標題裝飾與網頁視覺增強。
