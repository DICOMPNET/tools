✨ CSS Background Pattern Generator

Tune parameters to build a tileable CSS background texture such as dots, grids or waves, with live preview and exported code.

📐 工作原理與說明
生成條數鉗制在 1–50（預設 5）；第 i 條按 i 對 6 取模迴圈選取圓點 / 條紋 / 網格 / 棋盤 / 斜線 / 波浪六種紋理；每條隨機取兩個顏色 c1、c2 與一個尺寸 size（8–64 的隨機整數）。各紋理以 CSS 漸變表達：圓點用 radial-gradient 配 background-size；條紋用 repeating-linear-gradient(90deg) 以 size/2 為色標；網格用兩組 1px 的 linear-gradient 正交疊加；棋盤用 conic-gradient 四個 90° 扇區；斜線用 repeating-linear-gradient(45deg) 以 size/4 與 size/2 為色標；波浪用上下兩個 radial-gradient 圓疊加並配 background-size
以 CSS 漸變（repeating-linear-gradient 等）或 SVG 平鋪生成可重複背景紋理（點陣 / 網格 / 波浪），引數可調並匯出程式碼；用於 UI 背景裝飾。
