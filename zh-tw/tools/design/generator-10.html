🎲 CSS Keyframe Animation Generator

Compose a CSS keyframe animation visually, adjust duration, easing and properties, preview it live and export the @keyframes code.

📐 工作原理與說明
生成條數鉗制在 1–50（預設 5）；第 i 條預設按 i 對 8 取模迴圈選取 fadeIn、slideUp、bounce、pulse、rotate、shake、zoomIn、flip 八種關鍵幀模板，選「動畫型別」則全批統一為所選模板；動畫名 = 模板名 + "-" + 1–999 的隨機整數；時長（0.5–3.0 s）、延遲（0–2.0 s）、緩動、播放次數（1/2/3/infinite）、方向、填充模式六項留空時隨機，填寫即按所選值固定，最後拼裝為 animation 宣告與 @keyframes 程式碼塊。頁面頂部預覽區把第 1 條動畫實際應用到色塊上迴圈播放（@keyframes 以真實 style 元素注入，非僅顯示文本），可直觀判斷動效觀感後再複製程式碼；首次生成後隨機值按條快取，修改單項引數只更新該項，點選「生成（重新隨機）」才重抽全部屬性。
視覺化編排關鍵幀：把時間點、動畫屬性與緩動函式拼裝為 @keyframes 與 animation 宣告，即時預覽並複製；用於 CSS 動畫開發。
