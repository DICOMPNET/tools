🔤 Text Favicon Generator

📐 工作原理與說明
畫布邊長 = size（下限 16，預設 64）；字號 = size × 0.55（bold），文字中心 = (size ÷ 2, size ÷ 2 + size × 0.04)；圓角 > 0 時用四段二次貝塞爾繪製圓角矩形路徑再填充，為 0 時直接填充整幅；三檔預覽圓角與字號均按畫布比例等比縮放（16 / 64 / 128 px 檔分別取 radius ÷ size × 檔位邊長、字號 × 0.55），最終 toDataURL 匯出 PNG
把文字或字母渲染為方形圖示（可調字型、字號與配色）並匯出 PNG；適合無 Logo 的小站快速獲得品牌標識。
