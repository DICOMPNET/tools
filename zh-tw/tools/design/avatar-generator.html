👤 Avatar Generator

📐 計算公式 / 原理
雜湊 = 逐字元 ((h×32) − h + 碼位) 累加後取絕對值；block 風格按 5×3 網格（格寬 = size ÷ 5）左右映象填充，LCG 遞推 s = (s×9301 + 49297) % 233280，s ÷ 233280 ＞ 0.5 時畫塊；gradient 取對角線漸變 + 首字母（字號 size×0.4）
按種子確定性生成幾何 / 畫素 / 漸變頭像：種子決定形狀與配色，同一種子結果一致；可調大小與圓角，支援匯出 PNG 或 SVG，用於社交佔位圖與測試資料。

❓ 常見問題（FAQ）

頭像會重複嗎？
由暱稱雜湊派生，同暱稱同參數會得到相同圖形；不同暱稱通常不同，但不保證全域性唯一。
能上傳自己的照片嗎？
本工具按引數生成卡通圖形，不處理真人照片；如需真人頭像請用圖片裁剪類工具。結果以瀏覽器即時計算為準，純前端本地處理、資料不上傳；生成的樣式與程式碼僅作快速產出參考，正式專案請以設計系統、規範與瀏覽器實測為準。
