🎨 WCAG Contrast Check

Enter foreground and background colours to compute the WCAG 2.1 contrast ratio and see whether text passes the AA and AAA levels.

📐 計算公式 / 原理
CR = (L₁ + 0.05) / (L₂ + 0.05)，L = 0.2126R + 0.7152G + 0.0722B（sRGB 歸一化併線性化後）
依據 WCAG 2.1：先將 sRGB 各通道歸一化並按 gamma 線性化，再加權求相對亮度 L，兩色亮度各加 0.05 後取比值。CR ≥ 4.5 為 AA（正文）、≥ 7 為 AAA；大字號閾值分別為 3 與 4.5。

Formula & Standard References

Item Formula / Note Source / Standard
Relative luminance L = 0.2126 R + 0.7152 G + 0.0722 B after sRGB linearization WCAG 2.2 relative luminance definition
Contrast ratio (L1 + 0.05) / (L2 + 0.05), ranging from 1:1 to 21:1 WCAG 2.2 (1.4.3)
Thresholds AA needs 4.5:1 for body text and 3:1 for large text, AAA needs 7:1 WCAG 2.2 (1.4.3, 1.4.6)
⚠️ 使用說明與注意事項
  • 對比度計算遵循 WCAG 2.1 標準（W3C Web Content Accessibility Guidelines）
  • AA 級要求：正常文字 ≥ 4.5:1，大號文字（≥18px 或 ≥14px 粗體）≥ 3:1
  • AAA 級要求：正常文字 ≥ 7:1，大號文字 ≥ 4.5:1
  • 輸入色值支援 #RRGGBB、#RGB、rgb(r,g,b) 格式
  • 對比度比率範圍為 1:1（完全相同）到 21:1（黑白對比）
