🖼️ Pixel Art Generator

Draw a pixel picture on a grid, change the grid size and palette, and export the result as character art or CSS code.

📐 計算公式 / 原理
在網格上點選上色，資料按二維陣列儲存並渲染為字元畫或 CSS 畫素塊；網格大小與調色盤可調，用於畫素風圖形制作。

❓ 常見問題（FAQ）

色越多越真？
是，但失畫素味；按風格權衡色數。
塊大小怎麼選？
塊越大越畫素化；小圖用小塊更細膩，大圖可用大塊出風格。
會儲存或上傳我的內容嗎？
結果以瀏覽器即時計算為準，純前端本地處理、資料不上傳；生成的樣式與程式碼僅作快速產出參考，正式專案請以設計系統、規範與瀏覽器實測為準。
⚠️ 使用說明與注意事項
  • 點選網格上色，支援繪製/擦除兩種模式
  • 8 種基礎色板，網格 4-24 可調
  • 字元畫用 ■ / · 表示畫素，可複製
  • 純本地繪製，圖案不儲存不上傳
