Build a CSS Grid layout by setting columns, track sizing, gaps and breakpoints, then copy the generated CSS and HTML.

📐 計算公式 / 原理
grid-template-columns: repeat(n, 1fr | <固定寬度> | auto)；gap: <行間距> <列間距>
把列數、列寬方式（固定 / fr / auto）、gap 與斷點拼裝為 CSS Grid 宣告及對應 HTML，即時預覽並複製；用於二維佈局搭建。
