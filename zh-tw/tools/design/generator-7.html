📐 工作原理與說明
邊框樣式按 solid / dashed / dotted / double / groove / ridge / inset / outset 八種輪換（下拉可固定其中一種）；寬度與圓角留空時隨機（寬度 1–8 px、圓角 0–32 px），填寫後按填寫值固定輸出；配色預設在 10 色板內隨機，把「配色方式」切到「使用左側顏色」則統一使用所選色值；雙線 double 寬度小於 3 px 時自動提升到 3 px（否則瀏覽器按實線渲染）。單邊獨立開啟後只輸出 border-top / border-right / border-bottom / border-left 中的一條，四邊聯動則輸出 border 簡寫。
按邊框寬度、樣式、圓角與配色拼裝 border 系列宣告，支援單邊獨立設定；用於分隔線、卡片邊框等樣式產出。
