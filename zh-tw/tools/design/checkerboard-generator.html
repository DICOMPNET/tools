🏁 Checkerboard Pattern Generator

📐 工作原理與說明
方格邊長下限 5（預設 30）；兩層 45° 的 linear-gradient 疊加，色標均為：色二 0–25%、透明 25–75%、色二 75–100%；background-size = (邊長 × 2) × (邊長 × 2)，第二層 background-position 偏移 (邊長, 邊長)，錯開後半格形成棋盤
按行列交替填充兩種顏色生成棋盤圖案：格子尺寸與配色可調並複製 CSS 程式碼；用於棋類演示、背景底紋與遊戲素材。

Generate a checkerboard pattern with adjustable cells and colours for chess demos, backgrounds and game art, copyable as CSS code.
