😀 Emoji Favicon Generator

📐 工作原理與說明
畫布邊長 = size（下限 16，預設 128）；字號 = size × 0.65，繪製中心 = (size ÷ 2, size ÷ 2 + size × 0.02)；圓角 > 0 時以四段二次貝塞爾構造圓角矩形路徑填充，為 0 時填滿整幅；三檔預覽圓角按 radius ÷ size × 檔位邊長等比縮放（16 / 64 / 128 px），最終 toDataURL 匯出 PNG
將所選 Emoji 以指定字號渲染到 Canvas 並匯出為 PNG；用於快速更換站點圖示，純前端生成不上傳。
