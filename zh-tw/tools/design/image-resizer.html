📐 工作原理與說明
畫布尺寸 = 目標寬 × 目標高（兩者下限均為 1）；是否開啟影像平滑由 imageSmoothingEnabled 決定，關閉時縮放保留硬邊畫素；按 drawImage(原圖, 0, 0, 寬, 高) 縮放繪製後匯出 PNG
本工具為純前端線上工具，資料在瀏覽器本地處理、不上傳伺服器，依據對應領域標準與規範進行計算或處理，結果僅供參考。 工具名稱：圖片縮放 - 設計創意領域的線上工具。

Resize an image by pixels or percentage, optionally keeping the aspect ratio, and set the output quality before download.
