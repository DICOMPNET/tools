🔷 SVG Pattern Generator

📐 計算公式 / 原理
CSS 圖案：triangles 用 45° 線性漸變雙層、第二層錯位 size ÷ 2；diamonds 用 conic-gradient 從 45° 起四象限交替；hex 用徑向漸變、瓦片 size × (size×0.6)；chevron 四向 135° / 225° / 45° / 315° 組合；circles 徑向圓 20%；cross 用 2px 橫豎線網格
基於 SVG 生成無縫紋理（點陣 / 條紋 / 網格 / 波浪），調節間距、顏色與透明度後匯出 CSS 背景宣告；用於網頁裝飾。

❓ 常見問題（FAQ）

接縫怎麼避免？
引數取整除週期可無縫；否則會出現可見接縫。
密度怎麼調？
改週期與線寬即可；週期越大越疏，線寬越大越實。
會儲存或上傳我的內容嗎？
結果以瀏覽器即時計算為準，純前端本地處理、資料不上傳；生成的樣式與程式碼僅作快速產出參考，正式專案請以設計系統、規範與瀏覽器實測為準。
