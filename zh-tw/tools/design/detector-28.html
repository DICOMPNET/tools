📐 限值與判定口徑（GB 18580 / GB/T 39600 / 18582 / 18583）
人造板 / 地板甲醛釋放量：GB 18580-2017 強制底線 E1 ≤ 0.124 mg/m³（氣候箱法）；分級按 GB/T 39600-2021：ENF ≤ 0.025、E0 ≤ 0.050、E1 ≤ 0.124 mg/m³。內牆塗料（GB 18582-2020）為單一強制限值：VOC ≤ 80 g/L 且苯系物總和 ≤ 100 mg/kg（不分優等/合格）；膠粘劑（GB 18583）VOC ≤ 50 g/L 且苯系物 ≤ 5 mg/kg 為優等

人造板 / 木地板（按甲醛釋放量分級）：≤0.025 mg/m³ → ENF 級；≤0.050 mg/m³ → E0 級（優等）；≤0.124 mg/m³ → E1 級（合格，可直接用於室內）；>0.124 mg/m³ → 不合格，禁止用於室內裝修。E1 為 GB 18580-2017 強制底線，ENF / E0 是 GB/T 39600-2021 按甲醛釋放量劃分的等級，僅表示成品釋放量達標，不能據此推斷生產過程是否新增含甲醛物質；GB 18580-2017 已取消 E2 級，本工具不再輸出 E2。

內牆塗料（GB 18582-2020）：該標準是單一強制限值、不按有害物質限量分「優等/合格」——VOC ≤80 g/L 且 苯系物總和 ≤100 mg/kg 為本頁可核的兩項強制限值，兩項達標僅表示這兩項未超限，不構成整體合規結論；任一項超限則不符合。（VOC ≤30 g/L 且 苯系物 ≤10 mg/kg 是更嚴的推薦水平，可作為選品加分參考，但非國標分級，不能據此反推 50–100 mg/kg 區間「不合格」。）甲醛含量 ≤50 mg/kg 同為強制限值，但本頁甲醛輸入為釋放量 mg/m³（板材口徑）、未採集塗料甲醛含量，故不核查該項；重金屬等其他強制項同樣未納入，整體合規須以有資質檢測報告為準。

膠粘劑（GB 18583）：VOC ≤50 g/L 且 苯系物 ≤5 mg/kg → 優等品；VOC ≤100 g/L 且 苯系物 ≤50 mg/kg → 合格品；否則不合格。

判定邏輯：塗料與膠粘劑為「同時滿足」邏輯 —— VOC 與苯系物任一項超限即整體降級；人造板與地板只看甲醛釋放量檔位。表內限值是工具內建的對照口徑，正式驗收須以有資質檢測機構的報告為準。

📚 深度解析：室內環保控制（材料/標準/檢測判定）

💡 常見使用場景

  • 裝修選材時，按 GB 50325 限值預判板材、油漆、膠粘劑、地板的汙染物是否達標。
  • 完工後對照檢測結果判斷是否超標，決定通風時長或治理方案。
甲醛釋放量判定（I 類民用建築限值 0.08）
板材 0.05、油漆 0.06、膠粘劑 0.08、地板 0.07 mg/m³，對照 I 類限值 0.08：膠粘劑恰好達標(=0.08)，其餘均低於限值，整體判定合格但膠粘劑餘量最小需重點關注。
TVOC 與分級
若測得當量濃度 0.50 mg/m³（I 類 TVOC 限值），達限即臨界；>0.50 判超標，建議延長通風或活性炭/新風治理後複測。

❓ 常見問題（FAQ）

0.08 是什麼限值？
指 GB 50325 中 I 類民用建築甲醛濃度限量 0.08 mg/m³（II 類為 0.10）。選材檢測值應低於對應類別限值才有餘量。
達標了為什麼還建議通風？
多種材料疊加會使室內綜合濃度升高；單材料達標不代表房間整體達標，入住前仍建議通風並複測綜合值。

⚠️ 使用說明與注意事項
  • 人造板甲醛釋放量按GB 18580-2017氣候箱法檢測（單位mg/m³），強制底線E1≤0.124mg/m³
  • ENF≤0.025、E0≤0.050mg/m³ 分級出自GB/T 39600-2021；GB 18580-2017已取消E2級
  • 內牆塗料按 GB 18582-2020 單一強制限值判定：本頁僅核 VOC≤80g/L、苯系物總和≤100mg/kg 兩項，均達標僅表示這兩項未超限；甲醛含量≤50mg/kg（本頁未採集，甲醛輸入為釋放量 mg/m³ 屬板材口徑）與重金屬等其他強制項未納入，整體合規須以有資質檢測報告為準，不按有害物質限量分「優等/合格」
  • 膠粘劑有害物質限值按GB 18583，苯≤5g/kg，甲醛≤1g/kg
  • 建議選擇ENF/E0級材料用於兒童房、臥室等長時間停留空間
