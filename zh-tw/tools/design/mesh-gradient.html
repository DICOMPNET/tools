🌐 Mesh Gradient Generator

📐 工作原理與說明
第 i 個色標位置 (x,y) 由預覽圓點拖拽決定，預設 x = i ÷ (色數 − 1) × 100%、y = (i % 2) × 80 + 10%；輸出 radial-gradient(at x% y%, 色值 0px, transparent 50%) 並按順序逗號疊加，底色取首色；色數上限 5
對比度：L = 0.2126R + 0.7152G + 0.0722B（sRGB 線性化），CR = (L1+0.05)/(L2+0.05)，取疊加文字與各色標的最小值；≥7 AAA、≥4.5 AA、≥3 僅大文本達標
網格漸變由多個徑向漸變疊加構成：拖動預覽上的圓點調整各色團的位置，改動顏色即時重算；可複製 CSS、下載 800×500 PNG，並用 WCAG 對比度公式校驗疊加文字與每個色標的可讀性（報告最差的一處）。PNG 用 Canvas 按 farthest-corner 半徑近似繪製，與瀏覽器 CSS 渲染接近但不保證逐畫素一致。

Build a multi-colour mesh gradient background by dragging colour stops, then export the gradient as an image or CSS.
