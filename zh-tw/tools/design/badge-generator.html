🏅 Badge Generator

📐 工作原理與說明
四種樣式生成內聯徽章 CSS：solid 用背景色填充 + 內邊距 4px 10px；outline 背景透明 + 1px 同色描邊 + 內邊距 3px 9px；pill 圓角固定 50px + 內邊距 4px 12px；dot 在文字前插入 6px 圓形色點，間距 6px；統一 font-size = 設定值 px、font-weight: 600、border-radius = 圓角 px（pill 除外）
用純 CSS 生成徽章：文字、配色、圓角、字號與樣式（實心 / 描邊 / 藥丸 / 帶圓點）引數化後即時渲染，並可複製 CSS 程式碼；輸出是單個 span + .badge 樣式，不涉及圖片或 SVG，適合狀態標籤、活動角標與頁面裝飾。

Generate pure-CSS status badges: tune text, colors, radius, font size and style, preview live, and copy the CSS — no images or SVG, all processed locally in your browser.

❓ 常見問題（FAQ）

能直接用在 GitHub 嗎？
可複製生成的 CSS 與 span 片段，粘到支援 HTML/CSS 的頁面或自託管站點；GitHub README 不支援自定義 CSS，需改用圖片。本工具只生成程式碼，不託管檔案。
文字太長怎麼辦？
徽章按內容寬度自適應伸縮，過長建議縮寫。結果以瀏覽器即時計算為準，純前端本地處理、資料不上傳；生成的樣式與程式碼僅作快速產出參考，正式專案請以設計系統、規範與瀏覽器實測為準。
會儲存或上傳我的內容嗎？
