🔄 Viewport Unit (vw/vh) Converter

Convert between viewport units and pixels: vw and vh are 1% of the viewport width and height, handy for full-screen layouts.

📐 工作原理與說明
px → vw：vw = px ÷ 視口寬度 × 100；vw → px：px = vw × 視口寬度 ÷ 100（vh 同理按高度計算）
vw 與 vh 分別是視口寬、高的 1%，因此換算需給定基準視口尺寸。按寬度換算時以視口寬為基準、按高度換算時以視口高為基準，反向（vw/vh → px）則為乘算，用於替代寫死的 px 實現自適應間距與全屏佈局。

Formula & Standard References

Item Formula / Note Source / Standard
Viewport percentage 1vw is one percent of viewport width, 1vh of height CSS Values and Units Level 4
Mobile viewport height browser chrome makes 100vh overflow, so use svh, lvh or dvh CSS Values and Units Level 4
Extreme units vmin follows the shorter axis and vmax the longer CSS Values and Units Level 4
⚠️ 使用說明與注意事項
  • vw 永遠基於視口【寬度】，vh 永遠基於視口【高度】，二者互不相干。
  • 移動端注意：部分瀏覽器的 vh 包含位址列高度，可用 dvh/svh/lvh 等動態視口單位更精準。
  • 100vw 在大屏可能超出預期並引發橫向滾動，用於全寬時建議配合 overflow-x:hidden。

移動端位址列？
vh 受位址列影響有波動，關鍵佈局可用 dvh 等新版單位。
和 % 有什麼區別？
% 相對父元素，vh/vw 相對視口；全屏佈局用視口單位更直接。
