📐 計算公式 / 原理
中位切分：在 RGB 空間沿畫素分佈最長的顏色軸遞迴取中位分割，直至達到目標色數 k
基於中位切分（median-cut）色彩量化：反覆沿最長顏色軸中位切分，得到 k 個代表色，相比平均法更能保留畫面主色調；可編輯並匯出 CSS 或 JSON。

🎨 工具介紹與常見問題 ▼

調色盤提取器是一款純前端圖片顏色分析工具，採用中位切分法（Median Cut）演算法，從上傳的圖片中智慧提取主色調，幫助設計師和開發者快速獲取配色方案。

✨ 功能特點

  • 中位切分法顏色量化演算法
  • 支援拖拽和點選上傳圖片
  • 5/8/10/12 色自由選擇
  • 按頻率、亮度、色相排序
  • 匯出 CSS / JSON / SCSS / Tailwind
  • 純前端處理，圖片不上傳伺服器

🎯 使用場景

  • 提取設計稿/照片的主色調
  • 為專案生成配色方案
  • 分析品牌視覺色彩構成
  • 建立 CSS 變數和設計 Token

❓ 常見問題（FAQ）

透明背景影響嗎？
透明畫素通常不計入主色統計，避免被背景色干擾。
色數限制多少？
取前 N 主色即可；色數越多越接近原圖但越雜，一般 5~8 色夠用。
會儲存或上傳我的內容嗎？
結果以瀏覽器即時計算為準，純前端本地處理、資料不上傳；生成的樣式與程式碼僅作快速產出參考，正式專案請以設計系統、規範與瀏覽器實測為準。
