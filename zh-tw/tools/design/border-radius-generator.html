⭕ Border Radius Generator

📐 工作原理與說明
四角取值完全相同時輸出單值寫法 border-radius: 左上 + 單位；否則按 左上、右上、右下、左下 的順序輸出四值寫法；單位由所選單位決定（px 或 % 等）；演示框同步設定 borderRadius 屬性即時預覽
四角半徑分別對映為 CSS border-radius 的左上 / 右上 / 右下 / 左下值，即時預覽並生成宣告；支援獨立設定各角，用於前端圓角樣式落地。

Drag to set the corner radius of an element and copy ready-to-use CSS border-radius, with independent control of all four corners.
