🔘 CSS Button Generator

📐 工作原理與說明
從背景色十六進位制串取 R = slice(1,3)、G = slice(3,5)、B = slice(5,7) 按 16 進位制解析；按鈕樣式：padding = 縱向 px 橫向 px、background 取背景色、color 取文字色、border = 邊框寬 px solid 邊框色、border-radius = 圓角 px、font-size = 字號 px、box-shadow = 陰影X px 陰影Y px 模糊 px rgba(R,G,B,0.4)；懸停態上移 2px 且陰影改為 陰影Y+2 / 模糊+4、透明度 0.5
把背景、圓角、內邊距、陰影與懸停態引數拼裝為完整 CSS 規則（含 :hover 偽類），即時預覽並可複製；用於快速產出風格統一的按鈕樣式。

Style a button background, radius, shadow and hover state visually and copy the generated CSS, with several built-in presets.
