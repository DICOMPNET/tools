📐 工作原理與說明
網格邊長下限 10（預設 40）、線寬下限 1；四層 linear-gradient 分別按 30°、150°、270°、30° 繪製等距網格線；background-size = 邊長 × (邊長 × 0.5774)，高度按 tan(30°) 壓縮形成等距透視
等距網格由 30° / 150° 斜線按固定步距平鋪構成菱形格，網格尺寸與配色可調並匯出圖片；用於 2.5D 遊戲地圖、插畫底圖與示意圖。

Generate an isometric (2.5D) grid background with adjustable cell size and colours for game maps, illustrations and diagrams.
