📐 計算公式
數目法（日韓規則）：黑方得分 = 黑圍空 + 黑提子數，白方得分 = 白圍空 + 白提子數 + 貼目（通常 6.5 目）；數子法（中國規則）：黑方 = 黑方活子數 + 黑方圍空數，白方同理，黑方需達到 185 子以上方勝（361 點半數加貼子）；勝負差 = 雙方得分之差，正值表示黑優、負值表示白優。

💡 常見使用場景

  • 日本數目：圍空目數 + 提子數 + 貼目，算雙方目數差判定勝負。
  • 中國數子：活子數 + 圍空，按數子法（含貼子）判定勝負。
  • 貼目/貼子對比：不同規則貼目（如日韓 6.5 目、中國 3¾ 子≈7.5 目）對結果的影響。

❓ 常見問題（FAQ）

數目與數子區別？
日本數目算空點+提子+貼目；中國數子算活子+圍空+貼子。規則一致時勝負結論通常相同。
貼目一般多少？
因規則而異：日韓通常 6.5 目（防和棋），中國貼 3¾ 子（約 7.5 目）。
單官怎麼處理？
數目法單官不計；數子法單官歸收官方，影響細微但規則明確。
