Normality Calculator

Compute normality N = z·M (equivalents of solute per litre), where z is the equivalence factor.

📐 計算公式
N = n·z / V；z 為每摩爾的當量數。 1 mol H₂SO₄(z=2) 配 1 L 得 2 N。

當量濃度 = 物質的量 × 當量數 / 體積，常用於酸鹼氧化還原滴定。

📌 計算說明
  • N = n·z / V；z 為每摩爾的當量數。
  • 1 mol H₂SO₄(z=2) 配 1 L 得 2 N。

📚 深度解析：當量濃度（N = n·z / V）

💡 常見使用場景

  • 酸鹼滴定：一元酸 z=1、二元酸 z=2，N=c·z。
  • 氧化還原：由電子轉移數定 z，算當量濃度。
  • 當量換算：N 與 c 經 z 橋接，統一計量。
0.1 mol/L H₂SO₄（z=2）演練
輸入 c=0.1 mol/L、z=2，工具輸出 N=0.2 N，並提示 z 隨反應型別變。

❓ 常見問題（FAQ）

z（當量數）怎麼定？
酸鹼看可交換 H⁺/OH⁻ 數；氧化還原看電子轉移數。
當量濃度現在常用嗎？
滴定仍用，尤其氧化還原；現代多直接用 mol/L+z。
N 和 c 能直接比嗎？
N=z·c，z 不同數值不同，需註明反應型別。
