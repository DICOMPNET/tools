Molarity Calculator

Compute molarity c = n / V (moles of solute per litre of solution), or convert mass to molarity.

📐 計算公式
摩爾濃度（物質的量濃度）：c = n ÷ V（mol/L，n 溶質物質的量 mol、V 溶液體積 L）；聯動量：mmol/L 口徑 = c×1000、體積(mL) = V×1000、復算體積 = n ÷ (c||1)（L，c 為 0 時分母按 1 兜底）。校驗：n、V 兩項必填守衛；V=0 時 c 無定義，結果僅按 — 展示、不另行提示。判據：無固定分級，稀釋（V 增大）時 c 反比減小、n 守恆。

由物質的量與溶液體積計算物質的量濃度。

📌 計算說明
  • c = n / V；V 為溶液體積(L)。
  • 2 mol 溶於 1 L 得 2 mol/L。

💡 常見使用場景

  • 標準液配製：稱固體定容到 V 得 c，作滴定基準。
  • 滴定計算：由 c 與 V 算參加反應摩爾，聯算待測濃度。
  • 稀釋複核：稀釋後 c 按 C1V1=C2V2 變。
0.5 mol 溶質定容 250 mL 演練
輸入 n=0.5 mol、V=250 mL，工具輸出 c=2.0 mol/L，並提示須定容至刻度而非加溶劑到體積。

❓ 常見問題（FAQ）

定容到 V 不是加到 V？
是定容至刻度：先溶後加水至線，而非加溶劑到 V。
溫度影響嗎？
體積隨溫度變，c 略變；精確實驗需恆溫。
和 molality 怎麼選？
配製滴定多用 c，依數性用 b。
