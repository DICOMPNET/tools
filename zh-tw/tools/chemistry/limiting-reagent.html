Limiting Reagent Calculator

Identify the limiting reactant and theoretical yield from stoichiometric amounts of each reagent.

📐 計算公式
限量反應物：n_i = m_i ÷ M_i（mol），貢獻 ξ_i = n_i ÷ ν_i（ν 為化學計量係數）；反應程度 ξ = min(ξ_A, ξ_B)；理論產量 = ξ × c × M_P（g，c、M_P 為產物係數與摩爾質量）。校驗：8 項全必填守衛，M_A/M_B 置 0 報「分母不能為 0」，全 0 報錯。判據：ξ_A ≤ ξ_B 判 A 為限量反應物，否則 B（平局取 A）。

輸入兩種反應物的質量與摩爾質量，以及反應方程式係數，自動判定哪種是限量反應物。

📌 計算說明
  • ξ = n_i/ν_i，取較小者對應的物質為限量反應物。
  • 示例：HCl(36.46) 10g 與 NaOH(40) 8g，A 限量。

💡 常見使用場景

  • 投料最佳化：由多反應物摩爾數找最小比值者即限量物，避免原料浪費。
  • 理論產量：按限量物計量比算產物上限質量。
  • 過量核算：算某反應物過量倍數，提示可減投降本。

❓ 常見問題（FAQ）

怎麼找限量物？
各反應物摩爾÷自身係數，最小者限量。
過量物算產量嗎？
不計，產量由限量物決定；過量部分剩餘。
係數一定要整數配平嗎？
用最簡整數比即可，關鍵是摩爾比。
