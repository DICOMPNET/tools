Partial Pressure Calculator (Dalton’s Law)

Compute a gas component’s partial pressure from p_i = x_i·P_total using mole (or volume) fraction.

📐 計算公式
道爾頓分壓定律：Pᵢ = xᵢ×總壓（kPa，xᵢ 為摩爾分數）；聯動量：其餘組分分壓 = 總壓−Pᵢ、摩爾分數 % = xᵢ×100、其餘組分佔比 = (總壓−Pᵢ)÷(總壓||1)×100（總壓為 0 時分母按 1 兜底）。校驗：無強校驗，空值按 0 兜底。判據：無固定分級，各組分分壓之和恆等於總壓，分壓佔比按摩爾分數分配。

混合氣體中某組分的分壓等於其摩爾分數乘以總壓。

📌 計算說明
  • Pᵢ = xᵢ · P_總；xᵢ 為組分摩爾分數。
  • 摩爾分數 0.2、總壓 100 kPa 時分壓 20 kPa。

💡 常見使用場景

  • 混合氣分壓：由組成與總壓算各氣分壓，評估工況。
  • 氣體收集：排水法收集時扣除水蒸氣分壓得幹氣分壓。
  • 呼吸氣體：空氣中 O₂ 分壓≈0.21×總壓。
空氣 x_O2=0.21、P=1 atm 演練
輸入 x_O2=0.21、P=1 atm，工具輸出 P_O2≈0.21 atm，並提示分壓比=摩爾比=體積比。

❓ 常見問題（FAQ）

分壓和體積分數關係？
理想氣體分壓比=摩爾比=體積比。
水蒸氣怎麼扣？
總壓減該溫飽和蒸氣壓得幹氣分壓。
總壓變分壓怎麼變？
同組成下各分壓按總壓等比變。
