⚠️ 使用說明與注意事項
  • 本工具純前端執行，圖片資料不會離開您的裝置
  • 放大圖片不會增加真實細節，可能出現模糊或鋸齒
  • JPEG 格式不支援透明背景，輸出時會以白色填充；PNG/WebP 保留透明通道
  • 建議在主流瀏覽器（Chrome / Safari / Firefox / Edge）中使用
  • 超大圖片（如 10000px 以上）可能因記憶體限制處理緩慢

2000×1500 圖按 50% 縮放，輸出 1000×750，JPEG 質量 85，體積從 1.8MB 降到 260KB。
目標寬 1920
原 4000×3000，指定目標寬 1920，等比高 = 1920×3000/4000 = 1440，輸出 1920×1440。

❓ 常見問題（FAQ）

等比縮放高怎麼算？
新寬/原寬 = 比例，新高 = 原高×同比例。如寬縮到 1/2，高也縮到 1/2。
放大為什麼會糊？
放大是插值補畫素，沒有真實細節；質量選「smooth」演算法邊緣更柔，但無法憑空變清晰。

📝工具簡介

線上圖片縮放 / 調整尺寸，支援按比例或指定尺寸，平滑與快速兩種演算法，PNG/JPEG 輸出。純前端 Canvas 處理，圖片不上傳

✨功能特點

  • 按比例縮放（10%~200%滑塊 + 預設按鈕）
  • 精確指定目標寬高，可鎖定寬高比
  • 平滑 / 快速兩種重取樣演算法可選
  • PNG / JPEG / WebP 多格式輸出
  • JPEG/WebP 質量可調（10%~100%）
  • 即時預覽縮放效果與尺寸對比
  • 純前端 Canvas 處理，圖片不上傳
  • 支援深色模式與移動端響應式佈局

🎯使用場景

  • 網頁配圖按比例縮小，最佳化載入速度
  • 縮圖 / 封面圖批次尺寸調整
  • 社交媒體頭像、封面尺寸適配
  • 證件照、報名照指定畫素尺寸
  • 桌布、 banner 放大或縮小
  • 郵件附件圖片壓縮減小體積
