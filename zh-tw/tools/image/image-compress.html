⚠️ 使用說明與注意事項
  • 本工具純前端執行，圖片不會上傳到任何伺服器，保護隱私安全
  • JPEG 為有損格式，不支援透明背景（透明區域會填充白色）
  • WebP 相容現代瀏覽器（Chrome/Edge/Firefox/Safari 14+），壓縮率最優
  • PNG 為無損格式，質量滑塊不生效；對照片壓縮效果有限
  • 「最大尺寸」會等比縮放圖片，使長邊不超過設定值
  • 部分舊瀏覽器可能不支援 WebP 輸出，如遇失敗請改選 JPEG

💡 常見使用場景

  • 微信/郵箱對附件大小有限制，發圖前先瘦身。

原圖 4096KB 的 JPEG，轉 WebP 質量 80，體積降到約 700KB（壓縮率約 83%），肉眼幾乎無差。
JPEG 質量 85 上限寬 1920
長邊 4096 的圖，限制最大寬 1920 後等比重取樣，再 JPEG 質量 85，體積從 3.2MB 降到 380KB。

❓ 常見問題（FAQ）

質量係數越高越好嗎？
質量 80–85 通常體積與清晰度平衡最好；超過 90 體積翻倍但肉眼難辨，純浪費。
為什麼限制最大寬能大幅變小？
畫素數 = 寬×高，長邊從 4096 降到 1920，畫素數約降到 1/4.5，體積隨之大幅下降。

📝工具簡介

圖片壓縮工具是一款線上影像處理工具，利用瀏覽器 Canvas API 對圖片進行壓縮與最佳化。支援 JPEG、WebP、PNG 三種輸出格式，可自由調節壓縮質量（1%～100%），並可設定最大尺寸進行等比縮放。支援單張即時對比預覽與多張批次壓縮，所有處理在本地瀏覽器完成，圖片不離開裝置。

✨功能特點

  • 純前端 Canvas 壓縮，圖片不上傳
  • 支援 JPEG / WebP / PNG 三種格式
  • 質量滑塊 1%～100% 即時調節
  • 最大尺寸等比縮放限制
  • 拖拽滑塊對比壓縮前後效果
  • 批次壓縮多張圖片
  • 顯示壓縮率、節省體積、尺寸變化
  • 一鍵下載壓縮結果
  • 支援深色模式與響應式佈局

🎯使用場景

  • 網頁圖片最佳化，提升載入速度
  • 郵件附件體積過大需要縮小
  • 社交媒體上傳前壓縮圖片
  • 批次處理產品圖、文章配圖
  • 將 PNG 截圖轉為 WebP 減小體積
  • 部落格/網站素材壓縮最佳化
  • 手機照片壓縮節省儲存空間
  • 隱私敏感圖片的本地處理
