📐 工作原理與說明
圖片拼圖佈局與畫布尺寸計算
垂直堆疊(v)：統一寬度 = min(1600, 各圖最大寬) 或固定值
　各圖高度 = round(統一寬 ÷ 原寬 × 原高)；畫布高 = Σ各圖高 + gap×(n−1)
水平排列(h)：統一高度同理，畫布寬 = Σ各圖寬 + gap×(n−1)
網格(grid)：平均寬高比 = Σ(寬/高) ÷ 張數
　定寬模式：格寬 = ⌊(固定值 − 邊距×2 − gap×(列數−1)) ÷ 列數⌋，格高 = 格寬 ÷ 平均寬高比
　定高模式：格高同理反算格寬
　自適應模式：格高基準 300，按平均寬高比算格寬，超 3000px 時整體縮放
畫布尺寸 = 邊距×2 + 格數×格寬 + gap×(格數−1)
填充模式 cover/contain 由 drawImageFit 決定裁剪或留白
安全上限：任一邊 > 8000px 時按比例縮放並提示
圖片數超過格子數時僅合成前 行×列 張

2×2 拼四張
四張 600×600 圖，選 2×2 網格、間距 10px、邊距 20px，合成畫布 = 600×2+10+20×2 = 1260×1260px。
3×3 拼九張
九張 400×400，3×3 網格間距 8px 邊距 16px，輸出 400×3+8×2+16×2 = 1280×1280px。

❓ 常見問題（FAQ）

合成畫布尺寸怎麼估算？
邊長 = 單圖邊長×格數 + 間距×(格數−1) + 邊距×2。先用公式核一遍再匯出，避免超出預期。
透明底和純色底怎麼選？
需要疊加到其他背景用透明底（PNG）；單獨成圖用純色底更乾淨。

📝工具簡介

圖片拼圖合成工具是一款免費的線上拼圖生成器，可將多張圖片按豎排、橫排或網格佈局合成為一張長圖或拼圖。基於瀏覽器 Canvas API 即時渲染，支援自定義間距、外邊距、背景色、適應方式與拖拽排序，合成後可匯出 PNG 或 JPG 圖片。所有處理在本地完成，圖片不會上傳伺服器。

✨功能特點

  • 多圖上傳，支援拖拽排序與上下移動
  • 豎排拼接、橫排拼接、2×2 / 3×3 / 自定義網格
  • 可調圖片間距（0~50px）與外邊距
  • 自定義背景色，支援透明背景（PNG）
  • 自適應尺寸或固定寬度/高度
  • 網格適應方式：完整顯示、填滿裁剪、拉伸
  • 即時預覽，一鍵下載 PNG / JPG
  • 純前端處理，圖片不上傳，保護隱私

🎯使用場景

  • 將多張截圖豎排拼接為長圖分享
  • 製作朋友圈、小紅書九宮格拼圖
  • 產品多圖合成一張展示圖
  • 組合證件照、簽證照排版
  • 旅行照片拼接成長卷預覽
  • 課程筆記、聊天記錄合併為長圖
