🏋️ Body Fat Percentage Estimator

Estimate body fat percentage from waist, neck, hip and height using the US Navy circumference method, with the sex-specific formula and fitness band shown.

📐 計算公式與說明

BF% = 1.2·BMI + 0.23·年齡 − 10.8·性別(男1) − 5.4

Deurenberg 公式，僅供粗略估算。

📚 深度解析：體脂率估算（Deurenberg）

💡 常見使用場景

  • 體成分跟蹤：由 BMI、年齡、性別估體脂率，輔助減脂
  • 健身參考：看脂肪而非僅體重，避免"輕但胖"
  • 科普：理解年齡性別對體脂的影響
方法
演算法（Deurenberg）：體脂% = 1.2×BMI + 0.23×年齡 − 10.8×(男 1 / 女 0) − 5.4；BMI = 體重 ÷ 身高²。要求各值>0。屬粗略估算，誤差約 ±3.5%。
算例
例1（65kg / 170cm / 30 歲 / 男）：BMI = 22.5，體脂 = 1.2×22.5 + 0.23×30 − 10.8 − 5.4 = 17.7%。例2（55kg / 160cm / 40 歲 / 女）：BMI = 21.5，體脂 = 1.2×21.5 + 0.23×40 − 0 − 5.4 = 29.6%。

❓ 常見問題（FAQ）

估算準嗎？
公式法誤差較大，僅作趨勢參考；較準方法為皮褶厚度、生物電阻抗(BIA)、DXA（雙能 X 線）。健身者肌肉多會被高估體脂。
男女公式為何不同？
同 BMI 下男性基礎脂肪低於女性，公式用 −10.8（男）/0（女）修正性別差異；女性健康體脂通常高於男性。
