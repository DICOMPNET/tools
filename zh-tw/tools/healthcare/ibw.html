📐 計算公式與說明

男性 IBW = 50 + 0.91×(身高cm − 152.4)
女性 IBW = 45.5 + 0.91×(身高cm − 152.4)
校正體重 ABW = IBW + 0.4×(實際體重 − IBW)（僅當實際體重 > IBW，用於肥胖患者藥物劑量參考）
校驗：身高須為 100–250 cm 的正數，越界時提示換算單位並中止計算

常用於藥物劑量調整參考。

📚 深度解析：理想體重 IBW（Devine 公式）

💡 常見使用場景

  • 劑量基準：臨床由 IBW 算許多藥物劑量
  • 營養支援：機械通氣潮氣量等按 IBW 設
  • 參考意義：IBW 是臨床基準而非健康胖瘦標準
方法
演算法（Devine）：男 IBW = 50 + 0.91×(身高cm−152.4)；女 IBW = 45.5 + 0.91×(身高cm−152.4)；上限 = IBW×1.1、下限 = IBW×0.9；填寫實際體重且大於 IBW 時，校正體重 ABW = IBW + 0.4×(實際體重 − IBW)。身高須在 100–250 cm 之間，越界時拒絕計算並提示換算單位。
算例
例1（170cm、男）：IBW = 50 + 0.91×17.6 = 66.0kg，區間 59.4–72.6kg。例2（160cm、女）：IBW = 45.5 + 0.91×7.6 = 52.4kg，區間 47.2–57.7kg。

❓ 常見問題（FAQ）

IBW 是"標準體重"嗎？
不是健康評判，而是臨床計算的參考基準（尤其給藥、呼吸機引數）；實際理想體重因人而異，肌肉量高者 IBW 偏低也正常。
肥胖患者劑量按 IBW 還是實際體重？
視藥物與指南：脂溶性/分佈廣的藥物可能用校正體重，水溶/按 IBW 設計的則用 IBW；須依具體藥品說明書與臨床決策。
