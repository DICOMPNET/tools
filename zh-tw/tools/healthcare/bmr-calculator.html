🏋️ Basal Metabolic Rate Calculator

Estimate resting daily calorie burn with the Mifflin-St Jeor equation from height, weight, age and sex, as the baseline for any nutrition or weight plan.

📐 計算公式與說明

基礎代謝率（Mifflin-St Jeor 式）：BMR = 10×體重(kg) + 6.25×身高(cm) − 5×年齡 + (男 +5 / 女 −161)，結果取整以 kcal/天 展示。校驗：無強校驗，非數輸入按 0 兜底，性別由下拉取值（值 1 為男、其餘按女式）。判據：體重與身高越大、年齡越小 BMR 越高，同參數下男性基準項比女性高 166 kcal/天。

為基礎靜息消耗，非每日總消耗。

📚 深度解析：基礎代謝率 BMR（Mifflin-St Jeor）

💡 常見使用場景

  • 營養評估：估靜息最低熱量消耗，制定減脂/增肌飲食
  • 熱量預算：由 BMR 乘活動係數得 TDEE，定攝入目標
  • 科普：理解年齡、性別對代謝的影響
方法
演算法（Mifflin-St Jeor）：BMR = 10×體重(kg) + 6.25×身高(cm) − 5×年齡 + (男 +5 / 女 −161)，單位 kcal/天。要求各值>0。
算例
例1（65kg / 170cm / 30 歲 / 男）：BMR = 10×65 + 6.25×170 − 5×30 + 5 = 650 + 1062.5 − 150 + 5 = 1568 kcal/天。例2（55kg / 160cm / 25 歲 / 女）：BMR = 550 + 1000 − 125 − 161 = 1264 kcal/天。

❓ 常見問題（FAQ）

BMR 和 TDEE 區別？
BMR 是躺著不動的最低消耗；TDEE = BMR × 活動係數（久坐約 1.2、中等約 1.55、高強度約 1.9），才是 daily 總消耗。減脂攝入應略低於 TDEE。
公式適合所有人嗎？
Mifflin-St Jeor 對普通成人較準；運動員、孕婦、甲亢/減等特殊情況偏差大，僅作估算。
