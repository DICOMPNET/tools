❤️ Corrected QT Interval Calculator

Correct the QT interval for heart rate with the Bazett, Fridericia, Framingham and Hodges formulas, and flag the prolongation thresholds for each method.

📐 計算公式與說明

RR = 60 / HR（秒）
Bazett: QTc = QT / √RR
Fridericia: QTc = QT / ³√RR
Framingham: QTc = QT + 154 × (1 − RR)
Hodges: QTc = QT + 1.75 × (HR − 60)
正常上限：男 450 ms、女 460 ms；≥500 ms 高風險

QTc 延長與心律失常風險相關；公式下拉框決定實際使用的校正公式，性別決定正常上限。

📚 深度解析：QTc 校正心率

💡 常見使用場景

  • 用藥監測：抗心律失常/抗生素/精神藥等致 QT 延長
  • 心電圖判讀：QTc 延長提示心律失常風險
  • 隨訪：複查 ECG 看趨勢
方法
演算法：RR = 60/心率(秒)；QTc Bazett = QT / √RR；Fridericia = QT / ∛RR；Framingham = QT + 154×(1−RR)；Hodges = QT + 1.75×(心率−60)。正常上限男 450ms、女 460ms，≥500ms 高風險。要求心率 20–250 bpm、QT 與心率>0；公式由下拉框選擇，結果給出「延長/未延長」判定。
算例
例1（QT 400ms、HR 75、男）：RR=0.8，Bazett=447.2ms，Fridericia=430.9ms，Framingham=430.8ms，Hodges=426.3ms，未超男上限 450ms。例2（QT 500、HR 50、男）：RR=1.2，Bazett=456.4ms，超過 450ms 判延長。

❓ 常見問題（FAQ）

Bazett 和 Fridericia 哪個好？
Bazett 在心率快/慢時偏差大；Fridericia 較穩。臨床多看 Bazett，異常時輔以 Fridericia 與心率校正確認。
QTc 延長怎麼辦？
排查藥物（可查 crediblemeds 名單）、電解質紊亂（低鉀低鎂）、先天性心臟病；≥500ms 或症狀性需停藥就醫，非本工具能定。
