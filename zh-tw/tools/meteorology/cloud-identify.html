🔍 Cloud Type Identifier

Identify cloud types from satellite and sky images using visual features.

📐 工作原理與說明
按世界氣象組織十屬雲分類：低雲族（積雲、積雨雲、層積雲、層雲、雨層雲，雲底多在 2000 m 以下）、中雲族（高層雲、高積雲，雲底 2000 至 6000 m）、高雲族（捲雲、卷層雲、卷積雲，雲底 6000 m 以上）；積雨雲預示雷暴與強降水，卷層雲常預示鋒面臨近天氣轉壞，層積雲多為穩定天氣。
雲按雲底高度分四族：高雲（>5km）、中雲（2.5—5km）、低雲（<2.5km）、直展雲（垂直髮展旺盛）。

📚 深度解析：雲狀識別

💡 常見使用場景

  • 按高度與形態判別積雲/層雲/捲雲等。
  • 看雲預判短期天氣（如積雨雲雷雨）。
  • 攝影與科普標註雲類。
高雲
捲雲（Ci）白色絲縷、高度>6km，由冰晶組成，常預示天氣系統臨近；出現毛卷雲後 24–48h 可能變天。
直展雲
積雨雲（Cb）濃墨底部平坦、頂部鐵砧，伴雷電暴雨大風，看到即提示強對流預警。

❓ 常見問題（FAQ）

雲分幾族？
按高度分高/中/低雲加直展雲，共 10 屬（如 Ci/Cs/Cc、Ac/As、Cu/Sc/St/Ns、Cb）。
看雲能預報嗎？
只能短臨（小時級）粗略判斷，精確預報仍靠探空與數值模式。
