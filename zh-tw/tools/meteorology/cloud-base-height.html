Cloud Base Height Calculator

Estimate cloud base height from surface temperature and dew point.

📐 計算公式
h = (T−Td)/0.98 × 100 (m)

由氣溫與露點差，按經驗規則 H ≈ (T − Td) × 125（米/℃）估算雲底高度。

📌 計算說明
  • 經驗規則（約 125 m/℃），與氣壓、抬升率有關，作近似。

📚 深度解析：雲底高度估算

💡 常見使用場景

  • 由氣溫與露點溫差估雲底離地高度。
  • 航空/通航判斷雲底是否夠低影響起降。
  • 預報員用乾溼球差快速估雲高。
溫差估雲高
氣溫 20°C、露點 10°C，溫差 10°C → 雲底高度=10/2.5×1000=4000 ft≈1220 m（經驗率每溫差 1°C 約 400 ft）。
低雲預警
溫差僅 2°C → 雲底≈800 ft≈240 m，屬低雲，通航需謹慎。

❓ 常見問題（FAQ）

2.5 這個係數是哪來的？
幹絕熱(9.8°C/km)與露點直減(約 2°C/km)之差約 8°C/km，換算成每 °C 溫差≈125 m，經驗取 122 m（400 ft）。
雲底高度準嗎？
是近似，假設雲由地面空氣抬升凝結而成；層雲較準，積雲因對流會偏低。
