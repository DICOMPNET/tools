Quality - ( Standard / Evaluate / Improvement ) System

📐 工作原理與說明
養老服務質量得分 = 服務響應 + 專業能力 + 服務規範 + 滿意度 + 安全管理（每項 1 至 5 分），平均分 = 總分 ÷ 5；平均分不低於 4.5 為優秀、3.5 至 4.4 為良好、2.5 至 3.4 為一般、低於 2.5 為不合格，按最低分維度制定改進計劃。

養老服務質量評估體系（5維度，每項1-5分，總分5-25）

📚 深度解析：質量（標準/評估/改進）體系

💡 常見使用場景

  • 養老服務機構質量自評中，按服務響應、專業能力、服務規範、滿意度、安全管理五維打分。
  • 均值用於判定優秀/良好/一般/不合格，並定位需改進維度。
  • 質量改進閉環：達標維度保持，≤2 分維度列入整改。
算例：五維均評 5 分
質量總分 = 25 / 25，均值 = 5.00 → 『質量優秀』，建議總結經驗推廣、保持標準。
算例：五維均評 3 分
總分 = 15，均值 = 3.00 → 『質量一般』，需制定改進計劃、加強培訓與流程最佳化（均值 2.5–3.5 區間）。

❓ 常見問題（FAQ）

質量等級怎麼劃分？
按五維均值：≥4.5 優秀、≥3.5 良好、≥2.5 一般、<2.5 不合格（滿分 25，單維 0–5）。不合格須立即整改並限期複查。
哪一維低分最該優先改？
安全管理和服務規範通常與事故風險直接相關，單維≤2 即觸發整改；建議先補齊安全制度與規範流程，再做能力與滿意度提升。
