📐 計算公式
質量驗收抽樣判定（計數抽樣）
判定規則：樣本中不合格品數 d ≤ 合格判定數 Ac → 批次接收；d > Ac → 拒收
樣本不合格品率 = d ÷ n × 100%；抽樣比 = n ÷ N × 100%
AQL 處接收機率 Pa = Σ_{i=0..Ac} C(n,i)·p^i·(1−p)^(n−i)，p = AQL
生產方風險 α = 1 − Pa（好批被拒的機率）
LTPD（批容許不合格品率）：使接收機率降至 β=10% 的不合格品率
方案評價：Pa≥0.95 優｜≥0.90 良｜≥0.80 一般｜<0.80 差
質量驗收抽樣：基於計數標準型抽樣檢驗，輸入批次 N、樣本 n、合格判定數 Ac 與發現不合格品數 d，按 GB/T 2828 或 AQL 判定批次接收/拒收，用於入庫/出廠檢驗。
💡 判定規則：d ≤ Ac 接收批，d > Ac 拒收批。接收機率基於二項分佈 P(d≤Ac)=ΣC(n,i)·p^i·(1-p)^(n-i)，i=0~Ac。LTPD 為接收機率=10% 時的不合格品率。

⚠️ 注意事項
  • 樣本數 n 應小於或等於批次 N，通常 n ≤ N 的 10%（大批次時）
  • AQL 是使用方願意接受的最大過程平均不合格品率，常用值 0.65%、1.0%、1.5%、2.5%
  • LTPD（批容許不合格品率）是生產方風險 β=10% 時對應的不合格品率
  • 當 n/N > 0.1 時建議使用超幾何分佈，本工具採用二項分佈近似
  • 按 Enter 快速計算，Ctrl/Cmd + Enter 複製結果
  • 本工具純前端執行，資料不會上傳到伺服器

📚 深度解析：質量驗收抽樣檢驗（接收機率與 OC 特性）

💡 常見使用場景

  • 批次判定：按樣本量、合格判定數與發現不合格數判定接收/拒收
  • 方案評價：算 AQL 處接收機率與生產方風險，評估抽樣方案寬嚴
  • 質量分析：算 LTPD 與樣本不合格率，判斷過程質量水平
方法
演算法：按二項分佈計算接收機率 Pa(n, Ac, p) = Σ(i=0..Ac) C(n,i) pⁱ(1−p)^(n−i)；AQL 處接收機率 = Pa(n, Ac, AQL)；生產方風險 α = 1 − Pa（把合格批判為不合格的機率）；LTPD 用二分法求解使 Pa = 0.10 的不合格品率（使用方風險 β=10% 對應的質量水平）；樣本不合格品率 = d/n×100%；當 d ≤ Ac 判接收。方案評價：Pa ≥0.95 優（α 低）、≥0.90 良、≥0.80 一般、否則差需最佳化。
算例
例：批次 1000、樣本 80、Ac=2、發現 d=1、AQL 1.0% → AQL 處接收機率 95.3%、生產方風險 α=4.7%、LTPD 6.52%、樣本不合格率 1.25%、抽樣比 8.0%，判定「批次接收（合格）」，方案評價「優」（α=4.7%），但樣本不合格率 1.25% 高於 AQL 1.0%，提示過程質量不達標。若 d=3 → 3>Ac=2，判「批次拒收（不合格）」，樣本不合格率 3.75%。若把 Ac 收緊到 1（n=80、AQL 1.0%）→ 接收機率降至 80.9%、α 升到 19.1%，方案降為「一般」。

❓ 常見問題（FAQ）

生產方風險和使用方風險分別是什麼？
生產方風險 α 是把質量合格的批（不合格品率 ≤ AQL）誤判為不合格的機率，損害供方利益；使用方風險 β 是把質量低劣的批（不合格品率 ≥ LTPD）誤判為合格的機率，損害需方利益。標準抽樣方案的設計目標就是同時把 α 控制在 5% 左右、β 控制在 10% 左右，本工具正是按這兩個點計算。
為什麼二項分佈就夠了，不用超幾何分佈？
當批次 N 遠大於樣本量 n（一般 n/N < 0.1）時，不放回抽樣可用二項分佈很好近似，誤差可忽略。本工具預設例 n/N = 80/1000 = 8%，近似成立。若 N 很小（如 N=50、n=20），則應改用超幾何分佈，否則會高估接收機率。正式方案請按 GB/T 2828.1 的轉移規則與抽樣表執行。

📝工具簡介

質量驗收抽樣判定工具，基於計數標準型抽樣檢驗原理，輸入批次數 N、樣本數 n、合格判定數 Ac、AQL 和實際發現不合格品數 d，通過二項分佈計算接收機率、生產方風險和 LTPD，自動判定批次接收或拒收。純前端處理，資料不上傳。

✨功能特點

  • 基於二項分佈計算 AQL 處接收機率 Pa
  • 自動計算生產方風險 α（好批被拒機率）
  • 二分法求解 LTPD（β=10% 時的不合格品率）
  • 輸入校驗：n≤N、Ac<n、d≤n，自動提示錯誤
  • 抽樣方案優劣評價，輔助最佳化檢驗計劃
