📐 計算公式

月垃圾量 = 基礎量 + 食品殘渣 + 包裝 + 一次性用品 + 衣物；人均每日 = (月量 × 12 / 人數) / 365

基礎量 = 人數 × 1.2 kg/人/天 × (1 + 地區修正)（城區 0、郊區 −0.1、農村 −0.2）；食品殘渣 = 人數 × (烹飪係數 + 剩菜系數) × 30（烹飪：餐餐做 2.5 / 經常 1.5 / 偶爾 0.8 / 幾乎不做 0.3；剩菜：無 0 / 偶爾 0.3 / 較多 0.7，單位 kg/人/天）；包裝 = 外賣次數×4×0.4 + 快遞件數×4×0.15 kg；一次性 = 人數 × 係數 × 30（低 0.5 / 中 1.0 / 高 2.0）；衣物 = 無 0 / 少量 5 / 較多 15 kg。判定以人均每日計：<0.5 極低、<1.0 較低、<1.5 接近平均、否則偏高。

📚 深度解析：垃圾產生量計算器

💡 常見使用場景

  • 家庭自查：按人口與生活習慣估算月度垃圾量，並與人均 1–1.2 kg/天對照。
  • 減量規劃：對比減少外賣、合併快遞後包裝垃圾的下降幅度。
  • 社群宣傳：用不同引數演示一次性餐具與衣物消費對垃圾量的影響。
可復現算例：3 人城區家庭
輸入：3 人、城區、每週多次做飯、偶爾剩菜、外賣 3 次/月、快遞 2 件/月、偶爾用一次性餐具、少量添衣。 基礎量=3×1.2×(1+0)=3.6 kg；食品殘渣=3×(1.5+0.3)×30=162 kg； 包裝=(3×4×0.4)+(2×4×0.15)=4.8+1.2=6 kg；一次性=3×1.0×30=90 kg；衣物=5 kg； 月度合計≈266.6 kg，年約 3.20 t，人均≈2.92 kg/天 → 判為「偏高，需要減少」。減少外賣與一次性餐具是最直接的降量手段。

❓ 常見問題（FAQ）

人均多少算正常？
中國人均生活垃圾約 1–1.2 kg/天。低於 1.0 顯示環保良好，1.0–1.5 提示接近平均，高於 1.5 提示需減量。
哪幾項對結果影響最大？
按係數看，一次性餐具高檔為 2.0 kg/人/天、餐餐做飯為 2.5 kg/人/天，二者對總量影響最大；外賣與快遞按次數線性累加，減少頻次見效快。
