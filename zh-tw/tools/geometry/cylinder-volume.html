Cylinder Volume Calculator

Compute cylinder volume from base radius and height using V = πr²h.

📐 計算公式
圓柱體幾何：體積 V = π×r²×h（m³）；聯動卡：側面積 = 2πrh、底面積 = πr²、總表面積 = 2πr×(r+h)（m²）。校驗：r、h 均必填，空白不等於 0；負數與非有限數被拒絕，0 為合法退化值。判據：無固定分級，總表面積恆等於側面積加兩倍底面積，四卡聯動。

由底面半徑與高求圓柱體積。

💡 常見使用場景

  • 罐體/管道：圓柱形容積、管道內體積
  • 柱體填料：混凝土柱、樁身方量
  • 幾何建模：與圓錐、圓臺的體積關係對比
方法
演算法：圓柱體積 V = πr²h，側面積 S = 2πrh（同時輸出；總表面積另需加 2 個底面積 2πr²）。要求 r≥0、h≥0；0 為合法退化值（體積為 0），空白不等於 0。
算例
例：r=2m、h=5m → V=π×4×5=62.8319 m³、側面積=2π×2×5=62.8319 m²（此例因 r=2 使 2πrh=πr²h，數值恰相等）。若 r=3m、h=10m → V=282.7433 m³、側面積=188.4956 m²。

❓ 常見問題（FAQ）

側面積和體積數值會相等嗎？
僅在特定尺寸下巧合相等（如本例 r=2、h=5 滿足 2πrh=πr²h 即 r=2）。二者量綱不同（面積 vs 體積），相等只是數值巧合，不可當作一般規律。
總表面積怎麼算？
總表面積 = 側面積 + 2×底面積 = 2πrh + 2πr²。封閉圓柱（如儲罐）用總表面積，開口圓筒只用側面積。
