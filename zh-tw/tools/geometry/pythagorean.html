Compute the hypotenuse from legs a and b using c = √(a² + b²).

📐 計算公式
勾股定理與直角三角形要素（本頁程式碼口徑）：斜邊 c = √(a²+b²)；∠A = atan2(a,b)×180÷π（對邊 a、鄰邊 b，tanA = a÷b，已修正舊式 A/B 互換）、∠B = 90°−∠A；面積 = a×b÷2（m²）。校驗：兩項空值即提示；直角邊不得為負（0 合法）。判據：無固定分級，兩銳角互餘，∠A<45° 時 a 為較短直角邊。

📚 深度解析：勾股定理斜邊（c=√(a²+b²)）

💡 常見使用場景

  • 直角三角形：已知兩直角邊求斜邊
  • 平面距離：座標差構成的直角邊求直線距離
  • 螢幕尺寸：由寬高比換算對角線尺寸
方法
演算法：直角邊 a、b → 斜邊 c=√(a²+b²)；∠A 是邊 a 所對的銳角 ⇒ tan A = a/b ⇒ ∠A=arctan(a/b)，∠B=90°−∠A=arctan(b/a)。要求 a,b>0。
算例
例：a=3、b=4 → c=√(9+16)=5.0000 m；∠A=arctan(3/4)=36.87°、∠B=arctan(4/3)=53.13°。若 a=5、b=12 → c=13.0000 m、∠A=arctan(5/12)=22.62°（經典的 5-12-13 直角三角形）。

❓ 常見問題（FAQ）

已知斜邊和一個直角邊求另一個？
移項：b=√(c²−a²)。本工具按「已知兩直角邊求斜邊」設計；若求另一條直角邊，交換 a、b 或先算 c²−a² 再開方。
∠A 是哪個角？
∠A 是邊 a 所對的銳角，tan A = 對邊/鄰邊 = a/b，故 ∠A=arctan(a/b)；∠B 對邊是 b，∠B=arctan(b/a)=90°−∠A。斜邊越長的一側對應角越大。
