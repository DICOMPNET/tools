Compute rectangle diagonal from width w and height h using d = √(w² + h²).

📐 計算公式
矩形對角線與要素（本頁程式碼口徑）：對角線 d=√(寬²+高²)；面積=寬×高；周長=2×(寬+高)；兩對角線夾角=2×atan(寬高較小者÷較大者)×180÷π（°）。校驗：兩項輸入空值/非法值即提示並中止。判據：無固定分級，正方形時夾角為 90°、越扁夾角越小；對角線相互平分且相等。

💡 常見使用場景

  • 尺寸換算：螢幕、板材、邊框的對角線長度
  • 最大直線尺寸：裝箱/運輸限值的對角校核
  • 空間定位：矩形區域對角線與面積聯合估算
方法
演算法：矩形對角線 d=√(w²+h²)（即勾股定理），並同時輸出面積 A=w·h。要求 w,h>0。w=h（正方形）時 d=w√2≈1.414w。
算例
例：寬 w=3m、高 h=4m → d=5.0000m、面積=12.0000 m²（3-4-5 直角三角形）。若 w=6m、h=8m → d=10.0000m、面積=48.0000 m²。

❓ 常見問題（FAQ）

對角線和邊長什麼關係？
對角線是矩形兩鄰邊構成的直角三角形的斜邊；由勾股定理 d=√(w²+h²)，正方形時 d=w√2。
螢幕尺寸怎麼算？
顯示器"尺寸"即對角線（英寸），由解析度寬高比換算為畫素寬高再按上式得英寸對角線；本工具按長度單位計算，單位自定一致即可。
