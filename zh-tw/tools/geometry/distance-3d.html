3D Distance Calculator

Compute the straight-line distance between two points in 3D space using d = √[(x₂−x₁)² + (y₂−y₁)² + (z₂−z₁)²].

📐 計算公式
空間兩點距離：d = √[(x₂−x₁)² + (y₂−y₁)² + (z₂−z₁)²]（三維歐氏距離，算例 Δ=(3,4,12) → d=13）。校驗：無強校驗，非數輸入落 «—» 兜底。判據：無固定分級，結果保留 3 位小數，任一座標分量增大距離不減。

輸入兩點 (x1,y1,z1) 與 (x2,y2,z2)，求三維距離。

📌 計算說明
  • d=√[(Δx)²+(Δy)²+(Δz)²]。
  • 3,4,12 → d=13。

📚 深度解析：三維空間兩點距離

💡 常見使用場景

  • 空間定位：求三維座標下兩點直線距離
  • 工程測量：樓層、井巷、三維建模中的點距
  • 圖形學：碰撞檢測、最近鄰距離的初值
方法
演算法：三維歐氏距離 d = √((x2−x1)² + (y2−y1)² + (z2−z1)²)，是二維勾股定理在三維的自然推廣。座標可為任意實數，距離恆非負。
算例
例：P1=(0,0,0)、P2=(3,4,12) → d=√(9+16+144)=√169=13.000m。若 P1=(1,2,2)、P2=(4,6,6) → Δ=(3,4,4)、d=√(9+16+16)=√41=6.403m。

❓ 常見問題（FAQ）

三維距離和二維有何關係？
三維距離 = √(二維平面距離² + 高度差²)；若 z 相同即退化為二維距離。它本質是勾股定理逐維疊加。
座標有負值能用嗎？
可以，差值平方後負號消失，距離與座標正負無關，只取決於相對位置。
