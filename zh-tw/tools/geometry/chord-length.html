Chord Length Calculator

Compute chord length from radius and central angle in radians using c = 2r·sin(θ/2).

📐 計算公式
圓心角 θ 先由度轉弧度（×π÷180）；弦長 c = 2r × sin(θ÷2)；另輸出半弦 = c÷2、弧長 = r×θ、矢高 = r − r×cos(θ÷2)。校驗：無強校驗，數值預設按 0。判據：θ=180° 時弦長達最大值 2r、矢高等於 r，θ→360° 時弦長回落而弧長趨於整圓 2πr。

由半徑與圓心角（弧度）求弦長。

📚 深度解析：弦長計算（c = 2r·sin(θ/2)）

💡 常見使用場景

  • 圓內線段：已知半徑與圓心角求弦長，用於弓形、扇形設計
  • 齒輪/輪系：節圓弦長與齒距校核
  • 建築放樣：拱跨、弦杆長度的快速換算
方法
演算法：弦長 c = 2r·sin(θ/2)（θ 為弧度），半弦長 = c/2。θ=180° 時 c=2r 即直徑；0≤deg≤180° 時弦位於半圓內。要求 r>0、0≤deg≤180°。
算例
例：r=10m、θ=90° → c=2×10×sin(45°)=20×0.7071=14.1421m、半弦=7.0711m。若 θ=60° → c=2×10×sin(30°)=10.0000m（即半徑為 10 時 60° 圓心角對應的等邊三角形邊長）。

❓ 常見問題（FAQ）

弦長和弧長有什麼區別？
弦是連線圓弧兩端點的直線段（最短距離），弧是沿圓周的曲線段；同一圓心角下弧長 ≥ 弦長，僅當 θ→0 時二者趨近。本工具給弦長，弧長請用弧長計算器。
為什麼限制 θ≤180°？
sin(θ/2) 在 θ>180° 時仍單調，但幾何上“弦”通常指劣弧所對弦；若輸入 >180° 會給出優弧所對的長弦，可能不符合你的設計意圖，故建議 0~180° 區間使用。
