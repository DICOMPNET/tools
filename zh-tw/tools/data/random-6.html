Random Number

Random Number

📐 工作原理與說明
隨機整數在閉區間取值：x = floor(random() × (最大值 − 最小值 + 1)) + 最小值；隨機浮點數 = random() × (最大值 − 最小值) + 最小值 並按指定小數位擷取；批次去重時按集合判重後重抽，或用 Fisher-Yates 洗牌保證等機率無重複抽樣。

💡 常見使用場景

  • 抽獎抽樣：在編號區間取隨機整數，做公平抽取或樣本抽樣。
  • 模擬入參：給演算法造隨機浮點輸入，驗證邊界與穩定性。
  • 測試資料：批次生成數值填充表格或介面報文。
抽 3 個不重複整數
設範圍 1–100、數量 3、去重，工具輸出如「17 / 42 / 88」，可直接用於抽獎或抽樣編號。

❓ 常見問題（FAQ）

能批次去重嗎？
支援設定數量並勾選去重；數量超過範圍時會提示無法保證唯一，具體以頁面為準。
浮點精度如何？
按設定小數位生成，僅為模擬與測試用，不保證統計均勻性。
會留存結果嗎？
僅本地生成不上傳，關閉即清空，適合臨時取樣。
