📄 YAML / JSON Converter

📐 工作原理與說明
JSON 轉 YAML：先 JSON.parse 解析為物件，再按縮排層級遞迴序列化為 YAML 文本；YAML 轉 JSON：先解析為物件，再以 JSON.stringify(物件, null, 2) 輸出帶兩空格縮排的 JSON；任一環節異常時輸出錯誤資訊，輸入為空白時清空輸出

Convert between YAML and JSON in both directions with syntax validation and error hints.

📖 YAML 語法說明

  • 縮排：必須用空格，不能用 Tab，相同層級縮排相同
  • 鍵值對：key: value（冒號後有空格）
  • 陣列：用 - 開頭，或 [a, b, c]
  • 物件：用 {key: value} 內聯格式
  • 字串：通常無需引號，含特殊字元時用單/雙引號
  • 多行字串：| 保留換行，> 摺疊換行
  • 註釋：# 開頭
  • 布林：true/false/yes/no
  • 空值：null 或 ~

  • 配置格式互轉。

轉換
`name: Tom` → `{"name":"Tom"}`。

❓ 常見問題（FAQ）

註釋保留？
JSON 無註釋，轉換即丟。
註釋會保留嗎？
不會。YAML 註釋在解析為資料結構時即被丟棄，轉向 JSON 或轉回 YAML 都不保留註釋，需另行備份。
