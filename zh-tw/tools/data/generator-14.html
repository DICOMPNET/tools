Barcode / QR Code Data Generate

Barcode / QR Code Data Generate - generate results in-browser quickly and keep all data local.

📐 工作原理與說明
條形碼 Code128 每字元對應 11 位模組，校驗位按起始符與各字元權重 1、2 交替求和後取模 103 生成；二維碼按 QR Code 標準做資料編碼（數字、字母數字、位元組模式）、糾錯碼（L 7%、M 15%、Q 25%、H 30%）、掩碼選擇與定點陣圖案佈局，容量隨版本 1 至 40 遞增。

❓ 常見問題（FAQ）

支援哪些編碼？
支援常見一維條碼與二維碼格式；具體以頁面可選列表為準，均為本地編碼渲染。
內容有長度限制嗎？
二維碼容量有限，過長文本會降低密度與識別率；超長內容建議改用短鏈後再生成。
生成的碼安全嗎？
僅對輸入文本做本地編碼，不儲存、不上傳；請勿將敏感憑證直接編碼進公開張貼的碼。
