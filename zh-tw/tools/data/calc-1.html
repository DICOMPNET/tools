CSV to JSON Converter

Convert CSV data to a JSON array locally in your browser.

📐 工作原理與說明
CSV 轉 JSON 按行拆分：首行為表頭即欄位名，其後每行按分隔符（預設英文逗號，可自定義）切分欄位並與表頭逐列配對，生成「欄位: 值」物件陣列；欄位含分隔符或換行時按 RFC 4180 用雙引號包裹，引號內雙引號以兩個雙引號轉義，鍵值對按行序輸出。

Formula & Standard References

ItemFormulaSource / Standard
CSV parsing rule First row as header→keys, each row→object RFC 4180 (CSV format)
JSON encoding Array of objects + UTF-8 escape ECMA-404 / IETF RFC 8259
Delimiter Comma (configurable to ; or tab) RFC 4180 §2
📌 轉換規則
  • 首行為表頭時，欄位名取自第一行；否則使用 field_0、field_1 等預設鍵。
  • 支援引號包裹的欄位，引號內可包含分隔符和換行。
  • 空單元格將轉換為空字串，未填寫的行會被忽略。

💡 常見使用場景

  • 介面聯調：把後端匯出的 CSV 結果快速轉成 JSON 陣列，直接貼上進請求體或前端 mock，省去手寫欄位。
  • 表格遷移：Excel 或資料庫匯出的 CSV 需換成 JSON 以適配 NoSQL 儲存或多維結構，轉換後保留原始行列。
  • 欄位對齊：轉換時指定表頭對映與分隔符，避免中文逗號、半形引號導致的解析錯位與欄位錯位。
訂單 CSV 轉 JSON
貼上含「訂單號,金額,狀態」三列的 CSV，選擇逗號分隔、首行作為表頭；工具輸出 [{"訂單號":"A1001","金額":"99.00","狀態":"已付款"}]，可直接用於介面校驗或前端表格渲染。

❓ 常見問題（FAQ）

支援哪些分隔符？
支援逗號、製表符、分號及自定義單字元；引號包裹欄位內的分隔符不會被誤拆，欄位內容原樣保留。
中文或特殊字元會亂碼嗎？
轉換僅在本地進行，原樣保留 UTF-8 字元；匯出後建議以 UTF-8 儲存，避免二次開啟時編碼錯亂。
結果能直接當介面資料用嗎？
僅做格式轉換、不校驗業務合法性；金額、日期等型別仍按字串保留，接入前請按需做型別與範圍校驗。
