JSON Formatter

Validate, format and minify JSON locally.

📐 工作原理與說明
JSON 格式化按語法樹遞迴輸出：解析器先做詞法分析（識別字符串、數字、true/false/null 與括號），再按層級縮排（每層 2 空格或製表符）；壓縮即移除全部結構空白僅保留分隔符；校驗失敗時報出錯誤行列位置，字串內轉義序列須成對且不可跨行。

  • 若 JSON 不合法，將高亮顯示錯誤位置與原因。

❓ 常見問題（FAQ）

能校驗 JSON 是否合法嗎？
可以，格式化前先做語法校驗，非法位置會給出行號與原因；但僅校驗語法，不校驗業務欄位含義。
大檔案會卡嗎？
解析在本地進行，體積過大時受瀏覽器記憶體限制；建議分片或僅貼上關鍵片段，避免一次性處理超長文本。
壓縮會丟失資訊嗎？
壓縮只去除空白與換行，鍵名與值不變；若原文本含尾隨逗號等非法結構會先拒絕處理並提示。
