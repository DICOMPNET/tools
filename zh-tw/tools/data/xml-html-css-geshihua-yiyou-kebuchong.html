📄 XML / HTML / CSS Formatter

Format and beautify XML, HTML and CSS code with proper indentation.

程式碼格式化按層級縮排重建排版：行首縮排寬度 = 當前層級 × 每級空格數。HTML/XML 依開閉標籤配對計算層級，自閉合標籤與 HTML 空元素（br、img、input 等）不加深；CSS 依花括號配對計算層級，每條宣告單獨成行。格式化後字元數 = 原字元數 + 各行縮排空格之和 + 換行符數，程式碼內容本身不做任何改寫。

📚 深度解析：對 XML/HTML/CSS 程式碼做層級縮排美化與結構重排，輔助閱讀、教學與排錯。

💡 常見使用場景

  • 壓縮後的 HTML/CSS 一行程式碼難以閱讀，按層級縮排重排後快速定位巢狀關係與遺漏的閉合標籤。
  • 寫教學示例或文件片段時，把隨手貼上的緊湊程式碼整理成規範縮排，便於展示與講解。
  • 排查佈局/樣式異常時，先格式化再逐層核對選擇器與宣告歸屬，減少肉眼比對成本。
可復現算例：HTML 片段按 4 空格縮排
輸入：`<div class="a"><p>hi</p></div>`（30 字元，1 行），程式碼型別 HTML，縮排 4 空格。 處理：按開閉標籤配對計算層級，div 為第 0 層、p 為第 1 層，行首縮排 = 層級 × 4 空格。 輸出：3 行、36 字元（比原文本多 2 個換行符與 4 個縮排空格），最大巢狀深度 2 層，標籤數 4 個。 結論：格式化只重排縮排與換行，不改變任何程式碼內容；把縮排改成 2 空格可再省 4 個字元。

❓ 常見問題（FAQ）

格式化會修改我的程式碼內容嗎？
不會。只按開閉標籤（HTML/XML）或花括號（CSS）的配對關係重排縮排與換行，標籤名、屬性、文本、宣告內容均原樣保留，可放心用於生產程式碼。
HTML 與 XML 的處理有什麼區別？
區別在於空元素判定：HTML 模式下 br、img、input、meta 等空元素不加深層級；XML 模式只認自閉合寫法（以 /> 結尾），其餘一律視為需要閉合標籤的普通元素。
能順便校驗語法錯誤嗎？
本工具只做格式化，不替代完整語法校驗。它會如實統計最大巢狀深度與標籤數，若深度明顯異常（例如少寫閉合標籤導致層級一直加深），可據此發現標籤不配對的問題。
