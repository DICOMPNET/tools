Fourier Base

Fourier Base

📐 計算公式
週期訊號基頻：基頻 f₀ = 1 ÷ T（Hz，T 為週期 s）；聯動量：角頻率 ω = 2π·f₀（rad/s）、時間常數 1÷ω = 1 ÷ max(2πf₀,10⁻⁹)（s）、半週期 = T÷2（s）。校驗：週期 T 必填守衛且作為分母不得為 0。判據：無固定分級，週期越短基頻越高，角頻率與基頻成正比（2π 倍）。

週期訊號的基頻為其週期的倒數。

📌 計算說明
  • f₀ = 1 / T。
  • 週期 20 ms 對應 50 Hz 基頻。

📚 深度解析：基波頻率（f0 = 1/T）

💡 常見使用場景

  • 週期訊號週期 T 求基頻 f0。
  • 傅立葉級數展開的頻率基準。
  • 諧波頻率為基頻整數倍。
T=0.02s（50Hz 週期）
基頻 f0 = 1 / 0.02 = 50 Hz；二次諧波 100Hz、三次 150Hz。
週期變長
若 T=0.04s，則 f0=25Hz，基頻降一半、諧波同步下移。

❓ 常見問題（FAQ）

基頻與角頻率關係？
角頻率 ω0 = 2πf0 = 2π/T。
非週期訊號有基頻嗎？
嚴格非週期（單段）用傅立葉變換得連續譜，無離散基頻。
