Steady State Error

Steady State Error

📐 計算公式
單位階躍穩態誤差（本頁程式碼口徑，0 型系統比例控制）：穩態誤差 e_ss=1÷(1+比例增益 Kp)；聯動量：誤差百分數=e_ss×100（%）、誤差倒數=1÷max(e_ss,10⁻¹²)、Kp 佔比=Kp÷max(1+Kp,10⁻¹²)、乘積=e_ss×Kp。校驗：欄位經輸入守衛必填且須為合法數值，否則提示並中止。判據：無固定分級，Kp 越大誤差越小並趨近 0，Kp=0 時誤差恆為 1。

0 型單位反饋系統在單位階躍輸入下的穩態誤差。

📌 計算說明
  • e_ss = 1/(1+K_p)（0 型系統、單位階躍）。
  • K_p=9 時 e_ss=0.1（10%）。

📚 深度解析：單位反饋穩態誤差

💡 常見使用場景

  • 比例控制 Kp 求單位階躍穩態誤差 ess = 1/(1+Kp)。
  • 系統精度與增益權衡。
  • 對比不同 Kp 的靜差。
Kp=9
穩態誤差 ess = 1/(1+9) = 0.10，即終值偏差 10%；Kp 升到 99 則 ess≈1%。
積分消除靜差
純比例必有靜差，加入積分可使階躍 ess 趨於 0，但可能影響穩定性。

❓ 常見問題（FAQ）

為什麼純比例有靜差？
為維持輸出需一定誤差驅動控制器，零誤差則無驅動，故存在穩態偏差。
Kp 越大靜差越小？
是，ess=1/(1+Kp) 隨 Kp 增大而減小，但過大會引發振盪。
