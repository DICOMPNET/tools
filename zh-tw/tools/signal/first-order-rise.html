📐 計算公式
一階系統上升時間（10%~90%）：t_r = 2.2·τ（s）；聯動量：毫秒口徑 t_r×1000、τ 本值、3τ 達穩態 95%、5τ 達穩態 99.3%（s，均按科學計數法三位展示）。校驗：無強校驗，空值按 0 兜底。判據：無固定分級，τ 越小階躍響應越快。

一階系統從 10% 升到 90% 約需 2.2 個時間常數。

📌 計算說明
  • t_r ≈ 2.2·τ（10%–90%）。
  • τ=1 ms 時上升約 2.2 ms。

📚 深度解析：一階系統上升時間

💡 常見使用場景

  • RC 等一階系統從 10% 到 90% 上升時間 tr ≈ 2.2τ。
  • 頻寬與上升時間的互換評估。
  • 示波器/探頭響應速度測算。
τ=1ms
上升時間 tr = 2.2 × 0.001 = 0.0022 s = 2.2 ms；τ 減半則 tr=1.1ms。
頻寬換算
一階 −3dB 頻寬 fc≈1/(2πτ)≈159Hz，與 2.2τ 的上升時間互相對應。

❓ 常見問題（FAQ）

tr=2.2τ 的 10%~90% 是什麼？
指輸出從終值的 10% 升至 90% 所需時間，對一階階躍響應約為 2.2 個時間常數。
與頻寬的關係？
近似 tr×BW ≈ 0.35，可用於系統速度估算。
