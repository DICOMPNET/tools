臨床表現與實驗室檢查

📋 抗MDA5抗體 關鍵臨床意義

核心關聯

  • CADM-ILD：抗MDA5抗體是臨床無肌病型皮肌炎合併間質性肺病的標誌性抗體(陽性率50-70%)
  • RP-ILD：抗MDA5陽性患者RP-ILD發生率高達50-80%，6個月內死亡率40-60%(亞洲人群)
  • 皮膚潰瘍：MDA5陽性患者皮膚潰瘍/穿孔發生率顯著升高
  • 低肌酶：CK通常正常或輕度升高(區別於其他肌炎亞型)
  • 高鐵蛋白：血清鐵蛋白顯著升高是RP-ILD預後不良的標誌

📊 MDA5+ DM 風險分層

風險等級特徵RP-ILD風險管理建議
低風險MDA5+, 無ILD, 鐵蛋白正常低糖皮質激素+免疫抑制劑，定期HRCT
中風險MDA5+, 有ILD, 鐵蛋白輕中度升高中激素+他克莫司/環磷醯胺，密切監測肺功能
高風險MDA5+, ILD進展, 鐵蛋白>1000高大劑量激素+環磷醯胺+JAK抑制劑，評估肺移植
極高風險MDA5+, RP-ILD, 鐵蛋白>2000極高強化免疫抑制+血漿置換+托珠單抗，ICU監護
提示：抗MDA5抗體陽性皮肌炎是風溼免疫科危重症之一，RP-ILD是主要死因。治療策略強調早期識別和強化免疫抑制：大劑量糖皮質激素聯合鈣調磷酸酶抑制劑(他克莫司/環孢素)和環磷醯胺。JAK抑制劑(托法替尼/巴瑞替尼)和抗IL-6受體(托珠單抗)可用於難治性RP-ILD。血清鐵蛋白動態監測是預後判斷的關鍵指標。僅供臨床參考。

高風險
MDA5 陽性 + 臨床無肌病型(CADM) + 快速進展性肺間質病變(rpILD) + 皮膚潰瘍/手掌丘疹 + 鐵蛋白 1200 → 風險評分高，致死性 ILD 風險大，需積極免疫抑制。
中風險
MDA5 陽性 + 典型皮疹但無 rpILD、CK 正常 → 中風險，密切隨訪肺功能。

❓ 常見問題（FAQ）

為何警惕 rpILD？
抗 MDA5 陽性尤其 CADM 易伴快速進展 ILD，短期內可致呼吸衰竭，是皮肌炎最危重亞型。
CK 正常有意義嗎？
CADM 可肌酶正常但肺損傷重，CK 正常不除外高危，需以影像與鐵蛋白判。
