📋 BASDAI 計算方法

公式：BASDAI = (Q1 + Q2 + Q3 + Q4 + (Q5 + Q6)/2) / 5

第5、6項（晨僵嚴重程度和持續時間）取平均值後與其他4項加總，再除以5。

📊 BASDAI 臨床意義

BASDAI疾病活動度臨床決策
<4低活動度維持NSAIDs+功能鍛鍊
≥4高活動度考慮啟動抗TNF生物製劑
≥4 + ASDAS≥2.1高活動度(確認)推薦生物製劑/JAK抑制劑
提示：BASDAI≥4是ASAS/EULAR推薦啟動抗TNF生物製劑治療的主要標準之一。BASDAI主觀性較強，建議結合ASDAS(含CRP/ESR的客觀指標)綜合評估。ASDAS-CRP = 0.121×背痛 + 0.110×晨僵持續時間 + 0.073×患者總體 + 0.058×外周關節腫痛 + 0.579×ln(CRP[mg/L]+1)。僅供臨床參考。

❓ 常見問題（FAQ）

判讀？
0–4 低活動、>4 高活動；>4 常提示需調整生物製劑。晨僵取兩題均值後與前 4 題平均。
自評侷限？
BASDAI 含主觀症狀，需結合 CRP/影像與功能指標(BASFI)綜合判效。

如何使用強直性脊柱炎 BASDAI 疾病活動評估器

  1. 在對應的輸入框或選項中填寫、選擇所需引數。
  2. 點選「計算」或「生成」按鈕執行。
  3. 在結果區檢視輸出，可複製結果或匯出使用。

引數說明

  • 1. 疲勞/疲倦程度
  • 2. 頸/背/髖部AS疼痛程度
  • 3. 其他關節疼痛/腫脹程度（不含頸/背/髖）
  • 4. 侷限性壓痛部位不適程度
  • 5. 晨僵嚴重程度
  • 6. 晨僵持續時間（0=0小時，10=≥2小時）
