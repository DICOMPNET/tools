📐 工作原理與說明
IL-6 判讀（pg/mL）：<7 正常｜7-19 輕度升高｜20-99 中度｜100-999 顯著｜≥1000 極度（炎症風暴）
IL-6→CRP 一致性：IL-6≥20 而 CRP<10 → 下游通路受阻或樣本延遲；IL-6<7 而 CRP≥10 → 非 IL-6 通路驅動
炎症負荷評分 = IL-6(≥1000→5｜≥100→4｜≥20→2｜≥7→1) + CRP(≥50→2｜≥10→1) + ESR≥50(1) + 鐵蛋白(≥1000→2｜≥500→1) + PLT≥400(1) + 纖維蛋白原≥5(1) + 發熱(1) + 臟器功能不全(3)
分級：≥8 炎症風暴風險｜5-7 重度炎症｜3-4 中度｜<3 輕度/無；使用 IL-6 抑制劑時 CRP 被壓制，不能反映真實活動度

臨床表現

📋 IL-6 炎症通路

IL-6 → 急性時相反應通路

  • IL-6 → 肝臟 → CRP合成(最強刺激因子)
  • IL-6 → 肝臟 → 纖維蛋白原↑ → ESR↑
  • IL-6 → 肝臟 → 鐵蛋白↑(鐵代謝調節)
  • IL-6 → 骨髓 → 血小板↑(反應性增多)
  • IL-6 → B細胞 → 免疫球蛋白↑(多克隆啟用)
  • IL-6 → T細胞 → Th17分化(自身免疫驅動)

CRP與ESR本質上是IL-6驅動的下游產物，IL-6是更上游、更敏感的炎症標誌。

📊 IL-6水平臨床意義

IL-6 (pg/mL)判讀常見情況
<7正常無顯著炎症
7-20輕度升高慢性低度炎症、輕度感染
20-100中度升高自身免疫病活動、中度感染
100-1000顯著升高嚴重自身免疫炎症、成人Still病
>1000極度升高CRS(細胞因子風暴)、膿毒症休克

📋 IL-6靶向治療適應症

藥物靶點適應症
托珠單抗(Tocilizumab)IL-6RRA、sJIA、AOSD、CRS、巨淋巴結增生症
沙利魯單抗(Sarilumab)IL-6RRA(中重度)
西妥昔單抗(Siltuximab)IL-6Castleman病(HIV陰性/HHV-8陰性)
奧洛奇單抗(Olokizumab)IL-6RA(研發中/部分國家獲批)
提示：IL-6是連線先天免疫和適應性免疫的關鍵細胞因子。IL-6抑制劑(托珠單抗)通過阻斷IL-6訊號通路，不僅抑制CRP/ESR等急性時相反應，還抑制Th17分化和B細胞啟用。使用IL-6抑制劑後CRP可迅速降至正常(24-48小時)，但ESR下降較慢。需注意：IL-6抑制劑可掩蓋感染(CRP不升高)，需密切監測感染徵象；可引起中性粒細胞減少和肝酶升高；活動性感染、憩室炎/腸穿孔風險為禁忌。僅供臨床參考。

📚 深度解析：IL-6 與炎症評估

💡 常見使用場景

  • CRS/AAS
  • RA/脊柱炎
  • 感染/敗血症
重度炎症
IL-6 85 pg/mL、CRP 120、ESR 90、鐵蛋白 800、血小板 450 → 預期 CRP=min(85×1.5,200)=127.5 與實際 120 一致，炎症評分高，提示 IL-6 通路驅動，可考慮托珠單抗。
輕度
IL-6 5、CRP 8、ESR 20 → 輕/無炎症，隨訪即可。

❓ 常見問題（FAQ）

預期 CRP 怎麼來？
工具按 IL-6>7 時 crpExpected=min(IL6×1.5,200) 估算，與實際比對判斷一致性。
哪些病用IL-6抑制劑？
Castleman、AAS、RA、CRS 等；用藥前需排除活動性感染。
