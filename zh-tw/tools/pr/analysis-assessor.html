Sponsorship ROI Assessment

Analysis Assessor

📐 工作原理與說明
贊助 ROI = (媒體價值合計 − 投入合計) ÷ 投入合計 × 100%；≥ 100% 高回報、≥ 50% 回報良好、≥ 0 基本回本、< 0 未回本

每行輸入一條「權益項,媒體估值,實際投入」。贊助 ROI＝(媒體價值合計−投入合計)÷投入合計×100%；單項 ROI 按同一口徑逐項計算。並給出淨回報額與價值最高的權益項，用於贊助決策與結案復盤。

📚 深度解析：贊助專案評估與回報測算

💡 常見使用場景

  • 品牌方在贊助立項前，按各項權益的媒體估值與投入測算 ROI，判斷是否值得投入。
  • 贊助結案時彙總實際媒體價值與投入，輸出淨回報額與單項 ROI，用於復盤與續約談判。
  • 對比多個贊助方案的 ROI，篩選回報最高的權益組合。
四項權益回報試算
輸入「冠名權益,800000,300000；現場展位,250000,120000；媒體曝光,420000,150000；社交傳播,180000,60000」，媒體價值合計 1650000.00、投入合計 630000.00、淨回報 1020000.00、贊助 ROI 161.90%，判定為高回報。

❓ 常見問題（FAQ）

媒體估值從哪來？
通常按等效廣告刊例價、曝光量折算 CPM 或第三方監測報告估算；本工具只做彙總與 ROI 計算，估值口徑需您自行確定。
ROI 多少算好？
工具按 100%、50%、0% 三檔劃分：≥100% 為高回報，50%~100% 為回報良好，0%~50% 為基本回本，低於 0 為未回本。
投入為 0 的權益怎麼算？
單項 ROI 需要除以投入，投入為 0 時該項 ROI 顯示為 0.00%，請補填真實投入金額。
