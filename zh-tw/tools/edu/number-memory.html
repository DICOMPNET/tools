🎮 Number Memory Training

Train short-term memory by recalling progressively longer sequences of digits.

📐 工作原理與說明
數字記憶按序列長度遞進：正確率 = 正確位數 ÷ 總位數 × 100%；起始長度通常 3 至 5 位，全對則長度加 1、答錯則保持或減 1；記憶廣度 = 連續通關的最大位數，正常成人短期數字廣度約 7 ± 2 位；反應時間 = 提交時刻 − 呈現時刻。
第 3 位 最高記錄: 0 位

💡 記憶技巧

  • 分組法：將長數字分成3-4位一組記憶，如手機號分成3-4-4格式
  • 諧音法：用數字諧音編故事，如"14"諧音"鑰匙"
  • 影像法：將每個數字轉化為具體影像，形成記憶宮殿
  • 形狀法：0像雞蛋，1像鉛筆，2像鴨子，3像耳朵...
  • 多練習：短期記憶容量約7±2個組塊，訓練可以提升

📚 深度解析：依次閃現數字序列要求複述，逐步加長以訓練短時記憶廣度。

💡 常見使用場景

  • 序列閃現：短時呈現數字。
  • 長度遞增：逐輪加長。
  • 成績記錄：追蹤最高長度。
