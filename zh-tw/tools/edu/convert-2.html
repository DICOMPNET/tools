🎨 Color Code Converter (HEX/RGB/HSL/CMYK)

Convert color values between HEX, RGB, HSL and CMYK formats with live preview.

Separate RGB, HSL or CMYK channels with commas or spaces; optional wrappers are rgb(...), hsl(...) and cmyk(...). HSL saturation and lightness and CMYK channels may use %. Scientific notation is not supported.

顏色空間換算原理
顏色程式碼轉換（HEX/RGB/HSL/CMYK）
HEX → RGB：#RRGGBB 每兩位十六進位制轉十進位制（#ABC 縮寫展開為 #AABBCC）
RGB → HEX：各通道四捨五入後轉兩位十六進位制拼接
RGB → HSL：歸一化後 L=(max+min)/2，S 按 L 與 (max−min) 分段計算，H 按最大值通道分段求角
HSL → RGB：按色相落在 1/6、1/2、2/3 六個區間的分段插值
RGB → CMYK：K = 1−max(R,G,B)；C=(1−R−K)/(1−K)，M、Y 同理（K=1 時純黑）
CMYK → RGB：R = 255×(1−C)×(1−K)，G、B 同理
各顏色空間按標準定義獨立換算：HEX↔RGB 逐通道 16 進位制對映；RGB↔HSL 按 IEC 61966 近似公式；RGB↔CMYK 按減色法定義。

📚 深度解析：在 HEX、RGB、HSL、CMYK 之間互轉，輔助設計與前端取色。

💡 常見使用場景

  • 格式互轉：四格式任意轉換。
  • 取色複製：結果一鍵複製。
  • 輸出精度：HEX/RGB 逐通道取整，HSL/CMYK 按整數百分比輸出。
示例
示例：#FF6B35 → RGB(255,107,53) → HSL(16°,100%,61%)。

❓ 常見問題（FAQ）

為什麼轉 HSL？
HSL 更直觀表達色相/飽和/明度，便於調色。
CMYK 用途？
面向印刷四色，屏顯轉印刷需此格式。
精度？
換算按標準定義進行；輸出按各格式慣例取整（HEX/RGB 通道為整數，HSL/CMYK 為整數百分比）。
