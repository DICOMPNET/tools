📐 計算公式
CMC(l:c) 色差：ΔE_CMC = √((ΔL ÷ (l·S_L))² + (ΔC ÷ (c·S_C))² + (ΔH ÷ S_H)²)，其中 ΔL、ΔC、ΔH 為明度差、彩度差與色相差；S_L、S_C、S_H 均由標樣（參考樣）Lab 值計算：S_L = 0.040975·L₁/(1+0.01765·L₁)（L₁<16 時取 0.511），S_C = 0.0638·C₁/(1+0.0131·C₁)+0.638，S_H = S_C·(F·T+1−F)，F = √(C₁⁴/(C₁⁴+1900))，T = 0.56+|0.2cos(h₁+168°)|（164°≤h₁≤345°）否則 0.36+|0.4cos(h₁+35°)|；常用引數 l:c = 2:1（對明度差更寬容，適用紡織印染）或 1:1（對彩度差更嚴格，適用塗料）；ΔE_CMC 不超過容差（常見 1.0 或 1.5）判合格。

💡 常見使用場景

  • 印染大貨與標樣色差合格判定：按客戶來樣容差（常見 1.0~2.0）判讀批次是否可接受。
  • 配色打樣多方案視覺一致性比對：同一標樣多個配方打樣，量化色光差異擇優。
  • 染料配方調整後色光偏移歸因：由 ΔL/ΔC/ΔH 分量判斷偏深偏淺、偏豔偏暗或偏相。

❓ 常見問題（FAQ）

CMC(l:c) 與 CIELAB ΔE*ab 有何區別？
ΔE*ab 對各方向等權，與人眼視覺不一致；CMC(l:c) 對明度、彩度、色相分別加權（常用 l=2,c=1），更接近實際目視寬容度，是紡織行業主推的色差判定標準。
l 和 c 一般取多少？
紡織印染常用 CMC(2:1)，即明度權重 2、彩度權重 1；對深色或特殊要求可調整，但需與客戶在合同中約定一致。
結果能直接作為交貨依據嗎？
可作為內部色差判讀與打樣擇優參考；最終交貨以客戶封樣、合同容差與實驗室實測為準，不替代正式檢測報告。
