📐 工作原理與說明
移動平均預測（SMA/WMA/EMA）
SMA：MA(t) = 最近 N 期和 ÷ N
WMA：按時間從舊到新賦權 1,2,…,N（最新權重最大）
　WMA = Σ(x×w) ÷ [N(N+1)/2]
EMA：α = 2 ÷ (N+1)
　EMA(t) = x(t)×α + EMA(t−1)×(1−α)
　以首期為初值遞推
預測期滾動：SMA/WMA 用最新 N 期，WMA 權重方向與歷史同口徑；EMA 全序列遞推
SMA/WMA 從第 N 期起有值，EMA 從第 1 期起
輸入校驗：至少 2 期資料

SMA: mean of last N; WMA: weights 1,2,…,N with the newest weighted highest, denominator N×(N+1)÷2; EMA coefficient α = 2÷(N+1)

SMA：最近 N 期算術平均；WMA：近期權重更高；EMA：α=2/(N+1)，越近期影響越大。移動平均適用於無明顯季節波動的平穩序列。

📚 深度解析：銷售趨勢預測（移動平均）

💡 常見使用場景

  • 平滑短期波動：用簡單移動平均（SMA）消除日/周噪聲，看清銷售趨勢走向。
  • 關注近期權重：用加權移動平均（WMA）給最近期更高權重，對趨勢反轉更敏感。
  • 做指數平滑：用 EMA 以平滑係數 α=2/(N+1) 遞推，兼顧歷史與最新，適合連續預測。
舉例：序列 [100,120,110,130,140]，視窗 N=3
SMA(3)：第3期 (100+120+110)/3 = 110；第4期 (120+110+130)/3 = 120；第5期 (110+130+140)/3 = 126.67。 下一期預測 = 最近視窗均值 = (110+130+140)/3 = 126.67。 WMA(3) 權重 1/2/3，第5期 = (110×1+130×2+140×3)/6 = 131.67，對近期更敏感；EMA 平滑係數 α=2/(3+1)=0.5。

❓ 常見問題（FAQ）

SMA、WMA、EMA 怎麼選？
SMA 最平滑但滯後；WMA 給近期更高權重、對拐點更敏感；EMA 用 α 遞推、只需上一期結果、適合流式預測。資料噪聲大用 SMA，趨勢強且想跟緊用 WMA/EMA。
視窗 N 越大越好嗎？
N 越大越平滑但越滯後、越忽略近期；N 越小越靈敏但易受噪聲干擾。一般取 3–6；季節性明顯時可取週期長度（如 12）。
