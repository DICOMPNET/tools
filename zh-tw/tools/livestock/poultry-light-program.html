Poultry Light Program

Poultry Light Program

光照管理要點

基本原則

• 育雛期前3天：23~24h強光照，促進採食飲水

• 育成期：恆定或遞減光照，防止性早熟

• 產蛋期：恆定16h光照，不可隨意減少

• 光照強度：育雛 30~40 lux，育成 5~10 lux，產蛋 15~20 lux

注意事項

• 光照時長變化比絕對時長更影響性成熟

• 產蛋期光照只能增不能減，強度只能增不能減

• 開放舍需結合自然光照補充人工照明

• 燈泡建議使用暖白光 LED，色溫 2700~3000K

本程式為通用參考方案，實際生產中需根據品種手冊、季節和雞群發育狀況靈活調整。

蛋雞產蛋期
產蛋期建議恆定 16 h 光照（密閉舍自然 12h 須補 4h），促進排卵。
肉雞
前期 23h 促採食，後期降至 18~20h 平衡生長。

❓ 常見問題（FAQ）

為何控光？
光週期調控性成熟與產蛋，過長/短均影響產量與健康。
開放舍？
自然光照隨季變，須人工補光達到目標時長。
