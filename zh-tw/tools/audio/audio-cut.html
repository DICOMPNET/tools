📚 深度解析：音訊剪下工具

💡 常見使用場景

  • 從長錄音中擷取一段精彩片段或去頭尾靜音，生成可直接使用的短音訊。
  • 為影片剪輯或課件提取某句臺詞、某段音效，按波形精確定位起止點。
  • 把一首曲子裁成鈴聲或鈴聲素材，避免手動再轉碼。
精確裁剪與淡變示例
一段 44100Hz 立體聲音訊，若要擷取 30.000 秒到 35.250 秒，對應取樣點區間為 44100×30=1,323,000 到 44100×35.25=1,554,225（每聲道）。裁剪邊界處建議加 5~10ms 線性淡入淡出，避免起點/終點因波形不連續產生爆音。匯出 WAV 為非破壞性擷取，原取樣精度保留。

❓ 常見問題（FAQ）

剪下後為什麼開頭有咔噠一聲？
當裁剪點落在波形非零位置，訊號被硬切斷會形成不連續的跳變產生爆音。在裁剪邊界加極短的淡入淡出（幾毫秒）即可消除，本工具在波形上拖選後匯出即應用該處理。
剪下會損失音質嗎？
純按取樣點擷取是無損的（非重編碼），只要匯出格式與原精度一致（如都匯出 WAV）就不會二次有損；若匯出為有損格式才會引入壓縮損失。

📝 工具簡介

音訊剪下工具是一款基於 Web Audio API 的純前端線上音訊裁剪器。無需安裝軟體，上傳音訊後即可在視覺化波形上拖拽選擇片段，精確到毫秒級裁剪，並一鍵匯出標準 WAV 檔案。

✨ 功能特點

  • 拖拽上傳音訊
  • Canvas 波形視覺化
  • 滑鼠拖選剪下區域
  • 精確時間輸入（秒）
  • 片段試聽預覽
  • OfflineAudioContext 渲染匯出
  • 匯出標準 WAV（16bit PCM）
  • 純本地處理，資料不上傳
  • 支援深色模式與響應式

🎯 使用場景

  • 擷取音訊片段做鈴聲
  • 裁剪播客/錄音多餘開頭結尾
  • 提取音樂高潮部分
  • 為影片製作精準音訊素材
  • 去除音訊中的靜音或噪聲段
⚠️ 使用說明與注意事項
  • 本工具純前端執行，音訊檔案不會上傳到伺服器
  • 建議在主流瀏覽器（Chrome / Safari / Firefox / Edge）中使用
  • 首次播放/試聽需使用者互動後瀏覽器才會允許音訊輸出
  • 大檔案解碼可能需要數秒，請耐心等待
  • 匯出的 WAV 檔案體積較大（約每分鐘 10MB/單聲道），請注意儲存空間
