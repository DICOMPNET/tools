Extraction Stage Calculator (Distribution Coefficient)

Compute liquid-liquid extraction stages from distribution coefficient.

📐 工作原理與說明

Key formulas: Math.ceil(Math.log(1-0.999999)÷Math.log(q)); Math.ceil(Math.log(1-tFrac)÷Math.log(q)); min(max(target,0),99.999)÷100

💡 單次萃取後原相殘留分數 = V₀ / (V₀ + K·V)；n 次後總殘留 = [V₀/(V₀+K·V)]ⁿ；總回收率 = 1 − 殘留；所需次數 n = lg(1−目標) / lg[V₀/(V₀+K·V)]。

⚠️ 使用說明與注意事項
  • 按 Enter 快速計算，Ctrl/Cmd + Enter 複製結果
  • 分配係數 K = 萃取相濃度 / 原相濃度（達平衡時）
  • 多次小體積萃取優於單次大體積萃取（相同萃取劑總量）

反算次數
V0=100 mL、V=25 mL、K=4；單次殘留 q=100/(100+4×25)=0.5；達 99% 需 1−0.5ⁿ≥0.99 → n≈7 次。
合併體積
改一次加 7×25=175 mL：單次回收=4×1.75/(1+4×1.75)=87.5%，仍低於分 7 次的 99%。

❓ 常見問題（FAQ）

和分配係數法區別？
同一物理過程兩種表達：q=V0/(V0+K·V) 對應剩餘分數。
實際取幾次？
權衡溶劑與能耗，常 2~3 次達 85~95% 即停。
