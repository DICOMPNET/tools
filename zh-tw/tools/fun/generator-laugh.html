✨ Laugh Sound Generator (Web Audio)

Synthesizes a variety of laughs in real time with the Web Audio API, with randomized parameter tweaks and downloadable output.

📐 工作原理與說明

笑聲由 Web Audio API 在瀏覽器內即時合成,不涉及任何第三方音訊素材:

  • 基頻振盪器(sawtooth / square)模擬聲帶"哈"的頓挫。
  • ADSR 包絡控制每個"哈"的起音/衰減/釋放,形成節奏。
  • LFO 顫音 + 共振峰(formant)濾波逼近人聲母音音色。

引數隨機微調產生多樣的"哈哈哈"。合成音訊可自由下載使用,無版權風險。

方法（合成原理）
用瀏覽器原生 Web Audio API 即時合成：基頻振盪 + 顫音(LFO) + 包絡(起承轉合) 拼出笑聲波形，可調引數後匯出本地 wav，無第三方音訊素材。
算例（演示）
合成「哈哈哈」：基頻 200Hz、顫音 ±15Hz、時長 1.2s，聽感接近輕鬆笑；匯出為本地 wav 檔案。全程前端合成，無上傳、無版權風險。
