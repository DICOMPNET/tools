🌈 Color Memory (Simon)

📐 工作原理與說明
每關向序列追加 ⌊random × 4⌋（四色之一），序列長度即當前關卡進度；回放按 600 ms 間隔依次高亮，播完轉入作答。點選與序列第 userIdx 項一致則 userIdx 遞增，全部命中即通關、關卡 +1 並延時 1000 ms 進入下一關；任一點選不符立即結束並公佈正確序列

Watch and repeat a gradually growing color sequence to challenge short-term memory and reaction speed. Levels ramp up and it works fully offline.

📚 深度解析：顏色記憶（Simon）遊戲

💡 常見使用場景

  • 腦力訓練：跟隨並復現逐漸變長的顏色序列，挑戰短期記憶。
  • 多感官助記：序列伴燈光與聲音，幫助編碼與回憶。
  • 關卡遞進：每過一關序列 +1，記錄最長達成長度。
方法（序列規則）
工具依次亮燈+發聲播放顏色序列，玩家原樣復現；每過一關序列加 1 項，錯一處即結束並記錄本次達成長度。
算例（演示）
第 1 關序列 [紅,藍]，第 3 關 [紅,藍,綠,黃]；玩家復現錯在第 4 項則記錄「達成長度 3」。高手可記 20+ 項；用分組/唱名法（如「紅藍綠黃」編成詞）能顯著延長。

❓ 常見問題（FAQ）

怎麼記更長的序列？
把顏色編成節奏或詞語、分塊複述，比死記單列更有效；聲音線索也幫編碼。
有聲音嗎？
有。燈光配合提示音，多感官輸入降低記憶負荷。
