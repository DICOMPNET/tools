🗺️ 五分鐘上手路線

第一次進入不必急著深入堆場，按下面的順序熟悉操作，能減少迷路和誤觸：

  1. 先站穩：在出生區域用 W A S D 小步移動，緩慢移動滑鼠確認視角方向；如果轉身過快，先降低靈敏度再繼續。
  2. 再熟悉位移：找一段開闊通道練習 Shift 衝刺，再按 C 蹲下，比較兩種狀態下的移動速度與視野高度。
  3. 練習瞄準：對準牆面或空曠處的目標點按左鍵射擊，先停穩再射，觀察準星與命中反饋，然後嘗試邊走邊射。
  4. 開始探索：沿泊位、集裝箱堆場、冷鏈倉儲和多式聯運區域逐段推進；遇到岔路先記住顯眼貨櫃或標牌，再決定方向。
  5. 隨時暫停：按 Esc 回到操作速覽核對按鍵；若頁面卡住，先重新整理本介紹頁，再重新開啟試玩視窗。

🎛️ 操作與設定建議

不同裝置的手感差異很大，建議先做一輪低強度適應，再逐步提高難度：

  • 靈敏度循序漸進：滑鼠靈敏度從偏低開始，能在集裝箱通道中穩定轉身後再上調；每次調整後先靜止觀察一秒。
  • 衝刺看距離：穿越開闊地時用 Shift 縮短暴露時間，進入狹窄堆場或需要精確瞄準時改用步行。
  • 蹲下看掩體：C 蹲下適合藉助矮牆、貨櫃邊緣隱藏身形；起身前先確認周圍視野，避免突然暴露。
  • 射擊先停穩：遠距離目標先站穩再點射，近距離移動目標再嘗試連射；準星未落定時不要連續按鍵。
  • 手機觸屏：橫屏後雙手持機，左手控制移動、右手調整視角；手指不要長期壓住射擊按鈕，以免誤觸。
  • 視窗與全屏：若瀏覽器位址列擠佔畫面，可用全屏顯示；切換全屏後重新確認滑鼠或觸屏仍能正常控制視角。
