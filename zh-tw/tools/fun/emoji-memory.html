😊 Emoji Memory Game

📐 工作原理與說明
每輪從表情庫中取下標 floor(隨機數 × 表情總數) 的表情追加進序列，序列長度受「當前長度 + 2 與表情總數取較小值」限制；答對則關卡 +1；重置時置為未開始態、清空序列與關卡顯示並移除隱藏樣式

Match pairs of Emoji across increasing levels to train visual memory and concentration. Runs entirely in the browser and offline.

📚 深度解析：Emoji 記憶配對遊戲

💡 常見使用場景

  • 記憶訓練：翻牌找出成對的 Emoji，練視覺記憶與專注。
  • 關卡遞增：對數隨關卡增多，難度逐步上升。
  • 休閒放鬆：純前端離線可玩，記錄最短步數/時間。
方法（配對規則）
棋盤初始全部蓋住，每次翻兩張；相同則消除、不同則蓋回，全部配對成功過關。關卡越高對數越多。
算例（演示）
第 1 關 6 對（12 格），全配對過關；第 3 關 10 對（20 格）。記錄最短翻牌步數與用時，錯翻越多步數越長，用「位置編碼」能減少回翻。

❓ 常見問題（FAQ）

怎麼記牌更快？
翻第一張時就在腦裡給位置編號，錯配後記住那兩張在哪，下次直接配對。
有提示嗎？
翻錯會自動蓋回，本身即「負向提示」；部分版本提供限時預覽。
