💡 常見使用場景

  • 視覺記憶：閃現網格中若干亮格，要求復原其位置。
  • 難度遞增：亮格數量隨關卡增多。
  • 腦力訓練：記錄達成關卡。
方法（復原規則）
在 N×N 網格短暫高亮若干格，消失後要求點選還原這些位置；亮格數隨關卡增加，錯一處即本關結束並記錄。
算例（演示）
4×4 網格閃 3 格亮 → 復原這 3 格位置過關；關卡升到閃 8 格。用「座標法」(如第 2 行第 3 列) 編碼位置比死記更準。

❓ 常見問題（FAQ）

和 shape/emoji memory 區別？
規則同屬位置記憶；本工具用抽象網格圖案，emoji/shape 用具體圖示，練的都是空間位置記憶。
怎麼記更多格？
給每格編行列座標、分組記憶，比逐格硬記容量更大。
