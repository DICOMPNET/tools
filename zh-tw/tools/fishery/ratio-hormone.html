📐 計算公式
總劑量 = 親魚體重 × 劑量率；兩針法：第一針 = 總劑量 ÷ 3、第二針 = 總劑量 × 2 ÷ 3；雄魚參考劑量 = 總劑量 ÷ 2。劑量率按方案取值：HCG 常用 800–1200 IU/kg、LRH-A2 常用 3–8 μg/kg、DOM 常用 0.5–2 μg/kg（不同魚種差異很大，須按魚種與當地技術方案調整）。校驗：體重 ≤ 0 或劑量率 ≤ 0 時給出提示且不輸出數值。
本頁只做「體重 × 劑量率」的算術換算，不判斷方案是否適合某一魚種，也不替代催產操作規程。劑量率輸入框可手動覆蓋方案預設值。
💡 公式提示：總劑量 = 體重 × 劑量率；兩針法第一針 1/3、第二針 2/3；雄魚參考劑量為總劑量的 1/2。

兩種成分配比
數值 A=100、B=50：最大公約數 50，最簡整數比 = 2:1；A 佔 B 的 200%，即 A 是 B 的 2 倍。用於藥劑或營養配比的快速折算。

❓ 常見問題（FAQ）

最簡整數比怎麼來？
先求兩數的最大公約數 g，再約分為 A/g : B/g；如 100:50 約分為 2:1。
佔比和倍數有什麼區別？
佔比 = A/B×100%（相對 B 的百分量），倍數 = A/B（純比值）；兩者描述同一比例關係，表達角度不同。
