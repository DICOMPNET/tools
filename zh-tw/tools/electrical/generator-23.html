✨ Logic Truth Table Generator

Logic truth-table generator: builds the complete truth table for a Boolean expression and outputs the requested number of rows.

📐 工作原理與說明
生成規則：從真值表模板池按 ⌊random × 池長度⌋ 取 n 條（n 上限 50），每條渲染變數列 + 表示式列 + 全部取值組合行
本工具用於邏輯真值表生成器（表示式輸入）的即時計算，依據對應公式與標準運算規則處理，結果按精度即時輸出；純前端執行，資料不上傳。

📚 深度解析：邏輯真值表生成（表示式輸入）

💡 常見使用場景

  • 數字邏輯教學：輸入布林表示式，自動生成真值表
  • 電路驗證：核對組合邏輯輸出與預期
  • 化簡輔助：從真值表觀察冗餘項
方法
用法：輸入變數（A/B/C…）與表示式（支援 AND/OR/NOT/XOR、括號），工具列舉所有變數組合並求每行列值。n 個變數生成 2^n 行。
算例
例：表示式 (A AND B) → 2 變數共 4 行：00=0、01=0、10=0、11=1。表示式 (A OR B) AND C → 3 變數共 8 行，僅 A/B/C 全 1 時出 1，其餘為 0。

❓ 常見問題（FAQ）

支援哪些運算子？
與(AND/&/∧)、或(OR/|/∨)、非(NOT/!/¬)、異或(XOR)及括號分組；具體以頁面提示為準。
變數數上限？
隨變數增多行數指數增長（2^n），過多變數頁面過長；一般教學用 2~4 變數。
