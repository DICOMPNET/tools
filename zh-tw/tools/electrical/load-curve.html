📐 計算公式
日負荷統計：用電量 = Σ24h 整點負荷 × 1h（kWh）；平均負荷 = 總量 ÷ 24、負荷率 = 平均 ÷ 最大、峰谷差 = 最大 − 最小、峰谷差率 = 峰谷差 ÷ 最大。校驗：無強校驗，空值按 0 兜底。判據：負荷率 <50% 偏低（建議最佳化用電或儲能調峰）、>85% 較高（用電平穩）、其餘一般。

📋 負荷特性指標

負荷率 = 平均負荷 / 最大負荷，反映負荷平穩程度，越接近1越平穩。
峰谷差 = 最大負荷 − 最小負荷，反映負荷波動幅度。
峰谷差率 = 峰谷差 / 最大負荷，越大說明調峰需求越強。
需用係數 = 最大負荷 / 裝機容量（需輸入裝機容量估算）。
用電量 = Σ(各時段負荷 × 1h)，單位 kWh。

❓ 常見問題（FAQ）

負荷率怎麼用？
負荷率=日均負荷/日最大負荷，越高說明裝置利用率越好，節能改造時優先關注低負荷率迴路。本工具為電氣工程輔助計算，結果僅供方案設計、工程預研與教學參考，不替代正式電氣設計、IEC/NEC 標準與持證工程師的最終判定。
峰谷差過大有什麼影響？
變壓器空載損耗增加、配電裝置按峰值選型而長期低載、線路利用率低，可通過儲能或排程平滑。本工具為電氣工程輔助計算，結果僅供方案設計、工程預研與教學參考，不替代正式電氣設計、IEC/NEC 標準與持證工程師的最終判定。
最小負荷率指標？
一般≥60% 良好，<40% 表示波動劇烈，建議結合分時電價或儲能最佳化。本工具為電氣工程輔助計算，結果僅供方案設計、工程預研與教學參考，不替代正式電氣設計、IEC/NEC 標準與持證工程師的最終判定。
