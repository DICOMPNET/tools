Stage Color Temperature & Filter Reference

Color Temperature

📐 工作原理與說明
麥爾德值 = round(1000000 ÷ 色溫 K)，源與目標各算一次後取差值 = 目標麥爾德 − 源麥爾德。差值 > 0 判需加 CTO（色溫橙）：≥ 131 全 CTO、≥ 65 用 1/2 CTO、≥ 33 用 1/4 CTO、其餘 1/8 CTO；差值 < 0 判需加 CTB（色溫藍），按絕對值同樣分四檔；差值 = 0 判無需校正。源或目標色溫 ≤ 0 時提示色溫需大於 0

Color Temperature: computes and outputs results from the input parameters.

色溫說明：色溫單位為開爾文（K）。3200K 為暖白（鎢絲燈），5600K 為日光白。Mired 值 = 1000000 / 色溫K，用於色溫轉換計算。

💡 常見使用場景

  • 將鎢絲燈 3200K 光源統一到日光 5600K 時，用 Mired 差值選擇 CTB 濾色片，保證多燈色彩一致。
  • 混合使用 LED（可調 2700–6500K）與傳統鹵素燈時，先確定基準色溫，再為偏差燈具選 CTO/CTB 校正。
  • 日落黃金時段自然光約 2000–3500K，設計戶外或窗景投影時據此調配暖色氛圍光。
算例：3200K → 5600K 選片
源色溫 3200K、目標 5600K。Mired 源 = 1000000 / 3200 ≈ 313，目標 = 1000000 / 5600 ≈ 179，差值 = −134 Mired。負值表示需升高色溫，選用 CTB（色溫藍）；|Δ|≈134 ≥ 131，對應全 CTB（Full CTB）。

❓ 常見問題（FAQ）

Mired 是什麼，為什麼用差值選濾色片？
Mired = 1,000,000 / 色溫(K)，是色溫的倒數刻度。濾色片按 Mired 差值分級（全/半/1/4 CTO·CTB），差值越大所需校正越強。
LED 燈能否用濾色片替代色溫調節？
可調色溫 LED 優先用自身調節更精準且不失光；濾色片適合固定色溫光源或做特殊色調，但會衰減光通量。
