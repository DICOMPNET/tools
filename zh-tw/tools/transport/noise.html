📐 工作原理與說明
道路交通噪聲預測（FHWA 簡化模型）
Leq = 10·log₁₀V + 0.2·S − 10·log₁₀d + 40
V = 小時交通量(veh/h)，S = 平均車速(km/h)，d = 預測點距道路中心距離(m)
重型車能量修正 = 10·log₁₀(1 + 9p)，p = 重型車比例
總聲級 = 基礎項 + 重型車修正 + 地面衰減修正(dB)
標準限值：居住區晝間 ≤55 dB，交通幹線兩側晝間 ≤70 dB

Key formulas: 10×Math.log10(V)+0.2×S-10×Math.log10(d)+40; 10×Math.log10(1+9×p); hv÷100

💡 簡化 FHWA 模型：Leq ≈ 10·log₁₀(V) + 0.2·S − 10·log₁₀(d) + 40 + ΔHV + Δ地面。結果為參考估算，實際需專業軟體（TNM/CadnaA）測算。

📚 深度解析：交通噪聲（Leq）預測

💡 常見使用場景

  • 按小時交通量、平均車速、重型車比例與受聲點距離預測等效連續 A 聲級 Leq。
  • 評估道路兩側敏感點（住宅、學校）是否超出聲環境標準。
  • 比較限速、限行重型車或設定聲屏障前後的噪聲改善量。
預測模型
採用簡化 FHWA 模型：基準聲級 = 10·log₁₀(V) + 0.2·S − 10·log₁₀(d) + 40（V 為小時交通量 veh/h、S 為平均車速 km/h、d 為受聲點距離 m）；重型車修正 = 10·log₁₀(1 + 9p)（p 為重型車比例小數）；Leq = 基準 + 重型車修正 + 地面衰減項。感受分級：<50 dB 安靜、50~60 較安靜、60~70 較吵、70~80 吵鬧、80~90 很吵、≥90 極吵。
算例
V=1000 veh/h、S=60 km/h、d=30 m、重型車 10%：基準 = 10log₁₀(1000) + 0.2×60 − 10log₁₀(30) + 40 = 30 + 12 − 14.77 + 40 ≈ 67.2 dB；重型車修正 = 10log₁₀(1+0.9) ≈ 2.79 dB；合計約 70 dB（未計地面衰減），屬“較吵”，超出居住區晝間 55 dB 標準。

❓ 常見問題（FAQ）

為什麼交通量用對數？
聲能量疊加遵循對數規律：車流量翻倍時聲能量加倍，聲級只增加約 3 dB（10log₁₀2≈3），而非翻倍；這正是道路交通量大幅增長而噪聲只緩慢上升的原因。
重型車影響為什麼這麼大？
重型車單車噪聲顯著高於小客車，模型中用能量等效因子 9 折算：重型車佔 10% 時修正約 +2.8 dB，佔 30% 時約 +5.5 dB，因此夜間限行重卡是有效的降噪措施。
