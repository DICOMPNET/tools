Bearing Pressure

Bearing Pressure

📐 計算公式
基底壓力：p = 豎向力 N ÷ 底面積 A（kPa）；聯動量：帕斯卡口徑 = p×1000（Pa）、復算 N = p×A、單位荷載所需面積 = A÷N（m²/kN，N=0 時顯示「—」）。校驗：N、A 缺項提示「請填寫「豎向力 (kN)」後再計算。」；A=0 由分母守衛提示「⚠「底面積 (m²)」是本計算的分母，不能為 0。」並中止（不以 1 兜底）；N=0 時 p=0 並提示「不再替換為 1 kN」；全 0 輸入另提示無意義。判據：無固定分級，p 與 N 線性、與 A 反比聯動。

基礎底面平均接觸壓應力。

Formula & Standard References

Item Formula / Note Source / Standard
Average base pressure p = N / A, where N is the transmitted vertical force and A the base area GB 50007-2011, Code for design of building foundation
Bearing capacity check The average base pressure must not exceed the modified characteristic bearing capacity GB 50007-2011, Code for design of building foundation
Eccentric loading p_max/p_min = (N/A) · (1 ± 6e/B), where e is the eccentricity and B the base width GB 50007-2011, Code for design of building foundation
Distribution assumption Under a rigid footing the base pressure is assumed to vary linearly GB 50007-2011, Code for design of building foundation
📌 計算說明
  • p = N/A；N 用 kN、A 用 m² 得 kPa。
  • 100 kN、10 m² → 10 kPa。

📚 深度解析：承壓應力

💡 常見使用場景

  • 柱腳、支座墊塊下的平均承壓壓強。
  • 基礎底面與地基接觸壓力估算。
  • 支座承壓面積反算。
柱底 100kN / 10m²
N=100 kN, A=10 m²：p=N/A=100/10=10 kPa。
支座墊塊
N=500 kN, A=0.5 m²：p=500/0.5=1000 kPa=1 MPa。

❓ 常見問題（FAQ）

承壓與地基承載力？
p 須小於地基或墊塊材料容許承壓值，否則需加大面積。
區域性承壓注意什麼？
混凝土區域性承壓有強度提高係數，須按規範另行核算。
