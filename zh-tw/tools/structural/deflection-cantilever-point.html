δ = FL³ / (3EI)

Deflection Cantilever Point

📐 計算公式
彈性解（對照）：δ_el = F·L³ ÷ (3·E·I)（×1000 化 mm），圓截面 I = π·d⁴ ÷ 64（m⁴）。RC 長期剛度（GB 50010-2010，與彈性解並列輸出）：M_q = P_q·L；先按 7.1.1 判 M_q ≤ M_cr = f_tk·W_0（W_0 = b·h²/6，kN·m）→ 未開裂取 B_s = E_c·I_0、ψ 不適用；開裂後 σ_s = M_q/(0.87·h₀·A_s)，ψ = 1.1 − 0.65·f_tk/(ρ_te·σ_s)（夾取 0.2~1.0），B_s = E_s·A_s·h₀²/[1.15ψ + 0.2 + 6α_E·ρ]，θ = 2.0 − 0.4·min(1, ρ′/ρ)（7.2.5-1），B = B_s/θ（7.2.2-2），δ_lt = (1/3)·M_q·L²/B。校驗：F、L、E、d 非空守衛。判據：無固定分級，彈性撓度與端力、梁長三次方成正比、與直徑四次方成反比；RC 撓度按準永久組合與長期剛度驗算。

輸入端點力 F、長度 L、彈性模量 E、圓截面直徑 d，求撓度。

🧮 鋼筋混凝土長期剛度對照（GB 50010-2010）

本區預設把上方彈性截面按等面積、等慣性矩反推成等效矩形截面（b≈0.907d、h≈0.866d），並使用同一準永久荷載，使彈性解與 RC 長期剛度在同一截面下對照；結果區同時列出兩套截面引數與等效偏差百分比。改動上方截面後可點「按上方彈性截面重置 RC 引數」重新同步。

📚 深度解析：懸臂樑端集中力撓度

💡 常見使用場景

  • 懸臂結構自由端受集中力的彈性撓度。
  • 裝置支架端部變形限值校核。
  • 選材與截面最佳化（撓度敏感場合）。
鋼圓杆 d=100mm
F=100 N, L=2 m, E=200 GPa, d=0.1 m：I=πd⁴/64=4.91×10⁻⁶ m⁴，δ=FL³/(3EI)=100×8/(3×200e9×4.91e-6)=2.72×10⁻⁴ m≈0.27 mm。
直徑加倍
d 0.1→0.2：I 增 16 倍，δ 降至約 0.017 mm。

❓ 常見問題（FAQ）

撓度與剛度關係？
δ 與 EI 成反比，EI 為抗彎剛度，截面慣性矩 I 影響最顯著（四次方）。
均布與集中差別？
均布端撓度為 wL⁴/(8EI)，約為同總載集中力的 5/8。
