📐 工作原理與說明
四分音符時長 = 60000 ÷ BPM（ms），BPM 輸入鉗制在 40–300；各音符時長按四分音符乘係數：全音符 ×4、二分 ×2、四分 ×1、八分 ÷2、十六分 ÷4、三連音 ÷3、附點四分 ×1.5、4/4 小節 ×4。取樣點數 = round(時長 ms ÷ 1000 × 取樣率)；LFO 頻率按音符時長的倒數換算；反推 BPM 時由時長與所選音符型別解出每分鐘拍數

BPM 轉音符時長
120 BPM → 四分音符 = 60000/120 = 500 ms；八分 = 250 ms、十六分 = 125 ms、附點四分 = 500×1.5 = 750 ms。
LFO 與取樣數
120 BPM 下每拍 500 ms；要 LFO 每拍一個週期，頻率 = 1000/500 = 2 Hz。44100 Hz 取樣率下四分音符 = round(500/1000×44100) = 22050 個取樣點。

❓ 常見問題（FAQ）

BPM 和毫秒怎麼互轉？
四分音符毫秒 = 60000 / BPM；已知某音符毫秒 ms，對應 BPM = 60000 × 該音符的拍數 / ms（如八分音符拍數 0.5）。
LFO 同步頻率怎麼算？
週期毫秒 = 四分音符毫秒 × 倍數（每拍=1、每兩拍=2），頻率(Hz) = 1000 / 週期毫秒；如每小節(4 拍)一次 = 1000/(500×4)=0.5 Hz。
