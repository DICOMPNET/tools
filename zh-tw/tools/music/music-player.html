💡 常見使用場景

  • 瀏覽器內直接播放本地 MP3/WAV，免裝播放軟體
  • 建多曲播放列表連續聽，拖動進度定位段落
  • 調音量/暫停做背景音樂或跟練伴奏
播放列表管理
一次選入 5 個音訊檔案，列表順序即播放順序；點某曲跳播、拖動進度條到 1:23 處續聽，無需重新載入。
音量控制
音量滑塊對映到 Web Audio 的 GainNode（0–1 線性），0.5 約為一半響度；暫停保留當前進度，繼續從原位播放。

❓ 常見問題（FAQ）

檔案會傳到伺服器嗎？
不會，播放器用瀏覽器本地 File API 讀取，音訊只在本地記憶體播放，不聯網上傳，隱私安全。
支援哪些格式？
取決於瀏覽器解碼器，常見 MP3、WAV、OGG、AAC 多可播；FLAC 在部分瀏覽器需轉碼或不支援。
