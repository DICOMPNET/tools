🎶 關於和絃進行生成器 ▼

和絃進行（Chord Progression）是指一組和絃按照特定順序排列，構成音樂的基本和聲框架。不同風格的和絃進行能營造出截然不同的情感和氛圍，是歌曲創作和編曲的核心元素。

🌟 功能特點

  • 支援 10 種大調 + 9 種小調
  • 內建 8 種經典和絃進行
  • 4/8/16 小節靈活配置
  • Web Audio API 即時試聽
  • 可調節 BPM 速度
  • 一鍵複製和絃文本

🎪 適用場景

  • 吉他彈唱編曲
  • 鋼琴伴奏創作
  • 歌曲寫作靈感
  • 音樂理論學習

📚 深度解析：和絃進行生成器（級數走向）

💡 常見使用場景

  • 寫歌/編配時按調內級數生成 I–V–vi–IV 等常見走向，快速搭出伴奏框架
  • 扒帶後想找替代走向，對比 ii–V–I、I–vi–IV–V 等聽感差異
  • 給和絃進行配每個和絃的組成音，方便鋼琴/吉他彈奏
C 大調 I–V–vi–IV
C 大調七級和絃：I=C、ii=Dm、iii=Em、IV=F、V=G、vi=Am、vii°=Bdim。經典流行走向 I–V–vi–IV = C → G → Am → F，每個和絃取三音（根+大/小三度+純五度）。
級數轉實際和絃
G 大調 I–V–vi–IV：I=G、V=D、vi=Em、IV=C → G → D → Em → C；V 級 D 由 D F# A 構成（大三和絃 0/4/7 半音）。

❓ 常見問題（FAQ）

為什麼 vi 級聽起來悲傷？
vi 級是關係小和絃，I–V–vi–IV 裡 vi 把大調色彩拉到小調，形成流行歌常用的情緒轉折。
級數怎麼對應具體和絃？
先定調（如 C 大調音階 C D E F G A B），級數 1–7 依次取音為根，再按三度疊置加 3、5 音；小調級數同理用自然小調音階。
