📐 計算公式
物業績效考核：綜合得分 = Σ(六維得分 × 權重) ÷ Σ權重（維度：客戶滿意度/設施維護/響應時效/收費率/安全合規/環境品質）。校驗：任一非數報「請輸入有效數值」、權重總和為 0 報錯；得分截斷 [0,100]、權重去負。判據：≥90 A級·優秀、≥80 B級·良好、≥70 C級·合格、≥60 D級·待改進、<60 E級·不合格，並定位最低分維度優先改進。

六大維度加權評分（客戶滿意度20%+設施維護20%+響應時效15%+收費率15%+安全合規15%+環境品質15%），自動生成考核等級

💡 加權得分 = Σ(各維度得分 × 權重) / Σ權重。考核等級：A級(≥90)優秀 / B級(80-89)良好 / C級(70-79)合格 / D級(60-69)待改進 / E級(<60)不合格。維度得分參考：滿意度調查均分、設施完好率、工單響應時間達標率、實際收費率、安全檢查通過率、環境巡查合格率。

⚠️ 使用說明與注意事項
  • 各維度得分0-100分，參考實際考核資料填入
  • 權重可自定義調整，預設按行業經驗分配，總權重建議100%
  • 客戶滿意度建議採用季度調查均值（樣本量≥30%）
  • 響應時效：15分鐘內響應為100分，每超10分鐘扣5分
  • 安全合規含消防/電梯/配電/燃氣等特種裝置檢查通過率
  • 結果僅供參考，實際考核應結合合同約定和當地物業管理辦法

📚 深度解析：物業績效考核評分體系

💡 常見使用場景

  • 物業專案經理對各崗位按月評分
  • 多維度加權算綜合績效發獎金
  • 低分員工制定改進計劃並複評
加權評分
報修響應（權重 20，得 90）+ 環境衛生（25，85）+ 安全秩序（20，88）+ 業主滿意度（25，82）+ 成本控制（10，78）→ 綜合 = 20%×90 + 25%×85 + 20%×88 + 25%×82 + 10%×78 = 85.15 分。
等級應用
≥90 優秀、80–89 良好、70–79 合格、<70 待改進；85.15 為良好，獎金係數 1.0；連續兩月 <70 轉培訓。

❓ 常見問題（FAQ）

權重怎麼定？
按崗位核心職責：客服重滿意度、工程重響應、安保重秩序，差異化設權。
滿意度資料哪來？
來自回訪評分與投訴率，避免僅看內部工時，防止「忙但不達標」。

📝工具簡介

物業績效考核評分體系，支援客戶滿意度、設施維護質量、響應時效、收費率、安全合規、環境品質六大維度的加權評分計算。可自定義各維度權重，自動生成A-E五級考核結果，並識別薄弱環節提供改進建議。

✨功能特點

  • 六大考核維度全面覆蓋物業服務品質
  • 支援自定義權重，適應不同專案考核需求
  • 視覺化條形圖直觀展示各維度得分
  • 自動識別最低分維度並生成改進建議

🎯使用場景

  • 物業公司季度/年度績效考核
  • 業委會對物業公司服務品質評估
  • 多專案橫向對比評比
  • 物業服務合同履約評價
