📖 Benchmarking (Compare / Learn / Surpass) Analysis

Compare property and operations metrics against a benchmark, quantify gaps and output improvement priorities.

📐 工作原理與說明
相對差距 rel = (標杆值 − 自身值) ÷ 標杆值（方向 low 時取反）；rel > 0 為落後、rel < 0 為領先；改進空間評分 = 落後項的加權平均 rel × 100%，領先項不計入；優先改進按 rel × 權重降序取 Top3

標杆分析用於量化自身與行業/內部標杆的差距，明確改進優先順序：

方向 high 表示越高越好（如毛利率、滿意度）；low 表示越低越好（如費用率、空置率），計算時取反。只有 rel > 0 的落後項進入改進空間評分與 Top3；rel < 0 的領先項單獨列示，不推高改進空間。

標杆值為 0 時相對差距無意義，頁面改為顯示絕對差並標註“相對差距不適用”，該行不參與加權評分。每行可選填權重（預設 1）與口徑說明；方向、數值、權重不合法會逐行列出跳過原因。

💡 常見使用場景

  • 物業公司將本小區關鍵指標（報修響應、綠化達標率）與同級別標杆專案對比
  • 月度經營會用工單量與滿意度資料找差距
  • 制定趕超計劃，把標杆值設為下季度目標
報修響應對比
本小區平均響應 4.2 小時、標杆 2.0 小時，方向 low（越低越好）：相對差距 (2.0−4.2)/2.0 = −1.10，取反後 +110%，屬於落後項，列為一號改進項並設下季度目標 3.0 小時。
滿意度領先
本小區滿意度 95 分、標杆 90 分，方向 high：相對差距 (90−95)/90 = −5.6%，屬於領先項；只計入“領先項”展示，不進入改進空間評分和 Top3。
零基準與權重
投訴率 5、標杆 0，方向 low：相對差距無意義，頁面顯示絕對差 5、標註“相對差距不適用”，不參與評分；另一項人效 60 對 80、權重 2，落後 25%，加權後改進空間評分仍為 25%。

❓ 常見問題（FAQ）

標杆專案怎麼選？
選同城市、同檔次、規模相近且公開資料可信的專案，避免跨型別硬比導致結論失真。
對標後只抄指標行嗎？
不行，要分析標杆背後的流程（排班、培訓、回訪），把做法本地化，而非只追數字。
自身已經優於標杆會怎樣？
按方向判斷為領先項，單獨列出並計算平均優勢，不再進入改進空間評分和優先改進 Top3；優勢越大不會被誤判為越需改進。
標杆值為 0 怎麼算？
相對差距分母為 0，頁面改為顯示絕對差並標註“相對差距不適用”，該行不參與評分和 Top3。
