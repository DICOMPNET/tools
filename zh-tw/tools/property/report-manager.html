📐 工作原理與說明
結餘 = 收入 − 支出；結餘率 = 結餘 ÷ 收入 × 100%（收入合計為 0 時標“不適用”）；支出最大項按支出降序取首；收不抵支項 = 支出 > 收入的專案計數。解析規則：每行必須為「專案,收入,支出」三個欄位，金額須為純數字；行號、欄位數或數字有誤即停止生成並逐行提示，不靜默跳過；專案名按純文本轉義輸出。

每行輸入一條「專案,收入,支出」。結餘＝收入−支出；結餘率＝結餘÷收入×100%。彙總得到收入合計、支出合計與總結餘，並定位支出最大項與收不抵支的專案數，用於物業經營收支報表與審計自查。

📚 深度解析：物業收支報表與結餘測算

💡 常見使用場景

  • 物業公司財務按月彙總物業費、停車費、廣告位等收入與對應支出，生成收支報表供管理層審閱。
  • 業委會或審計方核對公共收益與公共能耗支出時，用本工具快速核算結餘與赤字專案。
  • 新接管專案做經營測算時，按預計收入與支出試算結餘率，評估專案盈虧可行性。
四專案收支試算
輸入「物業費,320000,180000；停車費,85000,22000；廣告位,40000,5000；公共能耗,0,96000」，收入合計 445000.00、支出合計 303000.00、結餘 +142000.00、結餘率 31.91%，支出最大項為物業費，收不抵支專案 1 個。

❓ 常見問題（FAQ）

沒有收入的專案怎麼填？
收入填 0 即可，如公共區域能耗這類純支出項，工具會將其計入赤字專案並在結餘中體現。
結餘率怎麼理解？
結餘率＝結餘÷收入×100%，反映每取得 1 元收入能留下多少結餘，是衡量物業專案經營質量的核心指標。
可以同時對比多個專案嗎？
目前一次輸入為一份報表的多個收支專案；多專案對比建議分別測算後記錄結果，或把專案名作為前綴合並輸入。
