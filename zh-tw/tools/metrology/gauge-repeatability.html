Gauge Repeatability Calculator

Compute repeatability standard deviation σ_r = R̄/d₂ from the average range of repeated readings using the range method for measurement system analysis (MSA).

📐 計算公式
量具重複性（極差法）：σ_r = R̄ ÷ d₂；d₂ 按測量次數查表——2 次 1.128、3 次 1.693、4 次 2.059、5 次 2.326，表外回落 1.693；99% 過程頻寬 = 5.15σ_r、95% 重複性區間 = ±2.576σ_r、6σ 過程變差 = 6σ_r。校驗：兩項空值即提示；平均極差不得為負、測量次數須為 ≥2 的整數（0 極差合法）。判據：無固定分級，σ_r 越小量具重複性越好。

重複性標準偏差 = 平均極差 / d₂。

Formula & Standard References

Item Formula / Note Source / Standard
Repeatability SD (range method) sigma_r = Rbar / d2, where Rbar is the average range and d2 a sample-size constant Montgomery DC, Introduction to Statistical Quality Control (7th ed.), Wiley
The d2 constant d2 is tabulated by subgroup size n from the expected range of a normal sample Montgomery DC, Introduction to Statistical Quality Control (7th ed.)
Definition of repeatability Variation with one operator, one gauge, one part over a short time AIAG, Measurement Systems Analysis (MSA) Reference Manual, 4th ed. (2010)
Combination into GRR GRR = sqrt(EV^2 + AV^2), where EV is equipment variation AIAG, Measurement Systems Analysis (MSA) Reference Manual, 4th ed. (2010)

  • d₂ 隨測量次數變化。

公式
重複性 EV = Rbar * K1（極差法）。例：Rbar=0.003、K1=0.5908（2 次），EV=0.0018。
平均極差 0.07，重複次數 4
查 d₂=2.059，σ_r=0.07/2.059=0.0340；99% 過程頻寬為 5.15σ_r=0.1751。d₂ 隨重複次數變化，選錯會明顯影響結果。

❓ 常見問題（FAQ）

與再現性？
重複性同人同具，再現性跨人/裝置。
判據？
EV% 應遠小於公差或過程變異。
