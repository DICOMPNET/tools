Absolute Bias Calculator

Compute absolute bias as x − x_ref from a measured value and the reference standard value to evaluate measurement system deviation.

📐 計算公式
絕對偏倚 = 測量值 x − 參考值 x_ref；相對偏倚% = 偏倚 ÷ max(x_ref, 1e−12) × 100；測量參考比 = x ÷ x_ref；絕對值 = |偏倚|。校驗：兩項數值輸入無強校驗，分母以 1e−12 兜底防除零。判據：正偏倚示值偏高、負偏低；|偏倚| 越小準確度越好，需對照允差限判定。

輸入測得值與參考標準值，求絕對偏倚。

💡 常見使用場景

  • 算量具系統偏倚
  • 偏倚判定
  • 校準修正
公式
bias = mean(測量值) - 參考值（真值）。例：參考 10.000 mm，10 次均值 10.015，bias = +0.015 mm。
測得值 20.35，參考值 20
Bias=x−x_ref=20.35−20=0.350。正值說明測量值系統性偏高，做修正時應從後續讀數中減去這一量。

❓ 常見問題（FAQ）

偏倚與誤差？
偏倚是重複測量的系統誤差平均，反映量具整體偏移。
如何修正？
校準時減去偏倚或建立修正曲線使用。
