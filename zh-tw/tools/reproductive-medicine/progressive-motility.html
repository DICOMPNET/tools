📋 Progressive Motility (PR) Percentage Assessor

Compute PR, NP, IM percentages and total motility (PR+NP), compared with WHO 5th-edition lower references (PR >= 32%, total motility >= 40%).

精子活力：前向運動 PR% = PR ÷（PR + NP + IM）× 100；總活力 = PR% + NP%；WHO 參考 PR 不低於32% 且總活力不低於40% 為正常、PR 達標但總活力偏低、PR 20–32% 弱精子症、PR 小於20% 嚴重弱精子症。

📋 WHO 第5版活力參考下限（第5百分位）

指標參考下限意義
前向運動 PR≥32%與受孕率相關
總活力 PR+NP≥40%總體活動能力

🔬 活力分級定義

  • PR：主動運動，有方向性（直線或大圓周）
  • NP：有運動但無方向性（原地、小圈、尾部擺動）
  • IM：無運動
  • 建議計數至少 200 個精子，每高倍視野多個視野取均值
提示：活力受取精後檢測時間（建議 30~60 分鐘內）、溫度（37℃）影響明顯。僅一次異常建議複查 2 次以上。

💡 常見使用場景

  • PR/NP/IM 三級佔比。
  • 弱精子症判定。
  • 精液常規核心指標。
PR 40、NP 10、IM 50
總數 100；PR%=40%、總活動(PR+NP)=50%；PR≥32% 正常，前向運動良好。
PR 20、IM 80
PR=20%<32% → 弱精子症（asthenozoospermia），建議複查與病因排查。

❓ 常見問題（FAQ）

三級含義？
PR 前向運動、NP 非前向、IM 不活動；WHO 以 PR≥32% 為參考。
活動力低怎麼辦？
排查精索靜脈曲張/感染/氧化應激，必要時 IUI/ICSI。
