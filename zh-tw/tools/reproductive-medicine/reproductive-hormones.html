⚗️ Reproductive Hormones (FSH/LH/E2/T) and Spermatogenesis Assessor

Input male FSH, LH, E2, testosterone T, PRL and other reproductive-hormone levels, compare against reference ranges to assess HPG-axis function and classify spermatogenic-disorder type (central vs testicular), for male-infertility initial screening.

男性生殖激素參考區間：FSH 1.5–12.4 IU/L、LH 1.7–8.6 IU/L、睪酮 T 9.9–27.8 nmol/L、雌二醇 E2 0–160 pmol/L、泌乳素 PRL 86–390 mIU/L；逐項與區間比對標註偏高/偏低/正常。

🔬 關鍵指標意義

  • FSH：評估生精功能的關鍵，顯著升高提示生精小管損傷、不可逆生精障礙
  • T/LH：T↓伴 LH↑ 提示 Leydig 細胞功能衰竭；T↓伴 LH↓ 提示垂體性
  • PRL↑：高泌乳素血症抑制 GnRH，導致性腺功能減退
  • E2↑：雌激素增多抑制 FSH/LH，可見於肥胖、肝病、芳香化酶活性升高
提示：參考範圍因實驗室方法不同存在差異，請以本室參考值為準。採血建議晨起空腹，避免劇烈運動。

PRL 80、餘正常
泌乳素顯著升高（正常<25） → 高泌乳素血症，抑制排卵，需查垂體 MRI。

❓ 常見問題（FAQ）

基礎 FSH 閾值？
卵泡期 FSH>10 提示儲備下降、>20 明顯減退、>25 反應極差。
LH/FSH 比值？
PCOS 常 LH/FSH≥2 伴 T 升高；需結合超聲。
