#️⃣ Hash Output Length

Look up the output length (bytes and bits) of common hash algorithms (MD5, SHA family) for hash value storage planning.

📐 計算公式與說明

MD5=128bit, SHA1=160bit, SHA256=256bit, SHA512=512bit
Hex 長度 = 位元組數 × 2

用於預估雜湊值儲存空間。

📚 深度解析：雜湊輸出長度

💡 常見使用場景

  • 欄位設計：為資料庫/索引選擇雜湊長度以平衡衝突與儲存。
  • 簽名對接：確認對端摘要位數（如 SHA-256 為 32 位元組）。
  • 教學速查：對比 MD5/SHA-1/SHA-256 輸出規模。
示例：SHA-256
輸出 256 bit = 32 位元組 = 64 個十六進位制字元。

❓ 常見問題（FAQ）

MD5 還能用嗎？
僅用於非安全校驗（如去重），因其已被攻破不可用於完整性/防篡改。
位數與安全性關係？
抗碰撞強度約與位數半相關（生日攻擊），SHA-256 遠強於 MD5/SHA-1。
為何同時給位元組與位數？
儲存按位元組、展示常用十六進位制（2 字元/位元組），兩者都常用。
