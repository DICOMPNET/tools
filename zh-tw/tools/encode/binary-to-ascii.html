🔐 Binary / Hex to ASCII

Paste a continuous bit or hex string and choose the radix to decode it into ASCII text (8 bits or 2 hex digits per character).

📐 工作原理與說明
按 8 位一位元組解析：ASCII 編碼範圍 0 至 127，如 01000001 = 65 = 字母 A、00110000 = 48 = 數字 0；十六進位制每位對應 4 位二進位制（0x41 = 01000001）；可列印字元為 32 至 126，其餘為控制字元（0x0A 換行、0x0D 回車）；無分隔時按 8 位分組，含空格分隔時按分隔符切分後逐組轉十進位制再對映字元。

Formula & Standard References

Item Formula / Rule Source / Standard
Bit width Standard ASCII uses 7 bits but is stored as one 8-bit byte ANSI X3.4-1986 American Standard Code for Information Interchange
Hex mapping Every two hex digits encode one byte, so n bytes need 2n characters ISO/IEC 646 International Reference Version (IRV)
Printable range Printable characters span 0x20–0x7E; the rest are controls or extended bytes ANSI X3.4-1986 §2 Character set and coding
⚠️ 使用說明與注意事項
  • 二進位制每組 8 位對應一個位元組；十六進位制每 2 位對應一個位元組，空格、換行會被自動忽略。
  • 僅覆蓋 ASCII（0–127）。非 ASCII（如中文 UTF-8）是多位元組編碼，需先做 UTF-8 位元組拆解再逐位元組轉，本工具不直接支援。
  • 若結果出現亂碼，多半是位數不對或混入了其他字元，請先清理輸入。

💡 常見使用場景

  • 協議報文解析：把抓包得到的 8 位二進位制/十六進位制串還原為可讀 ASCII。
  • 教學演示：直觀展示字元與二進位制/十六進位制的一一對應。
  • 除錯嵌入資料：從二進位制流中肉眼提取可讀字串。
示例：十六進位制 48656C6C6F
按每 2 位一組對映：48=H,65=e,6C=l,6C=l,6F=o → "Hello"。

❓ 常見問題（FAQ）

位數不對會怎樣？
二進位制需 8 位一組、十六進位制 2 位一組，長度不齊會錯位或補零，需對齊。
非列印字元能顯示嗎？
控制字元（如 0x00/0x0A）無可讀字形，通常以轉義或佔位顯示。
支援中文嗎？
需先按 UTF-8 轉為位元組序列再逐位元組解析，單字元可能跨多位元組。

結果含義

將二進位制（每 8 位一組）按 ASCII 碼錶對映為字元；結果即對應的文本。

用法

用於編碼除錯、教學與資料觀察。注意需按 8 位分組且採用一致字符集（如 UTF-8/ASCII）；非列印字元可能不顯示。
