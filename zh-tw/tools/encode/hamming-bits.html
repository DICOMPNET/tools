✅ Hamming Code Parity Bits

Compute the Hamming parity bits r from data bits m using 2^r >= m + r + 1 for single-bit error correction.

📐 計算公式與說明

滿足 2ʳ ≥ m + r + 1 的最小 r
碼長 = m + r，效率 = m/(m+r)

漢明碼可檢測並糾正單位元錯誤。

📚 深度解析：漢明碼校驗位

💡 常見使用場景

  • 記憶體 ECC 設計：為 m 位資料規劃最少校驗位以糾單位元錯。
  • 教學演示：展示資料位增長時校驗位呈對數增加。
  • 協議校驗規劃：為關鍵欄位加漢明保護的成本估算。
示例：8 位資料
需 r=4（2^4=16≥8+4+1=13），共 12 位碼字，可糾 1 位錯、檢 2 位錯。

❓ 常見問題（FAQ）

公式含義？
2^r ≥ m+r+1 保證 r 個校驗位能定位 m+r 個位置（含整體無錯）。
漢明碼能糾幾位？
標準漢明碼糾單位元錯、檢雙位元錯；SEC-DED 需加一位總奇偶。
校驗位放在哪？
放在 2 的冪位置（1,2,4,8…），資料位填其餘，由奇偶覆蓋定位錯誤位。
