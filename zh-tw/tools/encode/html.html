📏 HTML Entity Length

Estimate the escaped length when special characters (&, <, >, quotes, etc.) are converted to HTML entities.

📐 計算公式與說明

& < > " 等佔 4-5 字元
Unicode 實體 &#xHHHH; 約 7-8 字元

用於預估 HTML 轉義後文本長度。

📚 深度解析：HTML 實體長度

💡 常見使用場景

  • 模板體積評估：使用者內容含大量特殊字元時轉義後的儲存/傳輸增長。
  • XSS 防護核對：確認輸出編碼後實體長度不影響佈局截斷。
  • 富文本儲存：預估入庫前轉義欄位寬度。
示例："a<b&c"
轉義為 "a&amp;lt;b&amp;amp;c"，原 6 字元變 19 字元（每特殊字元擴為 4–5 字元實體）。

❓ 常見問題（FAQ）

哪些字元必須轉義？
& < > " ' 在對應上下文需轉義，防止解析錯亂與 XSS。
長度為何顯著增加？
每個實體如 &amp; 佔 5 字元，原文 1 字元，故含大量特殊字元時體積成倍增。
與 URL 編碼區別？
HTML 實體用於頁面文本安全顯示，URL 編碼用於傳輸，兩者場景不同。

Formula & Standard References

Item Formula / Rule Source / Standard
Named entity length "&amp;", "&lt;" and "&gt;" take 4 to 6 characters, longer than the literal character HTML Living Standard §13.5 Named character references
Numeric reference Written as "&#nnn;" or "&#xHH;", growing with the decimal digits of the code point HTML Living Standard §13.5 Numeric character references
Minimum escape set Text nodes need only & and < escaped; attribute values also need the quote character ISO 8879 SGML Reference Concrete Syntax
