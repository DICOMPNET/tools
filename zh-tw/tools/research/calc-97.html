📐 工作原理與說明
抽樣樣本量計算（Cochran + 有限總體修正）
無限總體樣本量 n₀ = Z² × p × (1−p) ÷ e²
Z 由置信度查表；p 為預期比例；e 為允許誤差
有限總體修正：n = ⌈n₀ ÷ (1 + (n₀−1)/N)⌉
未填 N 或勾選無限總體時 n = ⌈n₀⌉
實際抽樣誤差 = Z × √(p(1−p)/n) × FPC
FPC = √((N−n)/(N−1))（無限總體取 1）
判定：實際誤差 ≤ 目標誤差為滿足，否則需擴大樣本
樣本充足性：n ≥ n 需求時顯示超出量，否則顯示缺口
誤差與樣本量平方根成反比，樣本翻倍誤差僅降約 29%
分層比例配額：各層樣本 nᵢ = round(n × 層規模 ÷ 總規模)
　餘數加到規模最大層使合計 = n
約束：誤差須在 0~100% 之間，實際樣本須 ≥1

Key formulas: Math.round(n×s.size÷totalStrata); Math.ceil(n0÷(1+(n0-1)÷N)); Math.ceil(n0)

⚠️ 使用說明與注意事項
  • 分層規模之和應接近 N，否則按實際合計分配
  • 比例分配適用於各層方差相近；方差差異大時可考慮 Neyman 分配
  • 無限總體時不應用有限總體修正（FPC）
  • 實際誤差隨樣本量增大而遞減，但收益邊際遞減

📚 深度解析：樣本量、抽樣誤差與分層配額

💡 常見使用場景

  • 調研設計階段按置信水平、預期比例與允許誤差反推最小樣本量。
  • 已知實際樣本量時反算抽樣誤差，判斷結論能否支援決策。
  • 分層抽樣按各層規模比例分配配額，保證樣本結構與總體一致。
95% 置信、±5% 誤差需要多少樣本
置信水平 95%（z = 1.96）、預期比例 p = 50%（最保守）、允許誤差 e = 5%、無限總體：n₀ = 1.96² × 0.5 × 0.5 ÷ 0.05² = 384.16 → 至少 385 份。若總體 N = 5 000 且計入有限總體校正：n = 384.16 ÷ (1 + 383.16/5 000) = 356.8 → 357 份，比無限總體少 28 份。反向校驗：n = 385 時實際誤差 = 1.96 × √(0.25/385) = 4.99%，與設定的 5% 一致。

❓ 常見問題（FAQ）

為什麼預期比例預設取 50%？
p(1−p) 在 p = 50% 時取最大值，算出的樣本量最保守。若你確信比例接近 0 或 1（如罕見行為 5%），按實際比例算可顯著減少樣本量。
什麼時候要用有限總體校正？
當抽樣比 n/N 超過約 5% 時，校正能明顯減少所需樣本。勾選總體規模後工具自動套用 √(（N−n)/(N−1)) 因子；若總體很大可勾無限總體。
