Sample Size / Quota / Margin of Error Calculator

Compute sample size and actual sampling error, then allocate strata quotas by the largest-remainder method: every quota is non-negative and sums exactly to n.

📐 工作原理與說明
抽樣樣本量計算（Cochran + 有限總體修正）
無限總體樣本量 n₀ = Z² × p × (1−p) ÷ e²
Z 由置信度查表；p 為預期比例；e 為允許誤差
有限總體修正：n = ⌈n₀ ÷ (1 + (n₀−1)/N)⌉
未填 N 或勾選無限總體時 n = ⌈n₀⌉
實際抽樣誤差 = Z × √(p(1−p)/n) × FPC
FPC = √((N−n)/(N−1))（無限總體取 1）
判定：實際誤差 ≤ 目標誤差為滿足，否則需擴大樣本
樣本充足性：n ≥ n 需求時顯示超出量，否則顯示缺口
誤差與樣本量平方根成反比，樣本翻倍誤差僅降約 29%
分層比例配額：按最大余數法分配 nᵢ，先取 floor(n×層規模÷分層合計)，再把剩餘名額按餘數從大到小分配（餘數相同按層規模大→小、輸入順序前→後），保證 nᵢ 非負整數且合計 = n
約束：誤差須在 0~100% 之間，實際樣本須 ≥1

Key formulas: Math.round(n×s.size÷totalStrata); Math.ceil(n0÷(1+(n0-1)÷N)); Math.ceil(n0)

⚠️ 使用說明與注意事項
  • 分層規模之和應接近 N，否則按實際合計分配
  • 比例分配適用於各層方差相近；方差差異大時可考慮 Neyman 分配
  • 無限總體時不應用有限總體修正（FPC）
  • 實際誤差隨樣本量增大而遞減，但收益邊際遞減

💡 常見使用場景

  • 調研設計階段按置信水平、預期比例與允許誤差反推最小樣本量，並用有限總體校正檢查是否高估。
  • 已知實際樣本量時反算抽樣誤差；有限總體下先檢查 n 是否超過 N，避免把負數 N 當成無限總體。
  • 分層抽樣按最大余數法分配配額，保證每層非負且合計嚴格等於 n，不再把負餘數塞給最大層。
95% 置信、±5% 誤差需要多少樣本
置信水平 95%（z=1.96）、預期比例 p=50%、允許誤差 e=5%、無限總體：n₀ = 1.96² × 0.5 × 0.5 ÷ 0.05² = 384.16 → 至少 385 份。若總體 N=5000 並計入有限總體校正：n = 384.16 ÷（1 + 383.16/5000）= 356.8 → 357 份。反向校驗 n=385 時實際誤差約 4.99%，與 5% 一致。
四層等規模、n=2 的配額
分層「A,100」「B,100」「C,100」「D,100」，n=2、N=400：按 2×100÷400=0.5 取整後四層都是 0，剩餘 2 個名額按餘數相同、層規模相同、輸入順序前→後分配，得到 1、1、0、0，合計嚴格為 2，不會出現某個層 -1。
負數 N 不再被當作無限總體
未勾選「視為無限總體」且 N 填 -5 時，頁面提示「有限總體規模 N 必須是 >0 的整數」，不會走無限總體分支；N 留空才按頁面說明視為無限總體。n 填 2.5 也會被攔截，不會被 Math.round 悄悄改成 2 或 3。

❓ 常見問題（FAQ）

為什麼預期比例預設取 50%？
p(1−p) 在 p=50% 時最大，算出的樣本量最保守。若確信比例接近 0 或 1（如罕見行為 5%），按實際比例算可顯著減少樣本量。
什麼時候要用有限總體校正？
抽樣比 n/N 超過約 5% 時校正影響明顯。有限總體下 n 不能超過 N；n=N 是普查，抽樣誤差為零，但其他非抽樣誤差仍存在。
分層合計和 N 不一致怎麼辦？
配額按分層合計計算，不強制等於 N；若有限總體下分層合計大於 N，頁面會以口徑矛盾阻止計算。合計小於 N 時會提示未覆蓋部分未分配配額，請確認分層是否覆蓋全部總體。
