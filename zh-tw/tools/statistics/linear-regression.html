📐 計算公式
最小二乘線性迴歸：斜率 b = Σ(xᵢ−x̄)(yᵢ−ȳ) ÷ Σ(xᵢ−x̄)²；截距 a = ȳ − b·x̄（x̄、ȳ 為樣本均值，組數 n 取 X、Y 兩組中較短者）；頁面另給 x=3 處預測 ŷ = a+b·3。校驗：X、Y 兩組逗號分隔資料非空守衛。判據：無固定分級，兩組長度不等時按較短長度對齊截斷。

由資料擬合最佳直線。

📌 計算說明
  • 最小二乘：b=Σ(x−x̄)(y−ȳ)/Σ(x−x̄)²。
  • a = ȳ − b x̄。

📚 深度解析：簡單線性迴歸

💡 常見使用場景

  • 擬合 y=a+bx：b=(nΣxy−ΣxΣy)/(nΣx²−(Σx)²)。
  • 預測與斜率顯著性。
  • 殘差診斷驗證線性假設。
擬合直線
x=[1,2,3,4]、y=[2,4,5,7]：b=(4×50−10×18)/(4×30−100)=(200−180)/(120−100)=20/20=1.0；a=(18−1.0×10)/4=2.0；y=2+1.0x。（注：用此資料 b=1.0、a=2.0）
預測
x=5：ŷ=2+1.0×5=7.0。

❓ 常見問題（FAQ）

斜率 b 含義？
x 每增 1 單位，y 平均變 b 單位；其顯著性與置信區間由 t 檢驗給出。
R² 與迴歸關係？
簡單迴歸 R²=r²，一元情形下回歸解釋力等於相關係數平方。

📊 結果解讀

結果含義

一元線性迴歸 y=a+b·x：用最小二乘法擬合直線，b 為斜率（x 每增 1 單位 y 的平均變化）、a 為截距。

用法

結果可用於預測與趨勢判斷；應結合相關係數 R² 評估擬合優度，外推需謹慎（超出資料範圍不可靠）。
