SCOPE Cognitive Assessment

SCOPE Cognitive Assessment - 8 subtests scored against 4 age-band norms into standard scores and percentiles, with a 4-axis radar, history trends and CSV/PNG export.

📖 Source: 分測驗範式來源：Wechsler D. WAIS-IV (2008)；Stroop JR. J Exp Psychol. 1935;18(6):643-662；Kirchner WK. J Exp Psychol. 1958;55(4):352-358；Reitan RM. Percept Mot Skills. 1958;8(3):271-276 (TMT)。本工具為上述經典範式的線上組合改編，非標準化常模量表。 | 8 subtests across attention / working memory / processing speed / executive function · practice then test · for longitudinal self-comparison, not clinical diagnosis
📐 計分模型：原始分 → 標準分 → 百分位
Z = (X − M_age) ÷ SD_age × dir　　SS = 100 + 15 × Z　　PR = Φ(Z) × 100

X 為原始分，M_age 與 SD_age 取自內建的四層年齡常模（18–29 / 30–49 / 50–69 / 70+），dir 為方向係數：反應時、干擾量、連線耗時等「越小越好」的指標取 −1，廣度、正確數、正確率等「越大越好」的指標取 +1。標準分 SS 採用韋氏量表的經典刻度（均值 100、標準差 15），落在 85–115 即為常模平均範圍；百分位 PR 由標準正態累積分佈 Φ 換算，用 Abramowitz–Stegun 有理逼近計算誤差函式，精度約 1.5×10⁻⁷。維度分為該維度下各分測驗標準分的算術平均，綜合分為全部分測驗標準分的算術平均。反應時類指標先做去極值處理：試次數 ≥5 時剔除最慢一次再求均值，以降低單次走神造成的偏差。

準備好了就點「開始評估」 全程約 12 分鐘，建議在安靜環境、用非觸屏裝置完成以獲得更準的反應時讀數。 每項測驗都會先顯示指導語與練習試次，練習成績不計入結果。

維度分測驗測量內容方向
注意力簡單反應時 · 選擇反應時警覺水平與反應準備，選擇反應時額外包含刺激—反應對映的決策成分越小越好
工作記憶數字廣度正背 · 數字廣度倒背 · 2-back言語資訊的短時保持容量；倒背與 N-back 還需在保持的同時做心理操作越大越好
加工速度符號數字模態 · 連線測試 TMT-A視覺掃描、符號編碼與運動輸出的整體速度，對疲勞與用藥最敏感速度類越快越好
執行功能Stroop 干擾 · 連線測試 TMT-B抑制無關資訊的干擾、在兩套規則之間靈活切換（認知靈活性）干擾量與耗時越小越好
常模說明：內建常模是依據公開文獻報告的均值與標準差整理的近似分佈（含 SDMT、TMT、Stroop、數字廣度的常見成人資料區間），用於把原始分放到同齡人分佈上得到相對位置，並非某一特定標準化樣本的官方常模表。裝置差異會直接影響反應時類指標：觸屏與藍牙鍵盤通常比有線鍵盤慢 20–60 ms，跨裝置比較意義有限，建議固定同一臺裝置做縱向對比。
⚠️ 使用邊界：本頁是娛樂與自測參考工具，用於觀察自己在不同狀態（睡眠、咖啡因、疲勞）下的認知表現波動，不構成臨床診斷，也不能用於篩查認知障礙、評定行為能力或作為任何醫學、職業、司法用途的依據。若你或家人對記憶、注意力的真實變化有擔憂，請到神經內科或記憶門診做規範評估。

💡 常見使用場景

  • 多域篩查：依次完成注意、記憶、速度、執行等子任務，彙總各域得分形成個人認知畫像。
  • 訓練前後對比：以初次測評作基線，間隔複測觀察各域變化，指導訓練側重。
  • 自我瞭解：用相對強弱項識別「記憶弱於速度」等模式，安排針對性練習。
各域畫像示例
注意力 82 分、工作記憶 74 分、加工速度 88 分、執行功能 79 分（相對百分制）；工作記憶相對偏低，可作為後續訓練側重方向，分數僅站內自評、非標準常模。

❓ 常見問題（FAQ）

分數代表什麼水平？
各域分數為站內相對自評（百分制示意），非標準化常模換算，僅用於個人橫向對比與訓練追蹤。
能發現認知衰退嗎？
不能。這是自評與訓練輔助工具，若擔心記憶或認知變化，請諮詢專業機構做標準測評。
多久複測一次合適？
建議間隔數週以上以減少練習效應，且儘量在同一時段、相近狀態下複測，結果更具可比性。
