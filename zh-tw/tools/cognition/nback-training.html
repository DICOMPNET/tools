N-Back Working Memory Training - Online Tool

The classic working-memory paradigm with single/dual channels and adaptive N, reporting d′ in real time.

📖 Source: Kirchner WK. Age differences in short-term retention of rapidly changing information. J Exp Psychol. 1958;55(4):352-358. | n-back working-memory paradigm · judge whether the current stimulus matches the one n steps back · typically 1-back / 2-back / 3-back
📐 計算原理
訊號檢測論（log-linear 校正）：命中率 HR = (命中 + 0.5) ÷ (訊號數 + 1)，虛報率 FAR = (虛報 + 0.5) ÷ (噪聲數 + 1)，辨別力 d′ = 逆正態CDF(HR) − 逆正態CDF(FAR)；逆正態 CDF 用 Acklam 有理逼近——p < 0.02425 與 p > 0.97575 走尾部多項式，中間段走中心多項式。自適應：連續 4 次正確則 N + 1（上限 9）。反應時 = round(performance.now() − 呈現時刻)。d′ 判讀：≥ 2.0 優秀、1.0–2.0 良好、< 1.0 偏低；刺激生成以 0.42 機率復現 N 步前的位置或值來製造命中試次

命中率 HR = 命中數 / 訊號試次數，虛報率 FA = 虛報數 / 噪聲試次數。採用 log-linear 校正（HR′=(H+0.5)/(S+1)，FA′=(F+0.5)/(N+1)）避免 0/1 extremes；z 分數由 Acklam 逆正態 CDF 近似給出，d′ = z(HR′) − z(FA′)。雙通道下位置與字母分別獨立計算 d′。自適應規則：連續 4 試次全對則 N+1（上限 9），連續 3 試次有誤則 N−1（下限 1）。

鍵位：單通道按 空格=匹配 / N=不匹配；雙通道 位置按 Q=匹配 A=不匹配，字母按 P=匹配 L=不匹配。亦可點選螢幕按鈕。開啟語音時字母會朗讀出來（僅字母材質）。

📚 深度解析：N-back 工作記憶訓練

💡 常見使用場景

  • 工作記憶訓練：從 2-back 起步，命中率穩定後提升到 3-back，漸進增加記憶負荷。
  • 敏感度（d′）測算：結合命中率與虛報率計算訊號檢測論指標，評估辨別力而非單純正確率。
  • 研究/自我追蹤：記錄不同 N 下的命中率、虛報率與反應時，觀察訓練前後的工作記憶容量變化。
2-back 命中率與敏感度
30 個靶刺激中命中 27、虛報 4/60 非靶；按工具實際採用的 log-linear 校正 HR′=(27+0.5)/(30+1)=0.887、FA′=(4+0.5)/(60+1)=0.074，d′≈z(0.887)−z(0.074)≈1.21−(−1.45)=2.66，辨別力較好。

❓ 常見問題（FAQ）

N 代表什麼？
N 表示「往前數第幾個」：2-back 即判斷當前刺激是否與它前面第 2 個相同，N 越大記憶負荷越高。
命中率高低就能說明記憶好壞？
不完全。高命中常伴隨高虛報，需結合虛報率算 d′（敏感度）才能區分「真記得」與「亂猜也蒙對」。
能替代記憶力臨床診斷？
不能。這是訓練與自評工具，結果受狀態、疲勞、練習效應影響，認知評估請交由專業機構。
