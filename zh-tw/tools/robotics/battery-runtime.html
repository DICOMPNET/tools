Battery Runtime Estimator

Input battery capacity Ah, nominal voltage V, and load power P, estimate runtime t = (Ah·V)/P, helping robot and UAV designers select battery capacity based on mission power budget.

📐 計算公式
續航時長 t(h) = 容量Ah × 電壓V ÷ 功耗W（Ah×V 先折算電池能量 Wh，再除以功率得小時數）。校驗：容量、電壓、功耗均為必填有效數值（必填校驗殼攔截空值/非數）。判據：電池能量（Wh）越大或功耗越低續航越長，t 與容量成正比、與功耗成反比。

輸入電池容量 Ah、電壓 V、負載功率 P，求續航時間。

📌 計算說明
  • t = (Ah·V)/P = Wh/P。
  • 2Ah·12V / 24W → 1 h。

💡 常見使用場景

  • 移動機器人續航估算。
  • 容量-電壓-功率換算。
  • 任務規劃電源匹配。
12V 2Ah 供 24W
t=Ah·V/P=2×12/24=1h；電池能量 24Wh 供 24W 負載可用 1 小時。
負載降到 12W
t=24/12=2h，功耗減半續航翻倍。

❓ 常見問題（FAQ）

Wh 與 Ah 關係？
能量 Wh=Ah×V；續航=Wh/P。
實際會打折嗎？
會；放電倍率、溫度、老化使可用容量低於標稱。
