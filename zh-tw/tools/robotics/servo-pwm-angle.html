Servo PWM-to-Angle Calculator

Convert PWM pulse width to servo angle using mapping relation. Input pulse-width-range values to convert within 0–180° servo angle for servo-control debugging.

📐 計算公式
舵機 PWM 轉角（本頁程式碼口徑）：轉角=(當前脈寬−最小脈寬)÷(最大脈寬−最小脈寬)×180（°，脈寬單位 µs，線性對映到 0–180° 行程）。校驗：三欄位經輸入守衛必填且須為合法數值，否則提示並中止。判據：無固定分級，脈寬等於最小÷最大脈寬時分別對應 0°÷180°，脈寬超出區間時角度按同一比例式線性外推顯示。

由 PWM 脈衝寬度求舵機轉角。

📌 計算說明
  • 1500µs（500–2500 範圍）→ 90°。
  • 常見舵機 1000–2000µs。

💡 常見使用場景

  • 舵機脈寬對映角度。
  • 50Hz 舵機控制。
  • 關節角度設定。
脈寬 1500μs、範圍 500–2500
θ=(1500−500)/(2500−500)×180=1000/2000×180=90°（中位）。
脈寬 2000μs
θ=(2000−500)/2000×180=135°，隨脈寬線性增大。

❓ 常見問題（FAQ）

標準脈寬？
常見 500μs=0°、1500μs=90°、2500μs=180°（50Hz）。
不同範圍？
更換 pmin/pmax 即可適配 180°/270° 等舵機。
