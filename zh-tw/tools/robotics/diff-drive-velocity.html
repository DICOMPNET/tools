📖 檢視「差速驅動線/角速度計算器 使用指南」

v = (v_r + v_l)/2，ω = (v_r − v_l)/L

Input left and right wheel speeds, compute robot overall linear and angular velocity using the differential-drive model, for wheeled mobile robot motion control and odometry.

📐 計算公式
差速驅動運動學：線速度 v = (右輪速 v_r + 左輪速 v_l) ÷ 2（m/s）；角速度 ω = (v_r − v_l) ÷ 輪距 L（rad/s）。校驗：v_l、v_r、L 三項非空合法數值守衛，L=0 時除零落兜底。判據：無固定分級，兩輪同速時 ω=0 走直線、差速越大轉彎越急。

由左右輪速度求機器人線速度與角速度。

📌 計算說明
  • v=(v_r+v_l)/2。
  • 兩輪不等速產生轉向。

📚 深度解析：差速驅動線/角速度

💡 常見使用場景

  • 兩輪差速底盤運動學。
  • 左右輪速求位姿變化率。
  • 里程計基礎。
左 0.5、右 1.0 m/s、輪距 0.4m
v=(vl+vr)/2=0.75 m/s，ω=(vr−vl)/L=0.5/0.4=1.25 rad/s。
等速直行
vl=vr → ω=0，純平移；反向則原地旋轉。

❓ 常見問題（FAQ）

輪距 L？
兩驅動輪間距離；ω=(vr−vl)/L。
與里程計關係？
位移 ds=(vl+vr)/2·dt、轉 dθ=(vr−vl)/L·dt。
