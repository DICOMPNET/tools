📖 檢視「機器人轉彎最大速度計算器 使用指南」

v_max = √(a_max · R)

Given maximum centripetal acceleration constraint, input turning radius and allowable acceleration to compute upper turning speed limit, preventing mobile robot sideslip.

📐 計算公式
轉彎限速 v_max = √(最大向心加速度 a_max × 轉彎半徑 R)（m/s，保留 3 位小數），由向心加速度約束 a = v² ÷ R 反解而來。校驗：無強校驗，非數輸入按 0 兜底。判據：半徑或允許加速度越大限速越高，v_max² ÷ R 恆等於 a_max。

受最大向心加速度約束的轉彎速度上限。

📌 計算說明
  • v_max = √(a_max·R)。
  • a=2、R=1 → 1.414 m/s。

📚 深度解析：轉彎限速

💡 常見使用場景

  • 差速機器人轉彎最大速。
  • 給定向心加速度上限。
  • 防側翻/打滑速度。
半徑 1m、a_max=2m/s²
v=√(a_max·R)=√(2×1)=1.41 m/s，超過則向心加速度超限。
半徑減半
R=0.5 → v=1.0 m/s，限速隨半徑平方根下降。

❓ 常見問題（FAQ）

a_max 取多少？
依打滑（μg）或側翻閾值定，常取 1–3 m/s²。
與角速度？
v=ωR，亦可寫為 ω_max=√(a_max/R)。
