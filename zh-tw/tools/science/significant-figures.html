🧮 Significant Figures Calculator

Normalise, round and format numbers to a specified number of significant figures for lab reports and data handling.

📐 計算公式 / 原理
有效數字修約（本頁程式碼口徑）：位數 n 先取整並夾取 [1,20]；量級 e=⌊log₁₀|x|⌋，修約因子=10^(n−1−e)，結果=四捨五入(x×因子)÷因子；另按科學計數法輸出（尾數至多 4 位小數、去尾隨零，指數為正補 + 號）。校驗：數值非有限或位數<1 時提示「請輸入有效數值與位數」並中止。判據：無固定分級，x=0 原樣返回，修約只改變有效位不改變數量級。
有效數字規則：非零數字與夾在中間的 0 有效、前導 0 無效、小數部分尾隨 0 有效；乘除取最少有效位數、加減取最少小數位數，本專案按此給出規範化結果。

📌 示例

  • 1.2345，2位有效數字 → 1.2
  • 0.0012300，3位有效數字 → 0.00123
  • 12345，2位有效數字 → 1.2×10⁴

❓ 常見問題（FAQ）

四捨五入規則？
4 舍 6 入，5 看前位奇偶（銀行家法）或進一。
乘除怎麼定位數？
結果的有效數字位數取參與運算各數中位數最少者。
