📐 工作原理與說明
組合數 C(n,r) = n! / (r! · (n−r)!)；對稱性 C(n,r) = C(n, n−r)；遞推 C(n,r) = C(n−1,r−1) + C(n−1,r)

Compute the number of ways to choose r items from n without repetition using C(n,r) = n! / (r!(n−r)!).

從 n 個不同元素中取 r 個的組合數：C(n,r) = n! / (r!·(n−r)!)

📚 深度解析：組合數 C(n, r)

💡 常見使用場景

  • 從 n 個取 r 個不計順序。
  • 抽獎選號或分組時計算不重複的組合總數。
計算
C(10,3)=10!/(3!·7!)=120。

❓ 常見問題（FAQ）

組合與排列？
組合不計順序 C(n,r)，排列計順序 P(n,r)=C·r!。
允許重複怎麼算？
可重組合數為 C(n+r−1, r)。
