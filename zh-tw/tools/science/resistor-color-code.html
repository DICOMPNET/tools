⚡ Resistor Color Code Decoder

📐 工作原理與說明
阻值 = 有效數字碼 × 倍率；允許區間 = 標稱值 × (1 ± 色環公差%)

Decode 4- and 5-band resistor colour codes into resistance and tolerance, or reverse-search the colours from a resistance value.

❓ 常見問題（FAQ）

四環與五環？
五環多一位精度環，讀法是有效數字不同。
色環方向怎麼定？
公差環（金或銀色）位於末端，據此確定讀數方向。
