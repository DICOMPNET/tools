📐 分壓公式

Vout = Vin × R2 / (R1 + R2)

Vin：輸入電壓
Vout：輸出電壓
R1：上拉電阻
R2：下拉電阻

🔄 逆推公式

R1 = R2 × (Vin/Vout - 1)
R2 = R1 / (Vin/Vout - 1)

已知目標輸出電壓時，可計算所需電阻值

⚡ 電路引數

• 迴路電流：I = Vin / (R1 + R2)
• 總功耗：P = Vin × I = Vin² / (R1 + R2)
• R1功耗：P1 = I² × R1
• R2功耗：P2 = I² × R2

💡 設計要點

• 電阻值不宜過小，以免功耗過大
• 電阻值不宜過大，以免受負載影響
• 建議選擇E24或E96系列標準電阻
• 考慮電阻精度對輸出的影響
• 輸出端接負載時需考慮負載效應

❓ 常見問題（FAQ）

負載影響？
帶載會降低輸出，需高阻輸入。
分壓電路耗電嗎？
耗電。分壓電阻本身有持續電流，電池供電場景需注意靜態功耗。
