📐 計算公式
n 次方根（本頁程式碼口徑）：結果=x^(1÷n)；x<0 且 n 為奇整數時取 −(−x)^(1÷n)，x<0 且 n 為偶整數時實數範圍內無解、n 非整數時無定義，x=0 時結果為 0；驗證式 (結果)ⁿ≈x 逐步展示。校驗：x、n 非數值，或 n=0（根指數不能為 0）時提示並中止。判據：n 為 2–8 的整數且 x>0 時另列出全部 n 個複數根 x^(1÷n)×(cos(2πk÷n)+i·sin(2πk÷n))，k=0…n−1。
n 次方根 ⁿ√x = x^(1/n)：n 為奇數時負數亦有實根，n 為偶數時僅非負數有實根；n=0 無定義。

❓ 常見問題（FAQ）

負根？
偶次根非負實根，奇次根可負（如 ∛-8=-2）。
與分數指數什麼關係？
ⁿ√a = a^(1/n)，二者等價。
