📊 Logarithm Calculator

📐 工作原理與說明
y = log_a(x)；換底公式 log_a(x) = ln x ÷ ln a；常用 ln x = log_e(x)、lg x = log_10(x)
對數 logₐx 是滿足 aʸ=x 的指數 y；定義域 x>0、a>0 且 a≠1。本頁並列輸出 log₁₀x、ln x、log₂x 與自定底數結果，自定底數按換底公式 ln x / ln a 計算。

Compute base-10 logarithms, natural logarithms and logs to any base, with base-change support for decibels and scaling work.

💡 常見使用場景

  • 常用對數/自然對數。
  • 分貝、pH、地震震級等對數尺度量的計算。
計算
log₁₀(1000)=3；ln(e³)=3；log₂(8)=3。
📖 定義與公式
若 aʸ=x（a>0、a≠1、x>0），則 y=logₐx，即對數是指數運算的逆運算。常用性質：logₐ(x·y)=logₐx+logₐy、logₐ(x/y)=logₐx−logₐy、logₐ(xⁿ)=n·logₐx、logₐx=ln x / ln a（換底公式）。本頁固定輸出 log₁₀、ln、log₂ 三種常用口徑，並允許自定底數；底數 ≤0 或 =1 時提示無效。
⚠️ 適用條件與常見誤用
真數必須大於 0：輸入 0 或負數時頁面提示「真數 x 必須 > 0（對數定義域）」。 底數必須大於 0 且不等於 1；底數為 1 時任何真數都無法唯一對應指數。 log 與 ln 不要混用：工程與化學裡的 pH、分貝、震級多用 log₁₀，機率與連續增長多用 ln。 誤用一：把 logₐ(x+y) 寫成 logₐx+logₐy——加法沒有這條性質，只有乘積才能拆成和。 誤用二：把 logₐ(xⁿ) 與 (logₐx)ⁿ 混為一談，前者是 n·logₐx，後者是整體取冪。 顯示為 3 位小數，需要更高精度時應看頁面內部 12 位小數或自行用換底公式復算。
📊 多組輸入對照（實跑）
x = 1,000：log₁₀ = 3、ln = 6.908、log₂ = 9.966；換底步驟行同時給出 6.908 / 2.303 = 3。 x = 1,024：log₁₀ = 3.01、ln = 6.931、log₂ = 10，驗證行 2^10 = 1,024，是判斷「log₂ 是否算對」最直接的整數例。 x = 0.01：log₁₀ = -2、ln = -4.605、log₂ = -6.644，驗證行 10^-2 = 0.01；真數小於 1 時結果為負，不是算錯。 x = 0：頁面只輸出「真數 x 必須 > 0（對數定義域）」，不再給數值。 x = 8、底數 = 1：三種常用口徑仍會算出，但頁面同時提示「底數 n 必須 > 0 且 ≠ 1」，此時自定底數結果不可用。
🧭 使用場景與取值建議
對數把「乘法跨度」壓成「加減跨度」，因此凡數量級跨越幾個數量級的場景都優先用它：聲音用 dB = 20·log₁₀(p/p₀)，每 +20 dB 是 10 倍聲壓；酸鹼度 pH = −log₁₀[H⁺]，pH 每降 1 即氫離子濃度 ×10；地震震級每 +1 約對應能量 ×31.6。資訊理論裡 log₂ 直接給出位元數：8 種等可能狀態 = log₂8 = 3 bit。金融裡的「72 法則」也是 ln2 ≈ 0.693 的近似：年增長 8% 時本金翻倍約需 72/8 = 9 年。
x = 1,000
log₁₀(1,000) = 3（因為 10³=1,000）；ln(1,000) = 6.908（精確值 6.907755…，頁面保留 3 位）；log₂(1,000) = 9.966（精確值 9.965784…，頁面保留 3 位）。
自定底數 2
換底公式：log₂(1,000) = ln(1,000) / ln(2) = 6.908 / 0.693 = 9.966；頁面隨後用 2^9.966 = 1,000 做反向驗證。
精確可手算的例子
log₂(8)=3、log₃(81)=4、log₁₀(0.01)=−2；這三組整數結果可直接用於核對計算器口徑是否正確。

❓ 常見問題（FAQ）

換底公式？
logₐb=ln b/ln a。
log 與 ln 有何區別？
log 通常指以 10 為底的常用對數，ln 是以 e 為底的自然對數。
為什麼計算器只顯示 3 位小數？
頁面內部先算到 12 位小數，再按瀏覽器 locale 的預設規則保留最多 3 位；這是顯示口徑，不是計算精度缺失。
對數在生活裡有哪些用途？
pH=−log₁₀[H⁺]、聲壓級 dB=20·log₁₀(p/p₀)、地震震級、資訊熵都以對數壓縮跨度極大的數量級。
為什麼 ln(1,024) 是 6.931 而不是整數？
因為 1,024 = 2^10，ln(1,024) = 10·ln2 = 10×0.693147 = 6.931；只有以 2 為底時結果才是整數 10，換底公式恰好解釋了這一點。
底數為 10 時結果為什麼常帶小數？
log₁₀ 只在 10 的整數次冪上取整（如 100→2、0.01→-2），其餘真數都是無理數，頁面保留 3 位小數，反查時用 10^結果 驗證即可。
