🎯 Sample Size Calculator

📐 計算公式 / 原理
n₀ = z²·p(1−p)/e²　n = n₀ / [1 + (n₀−1)/N]
比例估計的樣本量：z 為置信水平對應分位數（95%→1.96）、p 為預期比例、e 為允許誤差；有限總體 N 時按第二式做修正。

📋 樣本量公式

無限總體：n₀ = z*² × p × (1−p) / E²  |  有限總體修正：n = n₀ / (1 + (n₀−1)/N)
關鍵引數：
• z*：置信水平對應的 z 臨界值（95% → 1.96）
• p：預期比例（取 0.5 時樣本量最大、最保守）
• E：可接受誤差範圍（按百分比填寫，如 5 表示 ±5%；內部按 0.05 參與計算）
• N：總體大小（有限總體時啟用修正）

📚 深度解析：樣本量計算器

💡 常見使用場景

  • 按置信度與誤差估所需樣本。
  • 問卷或實驗設計前估算所需的最小樣本量。
計算
Z=1.96、p=0.5、e=0.05 → n=Z²p(1-p)/e²≈384（95% 置信、±5% 誤差）。

❓ 常見問題（FAQ）

p 取多少？
未知時取 0.5 得最大樣本量。
總體較小時要修正嗎？
要。用有限總體修正 n' = n/(1+(n−1)/N)。
