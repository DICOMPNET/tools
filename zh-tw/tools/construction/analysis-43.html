📐 指標口徑與公式
單方指標 = 工程總費用 ÷ 體積（元/m³）；平米指標 = 工程總費用 ÷ 面積（元/m²）；延米指標 = 工程總費用 ÷ 長度（元/m）；僅對已填寫且大於 0 的基數生成指標行
單方指標（元/m³）= 總費用 ÷ 體積，用於混凝土、土方等按體積計量的分項；平米指標（元/m²）= 總費用 ÷ 面積，用於樓面、牆面、鋪裝等按面積計量的分項；延米指標（元/m）= 總費用 ÷ 長度，用於管道、護欄、幕牆等按延長米計量的分項。三個指標共用同一筆總費用，可同時得到不同計量口徑下的造價水平，便於橫向對比報價與編制概預算。輸入不得為 0 或負值。

📚 深度解析：單方 / 平米 / 延米指標換算與口徑

💡 常見使用場景

  • 工程概預算中按不同計量口徑折算造價指標
  • 材料用量與單價核算（混凝土、鋪裝、管道等）
  • 投標報價的橫向對比與合理性檢查
算例
總費用 120000 元：體積 80 m³ → 單方 1500 元/m³；面積 600 m² → 平米 200 元/m²；長度 250 m → 延米 480 元/m。
口徑選擇
混凝土、土方等按體積計量用單方指標；樓面、牆面按面積計量用平米指標；管道、護欄按延長米計量用延米指標。

❓ 常見問題（FAQ）

單方、平米、延米分別是什麼？
單方指每立方米（元/m³），平米指每平方米（元/m²），延米指每延長米（元/m，用於線性構件）。
三個指標可以同時用同一筆總費用嗎？
可以。它們共用同一筆總費用，只是除以不同的工程量基數，用於不同計量口徑下的造價對比。
基數為 0 或留空會怎樣？
對應指標不輸出；請至少填寫一個大於 0 的體積、面積或長度基數。
