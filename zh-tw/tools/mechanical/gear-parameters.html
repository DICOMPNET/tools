📐 工作原理與說明
分度圓 d = m·z；齒頂圓 da = d + 2(ha+x)m；齒根圓 df = d − 2(ha+c−x)m；基圓 db = d·cosα；中心距 a = (d₁+d₂)/2 + (x₁+x₂)m；傳動比 i = z₂/z₁（m 模數, α 壓力角, x 變位係數）

Key formulas: d1-2×(ha+c)×m+2×x1×m; d2-2×(ha+c)×m+2×x2×m; d1+2×ha×m+2×x1×m

💡 常見使用場景

  • 按模數、齒數與壓力角計算標準/變位直齒輪的幾何尺寸（分度圓、齒頂圓、齒根圓、基圓、中心距等）。
  • 變位齒輪設計時核算變位後的齒頂圓、齒根圓與實際中心距，避免干涉與根切。
  • 校核傳動比與中心距是否滿足結構設計約束。
公式
分度圓 d = m·z；齒頂圓 da = d + 2·ha*·m + 2·x·m；齒根圓 df = d − 2(ha*+c*)·m + 2·x·m；基圓 db = d·cosα；標準中心距 a = (d1+d2)/2；變位後中心距 a′ = a + (x1+x2)·m；齒距 p = π·m；傳動比 i = z2/z1。預設齒頂高係數 ha*=1、頂隙係數 c*=0.25、壓力角 α=20°。
算例
模數 m=2、z1=24、z2=36、α=20°、無變位（x1=x2=0）：d1=48、da1=52、df1=43、db1≈45.105 mm；d2=72、da2=76、df2=67、db2≈67.658 mm；中心距 a=60.000 mm；齒距 p≈6.283 mm；傳動比 i=1.500。若兩輪各變位 +0.5（x1+x2=1），齒頂圓相應增大、實際中心距變為 60+1×2 = 62 mm。

❓ 常見問題（FAQ）

基圓有什麼意義？
基圓是漸開線齒廓的生成圓，壓力角在基圓上為零；它決定漸開線形狀，也是判斷根切（齒數過少時刀具切入齒根）與計算重合度的幾何基礎。
為什麼要變位？
變位可避免少齒數齒輪根切、配湊中心距、改善齒面接觸強度與磨損均勻性；正變位使齒厚增加、抗彎強度提高，但齒頂會變尖，需控制變位係數上限並校核齒頂厚。
