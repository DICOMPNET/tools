📐 工作原理與說明
傳動比 i = d₂/d₁；帶速 v = π·d₁·n₁/60000 (m/s)；帶長 L = 2a + π(d₁+d₂)/2 + (d₂−d₁)²/(4a)；小輪包角 α₁ = 180 − 2·arcsin(|d₂−d₁|/(2a))·180/π (°)

Key formulas: 180-2×Math.asin(|(d2-d1)|÷(2×a))×180÷π; 2×a+π×(d1+d2)÷2+(d2-d1)^2÷(4×a); π×d1×n1÷60000

📋 設計公式

傳動比：i = D2 / D1（考慮滑差實際 i = D2/(D1·(1−ε))）
從動輪轉速：n2 = n1·D1/D2·(1−ε)
帶長：L = 2a + π(D1+D2)/2 + (D2−D1)²/(4a)
小輪包角：α1 = 180° − 2·arcsin((D2−D1)/(2a))×180/π ≥ 120° 為宜
線速度：v = π·D1·n1/60000 (m/s)，一般 v ≤ 25~30 m/s

💡 常見使用場景

  • 按主從帶輪直徑與中心距計算傳動比、帶速、帶長與小輪包角，完成 V 帶/同步帶初步選型。
  • 校核包角（宜 ≥120°）與帶速（宜 ≤25 m/s），避免打滑與離心力過大。
  • 考慮彈性滑動後的實際從動輪轉速核算，用於轉速鏈推算。
公式
理論傳動比 i = d2/d1；實際從動輪轉速 n2 = n1·d1/d2·(1−ε)，ε 為滑動率；帶速 v = π·d1·n1/60000（m/s，d 用 mm）；帶長 L = 2a + π(d1+d2)/2 + (d2−d1)²/(4a)；小輪包角 α1 = 180° − 2·arcsin[(d2−d1)/(2a)]·180/π。判定：α1 ≥ 120° 合格，v ≤ 25 m/s 合格。
算例
小輪 d1=120 mm、大輪 d2=360 mm、中心距 a=500 mm、n1=1450 r/min、滑動率 2%：i = 360/120 = 3.000；n2 = 1450×120/360×0.98 ≈ 473.7 r/min；v = π×120×1450/60000 ≈ 9.11 m/s；L = 2×500 + π×480/2 + 240²/(4×500) ≈ 1782.8 mm；α1 ≈ 152.2°。包角與帶速兩項判定均合格。

❓ 常見問題（FAQ）

為什麼要考慮滑動率？
帶傳動靠摩擦工作，存在不可避免的彈性滑動（通常 1~2%），實際從動輪轉速會略低於理論值；忽略它會導致輸出轉速與功率核算偏樂觀，精密傳動應改用同步帶。
包角不足會怎樣？
包角小則接觸弧短、摩擦力不足，易打滑並加速磨損、發熱甚至燒帶；工程上要求小輪包角 ≥120°，不足時應增大中心距或增設張緊輪。
