📐 計算公式（正時皮帶）
下次更換里程 = 基準里程 + 廠建議間隔（基準取上次更換里程，上次未填（0）時按 0 起算；間隔按所選車型查建議表，鏈條車型且間隔為 0 時走免維護分支，僅提示不做里程計算）。校驗：各里程輸入按非負處理（max(0, 值)）。
剩餘里程 = max(0, 下次更換里程 − 當前里程)，負值截 0 表示已超期。校驗：當前里程與上次更換里程均按非負處理。判據：剩餘里程 ≤0 判「已超期，立即更換」並提示已超 當前里程−下次更換里程 km。
使用進度 = (當前里程 − 基準里程) ÷ 廠建議間隔 × 100%，封頂 100%（基準里程與下次更換同口徑，上次未填按 0）。校驗：無強校驗，里程非負截 0。判據：剩餘里程 ≤ 間隔×10% 判「即將到期」（警告色），其餘為「狀態正常」。
日均里程 = 年均里程 ÷ 365（年均里程預設按 15000，輸入強制至少 1，按 max(1, 值) 兜底防除零）。校驗：無強校驗，非數按預設值。判據：日均里程越大同樣剩餘里程折算的剩餘天數越短，僅作時間餘量換算。
剩餘天數 = 剩餘里程 >0 時按 round(剩餘里程 ÷ 日均里程) 取整，剩餘里程為 0（已超期）時直接記 0。校驗：日均里程按 ≥1 兜底防除零。判據：剩餘天數與剩餘里程、進度條同源聯動展示保養時間餘量。
說明：正時鏈條（廠建議間隔 = 0）設計免維護，僅定期檢查張緊器與導板；正時皮帶按"里程或年限先到"更換，斷裂會頂氣門導致發動機大修。

📚 皮帶 vs 鏈條 對比

🔗 正時皮帶

• 材質：橡膠 + 玻璃纖維
• 噪音小、成本低
• 需定期更換（6-15萬km）
• 斷裂會導致發動機頂氣門，損壞嚴重
• 工作壽命可預測

⚙️ 正時鏈條

• 材質：金屬鏈條
• 噪音略大、成本高
• 通常免維護（設計壽命與發動機同壽）
• 極少斷裂，但可能拉長跳齒
• 需關注張緊器與導板磨損

一般日系（豐田/本田/馬自達）多采用正時鏈條，免維護；歐系（大眾/標緻/雪鐵龍）部分車型採用正時皮帶，需按週期更換。具體以隨車手冊為準。

⚠️ 正時皮帶故障預警訊號

🔊
發動機異響怠速時皮帶區域出現刺耳尖叫或拍打聲，可能皮帶鬆弛或磨損。
🚗
啟動困難 / 動力下降皮帶跳齒導致配氣正時偏移，點火不準、加速無力。
💧
皮帶可見裂紋 / 老化目視檢查發現橡膠硬化、龜裂、邊緣起毛，應立即更換。
🛢️
皮帶沾油發動機滲油侵蝕橡膠會加速皮帶老化，需先治漏再換帶。
⚙️
怠速抖動 / 故障燈亮鏈條拉長導致正時偏差，ECU 報故障碼，常見於高里程鏈條車型。
🚨 正時皮帶斷裂屬災難性故障，會導致活塞與氣門相撞，發動機大修費用高昂。達到更換里程務必提前更換，勿心存僥倖。

❓ 常見問題（FAQ）

皮帶和鏈條更換週期差多少？
正時皮帶多為橡膠件，廠建議 6–12 萬公里或 5–7 年更換；正時鏈條設計壽命更長（常稱免維護，但非永久），多以 20 萬公里為參考並靠異響/拉長判斷。皮帶斷了會頂氣門，必須按時換；鏈條靠狀態監測。
為什麼常建議連水泵一起換？
水泵與正時皮帶常同軸或同艙，拆裝重疊度高，單獨換皮帶後不久水泵漏液又要大拆，不如趁一次工時一併更換，總體更省且降低二次故障風險。
