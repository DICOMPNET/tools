三類損傷分域採集：鈍器傷 / 銳器傷 / 火器傷
鈍器傷：創口形態（星芒狀/線形/不規則形/挫傷）
　創緣特徵（挫傷帶/組織間橋/較整齊）→ 推斷致傷物（平面/棒狀/石塊/拳腳/墜落）
銳器傷：型別（切創/刺創/砍創/剪創）+ 形態（梭形/線形/哆開）
　創角特徵：雙銳角=雙刃｜一銳一鈍=單刃（鈍角為刀背側）｜雙鈍角需考慮其他可能
火器傷：創口型別（射入口/射出口）× 射擊距離（接觸/<30cm/30cm-1m/>1m）
　射入口：創口小、圓或橢圓、邊緣齊、有擦拭輪汙垢輪
　接觸射擊：槍口印痕 + 撕裂星芒創口 + 創內火藥顆粒
　射出口：創口大於入口、邊緣不規則、無挫傷帶、無火藥殘留、組織外翻
創口大小 = 長 × 寬（cm）

損傷型別選擇

鈍器傷 vs 銳器傷 鑑別要點

鑑別要點 鈍器傷 銳器傷
創緣不規則，有挫傷帶整齊，無明顯挫傷
創角鈍圓，不規則尖銳，整齊
創壁粗糙，有組織間橋光滑，無組織間橋
創腔口小底大（囊狀）口大底小（較淺）
出血外輕內重，皮下出血多出血明顯，外出血多
異物可留致傷物碎片較少異物殘留
骨折粉碎性/凹陷性骨折多見砍創可致骨折，較整齊

鈍器傷主要型別

• 表皮剝脫（擦傷）：真皮外露，可反映致傷物作用面形態

• 皮下出血（挫傷）：皮膚完整性未破壞，顏色隨時間變化（紅→紫→綠→黃）

• 挫裂創：鈍力致皮膚全層裂開，創緣不齊，有組織間橋

• 骨折：直接外力致骨折（粉碎、凹陷），間接外力致遠離部位骨折

銳器傷主要型別

• 切創：長軸方向切割，創口梭形，創角銳利，出血多

• 砍創：力大且重，創口深可達骨質，常伴骨折

• 刺創：創口小而創道深，常傷及內臟，致命性高

• 剪創：剪刃剪下致創，可呈"V"形或線形

方法
按形態描述：表皮剝脫（擦傷）邊界、挫裂創（創緣鈍、創角鈍、有組織間橋）、切創（創緣齊、創角銳）、砍創（深達骨、峽部深）；結合部位、大小（長×寬）生成標準化記錄。
算例
頭部表皮剝脫 5×1 cm、邊界規則、表面有平行溝紋 → 鈍器擦傷（如棍棒拖擦）；同區創口梭形、創角鈍、中央有組織間橋 → 挫裂創，支援鈍性打擊而非刃器切割。

❓ 常見問題（FAQ）

創角鈍就一定不是刀傷嗎？
多為鈍器挫裂創特徵；刃器切/砍創角銳、有組織間橋少，但薄刃反覆切割或骨擋也可鈍化，需結合創壁、間橋綜合。
標準化描述有什麼用？
統一術語利於文書規範、同行複核與資料庫比對，減少主觀詞（「較大創口」）歧義，便於致傷機制重建。
