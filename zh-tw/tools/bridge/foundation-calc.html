📐 計算公式
Ra = up·Σ(qsi·li,eff) + qp·Ap

單樁豎向承載力特徵值 Ra = 樁周總側阻 + 樁端阻力
側阻有效長度逐層截斷：l1,eff = min(l1, L)、l2,eff = min(l2, L − l1,eff)、l3,eff = L − l1,eff − l2,eff（不小於 0），超出樁長的土層厚度不計入側阻
up = π·d（樁周長），Ap = π·d²/4（樁端面積）
需要樁數 n = N / Ra（取整，並適當富餘）

💡 本公式適用於摩擦樁及端承摩擦樁；端承樁以樁端阻力為主。承載力特徵值已含安全係數，實際設計須按《建築樁基技術規範》JGJ 94 驗算。

📚 深度解析：樁基礎承載力計算

💡 常見使用場景

  • 摩擦樁單樁承載力估算：按樁徑、樁長與各土層側阻/端阻算出 Ra，再由上部荷載確定樁數。
  • 樁型方案比選：比較不同樁徑、樁長下側阻與端阻的佔比，判斷以側阻為主還是端阻為主。
  • 樁數初估與布樁：按 Ra 取整並結合承臺尺寸、群樁效應與上部荷載留富餘，供方案階段估算。
演練示例（預設引數）
樁徑 d=1.2 m、樁長 L=25 m、qp=1200 kPa，土層側阻 45/60/80 kPa、厚度 10/10 m（第三層取剩餘 5 m），上部荷載 12000 kN：up=π×1.2≈3.77 m、Ap=π×1.2²/4≈1.131 m²；總側阻=3.77×(45×10+60×10+80×5)=3.77×1450≈5466.4 kN，總端阻=1200×1.131≈1357.2 kN，Ra≈6823.5 kN（側阻約佔 80.1%、端阻 19.9%）；樁數 n=ceil(12000/6823.5)=2 根，單樁承擔 6000 kN。

❓ 常見問題（FAQ）

側阻與端阻特徵值從哪裡取？
由岩土勘察報告或 JGJ 94-2008 經驗表給出，應取特徵值（標準值需按規範折減）；施工工藝（鑽孔、打入、後注漿）會顯著改變側阻取值。
為什麼第三層側阻不用輸入厚度？
本工具按樁長逐層截斷：前兩層厚度先扣減，剩餘樁長自動歸入第三層，超出樁長的土層不參與側阻，避免把無效土層計入。
樁數算出來能直接布樁嗎？
n 僅按上部荷載與單樁 Ra 取整；實際布樁還需考慮承臺尺寸、群樁效應、偏心彎矩、沉降與構造要求，並留適當富餘。
