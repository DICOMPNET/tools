🧮 Aspheric Aberration Calculator

Compute spherical aberration of an aspheric surface from curvature and conic constant.

📐 計算公式

球面像差 LSA = (n−1)·h² / (2·n·R) · (1 + k/n²)；k 為圓錐常數

非球面相對球面像差的修正項：球面貢獻為 (n−1)h²/(2nR)，再乘以 (1+k/n²)；k=0 退化為球面，k=−n² 為最佳補償。

📐 錐面面型資料（不同口徑位置）

📊 橫向像差曲線（相對傍軸焦點面）

縱軸 = 相對口徑 (hᵢ/h)，橫軸 = 橫向像差 TRA (μm)，藍色為球面(K=0)，橙色為當前錐面(K)

💡 三級球差公式（無限遠物距，單折射面 air→glass）：縱向球差 LSA = (n−1)·h² / (2nR) × (1 + K/n²)；最佳錐面常數 K_opt = −n²；橫向像差 TRA = LSA × (h/f)，f = nR/(n−1)

⚠️ 使用說明與注意事項
  • 適用於無限遠物距（平行光入射）的單折射面近似，採用三級像差理論
  • 錐面常數 K：K=0 球面，K=−1 拋物面，K<−1 雙曲面，−1<K<0 橢球面
  • 錐面方程：z = c·r² / (1 + √(1 − (1+K)·c²·r²))，其中 c = 1/R

📚 深度解析：非球面（球差）矯正與最佳錐面常數

💡 常見使用場景

  • 單折射面設計：按折射率求最佳錐面常數 K，用非球面抵消三級球差。
  • 引數校核：對比球面（K=0）與當前 K 的縱向球差、邊緣橫向像差。
  • 工藝溝通：把最佳 K 與矢高（sag）交給非球面加工方作為面形目標。
方法
演算法：傍軸焦距 f = nR/(n−1)；球面縱向球差 LSA = (n−1)h²/(2nR)，取錐面常數 K 後 LSA = LSA球面×(1+K/n²)，令括號為零得最佳錐面常數 K = −n²；邊緣橫向像差 TRA = LSA×(h/f)；F 數 = f/(2h)、NA = h/f。錐面型別：K<−1 雙曲面、K=−1 拋物面、−1<K<0 橢球面、K>0 扁橢球面。
算例
例：n=1.5、R=100mm、h=10mm → f = 1.5×100/0.5 = 300mm、F/15、NA=0.0333，球面（K=0）縱向球差 LSA = 0.5×100/(2×1.5×100) = 0.1667mm = 166.7μm；取最佳 K = −n² = −2.25 後球差項歸零，邊緣橫向像差隨之大減。

❓ 常見問題（FAQ）

K = 0 和 K = −1 分別是什麼面形？
K=0 是球面，K=−1 是拋物面；−1<K<0 為橢球面（對無限遠物距的反射面最常用），K<−1 為雙曲面，K>0 為扁橢球面。本工具按 K = −n² 給出使三級球差歸零的最佳值。
為什麼球差不隨口徑線性變化？
三級（Seidel）球差的縱向量正比於通光半口徑的平方、橫向像差正比於三次方，口徑加倍縱向球差約增大 4 倍；所以收小光圈收效很快，非球面則用來在大口徑下同時壓制球差。
