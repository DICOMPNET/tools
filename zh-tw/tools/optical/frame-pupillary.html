👓 Frame PD and Eye Size Calculator

📐 計算公式
眼鏡移心：幾何中心距 = 鏡圈尺寸 A + 鼻樑寬 DBL、單眼瞳距 = PD ÷ 2，單眼移心量 = 幾何中心距 ÷ 2 − 單眼瞳距（正值向鼻側內移）；最小片徑 = ED + 2×|移心量| + 2（含 2mm 磨邊餘量）。校驗：無強校驗，非數按 0 兜底、ED 預設取 A。分級：|移心量| >4mm 紅色警告移心量過大、>2mm 黃色偏大、其餘綠色適中。

Match spectacle frame dimensions (eye size, bridge, BVD) to the wearer's pupillary distance.

幾何中心距 = A + DBL（兩鏡圈幾何中心間距）
單眼移心量 = (A + DBL) / 2 − PD / 2，正值表示向鼻側(內)移心，負值向顳側(外)移心
最小未切邊片徑 = ED + 2×|移心量| + 2mm 磨邊餘量
移心量過大需更大直徑鏡片或定製片，實際還需考慮散光軸位與稜鏡移心。結果供配鏡加工參考。

📚 深度解析：鏡架瞳距適配

💡 常見使用場景

  • 配鏡按雙眼瞳距定光學中心距。
  • 鏡架幾何中心常與瞳距差需移心。
  • 移心誤差致稜鏡效應。
移心計算
瞳距 PD=64mm、鏡架幾何中心距 70mm → 每片內移 (70−64)/2=3mm；若處方面不移會產生底向外稜鏡。
誤差影響
每 1mm 移心、−3.00D 產生 0.3Δ 稜鏡，超 2mm 明顯視物偏斜，須精準移心或選窄架。

❓ 常見問題（FAQ）

為什麼鏡架要合瞳距？
光學中心不對準瞳孔會產生稜鏡效應致視疲勞/斜看，PD 與架距差大必須移心或換架。
單眼瞳距也要測？
要。雙眼 PD 均分不總對，尤其臉不對稱，漸進片必測單眼 PD 與高度。
