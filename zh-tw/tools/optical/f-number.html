F-Number Calculator

Compute the photographic f-number and depth-of-field hints from aperture diameter.

📐 計算公式
光圈數 N = 焦距 f ÷ 有效孔徑 D；相對孔徑倒數 = D ÷ max(f, 10⁻⁹)；通光面積 = π×(D÷2)²；EV = ln(N²) ÷ ln2。校驗：f、D 兩項非空數值守衛。判據：N 越大光圈越小、通光面積按孔徑平方縮減，EV 隨 N 增大而增大。

由焦距與有效孔徑，按 N = f/D 計算攝影鏡頭光圈數。

📌 計算說明
  • N 每增大 √2 倍，進光量減半；景深隨 N 增大而增大。

📚 深度解析：光圈數 F 值

💡 常見使用場景

  • 由焦距與口徑算 F 數（F=f/D）。
  • F 數決定進光量與景深。
  • 通光面積∝1/F²。
基本換算
焦距 50mm、口徑 25mm → F=50/25=2.0（F2 大光圈）；口徑 12.5mm → F=4.0。
進光量
F2→F4 口徑減半、進光量降 1/4（差 2 檔）；F 數每×√2 進光減半，景深隨之變深。

❓ 常見問題（FAQ）

F 數小光圈大？
對。F=f/D，D 大則 F 小、進光多、景深淺，背景虛化強。
景深和 F 數？
F 數大（小口徑）景深深、前後都清；F 數小景深淺、虛化強。
