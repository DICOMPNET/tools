📐 計算公式

按 |度數| 與 目標（薄/價效比/光學）閾值推薦折射率檔位（1.50 / 1.56 / 1.60 / 1.67 / 1.71 / 1.74）

低度數選低折射率（色散小），高度數選高折射率（更薄），光學優先在高度數時跳過高色散檔（1.67/1.74）選 1.70/1.71。

邊緣厚度估算(負鏡)：t_edge = ct + D²×|F| / (2000×(n−1))，D為直徑(mm)，F為度數(D)。 阿貝數越高色散越小，光學品質越佳；折射率越高鏡片越薄但阿貝數通常越低。
本工具估算結果僅供參考，實際鏡片厚度受中心厚度、基彎、鏡框形狀等因素影響，請以驗配機構資料為準。

💡 常見使用場景

  • 同度數不同折射率比邊緣厚度。
  • 高折減薄但色散權衡。
  • 選折射率看度數與架型。
厚度對比
−6.00D：1.50 邊緣 8.0mm、1.60 約 7.0mm、1.74 約 5.8mm，折射率越高越薄，減 12%–27%。
色散權衡
折射率升阿貝數常降（1.50 阿貝 58、1.74 約 33），高折彩邊明顯，中低度選 1.60 平衡。

❓ 常見問題（FAQ）

折射率越高越貴？
一般越高越貴且越薄，但色散增大；不是越高度越好，按度數選。
阿貝數是什麼？
色散倒數，越高色散越小、視物越銳；低阿貝片邊緣可見彩邊。
