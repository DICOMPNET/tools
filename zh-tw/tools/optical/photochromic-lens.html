👓 Photochromic Lens Reference

Reference the UV response and fade time of photochromic spectacle lenses.

變色鏡片：透光率隨紫外強度與溫度變化，溫度越高變色越淺；按溫度與 UV 強度調整變暗/褪色時間，估算即時透光率。
變色片在紫外激發下變深，溫度升高會"競爭性"抑制變深(高溫變淺)。 變深時間約15-60秒；褪色(室內回覆)時間約2-8分鐘，溫度越低褪色越慢。

📚 深度解析：變色鏡片

💡 常見使用場景

  • 按紫外強度與溫度估變色深淺。
  • 室內無色、戶外自動變深。
  • 對比基片染與膜層變色。
變色條件
紫外線強（戶外）觸發銀鹵化物變深，透光率可由 85% 降到 35%；進室內無紫外數分鐘褪回。
溫度影響
溫度高變色淺（熱平衡偏無色），夏天數九比冬天淺；車內因玻璃隔 UV 幾乎不變，需專用車內變色片。

❓ 常見問題（FAQ）

車內為什麼不變？
汽車玻璃擋大部分 UV，變色片靠 UV 觸發，故普通變色在車裡不變深，需「車內變色」配方。
壽命多久？
反覆變色約 2–3 年明顯變慢/殘留底色，紫外線強地區更短。
