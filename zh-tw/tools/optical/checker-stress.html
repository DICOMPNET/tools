✅ Photoelastic Stress Analyzer

📐 計算公式
玻璃內應力（光程差法）：主應力差 σ = N × f ÷ d，N 為光彈條紋數、f 應力光學常數(nm/cm·MPa)、d 板厚(cm)；應力差 小於5MPa 極小、5–15 中等、大於15 偏大（鋼化玻璃需達 90MPa 以上）。

Analyze photoelastic stress patterns in transparent optical elements.

Formula & Standard References

Item Formula / Note Source / Standard
Stress-optic law Δn = C · ( sigma1 - sigma2 ), where C is the stress-optic coefficient Brewster D. (1816); Frocht MM, Photoelasticity (1941), Wiley
Optical path difference delta = C · ( sigma1 - sigma2 ) · t, where t is the path thickness Frocht MM, Photoelasticity (1941), Wiley
Fringe order N = delta / lambda, where lambda is the monochromatic wavelength Frocht MM, Photoelasticity (1941)
Recovering the stress difference sigma1 - sigma2 = N · lambda / ( C · t ) Frocht MM, Photoelasticity (1941)
⚠️ 使用說明與注意事項
  • 應力-光學定律：σ₁ - σ₂ = N × f / d（MPa）
  • 條紋級數N通過偏振光干涉儀（正交偏振場）讀取
  • 鋼化玻璃殘餘應力：表面壓應力應>90MPa，中心張應力<45MPa
  • 光學元件雙折射：精密級<10nm/cm，普通級<50nm/cm
  • 純前端執行，資料不會上傳到伺服器

💡 常見使用場景

  • 裝配後偏光鏡下看應力斑判裝配合格。
  • 應力過大易崩邊/畸變。
  • 驗收鏡片裝配質量。
應力判讀
偏光鏡觀察無彩色條紋/區域性亮斑=合格；邊緣明顯彩紋=裝夾過緊，需松框重灌以免長期應力致崩邊。
標準
應力等級 0–3，≤1 合格、2 需複檢、3 不合格；塑膠架比金屬架更易過夾，須控力矩。

❓ 常見問題（FAQ）

為什麼查應力？
裝配過緊產生雙折射與畸變，長期可致鏡片開裂，尤其 PC/高折片敏感。
自己能看嗎？
需偏光片+標準光源，肉眼看不出，門店用應力儀客觀判級。

📝工具簡介

偏振光應力分析工具，利用應力-光學定律（σ=N×f/d）計算透明件主應力差，支援硼矽玻璃/鈉鈣玻璃/PMMA/PC等多種材料，自動判定應力等級。
