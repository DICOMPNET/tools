🧮 AC/A Ratio Calculator

Compute the accommodative convergence to accommodation (AC/A) ratio from prism and fixation tests.

📐 計算公式

AC/A（梯度法）= (加鏡後隱斜 − 裸眼隱斜) / |鏡片度|；AC/A（計算法）= IPD(cm) + (近隱斜 − 遠隱斜) / (100 / 近距 cm)

梯度法用加鏡前後隱斜差除以鏡片度；計算法以瞳距加上隱斜差除以調節需求（100/近距cm）求得每屈光度引發的集合量（Δ/D）。

梯度法：AC/A = (隱斜加鏡片後 − 隱斜無鏡片) / 鏡片度數。隱斜外隱斜記為+，內隱斜記為−。
計算法：AC/A = IPD(cm) + (近距隱斜 − 遠距隱斜) / 調節需求(D)。調節需求 = 100/距離(cm)。

📋 AC/A 比值參考

AC/A (Δ/D)型別表現處理
3-5正常調節-集合協調無需處理
<3低AC/A集合不足，外隱斜集合訓練/BI稜鏡
>6高AC/A集合過強，內隱斜下加光/BO稜鏡
>8顯著高AC/A調節誘發內斜下加光+視覺訓練
高AC/A是調節性內斜視的重要指標，下加光可減少調節性集合。AC/A評估需結合隱斜與調節幅度綜合判讀。
AC/A測量受檢查方法、注視距離與鏡片精度影響，臨床應以規範雙眼視功能檢查為準。

📚 深度解析：AC/A 調節性集合比率

💡 常見使用場景

  • 用梯度法（梯度鏡片）估 AC/A 比值判斷隱斜性質。
  • 區分集合不足/過度，指導稜鏡或視覺訓練。
  • 斜視與視功能檢查輔助。
梯度法
不加鏡隱斜 +3Δ（外隱斜），加 +2.00D 鏡片後隱斜 −1Δ（內隱斜）→ AC/A=(−1−3)/2=−2... 取絕對值 2 Δ/D；正常約 4±2 Δ/D，偏低提示調節性集合不足。
計算法
AC/A = IPD(cm) + (近距隱斜−遠距隱斜)/調節需求(D)；IPD=6cm、差 4Δ、調節 2.5D → AC/A=6+4/2.5=7.6 Δ/D，偏高。

❓ 常見問題（FAQ）

AC/A 高或低說明什麼？
高=調節易誘發集合（內隱斜傾向），低=集合不跟調節（外隱斜傾向），決定稜鏡或訓練方案。
梯度法和計算法差很多？
梯度法反映即時反應、計算法含解剖因素，兩者差異大時需結合臨床判斷。
