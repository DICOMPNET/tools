👓 Polarized Axis Adjuster

Correct and set the polarization axis angle for polarized sunglasses.

📐 計算公式
配鏡傾斜誘導（本頁程式碼口徑，前傾角與面彎雙路）：等效球鏡 D=sph+cyl÷2；前傾角誘導柱鏡 cylPanto=D×tan²(前傾角)（@90°軸）、面彎誘導 cylWrap=D×tan²(面彎)（@180°軸）；總量 totalCyl=√(cylPanto²+cylWrap²)（兩正交軸 RSS 合成）；球鏡補償 ΔS=D×(tan²前傾+tan²面彎)÷3、有效球鏡=sph+ΔS。校驗：無強校驗，空值按 0 兜底。判據：軸位按主導方向——|cylPanto|>2×|cylWrap| 取 90°、反向取 180°、否則 atan2 歸 0–180°；totalCyl>0.25D 提示需補償，前傾角>12° 提示調至 8–12°、面彎>6° 建議定製補償。

根據鏡架前傾角(前傾)與面彎(包覆)計算傾斜誘導的柱鏡與有效軸位變化

傾斜誘導柱鏡(Martin法則三階近似)：
誘導柱鏡 C = D × tan²(θ)，D為等效球鏡度數，θ為傾斜角
球鏡增量 ΔS = D × tan²(θ) / 3
前傾角產生軸位 90° 柱鏡(垂直子午線)；面彎產生軸位 180° 柱鏡(水平子午線)。

📚 深度解析：偏光軸位誘導

💡 常見使用場景

  • 由鏡架俯角/包裹角算誘導柱鏡軸位。
  • 偏光片裝配軸位補償。
  • 避免偏光與散光軸衝突。
誘導軸位
鏡架俯角 panto 與包裹 wrap 給定 → 誘導柱鏡軸位=atan2(panto, wrap)；如 panto=10、wrap=17 → 軸位≈30.5°，裝配據此補償。
衝突規避
偏光振動方向若與散光軸近垂直會產生不可用眩光，須調軸位或選非偏光設計。

❓ 常見問題（FAQ）

偏光軸位重要嗎？
重要。軸位錯會削弱消眩效果甚至與散光片打架致視物不清， wraparound 鏡更敏感。
誘導軸位是什麼？
鏡架彎曲使入射光等效產生柱鏡，等效軸位即誘導軸位，處方面需計入。
