Optical Path Length Calculator

Compute optical path length and optical path difference for interference analysis.

📐 計算公式
光程：光程 OPL = 折射率 n × 幾何路程 L（mm）；聯動量：米口徑 = nL ÷ 1000（m）、折射率增量 = n−1、光程與 (n+1) 之比 = nL ÷ max(n+1,10⁻⁹)。校驗：無強校驗，空值按 0 兜底。判據：無固定分級，光程即同等傳播時間內光在真空中走過的距離，n 越大光程越長。

由折射率與幾何路程，按 光程 = n·L 計算光在介質中的等效真空路徑。

Formula & Standard References

Item Formula / Note Source / Standard
Definition of optical path length OPL = n · d, the product of refractive index and geometric distance ISO 80000-7:2019, Quantities and units - Part 7: Light and radiation
Fermat principle Light follows the path for which the optical path length is stationary, usually minimal Fermat P. (1662); Born M, Wolf E, Principles of Optics (7th ed.), Cambridge
Relation to phase Phase difference Δphi = (2·pi/lambda_0) · OPL, where lambda_0 is the vacuum wavelength Born M, Wolf E, Principles of Optics (7th ed.), Cambridge Univ. Press
Special case in vacuum In vacuum n = 1, so the optical path equals the geometric distance Born M, Wolf E, Principles of Optics (7th ed.)

📚 深度解析：光程計算

💡 常見使用場景

  • 由介質折射率與幾何路程算光程 OPL=n·L。
  • 干涉/等光程條件用。
  • 費馬原理等效空氣路徑。
單介質
n=1.5 的玻璃厚 10cm → 光程 OPL=1.5×10=15cm，等效空氣走 15cm 的相位延遲。
多段
空氣 5cm(n=1)+水 3cm(n=1.33) → OPL=5+3.99=8.99cm；干涉看各路 OPL 差是否為 λ 整數倍。

❓ 常見問題（FAQ）

光程是什麼？
幾何路程按折射率加權，反映相位累積；等光程即等相位，是干涉亮暗的判據。
光程和路程區別？
真空中相等；介質中光程=折射率×路程，比幾何路程長（光變慢）。
