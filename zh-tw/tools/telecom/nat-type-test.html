NAT Type Test

Query srflx mappings from 3 public STUN servers and infer cone vs symmetric NAT from port consistency.

📐 工作原理與說明
向多個 STUN 伺服器分別發起對映請求，比較返回的公網對映埠：若各伺服器看到的埠一致，多為錐形 NAT；埠各不相同則多為對稱 NAT。基於 STUN 的啟發式推斷，非精確檢測。

❓ 常見問題

結果準確嗎？
這是啟發式推斷，受多出口、運營商多級 NAT、STUN 可用性影響，僅供網路排查參考。
錐形和對稱有什麼區別？
錐形 NAT 對外埠固定，便於 P2P 直連；對稱 NAT 對每目標分配不同埠，P2P 更難穿透。
為什麼顯示無法判斷？
少於 2 個 STUN 返回有效對映時無法比較，通常是網路限制或 STUN 不可達。
