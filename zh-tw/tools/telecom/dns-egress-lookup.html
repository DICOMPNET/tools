DNS Egress Lookup

Explains how to reveal your recursive resolver IP using your own domain and DNS logs; this page provides no endpoint and degrades honestly.

📐 工作原理與說明
真實查詢 DNS 出口需要：① 在權威 DNS 為專屬子域開啟查詢日誌；② 頁面用隨機 token 載入圖片觸發一次解析；③ 從靜態介面按 token 取回解析器 IP。本頁不配置任何自有域名介面，因此只展示配置說明，不生成假結果。

❓ 常見問題

為什麼直接顯示配置說明？
DNS 出口 IP 必須從你自己的權威 DNS 日誌讀取，沒有自有域名和介面時無法真實測得，故不偽造資料。
DNS 出口 IP 有什麼用？
可判斷你的 DNS 查詢經由哪個遞迴解析器，用於排查 DNS 劫持或隱私洩露。
需要後端嗎？
需要自有域名和能讀取日誌的介面，本工具不提供也不上傳任何資料。
