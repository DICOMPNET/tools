Network Speed Test

Use Cloudflare speed endpoint: warm-up, repeated small requests for latency/jitter, multi-round downloads for median download speed.

📐 工作原理與說明
先預熱連線，再發 10 次小請求取延遲中位數與抖動；隨後對 1/5/10MB 各下載 2 輪，取下行速率中位數。測速端點為 Cloudflare 公共 __down 介面。

❓ 常見問題

這是專業測速嗎？
不是，僅用公共端點做粗略估算，受節點、時段、網路擁塞影響較大。
會消耗流量嗎？
會下載約 30MB 測試資料（多輪累加），請留意行動網路流量。
測速時要做什麼？
保持頁面在前臺、避免同時佔用頻寬，結果更穩定。
