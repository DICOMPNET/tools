📏 Wireless Video Link Distance (Friis)

Estimates maximum line-of-sight transmission distance via the Friis free-space path loss equation from transmit power, frequency, transmit and receive antenna gains and receiver sensitivity.

📐 計算公式
路徑損耗 Lp ≈ 20·log10(f) + 20·log10(d) + C（自由空間近似）
基於無線鏈路預算：圖傳距離由發射功率、收發天線增益、接收靈敏度與頻率決定（路徑損耗隨頻率與距離增大），用於無線圖傳裝置選型與覆蓋評估。
💡 Friis 公式：Pr = Pt + Gt + Gr − FSPL；FSPL(dB) = 20·lg(d_km) + 20·lg(f_MHz) + 32.44。令 Pr = 接收靈敏度，解得最大視距距離 d = 10^((Pt+Gt+Gr−Pr−20·lg(f)−32.44)/20) km。

⚠️ 使用說明與注意事項
  • 結果為理想自由空間視距距離，未考慮障礙物遮擋
  • 實際受多徑、干擾、人體遮擋、地面反射影響顯著
  • 5.8GHz 圖傳典型靈敏度約 −85 ~ −95 dBm

📚 深度解析：無線圖傳視距距離估算（Friis 路徑損耗）

💡 常見使用場景

  • 無線圖傳鏈路預算：輸入發射功率、頻率、收發增益與接收靈敏度，估視距最大距離
  • 方案選型：對比不同頻段/增益下的覆蓋
  • 現場排查：距離不達標時定位是功率、增益還是靈敏度瓶頸
方法
演算法（Friis）：EIRP = 發射功率 + 發射增益；鏈路預算 = 發射功率 + 發射增益 + 接收增益 − 接收靈敏度；FSPL(dB)=20log10(d_km)+20log10(f_MHz)+32.44；由預算反解 d_km = 10^((預算−20log10(f)−32.44)/20)；波長 λ=300/f（m）。
算例
例：20dBm、5.8GHz、收發各 3dBi、靈敏度 −90dBm → EIRP=23dBm、預算=116dB、距離≈2.6km、λ≈5.2cm。若 30dBm、2.4GHz、各 5dBi、−100dBm → 預算 140dB、距離≈99.5km、λ≈12.5cm。

❓ 常見問題（FAQ）

這是自由空間距離，現實更遠還是更近？
通常更近。Friis 僅算自由空間路徑損耗，實際還有遮擋、多徑、大氣與饋線損耗；山區/室內須用更保守模型（如 ITU-R 經驗模型）。
頻率越高距離越短？
同預算下 FSPL 隨頻率升高而增大，故高頻（如 5.8GHz）比低頻（如 915MHz）距離更短；高頻換來更大頻寬，須權衡。

📝工具簡介

無線圖傳距離估算器基於 Friis 自由空間路徑損耗公式，根據發射功率、頻率、收發天線增益與接收靈敏度，估算視距條件下的最大傳輸距離，適用於無人機圖傳、無線監控與對講鏈路規劃。

✨功能特點

  • Friis 公式鏈路預算計算
  • 輸出最大視距距離
  • 給出 EIRP 與可容許路徑損耗
  • 自動換算波長

🎯使用場景

  • 無人機圖傳鏈路評估
  • 無線監控覆蓋規劃
  • 對講機通訊距離估算
  • 天線選型與增益評估
