Service Status

Aggregate public status JSON from GitHub, Cloudflare, Vercel and npm with 5s timeout, showing unknown on failure.

📐 工作原理與說明
併發讀取各服務的公開狀態 JSON，把 indicator 對映為 operational / degraded / outage，並展示更新時間；讀不到時明確顯示 unknown，不猜測狀態。

💡 結果速讀

檢測會向你輸入的目標地址或公開介面發起請求，結果只在本地展示；最近一次成功結果僅儲存在本機瀏覽器（localStorage），不會上傳伺服器；結論僅供排查參考，不替代專業判斷。

❓ 常見問題

資料來源可靠嗎？
直接讀取各服務商官方狀態頁的公開 API，權威可靠。
為什麼顯示 unknown？
介面超時、CORS 限制或服務臨時不可用時顯示未知，不會臆測正常。
會定時重新整理嗎？
點選「重新整理狀態」重新讀取，本頁不自動輪詢以免產生持續流量。

🔗 相關工具

📡 CDN 節點探測輸入域名，向多個公共 DoH 解析與 CDN 節點發起請求，對比解析結果與響應時間； 🔗 DNS 出口查詢通過公共 DoH 介面解析域名，檢視本機出口解析到的 IP，用於排查 DNS 汙染與分流； 📚 IP 歸屬地查詢輸入 IPv4/IPv6，先本地校驗格式，再請求 ipwho.is（失敗回退 ipapi.co）展示… 🔍 NAT 型別檢測藉助 STUN 伺服器判斷本機 NAT 型別（全錐/受限/埠受限/對稱），用於 P2P 與聯機排查… 🔗 URL 可達性檢測對輸入 URL 發起請求並記錄狀態碼、耗時與跳轉，用於排查連結失效； 🔍 WebRTC 洩露檢測檢視 WebRTC 候選地址是否暴露真實內網/公網 IP，用於 VPN 洩露排查；
