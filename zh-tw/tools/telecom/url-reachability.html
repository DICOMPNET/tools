❓ 常見問題

為什麼不顯示 HTTP 狀態碼？
no-cors 模式下瀏覽器隱藏響應內容，只能判斷請求是否被網路層接受，無法讀取 200/404 等狀態碼。
可以探測內網地址嗎？
可以輸入內網 URL，但受瀏覽器混合內容與 CORS 策略限制，結果可能不準確。
支援哪些協議？
僅 http / https，省略協議時預設補 https://。
