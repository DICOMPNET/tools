自由空間路徑損耗 (FSPL) 計算，估算無線訊號傳輸損耗與接收功率。

📋 公式與說明

自由空間路徑損耗 (FSPL)：
FSPL(dB) = 20·log₁₀(d) + 20·log₁₀(f) + 32.44
（d 單位 km，f 單位 MHz）

接收功率：
Pr(dBm) = Pt + Gt + Gr − FSPL

典型場景：2.4GHz WiFi、5GHz WiFi、4G/5G 行動通訊、衛星鏈路等。
注：自由空間為理想模型，實際還需考慮大氣吸收、障礙物、多徑等附加損耗。

📚 深度解析：路徑損耗與接收功率估算

💡 常見使用場景

  • 基站或室分系統初設時，按頻率、距離與天線引數估算損耗與接收功率。
  • 對比 700 MHz / 2.6 GHz / 3.5 GHz 等不同頻段的覆蓋能力，為選頻提供依據。
  • 把估算結果與接收靈敏度比對，判斷是否需要加中繼或提高天線增益。
700 MHz 與 3.5 GHz 的覆蓋對比
同為 2 km：700 MHz → FSPL = 20log₁₀2 + 20log₁₀700 + 32.44 = 6.02 + 56.90 + 32.44 = 95.36 dB；3.5 GHz（3500 MHz）→ 6.02 + 70.88 + 32.44 = 109.34 dB，相差約 14 dB。在 Pt = 40 dBm、Gt = 15 dBi、Gr = 3 dBi 時，700 MHz 接收功率 = 58 − 95.36 = −37.36 dBm，3.5 GHz 為 58 − 109.34 = −51.36 dBm —— 頻率高 5 倍，接收功率低 14 dB，這正是低頻段覆蓋更好的原因。

❓ 常見問題（FAQ）

低頻段一定更好嗎？
覆蓋上低頻段損耗小、繞射強，但可用頻寬窄、容量低。5G 常用 3.5 GHz 做容量層、700 MHz 做覆蓋層，兩者互補而非替代。
室內場景能用這個模型嗎？
自由空間模型在室內會嚴重低估損耗。室內應疊加牆體穿透損耗（混凝土牆常 10–20 dB），或使用專門的室內傳播模型。
