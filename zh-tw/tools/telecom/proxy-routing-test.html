Proxy Routing Test

Probe domestic and global site groups separately to infer possible proxy routing mode with per-target details.

📐 工作原理與說明
併發探測國內組（百度/淘寶/QQ）與國外組（Google/GitHub/Cloudflare）的 favicon，按兩組的可達性組合推斷：全通、規則分流、全域性代理或網路故障。屬啟發式推斷，非讀取系統代理配置。

💡 結果速讀

檢測會向你輸入的目標地址或公開介面發起請求，結果只在本地展示，頁面不儲存查詢記錄；結論僅供排查參考，不替代專業判斷。

執行後自動生成解讀。

🕘 本機執行記錄與對比

最近一次成功結果只儲存在你本機瀏覽器（localStorage），不上傳。可展開對比本次與上次輸出的變化；換瀏覽器或清除站點資料後記錄會消失。

❓ 常見問題

這是讀取系統代理設定嗎？
不是，只通過外部站點的可達性差異推斷，無法讀取瀏覽器或系統的代理配置。
結果為什麼可能誤判？
站點改版、CDN 攔截、本地網路策略都會影響 favicon 可達性，結果僅供參考。
能測規則分流嗎？
當國內通、國外部分不通時，通常提示規則分流，但無法給出具體規則。

🔗 相關工具

📡 CDN 節點探測輸入域名，向多個公共 DoH 解析與 CDN 節點發起請求，對比解析結果與響應時間； 🔗 DNS 出口查詢通過公共 DoH 介面解析域名，檢視本機出口解析到的 IP，用於排查 DNS 汙染與分流； 📚 IP 歸屬地查詢輸入 IPv4/IPv6，先本地校驗格式，再請求 ipwho.is（失敗回退 ipapi.co）展示… 🔍 NAT 型別檢測藉助 STUN 伺服器判斷本機 NAT 型別（全錐/受限/埠受限/對稱），用於 P2P 與聯機排查… 🔗 URL 可達性檢測對輸入 URL 發起請求並記錄狀態碼、耗時與跳轉，用於排查連結失效； 🔍 WebRTC 洩露檢測檢視 WebRTC 候選地址是否暴露真實內網/公網 IP，用於 VPN 洩露排查；
