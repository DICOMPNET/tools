📐 工作原理與說明
tex = 1000 / 公支 Nm = 590.5 / 英支 Ne = 旦尼爾 D / 9

tex = g/km；Nm = m/g；Ne（英制棉紡）以 590.5 為常數；D = 9·tex。四者互相換算。

📚 深度解析：紗線（重量/長度/公定）換算

💡 常見使用場景

  • 按 tex 與長度互算紗線重量，核算單件用紗量
  • 不同回潮率下把淨重摺算為公定重量，公平結算
  • tex 與旦尼爾互轉（denier = tex × 9）
tex 轉旦尼爾
20 tex → denier = 20 × 9 = 180 D；即 20tex 合 180 旦，常用於長絲標註。
公定重量折算
淨重 1000 g、實際回潮率 6%、棉公定回潮率 8.5% → 公定重量 = 1000 × (1 + 8.5%) / (1 + 6%) ≈ 1023.6 g。

❓ 常見問題（FAQ）

為什麼要用公定重量？
紗線含水率隨環境變化，公定重量按標準回潮率折算，買賣計量才公平可比。
tex 和旦尼爾差在哪？
tex = g/km，denier = g/9km，旦尼爾多用於長絲、tex 多用於短纖與通用。
