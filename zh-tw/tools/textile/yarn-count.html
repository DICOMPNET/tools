📐 換算公式（以 tex 為基準）

tex = 1000g/km，1 tex = 10 dtex = D/9

tex = 590.54 / Ne

tex = 1000 / Nm

Nm = 1.6934 × Ne

D = 9 × tex = 5314.9 / Ne = 9000 / Nm

注：數值越大，定長制(tex/D)紗線越粗；定重製(Ne/Nm)紗線越細。

合股紗
雙股 30Ne 單紗合股 → 約 15Ne（支數減半、變粗）；tex 由 19.7 變約 39.4。

❓ 常見問題（FAQ）

合股支數怎麼算？
同支合股約支數減半（tex 加倍）；異支按重量平均。
tex 和支數反比對嗎？
對，tex 越小越細、支數越大越細，二者成反比關係。
