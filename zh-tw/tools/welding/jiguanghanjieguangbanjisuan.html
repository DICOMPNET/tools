📚 深度解析：雷射焊接光斑計算（焦斑/瑞利長度/功率密度）

💡 常見使用場景

  • 雷射焊工藝除錯：由功率、M²、焦距與光束直徑算焦斑與功率密度
  • 離焦量選擇：算不同離焦下的光斑尺寸，平衡熔深與焊縫寬度
  • 焊接模式判定：按功率密度區分熱傳導焊與深熔焊（匙孔）
方法
演算法：波長換毫米 λ = nm/1e6；衍射極限焦斑 d0 = 4λf/(π×光束直徑)；實際焦斑 d = M²×d0；焦斑半徑 w0 = d/2；瑞利長度 zR = π×w0²/λ；離焦光斑 dz = d×√(1+(離焦量/zR)²)；光斑面積 = π×(dz/2)²；功率密度 = 功率/面積（W/mm²），×100 得 W/cm²；>1×10⁶ W/cm² 為深熔焊（匙孔）、>1×10⁴ 為熱傳導焊、否則功率密度不足。
算例
例：2000W、M²=1.2、焦距 120mm、波長 1070nm、光束直徑 9mm、離焦 0 → 焦斑 21.8μm、瑞利長度 0.349mm、離焦光斑 21.8μm、面積 0.0003732mm²、功率密度 5.36×10⁶ W/mm²（5.36×10⁸ W/cm²），判定深熔焊（匙孔）。離焦改為 +2mm → 離焦光斑擴至 126.9μm、面積 0.012645mm²、功率密度降到 1.58×10⁵ W/mm²（1.58×10⁷ W/cm²），仍屬深熔焊但熔深明顯變淺。

❓ 常見問題（FAQ）

M² 是什麼，為什麼必須 ≥1？
M² 為光束質量因子，理想基模高斯光束 M²=1，實際雷射器 M²>1；M² 越大同樣聚焦條件下焦斑越粗、功率密度越低，直接決定能否進入深熔焊。
離焦量正負怎麼選？
正離焦（焦點在工件上方）光斑大、功率密度低，適合拼縫容錯與寬焊縫；負離焦（焦點在工件內部）熔深更大。實際常取微負離焦兼顧熔深與穩定性。
