Coordinate Increment from Distance and Bearing

Compute the coordinate increments (ΔN, ΔE) from a distance and a bearing.

📐 計算公式
座標正算：縱座標增量 ΔN = 平距 D × cos(方位角 α)、橫座標增量 ΔE = D × sin(α)（α 由度 × π ÷ 180 化弧度參與計算）；反算方位角 = atan2(ΔE, ΔN) × 180 ÷ π 化回度；增量平方和 = ΔN² + ΔE²（勾股復算口徑）。校驗：無強校驗，非數輸入按 0 兜底。判據：正反算互為逆運算，α = 0° 時只有 ΔN、α = 90° 時只有 ΔE，各項保留 3 位小數。

輸入距離 D 與方位角 α（度），求北向與東向增量。

Formula & Standard References

Item Formula / Note Source / Standard

Inverse check sqrt(ΔN^2 + ΔE^2) should return D, serving as a check GB 50026-2020, Code for engineering surveying
Azimuth definition Azimuth is measured clockwise from north, unlike the mathematical angle convention GB 50026-2020, Code for engineering surveying
📌 計算說明
  • 極座標到直角座標換算。
  • D=100,α=30° → ΔN≈86.6,ΔE=50。

📚 深度解析：偏距計算

💡 常見使用場景

  • 由基線距離與偏角算垂直偏距。
  • 道路邊線/管線偏移放樣。
  • 樁點橫向定位。
偏距
沿基線距離 50m、偏角 30° → 垂直偏距=50×sin30°=25m；偏角 90° 時偏距=全程=50m。
應用
道路中心線外 25m 布邊樁，用基線距+偏角快速釘樁，免逐點座標。

❓ 常見問題（FAQ）

偏距是垂直距離嗎？
是垂直偏距=基線距×sin(偏角)；若用斜距要乘 sin 而非直接等於。
偏角 0 什麼意？
偏距 0，點在基線上，無需橫移。
