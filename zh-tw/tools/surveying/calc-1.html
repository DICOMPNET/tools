📐 計算公式
水準閉合差平差（按權分配口徑）：閉合差 f_h = Σ觀測高差 − (終點高程 − 起點高程)；逐段改正數 v_i = −f_h × (權 f_i ÷ Σ權)（權取測站數或距離，Σ權 >0，否則 v_i 記 0）；平差後高差 = 觀測高差 + v_i，高程自起點逐段累加。容許閉合差：測站數口徑 4×√總測站數、距離口徑 12×√總里程(km)（mm）。校驗：測段數為 0 提示「請至少新增一個測段」，非數輸入按 0 兜底。判據：|f_h×1000| ≤ 容許閉合差 → 合格、否則超限。

輸入各測段高差觀測值及測站數（或距離），按測站數比例分配閉合差，計算平差後高差。

📌 計算說明
  • 閉合差 fh = Σh觀測 − (H終 − H始)
  • 改正數 vi = −fh × (ni / Σn) 或 −fh × (Li / ΣL)
  • 平差後高差 h′i = hi + vi
  • 容許閉合差：平地 ±12√K mm（K 為公里數），山地 ±4√n mm

💡 常見使用場景

  • 逐段累加得總里程（km）。
  • 多段折線總長核算。
  • 踏勘路線規劃。
累加
各段 1200+850+950+1000=4000 m → 總距=4000/1000=4.0 km，作為路線里程與油耗估算基準。
校核
與各段座標反算邊長之和對比，差大查漏段或重複計。

❓ 常見問題（FAQ）

和座標距區別？
座標距是兩點直線（弦），路線累加是沿路折線（弧），後者更長更貼近實際里程。
單位怎麼統？
統一 m 後 ÷1000 得 km，避免混用 ft/m 致里程錯。
