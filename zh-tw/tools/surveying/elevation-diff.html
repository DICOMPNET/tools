Closed Leveling Loop

Compute height differences and misclosure around a closed leveling loop.

📐 計算公式
水準測量高差計算（本頁程式碼口徑，逐站求和）：總高差 h=Σ(後視讀數ᵢ−前視讀數ᵢ)（m，逐站累加，前視缺失項按 0 補位）；平均站差=h÷後視測站數（m/站）。校驗：無強校驗，讀數按逗號分隔解析、缺失項按 0 兜底。判據：無固定分級，後視大於前視該站升高、反之降低；閉合差校核須另行具備起終點已知高程。

Σh = Σ(後視 − 前視)。

Formula & Standard References

Item Formula / Note Source / Standard
Theoretical condition of a closed loop For a closed levelling loop the sum of height differences is theoretically zero GB 50026-2020, Code for engineering surveying
Misclosure fh = sum h, the difference between observed and theoretical sums GB 50026-2020, Code for engineering surveying
Tolerance Limits are set by route length or station count, e.g. ±40·sqrt(L) mm or ±12·sqrt(n) mm GB 50026-2020, Code for engineering surveying
Distribution of misclosure Corrections are proportional to station count or distance and opposite in sign GB 50026-2020, Code for engineering surveying
📌 計算說明
  • 高差 = 後視 − 前視，逐站累加。
  • 閉合差應限差內。

📚 深度解析：高差計算

💡 常見使用場景

  • 由前後視讀數算高差。
  • 水準路線高差累積。
  • 沉降/隆起監測。
高差
後視 1.500、前視 0.950 → 高差=後視−前視=+0.550m（前點高 0.55m）。
累積
多站高差代數和得兩點總高差，閉合差=Σh−(終點已知−起點已知) 檢核。

❓ 常見問題（FAQ）

高差符號？
後視−前視為正表示前點高於後點，約定統一別反。
水準和三角高差？
水準直接測、最準；三角高差=斜距×cos(天頂)±儀高，受大氣折光影響。
