Highway Horizontal Curve Elements

Compute road centerline, cross-section and staking data for route design.

📐 計算公式
切線長 T = R·tan(α/2)；外距 E = R(sec(α/2)−1)；曲線長 L = R·α·π/180；弦長 C = 2R·sin(α/2)

圓曲線是道路中線的基本線形單元：切線長、外距、曲線長、弦長、中點垂距由半徑 R 與轉角 α 唯一確定，是中線測設放樣（主點 ZH/HY/QZ/YH/HZ）的必備要素。

💡 T = R·tan(α/2)；E = R(sec(α/2)−1)；L = R·α·π/180；C = 2R·sin(α/2)。

切線長與外距
R=300 m、α=60° → T=300×tan30°=173.205 m；E=300×(sec30°−1)=46.410 m。
曲線長
L=R·α·π/180=300×60×π/180=314.159 m；弦長 C=2R·sin(α/2)=300.000 m。

❓ 常見問題（FAQ）

圓曲線五要素是什麼？
切線長 T、外距 E、曲線長 L、弦長 C、中點垂距 M，由半徑 R 與轉角 α 唯一確定。
轉角 α 怎麼取？
由前後導線方位角之差得到；單位為度，公式用弧度需 ×π/180。
