公式
本期變化量 = 本期累計變形 − 上期累計變形；平均變化速率 = 末期累計變形 ÷ 監測期數；預警：累計變形 > 閾值 或 單期變化 > 速率閾值。
算例
W1 1.5、W2 3.8、W3 6.9、W4 9.4、W5 11.2 mm（閾值 10 mm、速率 2.5 mm/期）→ 期數 5、累計變形 11.20 mm（超閾值）；各期變化 1.5/2.3/3.1/2.5/1.8，最大單期變化 3.10 mm（W3，超速率）；平均變化速率 = 11.2/5 = 2.24 mm/期。

❓ 常見問題（FAQ）

累計變形沒超標就可以放心嗎？
不能。單期速率突變往往是失穩前兆，速率超閾值時應加密監測，即使累計量仍在閾值內。
第一期變化量怎麼算？
以 0 為起點，即第一期變化量 = 第一期累計變形量；其後各期為本期累計減上期累計。
