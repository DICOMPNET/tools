📐 計算公式
高斯-克呂格投影正算（CGCS2000 橢球 a=6378137、f=1/298.257222101）：3°帶 n = 四捨五入(L÷3)、L₀=3n；6°帶 n = ⌊L÷6⌋+1、L₀=6n−3（亦可自定義中央子午線）；縱座標 x = 子午線弧長 + N÷2·t·cos²B·l²·(1+高階項)；橫座標 y = N·cosB·l·(1+高階項) + 500000（500km 偏移，可前置帶號成完整橫座標）；子午線收斂角 γ = sinB·l·(1+高階項)。校驗：經緯度非數時僅清空結果。判據：無固定分級，成果供工程參考。

大地座標（經緯度）→ 高斯-克呂格平面座標（CGCS2000 橢球），含帶號、中央子午線與子午線收斂角

採用 CGCS2000 橢球（a=6378137，f=1/298.257222101）。高斯投影橫座標加 500km 偏移，並前置帶號。結果僅供工程參考，正式成果須經專業軟體嚴密計算。

📚 深度解析：座標系轉換

💡 常見使用場景

  • 地方獨立座標與高斯/大地座標互轉。
  • 不同工程座標系配準。
  • 四引數/七引數應用。
平移旋轉
兩系僅差原點與旋轉：x'=x cosθ−y sinθ+Δx，y'=x sinθ+y cosθ+Δy；θ=0.5°、Δ=50m 代入即得新座標。
尺度
加尺度因子 m：x'=m(x cosθ−y sinθ)+Δx，高精度需七引數（含高程與旋轉）配準。

❓ 常見問題（FAQ）

四引數夠嗎？
平面（2 平移+旋轉+尺度）夠；跨高程或大面積變形需七引數（含 3 旋轉+尺度）。
為什麼要轉？
設計用獨立系、成果報國家系，須統一才能拼接與驗收。
