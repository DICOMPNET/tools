Elevation on Vertical Curve from Grade and Length

Compute the elevation at any point on a vertical curve from the grade and curve length.

📐 計算公式
豎曲線高程（本頁程式碼口徑，按頁面 g₁/g₂/L 記號）：y=g₁×x+(g₂−g₁)÷(2L)×x²（x 為距曲線起點平距，與規範式 y=y₀+i·x+x²÷(2R) 數學等價，g₁ 即初坡 i、(g₂−g₁)÷L 對應曲率 1÷R）；聯動量：切線長 T=L÷2、外矢距 E=L×|g₂−g₁|÷8。校驗：四欄位經輸入守衛必填且須為合法數值，否則提示並中止。判據：無固定分級，拋物線形豎曲線按此式逐樁計算高程，坡差絕對值越大外矢距越大。

輸入前坡 g₁、後坡 g₂、曲線長 L 與距起點距離 x，求相對高程 y。

Formula & Standard References

Item Formula / Note Source / Standard
Vertical curve equation For a parabolic vertical curve: y = x^2/(2R), where x is the distance from the start JTG D20-2017, Design Specification for Highway Alignment
Expressed by gradient difference y = (i1 - i2) · x^2/(2L), where L is the vertical curve length JTG D20-2017, Design Specification for Highway Alignment
Vertical curve elements Key elements are radius R, curve length L, tangent T and external distance E JTG D20-2017, Design Specification for Highway Alignment
Design elevation Design elevation = gradient elevation ± vertical curve correction (minus for crest, plus for sag) JTG D20-2017, Design Specification for Highway Alignment
📌 計算說明
  • 拋物線型豎曲線常用公式。
  • g1=2%,g2=−1%,L=200,x=100 → 1.25 米。

📚 深度解析：縱坡交點高程

💡 常見使用場景

  • 兩坡度線求交點高程與樁號。
  • 豎曲線起止點定線。
  • 道路縱斷面設計。
交點
坡1：起點 100m、+2%/100m；坡2：從 300m 處 110m、−3%/100m。交點：100+0.02x=110−0.03(x−300)→100+0.02x=110−0.03x+9→0.05x=19→x=380m，高程=100+0.02×380=107.6m。
豎曲線
得交點後按豎曲線半徑 R 設拋物線過渡，避免折角突變。

❓ 常見問題（FAQ）

交點高程幹嘛？
是豎曲線頂點（變坡點）高程，縱斷面設計與標高控制基準。
為什麼用豎曲線？
直接折角駕駛顛、排水差，用拋物線/R 圓順過渡更平順安全。
