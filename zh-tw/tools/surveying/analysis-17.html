🗺️ Buffer (Radius) Analysis

Generate buffer zones around points, lines or polygons by a given radius and analyze the covered area.

📐 計算公式
點緩衝面積 = πr²；線緩衝面積（膠囊形）= 2rL + πr²；緩衝周長 = 2πr + 2L；線長為 0 時線緩衝退化為點緩衝

點緩衝面積=π×半徑²；線緩衝（膠囊形）面積=2×半徑×線長+π×半徑²；緩衝周長=2×π×半徑+2×線長。線長填 0 時僅計算點緩衝。

💡 常見使用場景

  • 以點地物（基站／監測站）為中心按半徑生成圓形緩衝，計算覆蓋面積與服務範圍。
  • 以線狀要素（道路／管線／河岸）為中心生成膠囊形緩衝，測算影響帶面積與周長。
  • 給定線長與半徑，評估施工退讓、用地紅線或生態緩衝帶的範圍規模。
示例：道路兩側緩衝
緩衝半徑 30 m、線長 100 m：點緩衝面積≈π×30²≈2827 ㎡；線緩衝（膠囊形）面積＝2×30×100＋π×30²≈8827 ㎡；緩衝周長＝2×π×30＋2×100≈389 m。線長填 0 時只算點緩衝。

❓ 常見問題（FAQ）

線緩衝面積為什麼比點緩衝多出 2×半徑×線長？
線緩衝是沿線段兩側各外擴半徑形成的矩形（面積 2rL）加兩端半圓（合起來一個圓 πr²），合計 2rL＋πr²；點緩衝只是 πr²。
周長怎麼算？
膠囊形周長＝兩條長邊 2L 加兩端整圓周長 2πr，即 2L＋2πr；半徑越大或線越長，覆蓋邊界越長。
