x' = x·cosθ − y·sinθ，y' = x·sinθ + y·cosθ。

📐 計算公式
平面座標旋轉（繞原點）：x′ = x·cosθ − y·sinθ、y′ = x·sinθ + y·cosθ（θ 旋轉角按度輸入、×π÷180 轉弧度參與計算）。校驗：無強校驗，空值按 0 兜底。判據：無固定分級，旋轉為正交變換、不改變點到原點的距離，結果保留三位小數。

x' = x·cosθ − y·sinθ，y' = x·sinθ + y·cosθ。

📌 計算說明
  • 逆時針為正。
  • 常用於座標轉換。

📚 深度解析：座標旋轉

💡 常見使用場景

  • 把點繞原點旋轉 θ 得新座標。
  • 軸線對齊/區域性系建立。
  • 圖形定向。
旋轉 90°
(1,0) 繞原點轉 90° → x'=1·cos90−0·sin90=0，y'=1·sin90+0=1 → (0,1)。
通用
θ=30°、點(2,0) → x'=2×0.866=1.732，y'=2×0.5=1.0 → (1.732,1.0)，用於把建築軸轉到正北。

❓ 常見問題（FAQ）

旋轉公式？
x'=x cosθ−y sinθ，y'=x sinθ+y cosθ；逆時針為正，注意符號與弧度。
和座標轉換關係？
旋轉是轉換的一部分，配合平移/尺度才完整（四引數）。
