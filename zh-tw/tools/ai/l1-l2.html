📐 計算公式 / 原理
L1/L2 正則懲罰（本頁程式碼口徑，三個權重 w1–w3）：L1 懲罰=λ₁×(|w1|+|w2|+|w3|)；L2 懲罰=λ₂×(w1²+w2²+w3²)；總懲罰=L1+L2，三項均保留 6 位小數。校驗：無強校驗，空值按 0 兜底。判據：無固定分級，λ₁、λ₂ 越大對應懲罰越重，權重全零時三項同時為 0。
L1 在 0 處不可導且梯度恆為 ±λ，會把不重要權重精確壓到 0，產生稀疏解可用於特徵選擇；L2 懲罰與權重成正比，越接近 0 推力越弱，只做均勻收縮、保留小權重，泛化通常更穩。二者混用即 Elastic Net。

📐 計算公式與說明

判讀與理論對照（本頁程式碼口徑，與上方公式互補）：總懲罰即正則項 λ₁‖w‖₁+λ₂‖w‖₂²，與上方三項共用同一組權重與係數；L1 項隨權重絕對值線性增長，趨向把小權重壓到 0 產生稀疏解；L2 項隨權重平方增長，趨向整體收縮權重幅值；增大 λ₁ 強化稀疏化、增大 λ₂ 強化平滑收縮，兩項疊加時同時生效。校驗：與上方共用同一組輸入，空值按 0 兜底。判據：無固定分級。

L1 產生稀疏權重，L2 使權重平滑。

📚 深度解析：L1 L2 正則化懲罰

💡 常見使用場景

  • 懲罰項加入損失：L_total=Loss+λ₁‖w‖₁+λ₂‖w‖₂²，統稱彈性網路(Elastic Net)。
  • L1 促稀疏(特徵選擇)，L2 促平滑(權重衰減)，二者互補。
  • 權重衰減(weight decay)本質是 L2，深度學習常用之穩定訓練。
組合懲罰
Loss=0.2, w=[3,−4], λ₁=0.01, λ₂=0.01：L1 懲罰=0.01×7=0.07，L2 懲罰=0.01×25=0.25，總損失=0.2+0.07+0.25=0.52。

❓ 常見問題（FAQ）

Elastic Net 比單獨 L1/L2 好在哪？
同時獲得稀疏性與分組穩定性，尤其特徵高度相關時比純 L1 更穩健；代價是多一個超參，需用交叉驗證調。
權重衰減和 L2 完全等價嗎？
在標準 SGD 下等價；但用 AdamW 時權重衰減與梯度解耦，實現不同、效果更優，不能簡單當作 L2 代入。

Use case L1 suits feature selection whereas L2 suits collinear predictors Tibshirani 1996, JRSS-B
