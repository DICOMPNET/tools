🧮 Model Accuracy Calculator

Compute overall accuracy and per-class accuracy from a confusion matrix, for model evaluation and error analysis reports.

📐 計算公式 / 原理
分類準確率（本頁程式碼口徑）：準確率=(真陽性 TP+真陰性 TN)÷(TP+TN+假陽性 FP+假陰性 FN)×100（%），保留 2 位小數。校驗：無強校驗，空值按 0 兜底；四項全 0 使分母為 0 時提示「部分結果無定義（分母為 0 或輸入為空）」。判據：無固定分級，準確率 100% 表示混淆矩陣對角線外全為 0。
分類模型最直觀的整體判對比例。它隱含"各類代價相同"的假設，當負樣本佔絕大多數時（如 99:1 的欺詐檢測），恆判負類即可拿到 99% 準確率卻毫無價值，此時必須配合精確率、召回率或 MCC 一起判讀。

📐 計算公式與說明

混淆矩陣判讀（與上方公式互補，同一組四格輸入）：TP/FN 刻畫真實正類被判對/漏判，TN/FP 刻畫真實負類被判對/誤報；本頁僅輸出總體準確率一項，精確率、召回率等派生指標未在頁面計算（定義式：精確率=TP÷(TP+FP)、召回率=TP÷(TP+FN)），類別不平衡時準確率高未必代表正類識別好。校驗：與上方一致，空值按 0 兜底。判據：無固定分級。

類別不均衡時準確率易誤導，應結合其他指標。

📚 深度解析：模型準確率

💡 常見使用場景

  • 整體準確率=(正確預測數)/(總樣本數)，按混淆矩陣 TP+TN 之和計算。
  • 各類別正確率=該類別預測正確數/該類別樣本數，揭示對少數類的表現。
  • 類別不平衡時整體準確率易虛高，需結合宏/微平均與混淆矩陣解讀。
整體與各類別
三類各 100 樣本，A 類對 90、B 類對 80、C 類對 60 → 整體準確率=(90+80+60)/300=76.7%；各類別 90%/80%/60%，可見模型在 C 類最弱。

❓ 常見問題（FAQ）

整體準確率高但某類很差是正常的嗎？
在不平衡或多類場景中常見，說明模型偏向多數/易分樣本。應報告各類別準確率與混淆矩陣，而非只看整體數字。
準確率和 F1 衝突聽誰的？
看業務代價。若漏檢/誤判代價高(醫療、風控)，優先看精確率/召回/F1 與具體類別指標，而非整體準確率。
