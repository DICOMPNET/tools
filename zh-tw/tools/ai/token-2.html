🔑 LLM Token Cost Estimator

Estimate API cost from input and output token counts and unit price, to budget a LLM feature before launch.

📐 計算公式 / 原理
輸入費用 = 輸入 tokens / 10⁶ × 輸入單價；輸出費用 = 輸出 tokens / 10⁶ × 輸出單價；人民幣 ≈ 美元 × 匯率
大模型 API 普遍按輸入與輸出分別計價，且輸出單價通常高於輸入，因此壓縮提示詞與控制生成長度都能直接省錢。換算人民幣時匯率按當期取值，另需考慮批次/緩存摺扣與最低計費粒度。

📐 計算公式與說明

費用判讀（與上式互補）：單項費用=Token 數÷1,000,000×每百萬單價（USD），輸入、輸出分開計價後相加為總費用；人民幣≈總費用×7.2（頁面固定匯率常數，非即時牌價）。校驗：無強校驗，空值按 0 兜底。判據：無固定分級，單價按 $/1M tokens 口徑，token 數翻倍費用同比例翻倍。

匯率按 1 USD ≈ 7.2 CNY 估算。

📚 深度解析：提示詞 Token 成本

💡 常見使用場景

  • 費用=輸入 token×輸入單價+輸出 token×輸出單價，按模型計費口徑估算。
  • 支援按 1 USD≈7.2 CNY 折算人民幣，輔助呼叫預算與成本對比。
  • 不同模型分詞器差異大，token 數需以對應模型為準，本估算為量級參考。
成本估算
輸入 10k token($0.01/1k)、輸出 2k token($0.03/1k) → 費用=10×0.01+2×0.03=0.16 USD≈1.15 元。批次呼叫前用此預判賬單。

❓ 常見問題（FAQ）

為什麼不同模型費用差很多？
單價隨模型能力與上下文長度差異大，且輸入輸出單價常不同；大上下文/強模型更貴，選型需權衡效果與成本。
估算的 token 數準嗎？
不準到精確位。中文在 GPT/Claude/國產模型下 token 數差異明顯，本工具給量級參考，精確計費以廠商賬單為準。
