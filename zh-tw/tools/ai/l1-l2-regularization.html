🔍 L1 / L2 Norm and Penalty Calculator

Compute the L1 and L2 norms of a weight vector together with the matching penalty terms, to build intuition about sparsity and shrinkage.

📐 計算公式 / 原理
L1/L2 範數（本頁程式碼口徑，四個權重 w1–w4）：L1=|w1|+|w2|+|w3|+|w4|；L2=√(w1²+w2²+w3²+w4²)，兩項均保留 3 位小數。校驗：無強校驗，空值按 0 兜底。判據：無固定分級，範數隨權重絕對值單調增長，權重全零時 L1 與 L2 同時為 0。
兩個範數量化權重矩陣的整體規模：L1 反映絕對值總量，對少量大權重敏感；L2（Frobenius 範數）反映能量，常被直接寫進損失作為懲罰項。監控範數隨訓練的變化能快速判斷是否出現權重爆炸。

📐 計算公式與說明

判讀與對照（本頁程式碼口徑，與上方公式互補）：由範數不等式恆有 L1≥L2，等號僅當至多一個權重非零時成立；權重同乘 c 後兩範數均乘 |c|（一次齊次）；對照圖按各權重繪製 |w| 與 w² 兩列——|w|<1 時 w² 更小、|w|>1 時 w² 更大，可直觀看出 L1 由大權重主導而 L2 相對壓低大權重貢獻。校驗：與上方共用同一組輸入。判據：無固定分級。

L1 傾向稀疏，L2 傾向小權重。

📚 深度解析：L1/L2 正則項

💡 常見使用場景

  • L1 範數 ‖w‖₁=Σ|wᵢ|，L2 範數 ‖w‖₂=√(Σwᵢ²)，分別衡量權重大小。
  • 對應懲罰項 λ‖w‖₁(Lasso,促稀疏)與 (λ/2)‖w‖₂²(Ridge,促平滑)。
  • 正則項加入損失函式，限制權重幅度以抑制過擬合。
範數計算
w=[3,−4]：‖w‖₁=|3|+|−4|=7；‖w‖₂=√(9+16)=5，L2 懲罰=(λ/2)·25。L1 對大權重同等懲罰，L2 更壓大權重。

❓ 常見問題（FAQ）

L1 為什麼能稀疏？
L1 在零點不可導、等高線為菱形，最優解易落在座標軸上使部分權重恰為 0，實現特徵選擇；L2 只縮小不置零。
正則係數 λ 怎麼選？
用驗證集網格/貝葉斯搜尋；λ 過小過擬合、過大欠擬合。通常對權重先標準化，再在 10⁻⁴~10 量級掃描。

Formula & Standard References

Item Formula / Note Source / Standard
L1 penalty the L1 penalty adds the sum of absolute weights and yields sparse solutions Tibshirani 1996, JRSS-B
L2 penalty the L2 penalty adds the sum of squared weights and shrinks large weights Hoerl & Kennard 1970, Technometrics
Strength coefficient a larger penalty coefficient tightens the constraint and over-regularises when too large Hastie et al., Elements of Statistical Learning
