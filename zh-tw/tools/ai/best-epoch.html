📐 計算公式 / 原理
最佳輪次判定（argmin 完整口徑）：最小驗證損失 minLoss = min(l₁…l₅)；最佳輪次 = 線性掃描取最小值所在輪（嚴格小於比較 a[i]<a[m]，並列時保留更早出現的輪次，下標+1 即輪號）。校驗：無強校驗，五輪驗證損失空值按 0 兜底。判據：無分級，minLoss 保留四位小數、最佳輪次取整數輪。
取驗證損失最低的輪次而非最後一輪，是早停的標準做法。若多個輪次損失接近，優先選更靠後的（通常更穩）或按次要指標（F1）再篩；注意"用驗證集選輪次"本身會輕微樂觀，嚴格評估應留出獨立測試集。

📐 計算公式與說明

早停判讀口徑：最佳輪次 = 五輪驗證損失中最小者所在輪；損失隨輪次遞減說明仍在收斂、可繼續訓練，觸底回升即出現過擬合拐點，應早停並回滾到該輪權重（並列取更早輪更穩妥）。校驗：無強校驗，未填損失按 0 計。判據：無固定分級，最佳輪次同時用於評估泛化——訓練損失續降而驗證損失回升即泛化開始劣化。

應結合驗證集，避免過擬合輪次。

📚 深度解析：最佳輪次選擇

💡 常見使用場景

  • 在記錄中各輪驗證指標(如驗證 loss/F1)取最優輪次，作為部署權重。
  • 監控指標上升即早停，並回退到最佳輪 checkpoint，避免用過擬合權重。
  • 若多指標衝突(如 loss 最低但 F1 非最高)，按業務優先順序選定主指標。

❓ 常見問題（FAQ）

用 loss 還是 F1 選最佳輪？
看目標。迴歸用驗證 loss/RMSE；分類常看 F1/Accuracy；若關注誤殺率則看精確率。主指標應直接對應業務收益。
驗證指標波動怎麼選？
取平滑後的最優且要求持續優勢(patience)，避免單點噪聲誤導；也可在最佳輪附近做少量額外驗證確認穩定。
