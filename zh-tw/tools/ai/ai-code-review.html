💻 AI Code Review

Statically analyze JavaScript and TypeScript in the browser to surface common issues such as unused variables, unsafe equality and missing error handling.

📐 工作原理與說明
逐條規則用正則對每行程式碼求匹配，命中行號記入該規則；評分（滿分 100）= max(0, 100 − 錯誤規則數 × 15 − 警告規則數 × 5 − 提示規則數)。分級：eval()、debugger 判錯誤；innerHTML 賦值、document.write、with、迴圈內建立函式判警告；console 呼叫、alert、for...in、new Array(n)、var、==、大數魔數、超長行（> 150 字元）、TODO/FIXME、空程式碼塊判提示

本工具在瀏覽器本地用規則與啟發式對 JavaScript/TypeScript 做靜態分析，識別未宣告變數、冗餘分支、可疑空值解引用等模式並給出提示；純前端執行，程式碼不上傳伺服器。

📚 深度解析：AI 程式碼審查

💡 常見使用場景

  • 在瀏覽器本地用規則與啟發式靜態分析 JS/TS 程式碼，識別未定義變數、冗餘分支、潛在空值等問題。
  • 純前端執行，程式碼不上傳，適合隱私敏感與離線場景的輕量自查。
  • 審查結果應作為人工複核的輔助，不能替代團隊 Code Review 與安全測試。
常見問題識別
輸入含 let x; if(x>0){} 的程式碼，工具提示 'x 未初始化即參與比較'；對 if(a){}else if(a){} 提示 '互斥分支不可能同時成立'。定位後由開發者確認修正。

❓ 常見問題（FAQ）

它能發現所有 bug 嗎？
不能。靜態分析只能捕獲模式化、確定性問題，無法理解業務語義與執行時行為；深度缺陷仍需單測、整合測試與人工評審。
為什麼強調純前端不上傳？
程式碼常含商業邏輯與金鑰風險，本地處理避免原始碼外洩；但僅本地也意味著無法呼叫雲端大模型做更深入的語義理解。
