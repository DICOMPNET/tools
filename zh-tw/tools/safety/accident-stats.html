📐 計算公式
傷亡人次 = 死亡 + 重傷 + 輕傷；FR(百萬工時傷害率) = 傷亡人次×1000000÷總工時，LTIFR、百萬工時死亡率、損失工作日率 SR 同為 ×1000000 基數；TRIR = 可記錄事件(取傷亡口徑)×200000÷總工時（20 萬小時基數）；平均損失工作日 = 損失工作日總數 ÷ 損工事故數（損工為 0 記 0）。校驗：總工時須為大於 0 的有效數值，否則提示「請輸入有效的總工時（>0）」。判據：TRIR <1.5 優秀、<3 良好、<5 需改進、≥5 較差（≥5 紅、≥3 黃、否則綠）；有死亡事故附「四不放過」提示。

📖 指標說明

頻率類指標（每百萬工時）

工傷頻率 FR = 傷亡人次 × 1,000,000 / 總工時

損工事故頻率 LTIFR = 損工事件 × 1,000,000 / 總工時

百萬工時死亡率 = 死亡人數 × 1,000,000 / 總工時

嚴重率與 OSHA 指標

嚴重率 SR = 損失工作日 × 1,000,000 / 總工時

TRIR（OSHA）= 可記錄事件 × 200,000 / 總工時（200,000≈100 名全職員工年工時）

平均損失工作日 = 損失工作日 / 損工事件

提示：可記錄事件含死亡、重傷、輕傷等需記錄事故，本工具預設取三者和，可按企業口徑調整輸入。

📚 深度解析：事故頻率 / 嚴重率統計報表

💡 常見使用場景

  • 同時統計事故頻率（發生的頻繁程度）與嚴重率（損失的嚴重程度），避免只看一面。
  • 錄入傷亡人次、損工天數、總工時，自動算出 FR 與嚴重率 SR。
  • 用於安全例會彙報與持續改進目標設定。
頻率與嚴重率
事故頻率 FR = 傷亡人次 × 1,000,000 ÷ 總工時；嚴重率 SR = 損失工時天數 × 1,000,000 ÷ 總工時（或按行業口徑用傷亡嚴重度加權）。兩指標結合區分“常發小傷”與“偶發重災”。
算例
總工時 1,500,000，傷亡 2 人次（損失工時共 30 天），則 FR = 2×1e6/1.5e6 ≈ 1.33，SR = 30×1e6/1.5e6 = 20；若另一單位 FR 相同但 SR 僅 5，說明其事故更輕，應差異化管控。

❓ 常見問題（FAQ）

嚴重率怎麼算更合理？
常用損失工時天數歸一化；也可按死亡/重傷/輕傷賦予不同權重，口徑需在報表中註明保持一致。
頻率低嚴重率高說明什麼？
事故少但單次後果重（如高處墜落、機械傷害），應強化本質安全與防護措施，而非僅靠減少頻次。
