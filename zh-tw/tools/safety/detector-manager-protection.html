📚 深度解析：職業健康風險評分（暴露/防護/檢測頻率）

💡 常見使用場景

  • 職場職業健康風險管理：輸入危害因素、日暴露時長、防護措施數與檢測頻率，評風險等級
  • 合規自查：分數對映暴露控制、工程防護與檢測閉環是否到位
  • 改進決策：低分項提示應先補哪類措施
方法
演算法：暴露分 = 時長≤限值×0.5?100 : ≤限值?70 : 40；防護分 = 措施≥5?100 : ≥3?75 : ≥1?50 : 20；頻率分 = 月檢?100 : 季檢?70 : 半年?50 : 20；總分 = 暴露×0.4 + 防護×0.35 + 頻率×0.25（四捨五入）；≥80 低、≥60 中、≥40 高、其餘極高。（限值：粉塵8/化學毒物4/噪聲8/高溫6/輻射4 h）
算例
例：粉塵崗位 6h/天、措施 3 項、每季檢 → 暴露 70、防護 75、頻率 70，總分 72 → 中風險。化學毒物 2h/天、措施 5 項、月檢 → 100/100/100，總分 100 → 低風險。噪聲 9h/天、措施 0、半年檢 → 40/20/50，總分 36 → 極高風險。

❓ 常見問題（FAQ）

限值是什麼？
為各危害因素的國家接觸限值示例（如粉塵 8h、化學毒物 4h 等 PC-TWA），實際以 GBZ 2.1 等現行標準為準。
分數能代替檢測報告嗎？
不能。本工具是管理自查的粗略評分，正式風險評價須以職業衛生檢測資料與評價報告為依據。

📝工具簡介

健康（防護/檢測/替代）管理工具，輸入職業危害因素、日暴露時間、防護措施數和健康檢查頻率，綜合評估職業健康風險等級。暴露控制權重40%、防護措施35%、健康檢查25%，輸出低/中/高/極高四檔風險等級及防護建議。適用於企業職業健康管理、防護措施最佳化和替代方案評估。

✨功能特點

  • 支援五種職業危害因素評估
  • 三維加權綜合評分
  • 針對不同危害輸出防護建議
  • 提供替代方案建議

🎯使用場景

  • 企業職業健康管理
  • 職業防護措施評估
  • 職業衛生檢查準備
  • 職業危害替代方案
