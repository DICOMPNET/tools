📜 Security Log Analyzer (Local Log Import)

Import a local security log to summarize anomalies by time, IP and event type for troubleshooting; files stay in the browser.

📐 工作原理與說明
日誌聚合規則：按空白切分取首段為 IP、其餘為事件描述；分別統計各事件型別次數與「同一 IP + 事件」組合次數，組合次數 ≥ 閾值（預設 3）判為可疑高頻源
安全日誌分析：逐行解析「IP 事件型別」日誌，按事件型別與 IP 聚合計數，並判定同一 IP 同一事件頻次超過閾值的疑似攻擊/異常源，全部本地解析不上傳。

📚 深度解析：安全日誌分析器（本地匯入日誌）

💡 常見使用場景

  • 伺服器/防火牆日誌排查：逐行貼上「IP 事件型別」，按事件型別與來源 IP 聚合計數，快速識別高頻攻擊源。
  • 暴力破解初篩：設定閾值（如同一 IP 5 分鐘內失敗登入 ≥10 次），自動標記可疑源供封禁或加固核查。
算例（5 行日誌，閾值=3）
日誌含 203.0.113.7 ssh_fail ×4 與 192.168.1.5 login_fail ×1；按型別聚合 ssh_fail=4、login_fail=1；按 IP+事件計數後，203.0.113.7/ssh_fail 達 4 次 ≥ 閾值 3，判定為可疑高頻源。全部本地解析，不上傳任何資料。

❓ 常見問題（FAQ）

日誌分析能發現所有攻擊嗎？
只能發現日誌中留下痕跡的異常；低頻、低速或加密隧道內的攻擊易漏報，需配合 IDS/IPS 與行為基線。本工具定位為本地快速聚合初篩，非即時入侵檢測。
大日誌會卡嗎？
按行流式解析並聚合計數，記憶體佔用低；建議先按時間窗或型別過濾再統計，超大數據可分批匯入。
