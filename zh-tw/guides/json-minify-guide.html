JSON 壓縮/格式化 使用指南

JSON 工具支援「壓縮」與「美化」兩種模式：壓縮用於減小儲存/傳輸體積並顯示壓縮率，美化用於閱讀與除錯。全程瀏覽器本地處理。

核心功能

  • 壓縮模式：去除空白與換行，顯示壓縮率
  • 美化模式：按層級縮排，便於閱讀
  • 顯示原始/輸出體積對比
  • 解析錯誤定位提示，方便排查
  • 一鍵複製結果

適用場景

  • 介面除錯：把返回的壓縮 JSON 美化閱讀
  • 儲存最佳化：壓縮配置/快取資料減小體積
  • 把 JSON 壓縮後放進 URL 引數

使用步驟

  1. 貼上 JSON 到輸入框
  2. 選擇「壓縮」或「美化」模式（支援即時切換）
  3. 檢視體積與壓縮率統計
  4. 點選「複製結果」使用

實用技巧

  • 壓縮率可能為負（小 JSON 反而變大），屬正常現象
  • 美化後的 JSON 縮排為 2 空格
  • 貼上前確認內容為合法 JSON，否則會提示錯誤位置

常見問題

壓縮和美化哪個好？
傳輸/儲存用壓縮，閱讀/除錯用美化；兩者不會改變資料本身。
為什麼壓縮後反而更大？
小 JSON 的空格佔比高，壓縮收益小甚至為負，屬正常。
