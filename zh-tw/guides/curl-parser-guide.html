curl 命令解析 使用指南

從一段 curl 命令中提取 HTTP 方法、URL、Header、Body 與引數，幫助複製到程式碼或 Postman。本地解析不上傳。

核心功能

  • 拆解方法/URL/Header/Body
  • 識別 -X -H -d 等引數
  • 格式化展示
  • 一鍵複製各部分
  • 本地處理

適用場景

  • 把瀏覽器複製的 curl 轉程式碼
  • 核對請求頭與體是否正確
  • 分享介面呼叫給他人

使用步驟

  1. 貼上 curl 命令
  2. 點選解析
  3. 檢視結構化欄位並複製

實用技巧

  • 從瀏覽器網路面板"Copy as cURL"最常用
  • -d 後為請求體，-H 為請求頭
  • Bearer 令牌在 Header 裡

常見問題

怎麼拿到 curl？
瀏覽器 DevTools 網路面板右鍵請求選 Copy as cURL。
能給個例子嗎？
curl -X POST -H "Authorization: Bearer x" -d "{}" https://api → 拆出 POST 方法、Header、空 Body 與 URL。
