競爭格局與市場份額測算 使用指南

先按已錄企業算樣本內份額與 HHI；只有錄入市場總規模且覆蓋完整市場時，才使用 2500/1500 閾值判集中度。

功能說明

逐行輸入「企業名,營收」，工具計算各企業份額、CR3、CR5 與 HHI。目標市場總規模是選填項：留空時分母取已錄企業合計，所有標籤顯示「樣本內」，不判完整市場集中度；填寫後先算覆蓋率，只有覆蓋率 100% 才給「高度集中/中度集中/競爭分散」結論。

輸入與校驗

  • 每行一條「企業,營收」，支援半形/全形逗號、頓號、分號或製表符；企業名不能為空。
  • 營收必須是大於 0 的數字，帶文字（如 12abc）會按原行號報錯並阻止計算；不再靜默跳過。
  • 市場總規模必須與營收使用同一單位（如都為萬元）；已錄企業合計大於市場總規模時屬於口徑矛盾，頁面會拒絕計算。
  • 企業數少於 3 時，CR3 只是已錄企業合計，頁面會單獨提示，不能當完整市場 CR3。

操作步驟

  1. 先把同一口徑、同一期間的企業營收按行錄入。
  2. 需要判斷完整市場時再填目標市場總規模；不確定時留空，只看樣本內份額。
  3. 點選計算，先看覆蓋率與「樣本內/完整市場」標籤，再看 CR3、HHI 與企業數提示。
  4. 若已錄合計大於市場總規模，回到原始資料核對單位、期間與重複計算。

算例

A 300、B 200、C 100，未填市場總規模：已錄合計 600，樣本內份額 50.0%/33.3%/16.7%，HHI=3888.89，CR3=100%，但頁面固定「不做完整市場集中度判定」。把市場總規模填為 600 後，覆蓋率 100%，才判「高度集中」。若市場總規模填 10000，覆蓋率僅 6%，HHI=14，不套 2500/1500 閾值。

注意事項

樣本內 HHI 只描述已錄企業，不能外推為行業集中度；HHI 閾值只在完整市場口徑下使用。營收單位不影響份額比例，但同一份輸入內必須統一。工具不自動校驗企業間重複、關聯交易或會計口徑差異。

不填市場總規模還能用嗎？
可以，但只能得到樣本內份額與樣本內 HHI，頁面會明確標註，不判完整市場集中度。
覆蓋率不是 100% 時能判集中度嗎？
不能。頁面只展示已知企業份額與 HHI，不套 2500/1500 閾值；需要補充未錄入企業或完整市場總規模。
資料會儲存或上傳嗎？
全部在瀏覽器本地計算；重新整理後輸入會恢復預設示例，不上傳伺服器。
