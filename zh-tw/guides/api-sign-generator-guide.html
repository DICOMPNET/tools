API 簽名生成器 使用指南

許多開放平臺要求把引數按規則排序拼接、加金鑰後雜湊作為 sign。本工具按常用演算法生成簽名，便於服務端比對。本地運算。

核心功能

  • 引數排序拼接
  • MD5/SHA 等雜湊
  • 金鑰拼接
  • 輸出 sign 值
  • 本地處理

適用場景

  • 開放平臺介面聯調
  • 服務端 sign 比對
  • 排查簽名不一致

使用步驟

  1. 填入引數鍵值與金鑰
  2. 選演算法與拼接規則
  3. 點生成得 sign
  4. 放入請求校驗

實用技巧

  • 引數需按約定排序(常按 key 字典序)
  • 空值引數是否參與需看文件
  • 時間戳防重放常一起用

常見問題

sign 失敗先看什麼？
排序規則與是否含空值、金鑰位置。
能給個例子嗎？
a=1&b=2 + key → 拼接 "a=1&b=2&key=K" 再 MD5 得 sign。
