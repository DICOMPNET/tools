哈森-威廉姆斯水頭損失計算器 使用指南

由流量、管長、粗糙係數 C 與管徑，按 h_f = 10.67·L·Q^1.852/(C^1.852·D^4.87) 計算水頭損失（SI）。

功能說明

由流量、管長、粗糙係數 C 與管徑，按 h_f = 10.67·L·Q^1.852/(C^1.852·D^4.87) 計算水頭損失（SI）。

使用步驟

  1. 填寫「流量 Q (m³/s)」。
  2. 填寫「管長 L (m)」。
  3. 填寫「粗糙係數 C」。
  4. 填寫「管徑 D (m)」。
  5. 結果區會即時更新；可一鍵複製結果用於記錄或彙報。

典型使用場景

  • 給水管網按經驗式估沿程損失。
  • 不同 C 值（管材）對比能耗。
  • 長距離配水校核末端壓力。

算例參考

  • 標準算例：Q=0.01 m³/s、L=100 m、C=120、d=0.1 → h_f=10.67×100×0.01^1.852/(120^1.85×0.1^4.87)≈0.25 m。
  • C 值影響：C 從 120 降到 100（舊管），同條件損失增約 40%，結垢顯著抬升能耗。

注意事項

本工具在瀏覽器本地執行，輸入內容不會上傳伺服器；結果為模型估算，工程決策請結合實測資料複核。
