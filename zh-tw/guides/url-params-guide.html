URL 引數解析器 使用指南

URL 查詢串（?a=1&b=2）常需解析、重組或編碼。本工具把 URL / 查詢串拆成結構化鍵值對，並支援編碼解碼。

目錄 適用場景 · 操作步驟 · 注意事項 · 常見問題

適用場景

  • 除錯介面時檢視請求帶了哪些引數
  • 從複雜 URL 中批次提取某個引數
  • 構造帶正確編碼的查詢串

操作步驟

  1. 貼上完整 URL 或僅查詢串（? 之後）
  2. 點選解析，得到鍵值對列表，可排序/篩選
  3. 對值做 URL 解碼（如 %E4%BD%A0 還原為中文）
  4. 複製結構化結果或重組後的 URL

注意事項

  • 引數值常經 URL 編碼，直接看是 %XX 形式，需解碼才可讀
  • 同名引數（a=1&a=2）應解析為陣列，注意後端取值方式
  • 構造 URL 時特殊字元務必編碼，避免截斷或注入

常見問題（FAQ）

%+ 和空格？

空格可編碼為 %20 或 +（僅查詢串），解碼時注意上下文。

同名引數怎麼處理？

標準允許多次出現，解析為陣列；後端可能只取第一個。

hash(#) 後的引數能解析嗎？

# 後是 fragment，不在查詢串裡，需單獨處理。
