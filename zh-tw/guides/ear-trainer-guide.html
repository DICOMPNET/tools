耳訓練器 使用指南

耳訓練器基於 Web Audio API 播放音程與和絃並訓練聽音辨識，反覆練習可提升視唱練耳與即興演奏的聽力基礎，適合音樂學習者。

功能說明

耳訓練器基於 Web Audio API 播放音程與和絃並訓練聽音辨識，反覆練習可提升視唱練耳與即興演奏的聽力基礎，適合音樂學習者。

典型使用場景

  • 聽兩個音判音程（小二度到大七度），練相對音感
  • 聽和絃判型別（大/小/屬七等），提升和聲辨識
  • 反覆隨機出題並即時反饋，建立音程與聽感的對映

算例參考

  • 音程半音數：相鄰音名半音差：小二度 1、大二度 2、小三度 3、大三度 4、純四度 5、三全音 6、純五度 7、小六度 8、大六度 9、小七度 10、大七度 11、八度 12。
  • 和絃辨識：同時響 C-E-G 為大三（明亮）、C-E♭-G 為小三（柔和）、C-E-G-B♭ 為屬七（帶張力）；聽色彩與完成度區分。

注意事項

本工具純前端執行，輸入內容不上傳伺服器；結果為按上述口徑得到的理論估算值。實際應用受裝置引數、測量條件與當地規範影響，請以裝置銘牌、檢測報告與現行標準為準，重大決策建議諮詢專業人士。

怎麼練相對音感？
從純五度、大三度等色彩鮮明的音程入手，記住參照曲（如《星球大戰》開頭純五度），再擴充套件到全部半音級數。
和絃辨識從哪開始？
先分大/小三和絃（明/暗），再加屬七（解決感）、大七（爵士柔光）；每次聽後看答案建立聽覺記憶。
