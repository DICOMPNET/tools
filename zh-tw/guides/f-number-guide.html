光圈數 N 使用指南

輸入鏡頭焦距 f 與有效孔徑 D，按 N = f/D 計算光圈數（F 值），並可反算不同光圈下的進光量與景深關係。用於攝影曝光與光學設計。

計算公式與原理

N = f/D

由焦距與有效孔徑，按 N = f/D 計算攝影鏡頭光圈數。

使用步驟

  1. 填寫「焦距 f (mm)」。
  2. 填寫「有效孔徑 D (mm)」。
  3. 結果區會即時更新；可一鍵複製結果用於記錄或彙報。

典型使用場景

  • 由焦距與口徑算 F 數（F=f/D）。
  • F 數決定進光量與景深。
  • 通光面積∝1/F²。

算例參考

  • 基本換算：焦距 50mm、口徑 25mm → F=50/25=2.0（F2 大光圈）；口徑 12.5mm → F=4.0。
  • 進光量：F2→F4 口徑減半、進光量降 1/4（差 2 檔）；F 數每×√2 進光減半，景深隨之變深。

注意事項

本工具純前端執行，輸入內容不上傳伺服器；結果為按上述口徑得到的理論估算值。實際應用受裝置引數、測量條件與當地規範影響，請以裝置銘牌、檢測報告與現行標準為準，重大決策建議諮詢專業人士。

F 數小光圈大？
對。F=f/D，D 大則 F 小、進光多、景深淺，背景虛化強。
景深和 F 數？
F 數大（小口徑）景深深、前後都清；F 數小景深淺、虛化強。
