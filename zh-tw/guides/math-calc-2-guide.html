比例計算 使用指南

依據比例式 A:B=C:D，輸入任意三項求解第四項未知數，適用於配方縮放、地圖比例與相似圖形計算等比例換算場景。

計算公式與原理

比例 a:b = a/b

根據比例式 A : B = C : D，輸入任意三項求解第四項。

使用步驟

  1. 填寫「A」。
  2. 填寫「B」。
  3. 填寫「C」。
  4. 填寫「D」。
  5. 結果區會即時更新；可一鍵複製結果用於記錄或彙報。

典型使用場景

  • 比例式 a:b = c:d（即 a/b = c/d）廣泛用於地圖縮放、配方、相似圖形與單位換算。
  • 已知三項求第四項（交叉相乘 a×d = b×c）是比例計算的核心操作。
  • 校驗兩條比例是否相等時，比較兩邊交叉乘積即可，避免逐項約分出錯。

算例參考

  • 算例：缺項求解（2:3 = 4:d）：由 a×d = b×c → d = b×c÷a = 3×4÷2 = 6.000000；校驗：2×6 = 12.000000，3×4 = 12.000000，等式成立。
  • 算例：求首個比值（a:5 = 3:4）：a = b×c÷d = 5×3÷4 = 3.750000。通用公式：缺誰就用其餘三項交叉相乘除以它的對角項。

注意事項

本工具純前端執行，輸入內容不上傳伺服器；結果為按上述口徑得到的理論估算值。實際應用受裝置引數、測量條件與當地規範影響，請以裝置銘牌、檢測報告與現行標準為準，重大決策建議諮詢專業人士。

比例和百分比有什麼聯絡？
百分比是『分母為 100 的比例』。比例重對應關係（a:b），百分比重相對大小（a/100）。兩者可互化：3:4 等價於 75:100，即 75%。
交叉相乘為什麼成立？
由 a/b = c/d 兩邊同乘 b×d 得 a×d = b×c。它是比例等式等價變形，用於解未知項與校驗等式，是最可靠的比例運算依據。
