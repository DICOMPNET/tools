assessor-64 使用指南

assessor-64：線上輸入引數即可即時得到結果，無需安裝與註冊。

計算公式與原理

綜合評分 = 師資×0.25 + 課程內容×0.25 + 教學環境×0.20 + 學員效果×0.30

師資力量 = 認證係數×0.6 + min(從業年限/10, 1)×4（上限 10）；課程內容 = 三項評分均值；教學環境 = 室溫×0.3 + 溼度×0.2 + 班級人數×0.25 + 人均面積×0.25（達標記 10、不達標記 5–6）；學員效果 = (滿意度×0.3 + 留存×0.3 + 續費×0.2 + 進度×0.2)/10。等級：≥8.5 卓越 S、≥7.5 優秀 A、≥6.0 良好 B、≥4.5 合格 C，其餘不合格 D；單項 < 7 判「待提升」。

典型使用場景

  • 瑜伽館或工作室做季度課程質量體檢：從師資、課程內容、教學環境、學員效果四個維度打分，得出可對比的綜合分與等級。
  • 教練自評或在評課時定位短板：任意維度低於 7 分即判「待提升」並自動列出改進項，避免只盯總分而忽略結構性問題。
  • 環境合規復核：室溫、溼度、班級人數、人均面積四項按閾值判定 ✓/✗，作為場館擇址或排課的硬性依據。

算例參考

  • 可復現算例：一節團體課的質量評估：輸入：認證 RYT200-500（cert=8）、從業年限 3 年；課程內容三項 7/6/8；環境室溫 30°C、溼度 55%、班級 20 人、場地 60m²；學員效果 滿意度 80、留存 70、續費 60、進度 65。 師資力量=0.6×8+min(3/10,1)×4=6.0；課程內容=(7+6+8)/3=7.0； 教學環境：室溫 30°C 不達標(5)、溼度 55% 達標(10)、人數 20>15 不達標(6)、人均面積 60/20=3.0 達標(10) → 5×0.3+10×0.2+6×0.25+10×0.25=7.5； 學員效果=(80×0.3+70×0.3+60×0.2+65×0.2)/10=7.0； 綜合評分=6.0×0.25+7.0×0.25+7.5×0.20+7.0×0.30=6.85 → 顯示 6.8/10，等級「良好（B級）」，薄弱項為師資力量(6.0)與室溫超標。 對照高效班：cert=10、年限 6、課程 9/8/9、室溫 24°C、溼度 50%、10 人、60m²、效果 90/80/75/85 → 綜合 8.8/10，等級「卓越（S級）」。

注意事項

本工具純前端執行，輸入內容不上傳伺服器；結果為按上述口徑得到的理論估算值。實際應用受裝置引數、測量條件與當地規範影響，請以裝置銘牌、檢測報告與現行標準為準，重大決策建議諮詢專業人士。

四個維度的權重為什麼是 25/25/20/30？
學員效果權重最高（30%），因為課程最終要落到留存與滿意度；師資與課程內容各 25% 是質量的直接來源；教學環境 20%，是必要條件但相對可改造。權重可在評估口徑調整時按同一比例替換。
為什麼 6.85 顯示成 6.8？
頁面用 toFixed(1) 保留一位小數，而 6.85 在二進位制浮點中略小於 6.85，故進位後顯示 6.8。這是四捨五入的邊界表現，不影響等級判定（6.0≤6.85<7.5 為良好 B 級）。
