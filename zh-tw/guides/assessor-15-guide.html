輸精管造影（通暢）評估 使用指南

輸精管造影通暢度評估工具，逐段評估輸精管/精囊/射精管通暢情況，輔助梗阻性無精子症診斷

功能說明

輸精管造影通暢度評估工具，逐段評估輸精管/精囊/射精管通暢情況，輔助梗阻性無精子症診斷

典型使用場景

  • 無精子症病因定位。
  • 梗阻性 vs 非梗阻性鑑別。
  • 顯微外科重建術前評估。

算例參考

  • 雙側各段均 2 分：評分 0=梗阻、1=部分、2=通暢；雙側全部 2 → 雙側通暢，不支援梗阻性無精子症。
  • 左段一處 0 分：左某段評 0 → 左側梗阻；若僅單側且對側通暢，仍有自然受孕可能，可先觀察。

注意事項

本工具純前端執行，輸入內容不上傳伺服器；結果為按上述口徑得到的理論估算值。實際應用受裝置引數、測量條件與當地規範影響，請以裝置銘牌、檢測報告與現行標準為準，重大決策建議諮詢專業人士。

評分怎麼用？
逐段（腹股溝/盆段/壺腹等）評 0–2，任一段 0 即該側梗阻，雙側 0 為梗阻性無精子症。
下一步？
雙側梗阻常選 PESA+ICSI；單側可據精液引數決定是否手術探查。
