色溫轉換（開爾文） 使用指南

核心功能

  • 在開爾文色溫（K）與 RGB / HEX 之間雙向轉換
  • 給出色溫描述（燭光 / 日光 / 陰天等）與相機白平衡參考預設
  • 提供色溫滑桿，可連續拖動觀察顏色變化
  • 純本地計算，不上傳任何輸入

適用場景

  • 把 6500K 轉成螢幕白點 RGB。
  • 估算燭光/日光燈的顏色。
  • 調攝影白平衡參考。

使用步驟

  1. 輸入色溫值（K）或直接填入 RGB
  2. 用滑桿細調直到顏色符合預期
  3. 讀取對應的 RGB / HEX 與白平衡說明
  4. 把 HEX 用於設計稿，或把 K 值作為拍攝白平衡參考
  5. 需要反向取值時切換 RGB 輸入模式

實用技巧

  • 低色溫（如 2700K）偏暖黃、高色溫（如 9000K）偏冷藍，與直覺相反，勿記反
  • 轉換基於經驗近似式，得到的是螢幕白點參考值，不用於色彩科學級的精確測量
  • 相機白平衡預設與螢幕色溫並非一一對應，實際拍攝仍以灰卡與實測為準
  • 顯示器自身色溫會疊加影響觀感，校色後的螢幕才有參考意義
