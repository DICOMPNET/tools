游泳划水效率（SWOLF）計算器

SWOLF = 單趟時間(秒) + 划水次數，綜合評估游泳技術經濟性；同時給出每劃距離 DPS 與劃頻 SR，越低/越優越高效。

公式與原理

SWOLF = 單趟時間(秒) + 划水次數；每劃距離 DPS = 池長 / 劃次；劃頻 SR = 劃次 / 時間 × 60。25m 自由泳參考：<35 精英 / 35–42 優秀 / 43–50 良好 / 51–60 中等 / 61–70 初級 / >70 入門。

使用步驟

  1. 選擇泳姿與泳池長度。
  2. 輸入單趟划水次數與用時。
  3. 結果區顯示 SWOLF、DPS、SR 與效率等級。

提升方向

  • 降低 SWOLF：減少划水次數（提升滑行性）同時保持速度。
  • 提高 DPS：強化划水力與身體流線。

注意事項

SWOLF 跨泳姿不可直接比較；同泳姿縱向對比才有意義。
