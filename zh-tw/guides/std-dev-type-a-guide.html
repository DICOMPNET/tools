由樣本標準差與測量次數求 A 類標準不確定度 使用指南

輸入樣本標準差 s 與獨立測量次數 n，按 u_A = s / √n 計算 A 類標準不確定度（統計評定法）。用於由重複觀測資料評定測量結果的不確定度分量。

計算公式與原理

u_A = s/√n

輸入樣本標準差 s 與測量次數 n，求 A 類標準不確定度。

使用步驟

  1. 填寫「樣本標準差 s」。
  2. 填寫「測量次數 n (次)」。
  3. 結果區會即時更新；可一鍵複製結果用於記錄或彙報。

典型使用場景

  • 由重複測估 s
  • 樣本標準差
  • 不確定度

算例參考

  • 公式：s = sqrt(sum((xi-xbar)^2)/(n-1))。例：5 次測 10.001,10.003,9.999,10.002,10.000，s≈0.0016。
  • 樣本標準差 1.5，測量次數 16：u_A=s/√n=1.5/4=0.3750。測量次數翻倍只能把 u_A 降到約 70%，靠增加 n 降低不確定度的收益遞減。

注意事項

本工具純前端執行，輸入內容不上傳伺服器；結果為按上述口徑得到的理論估算值。實際應用受裝置引數、測量條件與當地規範影響，請以裝置銘牌、檢測報告與現行標準為準，重大決策建議諮詢專業人士。
