齒輪加工計算 使用指南

按端面模數、齒數、螺旋角與加工方法（滾齒、插齒等），計算齒輪幾何引數與切削加工引數（如進給、轉速）；斜齒時齒頂圓/齒根圓按法向模數修正、基圓按端面壓力角修正，用於齒輪製造工藝。

計算公式與原理

齒輪幾何 = 端面模數 × 齒數，斜齒按法向模數修正

分度圓 d = mt×z；法向模數 mn = mt×cosβ；端面壓力角 αt = atan(tan20°÷cosβ)；齒頂圓 da = d+2×mn；齒根圓 df = d−2.5×mn；基圓 db = d×cosαt；端面齒距 pt = π×mt；軸向齒距 px = π×mt÷tanβ（直齒無）。切削：主軸轉速 n = 1000×Vc÷(π×d)，進給速度 Vf = n×f。

典型使用場景

  • 設計齒輪時求分度圓、齒頂圓、齒根圓、基圓直徑。
  • 由模數 m、齒數 z 決定齒距與齧合尺寸。
  • 核算轉速與進給匹配滾齒/插齒。

算例參考

  • 標準直齒輪：m=2、z=24：分度圓 d = 2×24 = 48mm，齒頂圓 da = 2×(24+2) = 52mm，齒根圓 df = 2×(24−2.5) = 43mm，基圓 db = 48×cos20° ≈ 45.1mm，齒距 p = 2×π ≈ 6.283mm。
  • 斜齒輪：mt=3、z=20、β=20°：mn = 3×cos20° ≈ 2.819mm，αt = atan(tan20°÷cos20°) ≈ 21.173°，d = 60.00mm，da = 60+2×2.819 ≈ 65.64mm，df = 60−2.5×2.819 ≈ 52.95mm，db = 60×cos21.173° ≈ 55.95mm，px = π×3÷tan20° ≈ 25.894mm。
  • 滾齒轉速：vc=40m/min：n = 1000×40÷(π×48) ≈ 265.3 rpm，進給速度按走刀量設定，保證齒面粗糙度。

注意事項

本工具純前端執行，輸入內容不上傳伺服器；結果為按上述口徑得到的理論估算值。實際應用受裝置引數、測量條件與當地規範影響，請以裝置銘牌、檢測報告與現行標準為準，重大決策建議諮詢專業人士。

模數是什麼？
模數 m = 分度圓直徑÷齒數，是齒輪尺寸與強度的核心引數，必須成對齧合相同，單位 mm。
斜齒和直齒的齒頂圓怎麼算？
直齒 da = m×(z+2)；斜齒按端面模數輸入時，da = mt×z + 2×mt×cosβ。齒根圓同理減 2.5×法向模數，基圓按端面壓力角 αt 計算。
基圓有什麼用？
基圓決定漸開線齒廓形狀，db = d×cos(壓力角)；壓力角標準 20°，基圓越小齒根越瘦。
