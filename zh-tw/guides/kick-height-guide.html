踢腿高度換算 使用指南

輸入身高、可選腿長與踢腿高度，換算高度比、腿長比與估算角度；腿長留空或填 0 時按身高 45% 估算並明示。

功能說明

身高與踢腿高度分別校驗：身高必填且在 120–220cm，踢腿高度可為 0、不得為負。腿長留空或填 0 時按身高 45% 估算並在結果中顯示使用值；填負數報錯。清空或非法輸入時清除舊結果。

典型使用場景

  • 訓練資料換算：輸入身高、腿長（可留空估算）與踢腿高度，得到高度比、腿長比和估算角度。
  • 動作對比：不同型別踢法有不同高度係數，按調整高度比分組，便於橫向檢視輸入差異。
  • 安全提示：用於設定訓練目標高度，避免過度追求高度拉傷；分級只是輸入高度的分組，不代表柔韌或技術實測。

算例參考

  • 算例：170cm 身高、前踢離地 165cm：身高170cm、腿長預設=170×45%=76.5cm、踢高165cm、前踢係數1.0。高度比=97.1%；腿長比=215.7%；估算角度=asin(165/(76.5+85))截斷為90.0°；調整高度比97.1%→分檔「良好」。踢高0cm時高度比0.0%、角度0.0°，不會報錯。

注意事項

本工具純前端執行，輸入內容不上傳伺服器；角度為簡化幾何估算，實際受髖關節靈活度與軀幹姿態影響。腿長估算值會在結果中明示；請勿把分檔當作柔韌或技術實測。

腿長留空或填 0 會怎樣？
按身高 45% 估算，並在結果中顯示「腿長使用值」與「按身高 45% 估算」提示。填負數會報錯；填具體正數則按輸入值計算。
踢腿角度是怎麼估算的？
角度=asin(踢高÷(腿長+半身高))，超過 1 時截斷為 90°。該式是簡化模型，實際角度還受髖關節靈活度、軀幹姿態影響，僅作訓練參考。
