樣本量/配額/誤差計算 使用指南

計算所需樣本量與實際抽樣誤差，並用最大余數法分配分層配額；負數 N、非整數 n 與非法分層行都會按欄位或原行號攔截。

功能說明

按置信水平、預期比例 p、允許誤差 e 與總體規模 N 計算所需樣本量和實際誤差；勾選無限總體時忽略 N。分層抽樣按各層規模比例分配 n，先取整數下限，剩餘名額按餘數從大到小分配，餘數相同按層規模大→小、輸入順序前→後，保證每層非負且合計嚴格等於 n。

輸入與校驗

  • N 為有限總體時必須大於 0 的整數；未勾選無限總體時負數、0 或小數不能當作無限總體。
  • 實際樣本量 n 必須是 ≥1 的整數；有限總體下 n 不能超過 N。
  • p 與 e 必須在 0–100% 之間且不含端點；分層每行「層名,規模」必須完整，規模為正整數。
  • 分層合計不等於 N 時提示未覆蓋部分；大於 N 時按口徑矛盾阻止計算。

使用步驟

  1. 先確定置信水平、p 與允許誤差，計算無限總體 n₀ 與有限總體校正後的 n。
  2. 有實際樣本量時反算誤差，檢查是否達到目標；n>N 會直接攔截。
  3. 需要分層時錄入各層規模，核對分配表合計是否嚴格等於 n。

算例

N=10000、p=50%、e=3%、95% 置信水平：所需樣本量 965；若實際 n=400，誤差約 4.8%，超過目標。四層各 100、N=400、n=2 時，四層下限均為 0，剩餘 2 個名額按輸入順序分配為 1、1、0、0。

注意事項

  • p=50% 時 p(1−p) 最大，樣本量最保守；確信比例接近 0 或 1 時可按實際比例估算。
  • 抽樣比 n/N 超過約 5% 時有限總體校正影響明顯；n=N 是普查，抽樣誤差為零但不代表沒有非抽樣誤差。
  • 分層配額按分層合計計算，不強制等於 N；合計小於 N 時請確認分層是否覆蓋全部總體。
N 填負數會怎樣？
未勾選無限總體時直接報「有限總體規模 N 必須是 >0 的整數」，不會把負數當無限總體。
n 可以填小數嗎？
不可以。實際樣本量必須是 ≥1 的整數，小數會被攔截。
分層配額合計會不等於 n 嗎？
不會。最大余數法保證每層為非負整數且合計嚴格等於 n。
