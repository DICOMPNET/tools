文本換行與填充 使用指南

線上文本換行與填充工具，按指定寬度對段落自動折行，或向每行填充字首/字尾至固定長度，適合程式碼註釋與排版對齊，純前端處理。

計算公式與原理

字元模式：行數 = ⌈文本長度 / 寬度⌉，第 i 行 = 文本[i×寬度 : (i+1)×寬度]；詞模式：按空白切詞，累計長度超過寬度即換行；超長詞（單詞長度 > 寬度）按寬度強制切分

字元模式嚴格按定長切分，會切斷英文單詞與中文詞語，適合固定寬度裝置（如小票、終端）。詞模式保持單詞完整，行數略多但可讀性好，是正文排版的預設選擇。兩種模式都按 UTF-16 code unit 計數，含 emoji 或代理對字元（如 𝕏、部分表情）時計數會偏大，視覺寬度以實際渲染為準。換行符可選 \n、\r\n 或 <br>，寫 HTML 片段用 <br>，生成 Windows 文本用 \r\n。

使用步驟

  1. 填寫「每行字元數」。
  2. 填寫「換行符」。
  3. 填寫「每行填充到長度」。
  4. 填寫「填充字元」。
  5. 填寫「起始數字」。
  6. 填寫「步長」。
  7. 填寫「分隔符」。
  8. 結果區會即時更新；可一鍵複製結果用於記錄或彙報。

典型使用場景

  • 固定寬度排版：把長段落按每行 N 字元斷行，適合終端/郵件正文。
  • 程式碼註釋換行：長說明按 80 列折行，符合規範。
  • 移動端預覽：窄屏按短行重排提升可讀。

算例參考

  • 按 40 字寬換行：一段 120 字說明設寬度 40，拆成 3 行各約 40 字，在等寬字型下整齊；注意不在單詞中間斷（除非開啟強制斷）。

注意事項

結果為按上述公式得到的理論估算值，實際表現受資料分佈、實現細節與執行環境影響，落地決策請以實測為準；本工具純前端執行，輸入不上傳伺服器。
