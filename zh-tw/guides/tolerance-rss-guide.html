公差疊加計算器（RSS） 使用指南

輸入線性尺寸鏈中各環節的公差，工具用均方根（RSS）法估計裝配後的統計總公差，相比極值法更貼近大批次生產的實際波動，輔助公差分配與可裝配性評估。

計算公式與原理

√0.0725≈0.269。 RSS 比最差情況寬鬆。

用均方根法估計線性尺寸鏈的統計總公差。

使用步驟

  1. 填寫「公差1 t₁」。
  2. 填寫「公差2 t₂」。
  3. 填寫「公差3 t₃」。
  4. 結果區會即時更新；可一鍵複製結果用於記錄或彙報。

典型使用場景

  • 尺寸鏈/裝配間隙分析中，用方和根（Root Sum Square）估算多個零件公差疊加後的總變異，比最壞情況更貼近統計實際。
  • 大批次生產下各零件誤差近似獨立隨機分佈，RSS 給出『典型』總公差而非極端值。
  • 在保證裝配功能前提下，用 RSS 放寬容差以降本，而非一味按最壞情況加嚴。

算例參考

  • 公式：T_RSS = √(t₁² + t₂² + … + tₙ²)，各 tᵢ 為對稱公差幅值。前提：各分量相互獨立、處於同一統計覆蓋水平（如均按 ±3σ 給定）。RSS 是統計疊加估計，不是 100% 保證的最壞情況界限；最壞情況用 ΣT。三項公差全為 0 時，「RSS 佔線性疊加比」為 0/0，應標為不適用而不是 0%。
  • 算例：某裝配尺寸鏈由三段組成，各段公差分別為 0.1、0.15、0.2 mm：T = √(0.1² + 0.15² + 0.2²) = √(0.01 + 0.0225 + 0.04) = √0.0725 ≈ 0.269 mm（RSS）。相比最壞情況疊加的 0.45 mm，RSS 顯著更小，說明大批次下可適度放寬單件公差而不超差。

注意事項

本工具純前端執行，輸入內容不上傳伺服器；結果為按上述口徑得到的理論估算值。實際應用受裝置引數、測量條件與當地規範影響，請以裝置銘牌、檢測報告與現行標準為準，重大決策建議諮詢專業人士。

RSS 和最壞情況（WC）怎麼選？
WC 假設所有誤差同時取極值同向疊加，給出絕對安全但過嚴的總公差；RSS 假設獨立隨機、給出典型值。單件/小批/安全關鍵件用 WC，大批次統計過程控制下用 RSS 更經濟。
RSS 的前提是什麼？
要求各組成誤差相互獨立、且分佈近似正態（或至少對稱）；若存在系統性偏差（如刀具統一偏大），應先當作偏移而非隨機公差處理，否則 RSS 會低估真實總誤差。
