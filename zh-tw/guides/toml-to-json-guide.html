TOML 轉 JSON 使用指南

將 TOML 片段解析為 JSON 物件，支援巢狀表、陣列與標準型別。適合把配置檔案餵給 JS/介面。本地解析。

核心功能

  • TOML→JSON 解析
  • 巢狀表展開
  • 陣列與型別還原
  • 錯誤定位
  • 本地處理

適用場景

  • 讀 Cargo.toml 配置
  • 配置檔案校驗
  • TOML→介面資料

使用步驟

  1. 貼上 TOML
  2. 點選解析
  3. 檢視 JSON

實用技巧

  • 表順序在 JSON 中會被打亂(物件無序)
  • 點號鍵如 a.b 會成巢狀
  • 日期時間轉字串

常見問題

TOML 日期能轉嗎？
能，按 ISO 字串輸出。
能給個例子嗎？
"[a] b = 1" → {"a":{"b":1}}。
