SQLite 線上執行 使用指南

「SELECT 1+1;」 → 2；「SELECT date('now')」 → 當前日期。

核心功能

  • 在瀏覽器內執行 SQLite 語句並檢視結果
  • 支援建表、插入、查詢等常見 DDL 與 DML
  • 資料全在本頁記憶體，重新整理即清空
  • 適合練習語法與驗證查詢結果

適用場景

  • 瀏覽器內跑 SQL，快速驗證查詢。
  • 驗證一段查詢邏輯：不用起資料庫服務，直接在瀏覽器裡建表、插資料、跑 SQL，快速確認結果是否符合預期。

使用步驟

  1. 在輸入框寫 SQL，多條語句用分號分隔
  2. 點執行檢視結果表格或受影響行數
  3. 查詢時用 LIMIT 控制返回行數，避免結果過大
  4. 重新整理頁面會清空庫，重要資料請自行匯出
  5. 語法報錯時先看提示裡的 near 位置，多數是缺逗號或引號不匹配

實用技巧

  • 瀏覽器內跑 SQL，快速驗證查詢。
  • 驗證一段查詢邏輯：不用起資料庫服務，直接在瀏覽器裡建表、插資料、跑 SQL，快速確認結果是否符合預期。

常見問題

能建表嗎？
可，運行於記憶體庫，重新整理即清空。
資料會儲存嗎？
不會。執行在瀏覽器記憶體（或臨時庫）中，重新整理頁面即丟失，且不上傳任何內容——這是它適合臨時驗證與教學演示的原因，也意味著不能當作持久化儲存使用。需要保留結果請手動匯出 SQL 或 CSV。
