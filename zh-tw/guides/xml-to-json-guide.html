XML 轉 JSON 使用指南

將 XML 對映為 JSON：標籤為鍵、屬性字首化、重複標籤轉陣列。便於前端用 JS 直接消費。本地轉換不上傳。

核心功能

  • XML→JSON 對映
  • 屬性轉 @ 字首鍵
  • 重複兄弟標籤轉陣列
  • 文本節點抽取
  • 本地處理

適用場景

  • 舊介面 XML 接入前端
  • 配置 XML 轉可讀物件
  • 資料格式遷移

使用步驟

  1. 貼上 XML
  2. 點選轉換
  3. 檢視 JSON 並複製

實用技巧

  • 屬性預設加 @ 字首避免與子節點衝突
  • 無子節點無屬性的標籤直接變字串
  • 同名多子節點自動成陣列

常見問題

屬性怎麼表示？
通常加 "@" 字首，如 <a id="1"> → {"a":{"@id":"1"}}。
能給個例子嗎？
"<a><b>1</b><b>2</b></a>" → {"a":{"b":["1","2"]}}。
