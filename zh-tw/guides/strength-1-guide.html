紙箱抗壓強度（馬基公式） 使用指南

由三項環壓估算 ECT，或用實測 ECT 直接計算 BCT；估算模式必須完整填寫三項環壓，空值不再按 0 處理。

功能說明

估算模式：ECT≈(面紙環壓 + 裡紙環壓 + 芯紙環壓×瓦楞率)×換算係數；直接模式：使用輸入的實測 ECT，完全忽略三項環壓。再由 McKee 近似式 BCT=5.87×ECT×√(周長×厚度) 計算，並結合安全係數、單箱重量與箱高給出堆碼層數。

典型使用場景

  • 已有 ECT 實測值：選直接模式，快速估算 BCT 與堆碼能力。
  • 只有原紙環壓：選估算模式，完整填寫三項環壓後估算 ECT。
  • 方案對比：調整楞型或環壓，觀察 BCT 與堆碼高度變化。

算例參考

  • C 楞、面紙 6000、裡紙 4000、芯紙 2500 N/m、係數 0.5：ECT≈(6000+4000+2500×1.45)×0.5=6812.5 N/m；400×300×300mm、厚 3.6mm 時 BCT≈3994 N。
  • 直接 ECT=7000 N/m：不再讀取環壓；即使環壓留空或為負，也不影響直接模式計算。

注意事項

環壓 0 表示確實測得為 0，不等同於未測；三項全為 0 時無法估算，頁面會拒絕。McKee 公式為經驗近似，實際 BCT 受箱型、開孔、印刷、溼度與堆碼時間影響，應以整箱實測為準。

BCT 公式 BCT=5.87·ECT·√(Pm·d) 適用條件？
這是 McKee 經驗公式的常用形式，適用於規則開槽箱(RSC)、瓦楞方向正確的 ECT 輸入。ECT 可由面/中紙環壓與楞型伸張係數估算（ECT≈(面+面+中×takeup)×效率），也可直接實測輸入。
安全係數取多少合適？
一般運輸倉儲取 3–5，潮溼/長週期/自動堆碼取高值。它綜合溫溼度、堆碼時間、振動與人工因素；安全係數過小易壓塌，過大則過度用材增成本。
