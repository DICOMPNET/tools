直線斜率計算器 使用指南

直線斜率計算器由兩點座標求直線斜率 k，適合解析幾何、函式作圖與工程坡度（如道路、屋頂）的傾斜度計算。

計算公式與原理

k = (y₂−y₁)/(x₂−x₁)

由兩點座標求直線斜率。

使用步驟

  1. 填寫「x₁」。
  2. 填寫「y₁」。
  3. 填寫「x₂」。
  4. 填寫「y₂」。
  5. 結果區會即時更新；可一鍵複製結果用於記錄或彙報。

典型使用場景

  • 求兩點連線的傾斜程度
  • 判斷函式增減性、趨勢
  • 工程坡度、道路仰角換算

算例參考

  • 兩點斜率：過 (1,2) 與 (4,8)：斜率 m=(8-2)/(4-1)=6/3=2，即 x 每增 1，y 增 2。垂直直線斜率不存在（分母為 0）。
  • 斜率與角度：m=tanθ，m=1 對應 45°，m=√3 對應 60°。負斜率表示下降。

注意事項

本工具純前端執行，輸入內容不上傳伺服器；結果為按上述口徑得到的理論估算值。實際應用受裝置引數、測量條件與當地規範影響，請以裝置銘牌、檢測報告與現行標準為準，重大決策建議諮詢專業人士。

斜率為 0 和不存在分別是什麼線？
斜率為 0 是水平線（y 恆定）；斜率不存在（分母 0）是豎直線（x 恆定）。
斜率和傾角關係？
m=tanθ，θ 為與 x 軸正向夾角。由此可從斜率反推角度，或從角度得斜率。
