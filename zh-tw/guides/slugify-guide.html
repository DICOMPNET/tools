URL Slug 生成器 使用指南

Slug 是 URL 中可讀的路徑段，如 "how-to-use-toolbox"。本工具把標題轉小寫、去標點、空格換連字元，並儘量保留語義，利於 SEO 與分享。本地轉換。

核心功能

  • 標題→slug 轉換
  • 空格/下劃線轉連字元
  • 去除或保留停用詞
  • 支援中文轉拼音
  • 本地處理

適用場景

  • 部落格/文章 URL 生成
  • 商品頁友好連結
  • 批次處理標題

使用步驟

  1. 貼上標題文本
  2. 選分隔符與語言策略
  3. 點選生成
  4. 複製 slug

實用技巧

  • slug 短而含關鍵詞更利 SEO
  • 避免連續連字元
  • 中文建議轉拼音或保留英文關鍵詞

常見問題

slug 為什麼重要？
清晰 slug 提升可讀性與搜尋點選率。
能給個例子嗎？
"Hello World! 2026" → "hello-world-2026"。
