CSAT客戶滿意度評分 使用指南

錄入各星級評價人數，自動計算 CSAT 得分、滿意度分佈與 NPS 趨勢參考，評估客戶體驗。

功能說明

錄入各星級評價人數，自動計算 CSAT 得分、滿意度分佈與 NPS 趨勢參考，評估客戶體驗。

典型使用場景

  • 滿意度核算：錄入各星級評價人數（1-5 星），工具算出 CSAT（4-5 星佔比）、NPS（推薦者−貶損者）、平均星級與等級評定。
  • 服務評級：按 CSAT 閾值（≥90 優秀 / ≥75 良好 / ≥50 合格 / 否則需改善）給出等級，結合貶損者佔比判斷是否觸發整改。
  • 趨勢對比：將不同週期（本月 vs 上月）的星級分佈分別核算，量化服務改善幅度，支撐 KPI 考核與團隊激勵。

算例參考

  • 算例：100 條評價（5星50 / 4星30 / 3星12 / 2星5 / 1星3）：總評價 100；滿意(4+5星)=80 → CSAT = 80.0%（良好）；推薦者(5星)=50% → NPS = 50% − 貶損者(1+2星=8%) = 42；平均星級 = (3×1+5×2+12×3+30×4+50×5)/100 = 4.19；貶損者佔比 8.0%。結論：滿意度良好，但仍有 8% 貶損者，建議針對差評工單做根因分析。

注意事項

本工具純前端執行，輸入內容不上傳伺服器；結果為按上述口徑得到的理論估算值。實際應用受裝置引數、測量條件與當地規範影響，請以裝置銘牌、檢測報告與現行標準為準，重大決策建議諮詢專業人士。

CSAT 和 NPS 有什麼區別？
CSAT 衡量「滿意」（4-5 星佔比），關注整體體驗；NPS 衡量「忠誠」（推薦者% − 貶損者%），關注復購與口碑。本工具二者同屏給出：上例 CSAT=80%、NPS=42。
等級評定依據什麼閾值？
CSAT ≥90 為優秀、≥75 為良好、≥50 為合格、低於 50 為需改善。上例 80% 處於「良好」檔；若貶損者佔比 >20% 會額外提示負面口碑風險。
