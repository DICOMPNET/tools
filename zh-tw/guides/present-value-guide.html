現值計算器 使用指南

現值（PV）線上計算器，輸入未來金額、折現率與期數求得當前價值，用於投資與理財決策，純前端執行。

計算公式與原理

PV = FV / (1 + r)^t

現值（PV）線上計算器，輸入未來金額、折現率與期數求得當前價值，用於投資與理財決策，純前端執行。

使用步驟

  1. 填寫「未來值 FV」。
  2. 填寫「貼現率 r (%)」。
  3. 填寫「年數 t」。
  4. 結果區會即時更新；可一鍵複製結果用於記錄或彙報。

典型使用場景

  • 貼現決策：錄入未來金額與貼現率，算現值判斷是否值得。
  • 債券估值：對多期票息+本金貼現求現值。
  • 教學演示：演示貼現率越高現值越低。

算例參考

  • 使用示例：示例：1 年後 11000、貼現率 10%，PV=11000/1.1=10000。

注意事項

本工具純前端執行，輸入內容不上傳伺服器；結果為按上述口徑得到的理論估算值。實際應用受裝置引數、測量條件與當地規範影響，請以裝置銘牌、檢測報告與現行標準為準，重大決策建議諮詢專業人士。
