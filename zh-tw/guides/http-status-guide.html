HTTP 狀態碼查詢 使用指南

HTTP 狀態碼標識請求結果：2xx 成功、3xx 重定向、4xx 客戶端錯誤、5xx 服務端錯誤。輸入碼號即查含義與排查方向，開發除錯常備。

核心功能

  • 1xx–5xx 全類查詢
  • 顯示類別與含義
  • 附常見觸發原因
  • 搜尋/瀏覽定位
  • 本地速查

適用場景

  • 介面返回 4xx/5xx 快速定位
  • 寫文件標註狀態碼含義
  • 面試/教學速查

使用步驟

  1. 輸入狀態碼如 404
  2. 檢視類別與說明
  3. 按需瀏覽同類碼

實用技巧

  • 4xx 多為請求問題(路徑/許可權)，5xx 多為服務端 bug
  • 301/302 是重定向，307/308 更嚴格
  • 401 未認證、403 無許可權

常見問題

404 和 410 區別？
404 資源未找到(可能臨時)，410 明確表示已永久刪除。
能給個例子嗎？
輸入 429 顯示"請求過多"，提示限流需退避重試。
