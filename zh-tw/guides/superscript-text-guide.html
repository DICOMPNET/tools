上標文字 使用指南

將選中文字轉為上標格式並生成可複製的 Unicode 或 HTML 上標程式碼，適合化學式、數學指數與腳註標註，便於在文件中插入上標。

功能說明

將選中文字轉為上標格式並生成可複製的 Unicode 或 HTML 上標程式碼，適合化學式、數學指數與腳註標註，便於在文件中插入上標。

使用步驟

  1. 填寫「轉換模式」。
  2. 結果區會即時更新；可一鍵複製結果用於記錄或彙報。

典型使用場景

  • 化學式與數學公式展示：把指數、階碼轉為上標形態（如 x²、CO₂ 的 2 用上標）。
  • 腳註與修訂標記：在正文標註上標序號，對應文末注。
  • 單位與版本號：如 m²、v2 的輕量展示。

算例參考

  • 生成 x 的平方：輸入「x2」，上標模式輸出「x²」；也可用上標數字區塊直接展示，適合化學式 H₂O、面積 m² 等無需公式環境的場景。

注意事項

本工具在瀏覽器本地執行，輸入內容不會上傳伺服器；結果為模型估算，工程決策請結合實測資料複核。

上標和普通小字區別？
上標用專用 Unicode 上標碼位（² ¹ ⁿ），排版位置更高且不被當作普通數字參與計算；普通縮小的字只是視覺變小。
所有數字都有上標嗎？
Unicode 上標有 ⁰¹²³⁴⁵⁶⁷⁸⁹ 及 ⁺⁻⁼⁽⁾ⁿ，連續多位可直接拼接；無對應碼位的符號需藉助富文本/HTML <sup>。
