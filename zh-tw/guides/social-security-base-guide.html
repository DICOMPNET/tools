社保繳納基數查詢 使用指南

查詢全國主要城市2024年社保繳納基數上下限及繳費比例，輸入工資計算實際繳納金額

功能說明

查詢全國主要城市2024年社保繳納基數上下限及繳費比例，輸入工資計算實際繳納金額

使用步驟

  1. 填寫「選擇城市」。
  2. 填寫「險種」。
  3. 填寫「月工資（元）」。
  4. 結果區會即時更新；可一鍵複製結果用於記錄或彙報。

典型使用場景

  • 按當地上下限把工資「 clamp 」到繳費基數，估算單位與個人各險種繳費額。
  • 工資低於下限按下限、高於上限按上限繳納。
  • 對比不同城市費率與基數，輔助參保與薪酬規劃。

算例參考

  • 基數 1 萬、常見費率：養老單位 16% = 1600、個人 8% = 800；醫療單位約 8% = 800、個人 2% = 200；失業單位 0.5% = 50、個人 0.5% = 50；月繳單位合計約 2470、個人約 1050 元（費率以當地為準）。
  • 工資越限處理：工資 3000 低於下限 4250 則按下限繳；工資 3 萬高於上限 21258 則按上限繳，超出部分不計入基數。

注意事項

本工具純前端執行，輸入內容不上傳伺服器；結果為按上述口徑得到的理論估算值，涉及具體爭議請以證據與司法機關認定為準，必要時諮詢執業律師。

繳費基數怎麼確定？
一般以上年度本人月平均工資為準，在當地公佈的上下限之間；新參保按起薪當月工資，後續年度調整。
單位和個人比例固定嗎？
全國框架統一但各省費率略有差異（如工傷按行業風險浮動、醫保單位比例不同），以參保地規定為準。
