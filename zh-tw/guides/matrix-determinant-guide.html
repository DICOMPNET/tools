矩陣行列式 使用指南

矩陣 [[a,b],[c,d]] 行列式 = ad−bc；如 [[3,2],[5,7]] → 3·7−2·5=11。…

核心功能

  • 計算 2×2 到 5×5 方陣的行列式
  • 切換尺寸即重新整理輸入格，無需手搭矩陣
  • 行列式為 0 說明矩陣不可逆
  • 用於線性代數作業、方程組可解性判斷

適用場景

  • 判斷方陣可逆性、解線性方程組（克拉默法則）。
  • 判斷線性方程組是否有唯一解：先算係數矩陣的行列式，為 0 則方程相關或無解，不必再往後求逆。

使用步驟

  1. 在尺寸下拉里選方陣階數（2 到 5）
  2. 在生成的表格裡逐格填數
  3. 點計算得到行列式值
  4. 若結果為 0，該矩陣不可逆，線性方程組無唯一解
  5. 填入分數或小數均可，注意精度導致的近似 0

實用技巧

  • 工程上直接交給數值庫，但要注意接近 0 的行列式可能只是浮點誤差

常見問題

行列式為 0 說明？
矩陣奇異、不可逆，方程組可能無解或無窮解。
大矩陣手工算容易錯怎麼辦？
手算高階行列式確實容易出錯，通常用「初等行變換化成上三角、再取對角線乘積」的辦法，比按行展開省事得多；計算時注意每交換兩行要變號、某行乘以 k 則行列式也乘 k。工程上直接交給數值庫，但要注意接近 0 的行列式可能只是浮點誤差。
