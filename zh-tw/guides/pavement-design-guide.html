路面厚度設計 使用指南

按 AASHTO 柔性路面 SN 法，輸入累計軸次、可靠度與路基模量，計算所需結構層數與各層厚度，用於公路路面結構設計。

功能說明

按 AASHTO 柔性路面 SN 法，輸入累計軸次、可靠度與路基模量，計算所需結構層數與各層厚度，用於公路路面結構設計。

典型使用場景

  • 按 AASHTO 經驗法，根據累計當量軸載作用次數 W₁₈、可靠度 R、總體標準差 S₀、路基土回彈模量 MR 與使用年限內服務效能衰減（p₀−pₜ），反算所需路面結構數 SN。
  • 將 SN 分配給瀝青面層、基層、底基層：各層結構數 = 層厚(in)×層係數 a，面層滿足後剩餘按 40% 基層 / 60% 底基層分配，得到各層厚度。
  • 對比不同材料組合（面層 a₁、基層 a₂、底基層 a₃ 取值不同）對總厚度與造價的影響，做方案比選。

算例參考

  • 可復現算例（W₁₈=1e7, R=95%, S₀=0.45, MR=80MPa, p₀=4.5, pₜ=2.5）：可靠度係數 Z_R = −1.645（95%）；dPSI = 4.5−2.5 = 2.0；MR(psi)=80×145.038 ≈ 11603。 目標式：log₁₀W₁₈ − Z_R·S₀ − 2.32·log₁₀(MR) + 8.07 + 0.20 = 7.0 + 0.740 − 9.430 + 8.27 ≈ 6.58。 二分求得所需 SN ≈ 4.33，向上取整 4.4。 面層 10cm（a₁=0.44）：SN₁=0.44×(10/2.54)=1.73；剩餘 4.4−1.73=2.67。 分配：基層 40%→SN₂≈1.07→D₂=ceil(1.07/0.14×2.54)=20cm；底基層 60%→SN₃≈1.60→D₃=ceil(1.60/0.11×2.54)=37cm。 總厚 = 10+20+37 = 67 cm，實際 SN≈0.44×3.94+0.14×7.87+0.11×14.57≈1.73+1.10+1.60=4.44 ≥ 4.4 → 滿足。

注意事項

本工具純前端執行，輸入內容不上傳伺服器；結果為按上述口徑得到的理論估算值。實際應用受裝置引數、測量條件與當地規範影響，請以裝置銘牌、檢測報告與現行標準為準，重大決策建議諮詢專業人士。

結構數 SN 是厚度嗎？
不是直接厚度，而是各結構層「層厚(英寸)×層係數 a」之和，反映整體抗彎能力。層係數 a 由材料型別決定（瀝青面層約 0.44、級配碎石基層約 0.14）。SN 達標後還需換算成實際層厚，並向上取整便於施工。
可靠度 R 和標準差 S₀ 怎麼影響結果？
R 越高（如 99% vs 80%）Z_R 絕對值越大，所需 SN 越高、路面越厚；S₀ 反映軸載與材料變異，變異越大也需更厚。提高可靠度直接增加造價，設計中需結合道路等級權衡。
