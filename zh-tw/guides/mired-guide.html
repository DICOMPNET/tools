色溫換算 mired 使用指南

輸入光源色溫（開爾文）或 mired 微倒數單位之一，工具在兩者間互換；攝影中可用 mired 描述濾光片帶來的色溫偏移量，便於校色與冷暖調補償時快速選取校正濾鏡。

計算公式與原理

Mired = 1,000,000 / KK = 1,000,000 / mired

輸入光源色溫（開爾文）或 mired 微倒數單位之一，工具在兩者間互換；攝影中可用 mired 描述濾光片帶來的色溫偏移量，便於校色與冷暖調補償時快速選取校正濾鏡。

典型使用場景

  • 由開爾文色溫求 Mired 值。
  • 用濾鏡 Mired 偏移校正色溫。
  • 混合光源白平衡。

算例參考

  • Mired 計算：3200K 鎢絲燈：Mired = 1e6/3200 = 312.5；加 +100 暖調濾鏡後 Mired=212.5 → 色溫 = 1e6/212.5 ≈ 4706K，明顯變暖。
  • 偏移方向：Mired 降=色溫升（偏藍冷），升=色溫降（偏橙暖）；校日光用減 Mired 藍鏡、校鎢絲用加 Mired 橙鏡。

注意事項

本工具純前端執行，輸入內容不上傳伺服器；結果為按上述口徑得到的理論估算值。實際應用受裝置引數、測量條件與當地規範影響，請以裝置銘牌、檢測報告與現行標準為準，重大決策建議諮詢專業人士。

為什麼用 Mired 不用 K？
濾鏡對色溫的影響是減法且非線性，用 Mired（1e6/K）近似線性，便於疊加濾鏡偏移量。
偏移量怎麼定？
目標色溫與現狀 Mired 之差即為需加偏移；如 5500K(182) 校到 3200K(312) 需 +130 Mired 橙鏡。
