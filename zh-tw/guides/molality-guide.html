質量摩爾濃度（b = n / m_溶劑） 使用指南

輸入溶質物質的量與溶劑質量（kg），按 b=n/m 計算質量摩爾濃度，該濃度不受溫度影響，常用於依數性與熱力學計算。

計算公式與原理

b = n / m_溶劑

質量摩爾濃度 = 溶質物質的量 / 溶劑質量(kg)，不受溫度影響。

使用步驟

  1. 填寫「物質的量 (mol)」。
  2. 填寫「溶劑質量 (kg)」。
  3. 結果區會即時更新；可一鍵複製結果用於記錄或彙報。

典型使用場景

  • 冰點降低：由 b 與 Kf 算 ΔTf，估溶液冰點。
  • 配製基準：稱溶質+溶劑質量得 b，不受體積溫度影響。
  • 滲透壓強：由 b 算滲透壓 π=bRT。

算例參考

  • 0.1 mol 溶質溶於 0.5 kg 水演練：輸入 n=0.1 mol、溶劑 0.5 kg，工具輸出 b=0.20 mol/kg，並提示溶劑質量不含溶質。

注意事項

本工具純前端執行，輸入內容不上傳伺服器；結果為按上述口徑得到的理論估算值。實際應用受裝置引數、測量條件與當地規範影響，請以裝置銘牌、檢測報告與現行標準為準，重大決策建議諮詢專業人士。
