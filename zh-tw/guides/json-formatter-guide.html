JSON 格式化 使用指南

JSON 是前後端通訊的事實標準，但原始的壓縮 JSON 難以閱讀。ToolBox JSON 格式化工具在本地幫你美化縮排、校驗語法錯誤、摺疊展開節點，是除錯介面返回值的得力助手。

核心功能

  • 一鍵美化：壓縮 JSON 按層級縮排顯示
  • 語法校驗：定位缺失的引號、逗號、括號等錯誤
  • 緊湊模式：把美化後的 JSON 再壓縮成單行
  • 樹形摺疊：大物件可逐層展開/收起
  • 複製結果：格式化後一鍵複製

適用場景

  • 對接介面時檢視後端返回的 JSON 結構
  • 排查前端報錯：定位 JSON.parse 失敗的準確位置
  • 整理配置檔案、日誌片段
  • 對比兩份 JSON 的結構差異

使用步驟

  1. 把原始 JSON 貼上到左側輸入框
  2. 點選"格式化"，右側出現帶縮排的結果
  3. 若提示語法錯誤，按高亮位置修正後重試
  4. 需要摺疊時點選行首三角收起子節點
  5. 點選"複製"把結果用於程式碼或文件

實用技巧

  • 格式化前先確認內容確實為 JSON，而非 XML 或 YAML
  • 超長單行 JSON 建議先格式化再閱讀，錯誤位置更易定位
  • 生產環境不要把包含金鑰的 JSON 貼上到不可信的線上工具，本地工具更安全

常見問題

為什麼提示 JSON 語法錯誤？
常見原因是尾部多了逗號、鍵名沒加雙引號、或使用了單引號；按提示位置修正即可。
格式化會修改資料嗎？
不會，僅調整排版與縮排，資料內容保持不變。
