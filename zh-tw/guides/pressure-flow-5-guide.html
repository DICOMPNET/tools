閥門選型計算（Cv/Kv 流量係數） 使用指南

演算法：相對密度 SG = 介質密度/1000；Kv = 流量×√(SG/壓差)；Cv = 1.167×Kv；設計 Cv = Cv×1.3；在標準通徑 Cv 系列中取首個 ≥ 設計 Cv 者作為推薦通徑；估算流速 = 流量…

核心功能

  • 按流量、壓差與介質密度計算 Cv/Kv
  • 按估算流速校核所選通徑
  • 反算既有閥門 Cv 判斷開度與調節效能
  • 輸出 Cv/Kv 換算與選型建議

適用場景

  • 調節閥選型：由流量、壓差與介質密度算 Cv/Kv 並選通徑
  • 口徑校核：用估算流速判斷所選通徑是否合適
  • 既有閥門評估：反算 Cv 判斷開度與調節效能

使用步驟

  1. 輸入流量與閥前後壓差
  2. 輸入介質密度（或相對密度）
  3. 點選計算，讀取所需 Cv/Kv
  4. 按 1.3 倍餘量選擇閥門通徑
  5. 用流速校核所選通徑是否合適

實用技巧

  • Kv 為公制（m³/h、1bar 水）、Cv 為英制（US gal/min、1psi），Cv = 1.167×Kv，須確認廠家口徑
  • 設計 Cv 常乘 1.3~2.0 留開度餘量，避免長期大開度導致調節效能變差
  • 選型須結合閥權度與可調比校核
  • 高黏度、閃蒸/汽蝕工況須特殊修正，必要時選防汽蝕閥內件

常見問題

Kv 和 Cv 有什麼區別？
Kv 是國際單位制流量係數（m³/h，壓差 1bar、介質為水）；Cv 是英制（US gal/min，壓差 1psi）。換算關係為 Cv = 1.167×Kv，選型時務必確認廠家樣本使用的是哪一種。
為什麼設計 Cv 要乘 1.3？
為閥門開度與工況波動留餘量，避免閥門長期在過大開度工作導致調節效能變差。調節型閥門通常按計算 Cv 的 1.3~2.0 倍選取，並結合閥權度與可調比校核。
