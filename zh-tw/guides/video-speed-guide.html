影片倍速時長計算器

輸入影片原時長與播放倍速，立刻算出倍速後的觀看時長與節省時間；支援時間碼與秒互轉、按幀率換算幀數，也可用目標時長反推需要的倍速，並附常見倍速對照表。

核心功能

  • 按時 / 分 / 秒 / 毫秒輸入原時長，設定倍速後得出實際觀看時長與節省量
  • 時間碼 HH:MM:SS:FF 與秒雙向互轉，幀率可設（常見 24 / 25 / 30 fps）
  • 反向計算：填入目標時長，反推需要的播放倍速
  • 常見倍速對照表（0.25x~4x），含節省百分比與適合場景
  • 計算歷史儲存在瀏覽器本地，可回看複用
  • 結果與時間碼一鍵複製

適用場景

  • 刷課前估算：這門課用 1.5 倍速看完需要多久
  • 剪輯排期：把時間碼換算成秒，安排片段與字幕
  • 配音對齊：按目標時長反推該用多少倍速

使用步驟

  1. 填入原時長的時 / 分 / 秒 / 毫秒
  2. 設定播放速度（可用 0.5x / 1x / 1.25x / 1.5x / 2x 等快捷按鈕）
  3. 檢視倍速後的時長、節省時間與節省百分比
  4. 需要時切到時間碼區，輸入 HH:MM:SS:FF 並設定幀率換算
  5. 已知目標時長時，填入「目標時長(秒)」反推所需倍速

實用技巧

  • 倍速後時長 = 原時長 ÷ 倍速
  • 幀率影響時間碼精度：國內電視常用 25 fps，影視常用 24 fps
  • 結果會按幀取整，與播放器顯示可能有幾幀誤差
  • 歷史記錄存於瀏覽器本地，清除瀏覽器資料會一併清除

常見問題

為什麼和播放器顯示的時間略有出入？
播放器常按幀取整或對音訊做變速處理，會產生幾秒差異，屬正常現象。
支援很慢或很快的倍速嗎？
支援 0.1x 到 16x 的輸入範圍，超出範圍請分次計算。
