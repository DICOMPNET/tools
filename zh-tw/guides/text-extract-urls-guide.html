提取 URL 使用指南

貼上含連結的文章/日誌/郵件，一鍵提取其中全部 http/https 連結，自動去重，方便批次檢查或匯出。本地處理。

核心功能

  • 正則提取 http/https 連結
  • 自動去重
  • 按出現順序列出
  • 一鍵複製全部

適用場景

  • 從網頁原始碼/筆記收集連結
  • 日誌裡抽取請求 URL
  • 批次核對外鏈

使用步驟

  1. 貼上文本
  2. 點選提取
  3. 檢視去重後的連結列表
  4. 複製或全部匯出

實用技巧

  • 僅匹配帶協議的完整連結
  • 去重按字串精確比對
  • 相對路徑(無 http)不會被識別

常見問題

為什麼有的連結沒被提取？
缺少 http(s):// 的相對路徑不會被匹配，需補全協議。
能給個例子嗎？
貼上"詳見 https://a.com 與 https://a.com 重複"，提取得 1 條去重連結。
