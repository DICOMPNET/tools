Ppk 過程效能計算器 使用指南

Ppk 過程效能計算器求考慮中心偏移的長期過程效能指數，適合實際生產資料的能力評估與供貨質量承諾。

計算公式與原理

Ppk = min((USL−μ),(μ−LSL)) / (3σ_lt)

Ppk 過程效能計算器求考慮中心偏移的長期過程效能指數，適合實際生產資料的能力評估與供貨質量承諾。

使用步驟

  1. 填寫「上規格限 USL」。
  2. 填寫「下規格限 LSL」。
  3. 填寫「過程均值 μ」。
  4. 填寫「長期標準差 σ_lt」。
  5. 結果區會即時更新；可一鍵複製結果用於記錄或彙報。

典型使用場景

  • 用整體標準差（長期）評估過程實際效能 Ppk，同時納入均值偏移，給出長期可達的合格品能力。
  • 與 Cpk 對照：Ppk 用整體σ、Cpk 用組內σ，兩者差大表示長期存在偏移或特殊原因。
  • 客戶年度稽核、PPAP 等用 Ppk 作為長期質量承諾指標。

算例參考

  • 公式與判定：Ppk = min[(USL − μ)/(3σ_long), (μ − LSL)/(3σ_long)]，σ_long 為整體標準差。判定：≥1.33 長期充足、<1.00 不足。Ppk 通常 ≤ Cpk。
  • 算例：規格 USL=10.05、LSL=9.95，長期均值 μ=10.0、整體σ_long=0.015：Ppk = min[(10.05−10.0)/(3×0.015), (10.0−9.95)/(3×0.015)] = min[0.05/0.045, 0.05/0.045] = min[1.111, 1.111] = 1.111。若短期 Cpk=1.667，則 Ppk<Cpk，提示長期需進一步穩定化。

注意事項

本工具純前端執行，輸入內容不上傳伺服器；結果為按上述口徑得到的理論估算值。實際應用受裝置引數、測量條件與當地規範影響，請以裝置銘牌、檢測報告與現行標準為準，重大決策建議諮詢專業人士。

Ppk 與 Cpk 的核心區別？
唯一差別在σ 的來源：Cpk 用組內（短期）標準差，Ppk 用整體（長期）標準差；兩者都計均值偏移。因而 Ppk 更貼近客戶長期收到貨的實際表現。
客戶要 Ppk 還是 Cpk？
PPAP/年度稽核多要求 Ppk（長期承諾），過程開發階段內部用 Cpk（短期能力）驅動改進；穩妥做法是兩者都達標且差距小，說明過程既能力強又穩定。
