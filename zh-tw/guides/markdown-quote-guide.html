Markdown 引用轉換器 使用指南

將貼上的多行文本批次轉換為 Markdown 引用塊（每行前加 >），便於在文件中引用他人內容或做批註說明。

功能說明

將貼上的多行文本批次轉換為 Markdown 引用塊（每行前加 >），便於在文件中引用他人內容或做批註說明。

典型使用場景

  • 引用他人內容：把選中段落批次加上 > 字首，生成規範 blockquote。
  • 多級引用與巢狀：演示如何在引用內再引用，保持縮排正確。
  • 寫文件「提示/警告」框：用引用塊承載 tip/note 內容。

算例參考

  • 多行加引用：貼上 3 行文字，工具在每行前加「> 」，得到「> 第一行 > 第二行 > 第三行」，渲染為連續引用塊；空行分隔可斷開為多個獨立引用。

注意事項

本工具在瀏覽器本地執行，輸入內容不會上傳伺服器；結果為模型估算，工程決策請結合實測資料複核。

怎麼巢狀引用？
在子行字首用「> > 」即可形成二級引用；層級越多字首 > 越多，注意層級間用空行分隔更易讀。
引用塊能包含程式碼嗎？
可以，引用塊內再用程式碼圍欄即可；但縮排與圍欄要正確閉合，否則會破壞引用結構。
