JSON 修復器 使用指南

手寫或介面返回的 JSON 常因漏括號、多逗號、用了單引號而報錯。本工具嘗試定位並修復常見格式問題，方便複製進程式碼或配置。純前端，資料不上傳。

核心功能

  • 補全缺失的括號與引號
  • 去除尾隨逗號
  • 單引號轉雙引號
  • 錯誤位置提示
  • 本地處理

適用場景

  • 介面返回的 JSON 被截斷
  • 從網頁複製的 JSON 漏了符號
  • 除錯 JSON.parse 報錯

使用步驟

  1. 貼上疑似出錯的 JSON
  2. 點選修復
  3. 複製修正後的結果

實用技巧

  • 修復後仍建議再校驗一次
  • 巢狀深時優先檢查最內層
  • 單引號是最常見的一個坑

常見問題

能修復所有錯誤嗎？
不能，僅處理常見格式問題；欄位語義錯誤仍需人工核對。
能給個例子嗎？
{"a":1,} 去掉尾隨逗號得到 {"a":1}。
