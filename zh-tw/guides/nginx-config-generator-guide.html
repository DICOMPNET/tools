Nginx 配置生成器 使用指南

Nginx 配置塊多易錯。本工具按常見場景（反向代理、靜態目錄、重定向、HTTPS）產出可用的 server 塊。本地生成不上傳。

核心功能

  • 反向代理片段
  • 靜態站點配置
  • 301 重定向
  • HTTPS/證書佔位
  • 本地處理

適用場景

  • 部署前端靜態站
  • 給後端加反向代理
  • 配置域名重定向

使用步驟

  1. 選場景填域名/埠
  2. 點選生成
  3. 複製 server 塊

實用技巧

  • proxy_pass 末尾斜槓注意
  • 靜態站用 root+try_files
  • 改完 nginx -t 校驗

常見問題

怎麼生效配置？
儲存後 nginx -s reload。
能給個例子嗎？
反向代理生成 location / { proxy_pass http://127.0.0.1:3000; }。
