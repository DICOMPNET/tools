JSON 轉 TOML 使用指南

TOML 是易讀的配置檔案格式（Rust/Cargo、Python pyproject 用）。本工具將 JSON 轉成等效 TOML，保持層級與型別。本地轉換。

核心功能

  • JSON→TOML 轉換
  • 巢狀表與陣列表達
  • 型別保真(數字/布林/字串)
  • 本地處理

適用場景

  • 寫 Cargo.toml / pyproject 片段
  • 配置格式遷移
  • 人讀化 JSON 配置

使用步驟

  1. 貼上 JSON
  2. 點選轉換
  3. 複製 TOML

實用技巧

  • TOML 表用 [section] 表達巢狀
  • 陣列用雙方括號 [[ ]]
  • 鍵含特殊字元需加引號

常見問題

TOML 和 YAML 選誰？
TOML 更貼近 ini、型別明確；YAML 更緊湊但縮排敏感。
能給個例子嗎？
{"a":{"b":1}} → "[a] b = 1"。
