文本轉 ASCII 藝術字 使用指南

用點陣字型把文字放大成由字元組成的圖案，常用於 README 橫幅與終端歡迎語。本工具按字型渲染並支援複製。純前端，不上傳。

核心功能

  • 多種字型風格
  • 橫幅大字渲染
  • 一鍵複製
  • 寬度自適應
  • 本地處理

適用場景

  • README 橫幅
  • 終端歡迎語
  • 趣味簽名

使用步驟

  1. 輸入文字
  2. 選字型
  3. 點選生成複製

實用技巧

  • 中文需用專用字型
  • 注意等寬顯示
  • 太長會折行

常見問題

能匯出圖片嗎？
本工具輸出文本，可截圖或粘到程式碼塊。
