笑聲合成器 使用指南

用瀏覽器原生 Web Audio API 即時合成笑聲波形（基頻振盪 + 顫音 LFO + 包絡），可調引數試聽，無音訊檔案、無版權風險。…

核心功能

  • 素材製作：本地合成「呵呵/哈哈」等笑聲，免找版權音訊。
  • 引數試聽：調基頻、時長、顫音即時試聽不同笑法。
  • 離線可用：純 Web Audio API 合成，無需聯網。
