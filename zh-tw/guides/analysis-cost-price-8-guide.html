價格（行情/成本/競爭）分析 使用指南

價格（行情/成本/競爭）分析工具。輸入產品價格、成本與競品資料，按通用財務規則測算毛利率與競爭定位，用於消防產品定價與經營分析（結果僅供參考）。

計算公式與原理

毛利 = 售價 - 單位成本；毛利率 = 毛利 / 售價

用售價、單位成本和競品價格列表評估單件利潤、毛利率與市場價格位置。

典型使用場景

  • 定價與競品分析是銷售策略的基礎：由售價、單位成本與競品價格帶，量化毛利、毛利率與市場定位。
  • 新品定價或調價時，需對照競品區間判斷自身處於高價、低價還是中段，避免定價脫離市場。
  • 毛利率低於行業基準時需回溯成本結構或調整售價，競品均價是重要參照錨點。

算例參考

  • 算例：售價 100、成本 60、競品[80,90,100,110,120]：單件毛利 = 100 − 60 = 40.00 元；毛利率 = 40/100×100 = 40.00%；競品均價 = (80+90+100+110+120)/5 = 100.00 元；售價相對競品均價 = (100/100−1)×100 = 0.00% → 處於競品區間。
  • 算例：價格位置判定：若售價 < 最低競品則『低於全部競品』，> 最高競品則『高於全部競品』，否則『處於競品區間』。結論隨競品集合與售價即時變化，輸入至少 1 個有效競品價才有意義。

注意事項

本工具純前端執行，輸入內容不上傳伺服器；結果為按上述口徑得到的理論估算值。實際應用受裝置引數、測量條件與當地規範影響，請以裝置銘牌、檢測報告與現行標準為準，重大決策建議諮詢專業人士。

毛利率和單件毛利有什麼區別？
單件毛利=售價−成本（絕對額，元），毛利率=毛利÷售價×100%（相對比例）。毛利率排除了售價量級影響，更適合跨品類、跨價位比較。
競品價格帶不完整會影響結論嗎？
會。最低/最高競品決定『高於/低於全部競品』的判定，均價決定相對位置。樣本過少或漏掉關鍵競品會使定位失真，建議覆蓋主流競品後再下結論。
