BPM 速度轉換器 使用指南

BPM 與音符時長、延遲時間、LFO 頻率、取樣長度互轉，音樂製作與 DJ 必備

功能說明

BPM 與音符時長、延遲時間、LFO 頻率、取樣長度互轉，音樂製作與 DJ 必備

使用步驟

  1. 填寫「BPM 數值 (40-300)」。
  2. 結果區會即時更新；可一鍵複製結果用於記錄或彙報。

典型使用場景

  • 編曲時把 BPM 轉成四分音符毫秒，對齊音符網格與延遲時間
  • 給 LFO/顫音設與 BPM 同步的頻率（如每拍一次的濾波掃頻）
  • 按取樣率算某音符佔多少採樣點，做精準切片

算例參考

  • BPM 轉音符時長：120 BPM → 四分音符 = 60000/120 = 500 ms；八分 = 250 ms、十六分 = 125 ms、附點四分 = 500×1.5 = 750 ms。
  • LFO 與取樣數：120 BPM 下每拍 500 ms；要 LFO 每拍一個週期，頻率 = 1000/500 = 2 Hz。44100 Hz 取樣率下四分音符 = round(500/1000×44100) = 22050 個取樣點。

注意事項

本工具純前端執行，輸入內容不上傳伺服器；結果為按上述口徑得到的理論估算值。實際應用受裝置引數、測量條件與當地規範影響，請以裝置銘牌、檢測報告與現行標準為準，重大決策建議諮詢專業人士。

BPM 和毫秒怎麼互轉？
四分音符毫秒 = 60000 / BPM；已知某音符毫秒 ms，對應 BPM = 60000 × 該音符的拍數 / ms（如八分音符拍數 0.5）。
LFO 同步頻率怎麼算？
週期毫秒 = 四分音符毫秒 × 倍數（每拍=1、每兩拍=2），頻率(Hz) = 1000 / 週期毫秒；如每小節(4 拍)一次 = 1000/(500×4)=0.5 Hz。
