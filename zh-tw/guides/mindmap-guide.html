思維導圖編輯器 使用指南

在左側用 Markdown 縮排書寫層級，右側即時生成思維導圖，支援縮放、拖拽與匯出，輔助知識整理。

功能說明

在左側用 Markdown 縮排書寫層級，右側即時生成思維導圖，支援縮放、拖拽與匯出，輔助知識整理。

使用步驟

  1. 填寫「Markdown 編輯區Tab 增加層級 / Shift+Tab 減少」。
  2. 結果區會即時更新；可一鍵複製結果用於記錄或彙報。

典型使用場景

  • 做讀書筆記或頭腦風暴時，用 # 標題與 - 列表的縮排直接表達層級，右側自動生成思維導圖，比手動畫節點更快。
  • 整理會議議題時，把中心主題放在一級、討論點放在子級，縮排越深層級越深，結構一目瞭然。
  • 準備彙報大綱時，先把要點寫成 Markdown 大綱再匯出圖片，配合縮放、拖拽、節點摺疊展開做演示。

算例參考

  • 示例：用縮排語法寫一張思維導圖：# 產品規劃 ## 使用者增長 - 渠道投放 - 活動裂變 ## 體驗最佳化 - 效能 - 互動 左側按縮排書寫，右側即時生成導圖；滾輪縮放、拖拽平移、單擊圓點可摺疊/展開子節點。匯出 PNG 前先點「適應螢幕」讓內容完整顯示。

注意事項

本工具純前端執行，輸入內容不上傳伺服器；結果為按上述口徑得到的理論估算值。實際應用受裝置引數、測量條件與當地規範影響，請以裝置銘牌、檢測報告與現行標準為準，重大決策建議諮詢專業人士。

如何調整節點層級？
用 # 表示標題層級、用 - 列表表示子節點，縮排越多層級越深；Tab 鍵可快速縮排調整從屬關係。
怎麼匯出完整思維導圖？
支援匯出 SVG 與 PNG；匯出 PNG 前建議先點「適應螢幕」，確保所有內容落在畫布內不被裁切，草稿儲存在 localStorage。
