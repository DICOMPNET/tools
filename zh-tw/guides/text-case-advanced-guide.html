高階大小寫轉換 使用指南

在基礎大小寫轉換之上支援按句、按標題規則智慧轉換英文大小寫，並保留專有名詞，適用於長文件英文排版規範化，本地處理不聯網。

功能說明

在基礎大小寫轉換之上支援按句、按標題規則智慧轉換英文大小寫，並保留專有名詞，適用於長文件英文排版規範化，本地處理不聯網。

典型使用場景

  • 程式設計命名互轉：在 camelCase、PascalCase、snake_case、kebab-case 之間轉換，統一多語言程式碼風格。
  • 資料庫欄位與 API 欄位對映：把下劃線欄位轉前端駝峰，或反向。
  • 配置檔案鍵規範化：批次把 YAML/JSON 鍵統一為某風格。

算例參考

  • my_var_name 轉 camelCase：輸入「my_var_name」，camelCase 輸出「myVarName」，PascalCase 輸出「MyVarName」，kebab-case 輸出「my-var-name」；用於把 Python 變數名改成 JS 屬性名。

注意事項

本工具在瀏覽器本地執行，輸入內容不會上傳伺服器；結果為模型估算，工程決策請結合實測資料複核。
