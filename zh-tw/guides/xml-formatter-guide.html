XML 格式化 使用指南

XML 常用於配置與資料交換。本工具對縮排混亂的 XML 重新排版、高亮層級，並可檢測標籤是否閉合。純前端，資料不上傳。

核心功能

  • 縮排美化 XML
  • 標籤閉合校驗
  • 摺疊展開節點
  • 支援大檔案分段
  • 本地處理

適用場景

  • 檢視介面返回的 XML
  • 整理配置檔案
  • 排查標籤缺失

使用步驟

  1. 貼上 XML
  2. 點選格式化
  3. 檢視縮排結果或錯誤提示

實用技巧

  • 屬性與子元素混排時注意層級
  • CDATA 內文本不被解析
  • 錯誤會標出大致行號
