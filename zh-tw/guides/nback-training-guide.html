N-Back 工作記憶訓練

螢幕上連續出現字母、位置或圖形，你需要判斷當前這一個是否與前面第 N 個相同。N 越大越難（1-back 最簡單，3-back 已很有挑戰）。這是認知訓練研究中最常用的範式，可提升工作記憶與注意力。

核心功能

  • 可調 N 值（1-back 到 3-back 及以上）
  • 刺激型別可選字母 / 位置 / 雙 N-back
  • 逐 trial 即時反饋對錯
  • 得分、正確率與連續正確統計
  • 難度隨 N 自適應或手動設定
  • 純前端執行，資料不上傳

適用場景

  • 認知訓練：系統提升工作記憶容量
  • 研究參與：復現經典 N-back 範式
  • 專注力練習：每天幾組保持狀態

使用步驟

  1. 選擇 N 值（新手從 1-back 起）與刺激型別
  2. 記住前面第 N 個刺激是什麼
  3. 當前刺激出現時判斷是否匹配
  4. 答對繼續，答錯看反饋後繼續
  5. 逐步把 N 調到 2、3 提升難度

實用技巧

  • 2-back 已接近多數人的舒適上限
  • 雙 N-back（同時看字母和位置）難度陡增
  • 先把 1-back 練到幾乎全對再升 N
  • 保持節奏，過快易錯、過慢記不清

常見問題

N-back 訓練真的有效嗎？
研究顯示對訓練任務本身提升明顯，遷移到日常其他任務存在爭議，但作為腦力鍛鍊有普遍價值。
N 越大越好嗎？
不是，超過自己能力太多隻會挫敗；在能做對七八成的難度最利於提升。
