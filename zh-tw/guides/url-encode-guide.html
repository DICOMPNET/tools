URL 編碼 使用指南

URL 只允許部分安全字元，中文、空格、& 等需編碼。ToolBox URL 編碼在本地幫你對網址或引數做編碼/解碼，避免請求出錯。

核心功能

  • URL 編碼與解碼雙向
  • 處理中文、空格、特殊字元
  • 保留常見安全字元 unchanged
  • 支援整段或引數片段
  • 一鍵複製

適用場景

  • 把中文關鍵詞拼進查詢引數
  • 構造含特殊字元的下載連結
  • 除錯介面 400/亂碼問題
  • 表單 GET 引數預處理

使用步驟

  1. 選擇編碼或解碼
  2. 貼上待處理文本
  3. 點選轉換，得到結果
  4. 核對編碼後是否可被正常解析
  5. 複製用於連結或請求

實用技巧

  • 空格在 URL 中常編碼為 %20 或 +，按場景選擇
  • 僅編碼引數值，別把整個協議/域名編碼了
  • 解碼前確認是標準編碼，避免雙重編碼

常見問題

為什麼中文會變成 %E4%BD%A0？
那是 UTF-8 位元組的百分號編碼，瀏覽器/伺服器會自動還原。
編碼後連結打不開？
可能編碼了不該編碼的部分（如 :// 或 /），只編碼引數值即可。
