(原值 − 殘值) / 年限 使用指南

輸入資產原值、預計殘值與使用年限，按直線法計算每年折舊額與折舊率，適用於固定資產攤銷、稅務折舊與資產賬面管理。

計算公式與原理

年折舊 = (原值−殘值)/年限

年折舊 = (C − S) / n。

使用步驟

  1. 填寫「原值 C (元)」。
  2. 填寫「殘值 S (元)」。
  3. 填寫「使用年限 (年)」。
  4. 結果區會即時更新；可一鍵複製結果用於記錄或彙報。

典型使用場景

  • 房屋、傢俱等效用在各期均衡的資產，用直線法平穩分攤成本。
  • 需要簡單、可預期的年度折舊費用便於預算與報價。
  • 稅務折舊與會計折舊一致時，減少納稅調整工作量。

算例參考

  • 計算直線法年折舊：某裝置原值 50 萬元、預計殘值 5 萬元、使用年限 5 年，年折舊=(50−5)/5=9 萬元，月折舊 0.75 萬元，五年後賬面淨值等於殘值 5 萬元。

注意事項

本工具純前端執行，輸入內容不上傳伺服器；結果為按上述口徑得到的理論估算值。實際應用受裝置引數、測量條件與當地規範影響，請以裝置銘牌、檢測報告與現行標準為準，重大決策建議諮詢專業人士。

直線法為什麼最常用？
計算簡單、各期費用均衡、利潤平滑，適合效用穩定、技術更新慢的資產，也便於與外部報表和稅務銜接。
預計淨殘值為 0 或負數怎麼辦？
淨殘值一般取預計處置收入減處置費用後的淨額，通常≥0；若預計處置費用高於收入，實務中仍按 0 處理，不得提為負。
