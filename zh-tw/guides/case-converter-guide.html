大小寫轉換 使用指南

變數命名風格五花八門（camelCase、snake_case、kebab-case…）。ToolBox 大小寫轉換在本地一鍵互轉，程式設計師與寫作者都常用。

核心功能

  • 支援 camelCase / PascalCase / snake_case / kebab-case / 全大寫/全小寫
  • 批次轉換整段文本
  • 保留單詞邊界，智慧分詞
  • 一鍵複製
  • 處理空格與標點邊界

適用場景

  • 程式碼重構時統一變數命名風格
  • 把文案轉成標題大小寫
  • 生成 URL slug(連字元)
  • 資料庫欄位與程式碼變數名對齊

使用步驟

  1. 貼上或輸入待轉換文本
  2. 選擇目標風格（如 snake_case）
  3. 即時得到轉換結果
  4. 檢查分詞是否正確（尤其縮寫）
  5. 複製使用

實用技巧

  • 連續大寫縮寫(如 "HTTP")在 camelCase 中常被誤拆，轉換後請複核
  • 中文混排時以空格/標點作為分詞邊界
  • kebab-case 常用於 URL，snake_case 常用於資料庫

常見問題

駝峰和帕斯卡有什麼區別？
camelCase 首字母小寫，PascalCase 首字母大寫，常用於不同語言約定。
為什麼分詞錯了？
工具按空格/標點/大小寫切換分詞，異常縮寫可能誤判。
