訴訟時效屆滿日計算 使用指南

輸入權利受侵害或約定履行期限屆滿的起算日期，依據《民法典》第188條計算訴訟時效屆滿日，並即時顯示距屆滿的剩餘天數，便於及時主張權利。

功能說明

輸入權利受侵害或約定履行期限屆滿的起算日期，依據《民法典》第188條計算訴訟時效屆滿日，並即時顯示距屆滿的剩餘天數，便於及時主張權利。

使用步驟

  1. 填寫「時效型別」。
  2. 填寫「訴訟時效起算日（知道/應當知道之日）」。
  3. 填寫「中斷事由消除日（重新起算日）」。
  4. 結果區會即時更新；可一鍵複製結果用於記錄或彙報。

典型使用場景

  • 買賣合同欠款到期未還，從履行期限屆滿之日起算 3 年普通時效，計算屆滿日以免喪失勝訴權。
  • 訴訟時效期間內發生催款、起訴、對方承諾還款等中斷事由的，時效重新計算 3 年。
  • 涉及最長保護期（20 年）的，自權利受損害之日起超過 20 年法院不予保護。

算例參考

  • 普通 3 年時效：約定還款日 2023-01-01，時效自次日起算 3 年，屆滿日為 2026-01-01；若 2026-01-01 前未起訴且未中斷，則可能因時效屆滿敗訴。
  • 時效中斷重算：若 2024-06-01 通過簡訊/書面催款並保留證據，時效自該日起重新計算 3 年，新屆滿日為 2027-06-01。

注意事項

本工具純前端執行，輸入內容不上傳伺服器；結果為按上述口徑得到的理論估算值，涉及具體爭議請以證據與司法機關認定為準，必要時諮詢執業律師。

哪些情形會導致時效中斷？
權利人向義務人提出履行請求、義務人同意履行義務、權利人提起訴訟或申請仲裁，以及與訴訟等價的其他情形，均引起時效中斷並重新計算。
屆滿日遇到節假日怎麼辦？
訴訟時效期間是法定期間，屆滿日若為週末或法定假日通常順延至其後第一個工作日，但具體以受理法院口徑為準；建議提前起訴而非卡到最後一刻。
