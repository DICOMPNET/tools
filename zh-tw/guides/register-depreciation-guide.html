固定資產（登記/折舊/盤點） 使用指南

登記資產資訊，自動計算折舊（直線法 / 雙倍餘額遞減法 / 年數總和法），生成折舊明細表與賬面價值。

功能說明

登記資產資訊，自動計算折舊（直線法 / 雙倍餘額遞減法 / 年數總和法），生成折舊明細表與賬面價值。

典型使用場景

  • 新購筆記本、印表機等入賬時，填入原值、殘值、使用年限與折舊方法，自動算每年/每月折舊額，生成可歸檔的折舊臺賬。
  • 年末計提折舊時，對全部固定資產批次核算當期折舊，匯出清單供財務記賬與稅務申報。
  • 車輛、裝置盤點時，核對賬面原值與累計折舊，結合當前二手殘值判斷是否減值或報廢。

算例參考

  • 筆記本直線法折舊測算：資產：聯想筆記本，類別電子裝置，原值 6000 元，殘值 600 元，使用年限 5 年，直線法。年折舊額 =（6000-600）/ 5 = 1080 元，月折舊額 = 90 元；5 年後賬面殘值恰為 600 元。若改用雙倍餘額遞減法，前兩年折舊更高、後期遞減。

注意事項

本工具純前端執行，輸入內容不上傳伺服器；結果為按上述口徑得到的理論估算值。實際應用受裝置引數、測量條件與當地規範影響，請以裝置銘牌、檢測報告與現行標準為準，重大決策建議諮詢專業人士。

三種折舊方法有什麼差別？
直線法每年等額；雙倍餘額遞減法前期多提、後期少提（加速折舊）；年數總和法也是加速但更平緩。會計折舊方法一經確定不得隨意變更，稅務折舊另有規定，具體以《企業所得稅法》及本單位財務制度為準，工具僅做計算演示。
殘值可以為 0 嗎？
可以。若預計報廢無殘值，殘值填 0，則年折舊 = 原值 / 使用年限。殘值率過低或過高都會影響每期費用，建議參考同類資產歷史處置價合理估計。
