水電（讀數/週期）結算 使用指南

按讀數結算水電燃氣費用：末檔不設上限，空讀數和讀數倒退會被攔截，換表可勾選後從 0 起算。

功能說明

記錄水電燃氣讀數並按階梯或單一費率結算；末檔不設上限、支援換表與計費週期累計，空讀數和讀數倒退會阻止結算。

使用步驟

  1. 選擇電費/水費/燃氣費，配置單一單價或階梯檔位；階梯上限須嚴格遞增、單價非負。
  2. 填寫每次抄表日期與讀數；換錶行勾選「換表」。
  3. 選擇階梯累計週期：每次區間獨立套檔或整個結算週期累計。
  4. 點「計算結算」，檢視各段用量、費用與階梯明細；空讀數或倒退會列出具體行。

典型使用場景

  • 退租或換租時按上次/本次讀數結算。
  • 階梯電量超過原末檔上限時，核對超出部分是否仍計費。
  • 電錶更換後按新表從 0 起算，避免把倒退讀數記成 0。

算例參考

330 kWh 與超過末檔上限

12 450 → 12 780，用電 330 kWh。單一價 0.60：330×0.60 = 198.00 元。階梯 0–200 按 0.55、200–600 按 0.63：200×0.55 + 130×0.63 = 191.90 元。若 700 kWh 且末檔從 600 起不限：200×0.55 + 400×0.63 + 100×0.83 = 445.00 元，超出 100 kWh 不漏計。

注意事項

讀數倒退預設阻止結算，勾選「換表」才按新表從 0 起算；空讀數不再儲存為 0；整個週期累計時費用按各段用量比例分攤並在報告註明。

讀數倒退怎麼辦？
先更正讀數；確為換表則勾選該行「換表」，按新表從 0 起算。
階梯按區間還是整週期？
可在「階梯累計週期」選擇；整週期累計會先對總用量套檔再按比例分攤。
空讀數會記 0 嗎？
不會，空讀數會阻止結算並提示補填或刪除該行。
