由各級增益(dB)求總增益 使用指南

輸入多級（如三級）增益 dB 值，按 G_total(dB) = Σ Gᵢ 求總增益並換算為線性倍率，用於射頻級聯放大器與鏈路預算計算。

計算公式與原理

20=27 dB → 線性≈501。

輸入三級增益（dB），求總增益與線性總增益。

使用步驟

  1. 填寫「第1級增益 G₁ (dB)」。
  2. 填寫「第2級增益 G₂ (dB)」。
  3. 填寫「第3級增益 G₃ (dB)」。
  4. 結果區會即時更新；可一鍵複製結果用於記錄或彙報。

典型使用場景

  • 多級放大器/衰減器總增益按 dB 直接相加。
  • 已知各級 g1/g2/g3 求總 dB 與線性倍率。
  • 含負增益（衰減）的鏈路測算。

算例參考

  • g1=10、g2=−3、g3=20 dB：總增益 = 10 − 3 + 20 = 27 dB；線性倍率 = 10^(27/10) ≈ 10^2.7 ≈ 501 倍。
  • 淨衰減：若三級均 −3dB，則總 −9dB、線性 ≈ 0.126 倍（約衰減到 1/8）。

注意事項

本工具純前端執行，輸入內容不上傳伺服器；結果為按上述口徑得到的理論估算值。實際應用受裝置引數、測量條件與當地規範影響，請以裝置銘牌、檢測報告與現行標準為準，重大決策建議諮詢專業人士。

為什麼 dB 直接相加？
dB 是對數單位，級聯相乘對應對數相加，故總增益為各級 dB 之和。
負 dB 代表什麼？
負 dB 表示衰減，如 −3dB 約衰減到 0.707 倍（一半功率）。
