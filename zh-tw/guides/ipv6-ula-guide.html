IPv6 ULA Generator 使用指南

隨機 ULA 字首如 「fd12:3456:789a::/48」（48 位全域性 ID 隨機，後接子網）。

核心功能

  • 按 RFC 4193 生成唯一的本地 IPv6 地址（ULA，fc00::/7）
  • 可一次生成多個地址
  • 含 /48 字首與 /64 子網的結構，便於內網規劃
  • 地址在本地生成，不上傳

適用場景

  • 生成 fd00::/8 的唯一本地地址用於內網。
  • 搭建內網或實驗環境：生成 fd00::/8 段內的 /48 字首，再自行劃分子網，避免與公網路由衝突。

使用步驟

  1. 填要生成的數量
  2. 點生成得到 ULA 字首與地址
  3. 把 /48 字首按子網再劃分為多個 /64 分配給不同網段
  4. 在路由器或主機上配置該地址（ULA 不能在公網路由）
  5. 記錄所生成字首，重建時若需保持不變應顯式指定而非隨機生成

實用技巧

  • 不能，fd00::/8 僅本地通訊，類似 IPv4 私網
  • 搭建內網或實驗環境：生成 fd00::/8 段內的 /48 字首，再自行劃分子網，避免與公網路由衝突。

常見問題

ULA 能上公網嗎？
不能，fd00::/8 僅本地通訊，類似 IPv4 私網。
為什麼要隨機生成 Global ID？
RFC 4193 要求 ULA 的 40 位 Global ID 用隨機演算法生成，而不是手寫 fd00:0000:0000::/48 之類。目的是保證兩家組織的地址空間幾乎不可能重合，將來做 VPN 互聯或公司合併時不會出現地址衝突。
