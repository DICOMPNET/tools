折射率計算器使用指南

由光在介質中的速度求折射率。已知光在介質中的傳播速度，反推該介質的折射率，用於介質光學特性判斷。本指南整理適用場景、操作步驟與常見問題。

計算公式與原理

n = c / v

由光在介質中的速度求折射率。

使用步驟

  1. 填寫「介質光速 v (m/s)」。
  2. 填寫「真空中光速 c (m/s)」。
  3. 結果區會即時更新；可一鍵複製結果用於記錄或彙報。

典型使用場景

  • 已知光在介質中的傳播速度，反推該介質的折射率。
  • 比較不同光學材料對光的減速能力，用於材料選型。
  • 校核實驗測得的光速資料是否落在合理折射率區間。

算例參考

  • 水中光速 v=2.25e8 m/s：n=c/v=3e8/2.25e8=1.3333，與水在可見光波段的折射率約 1.33 一致。
  • 玻璃中光速 v=1.5e8 m/s：n=c/v=3e8/1.5e8=2.0000。該值對應高折射率光學玻璃（普通冕牌玻璃約 1.5，對應 v≈2.0e8 m/s）。

注意事項

本工具純前端執行，輸入內容不上傳伺服器；結果為按上述口徑得到的理論估算值。實際應用受裝置引數、測量條件與當地規範影響，請以裝置銘牌、檢測報告與現行標準為準，重大決策建議諮詢專業人士。

折射率可以小於 1 嗎？
按 n=c/v，若算得 n<1 說明介質中光速大於真空光速，這違背狹義相對論，通常意味著輸入有誤（如單位寫錯或把群速度/相速度混用）。常規透明介質 n≥1。
折射率與波長有關嗎？
有關，這就是色散。同一材料對短波（藍紫光）的折射率通常更大，因此稜鏡能把白光分解成光譜。計算時應註明所用波長，常見參考值是鈉黃光 589 nm 下的 n_D。
