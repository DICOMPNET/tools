增長率（同比/環比）計算 使用指南

輸入本期與基期（去年同期或上期）數值，計算同比增長率與環比增長率，用於電商銷售與運營指標的走勢分析。

計算公式與原理

增長率 = (本期−同期)/同期 × 100%

本工具按本期與基期數值計算同比/環比增長率，自動處理基期為零與跨期對比，輸出百分比與變動絕對值。

典型使用場景

  • 同比：錄入本年與去年同月，算 YoY，剔除季節影響。
  • 環比：錄入本月與上月，算 MoM，看短期走勢。
  • 教學演示：演示基期為 0 時增長率無定義，須特殊處理。

算例參考

  • 使用示例：示例：本月 120、上月 100，環比=(120−100)/100=20%；本年 120、去年同月 90，同比=33.3%。

注意事項

本工具純前端執行，輸入內容不上傳伺服器；結果為按上述口徑得到的理論估算值。實際應用受裝置引數、測量條件與當地規範影響，請以裝置銘牌、檢測報告與現行標準為準，重大決策建議諮詢專業人士。

基期為 0 怎麼辦？
基期為 0 時公式無意義，應標註"由 0 起步"或用絕對增量，避免無窮大。結果僅供電商運營測算、選品與決策參考，不構成財務或稅務意見，也不替代各平臺最新規則與正式對賬，以平臺官方規則與賬實為準。
