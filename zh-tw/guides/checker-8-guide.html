質量（服務標準/檢查/改進） 使用指南

按人員、執行、裝備、服務四類共十四項指標評分並加權得出服務質量總分與待改進項，適用於保安服務與現場服務質量檢查。

計算公式與原理

人員得分 = (持證上崗率 + 培訓完成率 + 著裝規範率 + 出勤率) / 4；服務流程得分 = (巡邏到位率 + 門禁登記率 + 響應得分 + 記錄完整率) / 4，其中響應得分按響應時間 ≤3 分鐘=100、≤5=80、≤10=50、>10=20 折算；裝備得分 = (監控覆蓋率 + 裝置完好率 + 通訊配備率) / 3；滿意度得分 = max(0, (滿意度 + 投訴解決率)/2 − max(0, 月投訴數 − 5) × 3)；總分 = 人員×25% + 流程×30% + 裝備×20% + 滿意度×25%

四個維度權重合計 100%，流程權重最高是因為服務交付過程最容易被抽查取證。響應時間屬逆向指標（越小越好），必須先折算成百分制得分才能與其他比率型指標求平均，否則"越小越好"會被算成"越低越差"。投訴次數超過 5 次後每次扣 3 分，屬超額懲罰而非線性扣分，模擬"容忍閾值"管理慣例；滿意度得分下限截為 0 避免負分抵消。總分分檔為 ≥90 優秀、≥75 良好、≥60 一般、<60 不合格，用於整改優先順序排序。

使用步驟

  1. 填寫「持證上崗率（%）」。
  2. 填寫「培訓完成率（%）」。
  3. 填寫「著裝規範率（%）」。
  4. 填寫「出勤率（%）」。
  5. 填寫「巡邏到位率（%）」。
  6. 填寫「門禁登記率（%）」。
  7. 填寫「事件響應時間（分鐘）」。
  8. 填寫「巡邏記錄完整率（%）」。
  9. 填寫「監控覆蓋率（%）」。
  10. 填寫「裝置完好率（%）」。
  11. 填寫「通訊裝置配備率（%）」。
  12. 填寫「客戶滿意度（%）」。
  13. 填寫「投訴解決率（%）」。
  14. 填寫「月均投訴次數」。
  15. 結果區會即時更新；可一鍵複製結果用於記錄或彙報。

典型使用場景

  • 保安/物業專案月度質檢：錄入持證率、巡邏到位率、響應時間等 14 項，得到四維度得分與總分。
  • 投標或續約前自查，用總分與等級說明服務水平，並列出需整改的短板項。
  • 整改後複測，對比前後總分判斷措施是否真正落到關鍵維度。

算例參考

  • 響應時間把流程分拉下來：其餘三項均在 95% 以上，但事件響應時間 12 分鐘（折算僅 20 分），服務流程得分約 (96+94+20+92)/4≈75.5，總分被拉到 82；此時改響應流程的邊際收益遠大於繼續提高巡邏率。
  • 投訴扣分的影響：滿意度 92%、投訴解決率 88%、月投訴 9 次：滿意度得分 =(92+88)/2−(9−5)×3＝78；若把月投訴壓到 5 次以內，該項升至 90，總分約提升 3 分。

注意事項

結果為按上述公式得到的理論估算值，實際表現受資料分佈、實現細節與執行環境影響，落地決策請以實測為準；本工具純前端執行，輸入不上傳伺服器。

14 項裡哪幾項最影響總分？
服務流程權重最高（30%），其中響應時間是唯一的非線性項（≤3 分鐘 100 分、>10 分鐘僅 20 分），通常也是拉分最狠的一項。
某項暫時取不到數，填 0 可以嗎？
填 0 等同於完全不達標，會明顯拉低該維度得分；建議按實際估算填寫，或本次先不納入評分並在備註中說明。
總分 90 以上還需要整改嗎？
需要看四維度分解。任一維度明顯低於其他維度（如裝備 60、其餘 95）仍應專項整改，因為事故中短板往往是決定性的。
