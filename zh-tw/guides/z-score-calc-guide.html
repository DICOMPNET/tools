標準分 Z 值計算器 使用指南

標準分 Z 值計算器：輸入原始值、均值與標準差，求標準分 Z = (x−μ)/σ，用於資料標準化與離群判斷。

計算公式與原理

z = (x − μ) / σ

標準分把原始值 x 減去均值 μ 再除以標準差 σ，得到相對均值的標準差數。z &gt; 0 高於均值、z &lt; 0 低於均值，常用於資料標準化與離群判斷（如 |z| &gt; 2 或 3 視為異常）。

使用步驟

  1. 填寫「數值 x」。
  2. 填寫「均值 μ」。
  3. 填寫「標準差 σ」。
  4. 結果區會即時更新；可一鍵複製結果用於記錄或彙報。

典型使用場景

  • z=(x−μ)/σ，單值標準化。
  • 離群識別、跨分佈比較。
  • |z|>3 通常判異常。

算例參考

  • 身高：x=190cm、μ=170、σ=10：z=2.0，高於均值 2σ（約超 97.7%）。
  • 低值：x=140：z=−3.0，低於均值 3σ，可能異常或特殊亞群。

注意事項

結果為按上述公式得到的理論估算值，實際表現受資料分佈、實現細節與執行環境影響，落地決策請以實測為準；本工具純前端執行，輸入不上傳伺服器。
