隧道掘進速度估算 使用指南

輸入孔深、利用率、工序耗時、計劃迴圈數、有效日工時、施工天數與目標長度；同時給出整迴圈與跨日平均日進尺、月進尺與工期，並提示理想假設。

功能說明

輸入孔深、利用率、工序耗時、計劃迴圈數、有效日工時、施工天數與目標長度；同時給出整迴圈與跨日平均日進尺、月進尺與工期，並提示理想假設。

典型使用場景

  • 單迴圈進尺：迴圈進尺=炮孔深度×炮孔利用率 η（一般 0.85~0.95，由巖性與鑽孔精度決定）；孔深加大能提高進尺，但 η 通常隨之下降。
  • 整迴圈模型：時間允許的完整迴圈=floor(有效日工時÷單迴圈時間)，實際完整迴圈=min(計劃迴圈數, 時間允許迴圈數)，日進尺=單迴圈進尺×完整迴圈數。該模型不允許迴圈跨日，單迴圈超過日工時即日進尺為 0。
  • 跨日平均模型：按連續施工折算每日迴圈=min(計劃迴圈數, 有效日工時÷單迴圈時間)，允許單迴圈跨日；日進尺=單迴圈進尺×折算迴圈數，用於連續掘進與工期估算。
  • 月進尺與工期：月進尺=跨日平均日進尺×30；工期=目標掘進長度÷跨日平均日進尺。工具另按計劃施工天數給出該時段進尺，便於比較不同工序組合的邊際收益。

算例參考

  • 算例：孔深 3 m、利用率 0.9、迴圈 9.5 h：輸入孔深 3 m、利用率 0.9、鑽孔 3 h、爆破 1 h、通風 0.5 h、出渣 3 h、支護 2 h、計劃 3 次/日、有效日工時 24 h。單迴圈進尺=2.70 m；單迴圈時間=9.50 h；整迴圈模型 floor(24÷9.5)=2 次/日，日進尺 5.40 m；跨日平均模型 24÷9.5=2.526 次/日，日進尺 6.82 m；月進尺約 204.6 m；1000 m 工期約 146.6 天（4.9 個月）。若有效日工時改為 8 h：整迴圈為 0 次/日，跨日平均為 0.842 次/日、日進尺 2.27 m、月進尺 68.2 m、1000 m 工期約 439.8 天，說明單迴圈跨日時必須看平均模型。

注意事項

本工具純前端執行，輸入內容不上傳伺服器；結果為按上述口徑得到的理論估算值。實際應用受裝置引數、測量條件與當地規範影響，請以裝置銘牌、檢測報告與現行標準為準，重大決策建議諮詢專業人士。

為什麼整迴圈日進尺和跨日平均日進尺會不同？
整迴圈模型要求每個迴圈都在當日工時內完成，餘下不足一個迴圈的時間不計入進尺；跨日平均模型按連續施工把剩餘工時折算成迴圈份額，因此單迴圈時間不能整除日工時時兩者不同。前者適合按班制排程、不允許跨日的場景；後者適合連續掘進與工期估算。頁面同時展示兩者，避免把任意一個當作唯一真值。
單迴圈總耗時填 0 為什麼不能估算？
單迴圈時間是計算每日迴圈數與工期的分母。總耗時為 0 不是“無限快”，而是缺少有效工序資料；頁面會明確提示必須填寫大於 0 的總耗時，並清除舊結果，避免用 0 分母得出無意義的天數。
