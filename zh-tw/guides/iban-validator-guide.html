IBAN 校驗 使用指南

IBAN = 國別碼(2 字母)+ 校驗位(2 數字)+ 本國賬號 BBAN。如 DE89 3704 0044 0532 0130 00：DE 德國、89 校驗位、後接德國賬號。

核心功能

  • 按 ISO 13616 校驗 IBAN 的國家程式碼與長度
  • 用 mod-97 演算法驗證兩位校驗位
  • 解析國家碼與 BBAN 結構
  • 可點選目標國家載入標準示例賬號

適用場景

  • 校驗國際銀行賬號 IBAN 格式與校驗位
  • 跨境匯款前防錯
  • 識別國家碼與 BBAN 結構
  • MOD-97 演算法

使用步驟

  1. 選擇目標國家，確認該國 IBAN 的標準長度
  2. 貼上或輸入 IBAN（可含空格）
  3. 頁面把前 4 位移到末尾，再將字母轉為數字（A=10…Z=35）
  4. 對轉換後的整數取模 97，判斷餘數是否為 1
  5. 讀取校驗結論與結構解析，用於匯款前複核

實用技巧

  • 校驗通過僅說明格式與校驗位正確，不代表賬戶真實存在；大額匯款建議先小額試匯
  • 各國 IBAN 長度不同（15–34 位），跨幣種匯款前先確認收款國標準長度
  • 手工錄入時分 4 位一組更易發現漏位，空格會被自動忽略
  • IBAN 是國碼+校驗位+本地賬號（BBAN）的標準化封裝，國內轉賬仍用本地賬號

常見問題

IBAN 和賬號關係？
IBAN 是在本國賬號(BBAN)前加國碼與校驗位的標準化形式，便於跨國自動校驗路由；本國內部仍用本地賬號。
校驗通過就一定能匯款嗎？
通過僅說明格式與校驗位正確；能否到賬還取決於賬戶真實存在、行號有效及收款行政策，大額建議先小額試匯。
