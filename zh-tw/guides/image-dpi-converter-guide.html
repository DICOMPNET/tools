圖片 DPI 轉換 使用指南

核心功能

  • 在畫素尺寸與物理尺寸（英寸/釐米）之間雙向換算
  • 按螢幕對角線計算實際 PPI
  • 三個頁籤分別處理畫素→物理、物理→畫素、螢幕 PPI
  • 純本地計算，不上傳任何輸入

適用場景

  • 網頁圖轉列印 300DPI。
  • 確認輸出尺寸。
  • 印刷前校尺寸。

使用步驟

  1. 選擇換算方向（畫素 → 物理尺寸 / 物理尺寸 → 畫素 / 螢幕 PPI）
  2. 輸入畫素值或物理尺寸，並填寫 DPI / PPI
  3. 讀取結果區的物理尺寸與寬高比
  4. 印刷前核對輸出尺寸是否滿足要求
  5. 螢幕 PPI 場景填入對角線與解析度即可

實用技巧

  • DPI 只決定列印尺寸下的畫素密度，螢幕上顯示多大隻由畫素數決定
  • 「DPI」與「PPI」在影像檔案中常被混用，畫素/英寸才是判斷依據
  • 網頁圖片標註 72DPI 或 300DPI 不影響顯示大小，改的只是後設資料
  • 印刷廠要求的有效 DPI 通常指圖片實際畫素 ÷ 成品尺寸，務必按成品尺寸核

常見問題

DPI 影響清晰嗎？
DPI 決定列印尺寸下的畫素密度；螢幕顯示只看畫素數。結果以瀏覽器即時計算為準，純前端本地處理、資料不上傳；生成的樣式與程式碼僅作快速產出參考，正式專案請以設計系統、規範與瀏覽器實測為準。
處理大圖會卡嗎？
在瀏覽器本地用 Canvas 完成，圖越大越佔記憶體；建議先縮到合適尺寸再處理，資料不上傳。
