笑聲音效合成器 使用指南

用瀏覽器原生 Web Audio API 即時合成：基頻振盪 + 顫音(LFO) + 包絡(起承轉合) 拼出笑聲波形，可調引數後匯出本地 wav，無第三方音訊素材。…

核心功能

  • 素材製作：本地合成「哈哈哈」等笑聲，免找版權音訊。
  • 引數微調：調基頻、顫音、時長生成不同笑法。
  • 離線可用：純 Web Audio API 即時合成，可下載。
