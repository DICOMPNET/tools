CSV 轉 JSON 使用指南

將表格型 CSV 轉換為程式易處理的 JSON 陣列，每行成為物件、表頭為鍵。支援自定義分隔符與引號，本地轉換不上傳。

核心功能

  • CSV→JSON 陣列轉換
  • 首行作為鍵名
  • 自定義分隔符(逗號/製表符)
  • 支援引號包裹欄位
  • 預覽與下載

適用場景

  • 表格資料接入前端介面
  • Excel 匯出後轉 JSON
  • 批次資料處理前置

使用步驟

  1. 貼上或上傳 CSV
  2. 確認分隔符與表頭行
  3. 點選轉換檢視 JSON
  4. 下載結果

實用技巧

  • 含逗號的欄位需用引號包裹
  • 表頭有重複鍵會覆蓋
  • 大檔案建議先抽樣

常見問題

表頭中文能用嗎？
可以，鍵名即為表頭文本，程式側按中文鍵讀取。
能給個例子嗎？
CSV "name,age\nTom,3" → [{"name":"Tom","age":"3"}]。
