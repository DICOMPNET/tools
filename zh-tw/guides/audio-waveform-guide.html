音訊波形顯示工具 使用指南

線上音訊波形顯示工具，基於 Web Audio API 即時繪製時域波形與頻域頻譜（FFT），支援本地檔案分析，適合音訊除錯，純前端。

功能說明

線上音訊波形顯示工具，基於 Web Audio API 即時繪製時域波形與頻域頻譜（FFT），支援本地檔案分析，適合音訊除錯，純前端。

典型使用場景

  • 除錯錄音或混音時觀察時域波形，判斷音量是否過載、有無靜音段與爆音。
  • 分析一段音訊的頻域能量分佈，定位某頻率的嗡嗡聲或共振峰。
  • 教學或演示時把聲音視覺化，直觀展示振幅與頻譜的關係。

算例參考

  • FFT 頻譜引數示例：在 Web Audio 中用 AnalyserNode 取資料：設 fftSize=2048，則頻域 bin 數為 1024，頻率解析度 = 取樣率÷fftSize = 44100÷2048 ≈ 21.5Hz/bin。疊加漢寧窗（Hann）可減少頻譜洩漏。時域波形則直接反映每個取樣點的振幅（−1~+1），縱軸常按 dB 或線性幅度顯示。

注意事項

本工具純前端執行，輸入內容不上傳伺服器；結果為按上述口徑得到的理論估算值。實際應用受裝置引數、測量條件與當地規範影響，請以裝置銘牌、檢測報告與現行標準為準，重大決策建議諮詢專業人士。

為什麼頻譜圖會糊成一片？
解析度不夠或沒加窗函式會導致洩漏。增大 fftSize 可提高頻率解析度（但時間解析度下降），並對訊號加漢寧/漢明窗抑制邊緣不連續，頻譜會更清晰銳利。
波形上看不見聲音但能聽到？
可能是極小幅度的超音波段或相位抵消在單聲道顯示時被平均，也可能是波形縱軸縮放在滿量程而訊號很小。可放大縱軸或切換頻譜檢視交叉驗證。
