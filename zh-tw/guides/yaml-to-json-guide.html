YAML 轉 JSON 使用指南

YAML 是 JSON 超集、用縮排表達層級。本工具把 YAML 解析為等效 JSON，方便程式讀取與轉換。本地解析不上傳。

核心功能

  • YAML→JSON 轉換
  • 縮排層級解析
  • 支援錨點/引用
  • 型別推斷
  • 本地處理

適用場景

  • K8s/Docker Compose 配置轉資料
  • 寫文件示例
  • 格式校驗

使用步驟

  1. 貼上 YAML
  2. 點選轉換
  3. 檢視 JSON

實用技巧

  • 縮排務必用空格不用 Tab
  • 錨點 & 與 * 會被展開
  • 多文件 --- 取首個

常見問題

YAML 和 JSON 能互轉嗎？
能，YAML 是 JSON 超集。
能給個例子嗎？
"a: b: 1" → {"a":{"b":1}}。
