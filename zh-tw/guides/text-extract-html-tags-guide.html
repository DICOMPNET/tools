提取 HTML 標籤 使用指南

從 HTML 片段中抽出所有標籤或指定標籤（可保留屬性），統計標籤數量與不同標籤數並去重，便於檢查頁面結構、清理冗餘標籤或核對模板標記。

功能說明

從 HTML 片段中抽出所有標籤或指定標籤（可保留屬性），統計標籤數量與不同標籤數並去重，便於檢查頁面結構、清理冗餘標籤或核對模板標記。

典型使用場景

  • 分析頁面結構：列出文件中所有標籤與不同標籤數，快速瞭解骨架。
  • 抽取特定標籤：在“指定標籤”填 a,img 等，勾選保留屬性，篩出對應標籤做資源盤點。
  • 模板審查：匯出開/閉標籤清單後人工比對，發現缺失的閉合標籤。

算例參考

  • 抽取並核對 a 標籤：貼上一段 HTML，在“指定標籤”填 a 並勾選“保留屬性”，結果逐條列出全部 <a ...> 開標籤，可檢查 href 是否為空或指向站外；取消保留屬性則只輸出 <a> 形式，便於計數。

注意事項

本工具在瀏覽器本地執行，輸入內容不會上傳伺服器；結果為靜態文本匹配，遇到巢狀或畸形 HTML 可能有偏差，結構性判斷請結合 DOM 工具複核。
