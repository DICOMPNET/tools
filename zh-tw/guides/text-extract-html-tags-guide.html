提取 HTML 標籤 使用指南

從 HTML 片段中抽出所有標籤名或指定標籤，統計出現次數並去重，便於檢查頁面結構、清理冗餘標籤或核對模板標記。

功能說明

從 HTML 片段中抽出所有標籤名或指定標籤，統計出現次數並去重，便於檢查頁面結構、清理冗餘標籤或核對模板標記。

典型使用場景

  • 分析頁面結構：列出文件中所有標籤名及出現次數，快速瞭解骨架。
  • 抽取特定標籤：如把所有 <a href>、<img src> 摘出做資源盤點。
  • 模板審查：檢查是否有未閉合或濫用標籤。

算例參考

  • 統計 div 與 a：貼上一段 HTML，工具列出「div×12、a×5、img×3」並匯出所有 <a> 的 href 列表，便於檢查死鏈或外鏈。

注意事項

本工具在瀏覽器本地執行，輸入內容不會上傳伺服器；結果為模型估算，工程決策請結合實測資料複核。
