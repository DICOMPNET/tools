平面點繞原點旋轉 使用指南

平面座標旋轉線上計算器，輸入點座標與旋轉角求得繞原點旋轉後的新座標，用於測量與圖形變換，純前端執行。

計算公式與原理

x'=x·cosθ−y·sinθ, y'=x·sinθ+y·cosθ

x&#x27; = x·cosθ − y·sinθ，y&#x27; = x·sinθ + y·cosθ。

使用步驟

  1. 填寫「點 X (m)」。
  2. 填寫「點 Y (m)」。
  3. 填寫「旋轉角 θ (°)」。
  4. 結果區會即時更新；可一鍵複製結果用於記錄或彙報。

典型使用場景

  • 把點繞原點旋轉 θ 得新座標。
  • 軸線對齊/區域性系建立。
  • 圖形定向。

算例參考

  • 旋轉 90°：(1,0) 繞原點轉 90° → x'=1·cos90−0·sin90=0，y'=1·sin90+0=1 → (0,1)。
  • 通用：θ=30°、點(2,0) → x'=2×0.866=1.732，y'=2×0.5=1.0 → (1.732,1.0)，用於把建築軸轉到正北。

注意事項

本工具純前端執行，輸入內容不上傳伺服器；結果為按上述口徑得到的理論估算值。實際應用受裝置引數、測量條件與當地規範影響，請以裝置銘牌、檢測報告與現行標準為準，重大決策建議諮詢專業人士。
