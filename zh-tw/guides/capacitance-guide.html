晶振負載電容匹配 使用指南

晶振負載電容匹配計算器。輸入晶振標稱負載電容 CL 與電路雜散電容，計算所需外接匹配電容值，確保晶振穩定起振並工作在標稱頻率，適合時鐘電路除錯。

計算公式與原理

當 C₁=C₂=C 時：C_L = C ÷ 2 + C_s，故 C = 2 × (C_L − C_s)

晶振負載電容匹配計算器。輸入晶振標稱負載電容 CL 與電路雜散電容，計算所需外接匹配電容值，確保晶振穩定起振並工作在標稱頻率，適合時鐘電路除錯。

典型使用場景

  • MCU 時鐘：8MHz 晶振 CL=20pF、CS=5pF → C1=C2=30pF（取標準 27pF 或 33pF）。
  • 即時鍾 RTC：32.768kHz 晶振 CL=12.5pF → C1=C2≈15pF。
  • 藍牙模組：26MHz 晶振 CL=10pF → C1=C2≈10pF。
  • 乙太網路 PHY：25MHz CL=16pF → C1=C2≈22pF。

算例參考

  • 8MHz CL=20pF CS=5pF：C1=C2=2×(20-5)=30pF；取標準 27pF（向下偏容讓晶振偏頻向上偏移微調）或 33pF。

注意事項

本工具純前端執行，輸入內容不上傳伺服器；結果為按上述口徑得到的理論估算值。實際應用受裝置引數、測量條件與當地規範影響，請以裝置銘牌、檢測報告與現行標準為準，重大決策建議諮詢專業人士。
