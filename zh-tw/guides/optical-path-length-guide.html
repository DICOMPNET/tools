光程 OP 使用指南

由折射率與幾何路程，按 光程 = n·L 計算光在介質中的等效真空路徑。

計算公式與原理

OP = n·L

由折射率與幾何路程，按 光程 = n·L 計算光在介質中的等效真空路徑。

使用步驟

  1. 填寫「折射率 n」。
  2. 填寫「幾何路程 L (mm)」。
  3. 結果區會即時更新；可一鍵複製結果用於記錄或彙報。

典型使用場景

  • 由介質折射率與幾何路程算光程 OPL=n·L。
  • 干涉/等光程條件用。
  • 費馬原理等效空氣路徑。

算例參考

  • 單介質：n=1.5 的玻璃厚 10cm → 光程 OPL=1.5×10=15cm，等效空氣走 15cm 的相位延遲。
  • 多段：空氣 5cm(n=1)+水 3cm(n=1.33) → OPL=5+3.99=8.99cm；干涉看各路 OPL 差是否為 λ 整數倍。

注意事項

本工具純前端執行，輸入內容不上傳伺服器；結果為按上述口徑得到的理論估算值。實際應用受裝置引數、測量條件與當地規範影響，請以裝置銘牌、檢測報告與現行標準為準，重大決策建議諮詢專業人士。

光程是什麼？
幾何路程按折射率加權，反映相位累積；等光程即等相位，是干涉亮暗的判據。
光程和路程區別？
真空中相等；介質中光程=折射率×路程，比幾何路程長（光變慢）。
