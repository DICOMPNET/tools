磁羅經校正 使用指南

基於五係數自差模型，在真航向、磁航向、羅航向間相互換算，並生成各羅經航向的自差值表，用於船舶磁羅經校正與航行誤差修正。

功能說明

基於五係數自差模型，在真航向、磁航向、羅航向間相互換算，並生成各羅經航向的自差值表，用於船舶磁羅經校正與航行誤差修正。

典型使用場景

  • 航行推算時，在羅航向(CH)、磁航向(MH)、真航向(TH)之間按磁差(Var)與自差(Dev)互轉，滿足航行計劃與避碰需求。
  • 羅經自檢或新裝羅經後，用五係數法（A/B/C/D/E）繪製自差表，量化各羅經向位的自差修正量。
  • 海圖作業或 GPS 偏置比對時，將羅經讀數修正為真北基準，消除羅經差（Dev+Var）帶來的航向偏差。

算例參考

  • 羅航向求真航向示例：某海區磁差 Var = 5°E、自差 Dev = 3°E，羅航向 CH = 090° 求真航向。羅經差 = Dev + Var = 3 + 5 = 8°E；磁航向 MH = 090 + 3 = 093°；真航向 TH = 093 + 5 = 098°。反向（真→羅）則逐次減去修正量：CH = TH − Var − Dev。

注意事項

本工具純前端執行，輸入內容不上傳伺服器；結果為按上述口徑得到的理論估算值。實際應用受裝置引數、測量條件與當地規範影響，請以裝置銘牌、檢測報告與現行標準為準，重大決策建議諮詢專業人士。

磁差和自差有什麼區別？
磁差 Var 是地磁北與真北的夾角（隨海區與年變），自差 Dev 是船體磁材對羅經的干擾（隨船首向變化）；羅經差 = Dev + Var，是羅經讀數與真北的總偏差。航行中按船首向查自差表修正即可抵消。
自差表（五係數）怎麼用？
自差 Dev = A + B·sin(CH) + C·cos(CH) + D·sin(2CH) + E·cos(2CH)，係數由實測羅經向位擬合。表中每個羅航向 CH 對應一個修正量，航行時按當前船首向查表加減即可得磁航向，再加磁差得真航向。
