Basic Auth 生成器 使用指南

Basic Auth 把"使用者名稱:密碼"Base64 後放入請求頭。本工具生成標準頭值與可複製的 curl 命令，便於聯調。本地生成不上傳憑據。

核心功能

  • 生成 Authorization 頭
  • Base64 編碼憑據
  • 輸出 curl 示例
  • 本地運算

適用場景

  • 除錯受保護介面
  • 快速聯調後臺
  • 生成測試請求

使用步驟

  1. 輸入使用者名稱與密碼
  2. 點生成得頭值
  3. 複製 curl 或請求頭

實用技巧

  • Basic Auth 明文傳輸，務必配 HTTPS
  • 頭格式 "Basic <base64>"
  • 憑據勿硬編碼進前端

為什麼要 Base64？
僅編碼非加密，配合 HTTPS 才安全。
