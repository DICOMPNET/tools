廣告效果指數 AEI 使用指南

觸達 0、無輔助回憶 0、投入 0 都是合法輸入；只讓對應比率顯示「未定義」或「¥0」，其他指標繼續計算。

功能說明

從曝光（觸達率、頻次、CTR）、記憶（輔助/無輔助回憶、品牌識別）、態度（好感提升、購買意向、NPS）三維計算 AEI，並按 ≥80/65/50 分檔評級。另算 CPM（元/千次曝光）與每回憶使用者成本，用於跨渠道價效比比較。

輸入與範圍

  • 觸達人數為非負整數，目標人群為大於 0 的整數；觸達不能大於目標。
  • 平均頻次、CTR、回憶率、識別率、好感/意向提升按頁面範圍填寫；NPS 允許 −100–100。
  • 廣告投入以萬元計，必須是非負數；0 表示免費投放，不會被替換成 1 萬元。
  • 零觸達或零頻次時 CPM 顯示「未定義（觸達人數或平均頻次為 0）」；零回憶時每回憶使用者成本顯示未定義。

操作步驟

  1. 先填目標人群與去重觸達人數，確認觸達率口徑。
  2. 填平均頻次、CTR 與三項記憶指標；沒有做回憶調研時不要用 0 冒充「未測量」，應留空或先補資料。
  3. 填好感、意向、NPS 與投入，檢視 AEI、三維得分和成本指標。
  4. 按短板建議調整創意/媒介，不要只因為 AEI 低就加預算。

算例

觸達 400000/目標 800000（50%→15 分）、頻次 4（40 分）、CTR 2.0%（12 分）→曝光 67；輔助 60/無輔助 35/識別 70→記憶 53；好感+20/意向+15/NPS30→態度 48；AEI≈55「效果一般」。投入 50 萬元時，每回憶使用者成本=500000÷140000≈3.57 元，CPM=500000÷1600=312.5 元。

注意事項

AEI 是加權評估，不是銷量預測；觸達、回憶和態度指標必須同源同口徑。零值代表真實的「沒有」或「免費」，但若實際是漏填，結果會嚴重失真。工具不上傳資料。

觸達填 0 為什麼還能算？
0 是合法的「沒有觸達」；其餘分項仍計算，但觸達率、CPM 會明確顯示 0 或未定義，並提示不能代表真實投放。
投入 0 時 CPM 是多少？
CPM 與每回憶使用者成本均為 ¥0；頁面會提醒確認是免費資源，而不是漏填預算。
為什麼每回憶使用者成本顯示未定義？
分母需要觸達人數與無輔助回憶率都大於 0；任一為 0 時沒有可計算的回憶人數。
