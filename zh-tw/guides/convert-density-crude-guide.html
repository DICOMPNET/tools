原油API度與密度換算 使用指南

在原油 API 重度與密度（kg/m³ 或 g/cm³）之間相互換算，便於原油貿易計量與煉廠配方計算的口徑統一。

功能說明

在原油 API 重度與密度（kg/m³ 或 g/cm³）之間相互換算，便於原油貿易計量與煉廠配方計算的口徑統一。

典型使用場景

  • API 度↔密度互算：由實驗室密度反算 API 度，或由 API 度查對應密度，統一計量口徑。
  • 輕/重質油分類：按 API 度劃定輕質（>31.1）、中質、重質（<22.3），影響計價與加工路線。
  • 貿易計量密度校正：將不同溫度密度校正到標準溫度，減少交貨量爭議。

算例參考

  • API 32 對應密度演練：輸入 API 度 32，工具輸出 15℃ 密度約 0.865 g/cm³，並判定為輕質原油，提示煉化輕油收率較高。

注意事項

本工具純前端執行，輸入內容不上傳伺服器；結果為按上述口徑得到的理論估算值。實際應用受裝置引數、測量條件與當地規範影響，請以裝置銘牌、檢測報告與現行標準為準，重大決策建議諮詢專業人士。

API 度越高油越輕嗎？
是。API 度與密度成反比，數值越大密度越小、油越輕；輕質油通常更易開採且輕油收率高。
為什麼用 15℃ 標準密度？
為消除溫度對體積的影響，貿易與庫存多用標準溫度下的密度/體積結算，避免溫度爭議。
密度與計價有關嗎？
有關。輕質、低硫原油通常溢價；密度是分類與計價的關鍵引數之一，需與硫含量等聯用。
