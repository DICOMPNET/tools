JSON 轉 CSV 使用指南

把 JSON 陣列一鍵轉為 CSV 表格：自動彙總所有物件的欄位作為表頭，巢狀物件序列化為 JSON 字串，支援複製與下載，適合資料遷移、Excel 處理。

核心功能

  • 自動提取所有欄位為 CSV 表頭
  • 處理陣列與巢狀物件（序列化）
  • NULL/缺失欄位輸出為空單元格
  • UTF-8 BOM 匯出，Excel 開啟不亂碼
  • 一鍵複製或下載 .csv 檔案

適用場景

  • 把介面返回的資料匯出為表格給運營/銷售
  • 資料遷移：JSON → Excel/表格
  • 批次匯入前的格式轉換

使用步驟

  1. 貼上 JSON 陣列（如 [{...},{...}]）
  2. 點選「轉換」，自動生成 CSV
  3. 檢視行列統計：N 行 × M 列
  4. 點選「下載 .csv」儲存為檔案

實用技巧

  • 輸入必須是陣列，物件會提示錯誤
  • CSV 中所有單元格用雙引號包裹，含逗號也安全
  • Excel 開啟亂碼時請使用「下載」功能（自帶 BOM）

常見問題

巢狀物件怎麼處理？
巢狀物件會序列化為 JSON 字串存入單元格，如 {"a":1} 會顯示為 {"a":1}。
為什麼 Excel 開啟中文亂碼？
請用「下載 .csv」按鈕匯出（帶 UTF-8 BOM），直接複製貼上可能亂碼。
