方程求解器 使用指南

方程求解器支援一元一次/二次、二元及三元線性方程組求解，輸入係數即時輸出根或解，適合數學作業、工程計算與方程組驗證。

計算公式與原理

一次方程：x = −b / a；二次方程：x = (−b ± √Δ) / 2a，Δ = b² − 4ac；三次方程：牛頓迭代 + 二分法求全部實根

一次方程直接求解；二次方程先算判別式 Δ = b² − 4ac，Δ > 0 得兩個實根、Δ = 0 得重根、Δ < 0 輸出一對共軛復根；三次方程以牛頓法配合區間掃描求全部實根。

典型使用場景

  • 一元一次/二次方程求解用於物理公式變形、盈虧平衡點與運動學求時間。
  • 判別式 Δ 決定二次方程實根個數，是解題第一判據。
  • 驗證根時把解代回原方程，看是否約等於 0，可快速發現輸入錯誤。

算例參考

  • 算例：一次方程 2x − 6 = 0：x = −b/a = −(−6)/2 = 3.000000；驗證 2×3 − 6 = 0.000000。
  • 算例：二次方程 x² − 5x + 6 = 0：Δ = b²−4ac = 25 − 24 = 1；x₁ = (−b+√Δ)/(2a) = 3.000000，x₂ = (−b−√Δ)/(2a) = 2.000000。

注意事項

本工具純前端執行，輸入內容不上傳伺服器；結果為按上述口徑得到的理論估算值。實際應用受裝置引數、測量條件與當地規範影響，請以裝置銘牌、檢測報告與現行標準為準，重大決策建議諮詢專業人士。

判別式 Δ 代表什麼？
Δ = b²−4ac：Δ>0 兩不等實根，Δ=0 兩相等實根（重根），Δ<0 無實根但有一對共軛復根。它是判斷根的性質的第一道關口。
二次方程無實根怎麼辦？
實數範圍內無解，但復根 x = (−b ± i√|Δ|)/(2a) 仍有意義（如電路、振動分析）。若業務只認實數，應提示『無實數解』而非報錯中斷。
