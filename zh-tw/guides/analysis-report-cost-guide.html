財務（成本/利潤/報表）分析使用指南

每行輸入一條「科室,收入,成本」。結餘＝收入−成本；成本率＝成本÷收入×100%；結餘率＝結餘÷收入×100%。彙總得到全院收入合計、成本合計與總結餘，並定位…

計算公式與原理

結餘 = 收入 − 成本　　成本率 = 成本 ÷ 收入 × 100%

按本頁口徑彙總：結餘＝收入−成本，成本率＝成本÷收入×100%，結餘率＝結餘÷收入×100%；逐行解析後給出全院收入合計、成本合計與總結餘，用於定位結餘為負的科室。

典型使用場景

  • 科室盈虧盤點：按「科室,收入,成本」逐行錄入，一次得到逐科室結餘與全院總結餘
  • 成本率監控：按科室看成本率（成本 ÷ 收入 × 100%），收入為 0 時該科室成本率記 0.00%
  • 虧損定位：列出成本大於收入的科室數，並用結餘率判斷全院當期是否收不抵支

算例參考

  • 方法：每行按「科室,收入,成本」解析，支援中文逗號、製表符或空格分隔；收入或成本非數值的行跳過，至少一行有效才計算。彙總全院收入合計、成本合計、收支結餘、成本率與結餘率，並標出結餘最高科室與虧損科室數。
  • 算例：內科,100,70 與 外科,80,90 ⇒ 收入合計 180.00、成本合計 160.00、結餘 +20.00、全院成本率 88.89%、結餘率 +11.11%；結餘最高為內科（+30.00），虧損科室 1 個（外科 −10.00）。若兩科室均為 100,100，則結餘 0.00、結餘率 0.00%、虧損科室 0 個。

注意事項

醫療健康類結果為按公式得到的估算值，不能替代醫生診斷與處方。給藥劑量、補液速度、抗凝與溶栓決策必須以藥品說明書、臨床指南和主治醫師判斷為準；出現胸痛、呼吸困難、意識改變等急症請立即就醫。

收入為 0 的科室怎麼處理？
該行仍計入科室數與成本合計，但按頁面口徑把該科室成本率顯示 0.00%，避免除零；全院比率同樣只在收入合計大於 0 時計算。
結餘率與成本率有什麼關係？
成本率 = 成本 ÷ 收入 × 100%，結餘率 = 結餘 ÷ 收入 × 100%；收入大於 0 時兩者之和為 100%，結餘率為負表示當期收不抵支。
