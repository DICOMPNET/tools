債務/欠款訴訟時效計算器 使用指南

針對借款、欠款類糾紛，輸入借款到期或違約起算時間，計算訴訟時效屆滿日，並提示時效中斷、中止等情形，幫助債權人把握催收與起訴時機。

功能說明

針對借款、欠款類糾紛，輸入借款到期或違約起算時間，計算訴訟時效屆滿日，並提示時效中斷、中止等情形，幫助債權人把握催收與起訴時機。

使用步驟

  1. 填寫「債務型別」。
  2. 填寫「約定還款日期」。
  3. 填寫「最近一次催款日期」。
  4. 填寫「對方最近承諾還款日期」。
  5. 結果區會即時更新；可一鍵複製結果用於記錄或彙報。

典型使用場景

  • 借條約定了還款日期，從屆滿日起算 3 年，計算喪失勝訴權的風險日。
  • 未約定還款期的，可隨時主張，時效從第一次催款之日起算 3 年。
  • 催款、部分還款、對方承諾還款均構成時效中斷，重新計算 3 年。

算例參考

  • 約定還款日情形：借條約定 2023-06-01 還款，時效自次日起算 3 年，屆滿 2026-06-01；若此前未催款也未起訴，將因時效屆滿難以強制執行。
  • 催款中斷：2024-06-01 書面催款並保留證據，時效自該日重新計算 3 年，新屆滿日 2027-06-01；多次催款以最後一次為準。

注意事項

本工具純前端執行，輸入內容不上傳伺服器；結果為按上述口徑得到的理論估算值，涉及具體爭議請以證據與司法機關認定為準，必要時諮詢執業律師。

沒有借條只有轉賬記錄能算時效嗎？
轉賬記錄可證明借貸關係，但起算點需結合聊天記錄、催款證據確定；建議補寫借條或留存催款憑證以固定時效。
超過 3 年就徹底要不回了嗎？
時效屆滿喪失的是勝訴權而非債權，對方自願履行的有效；若對方不提出時效抗辯，法院不主動適用，仍有受償可能。
