Unicode 碼點與字元查詢

理解 U+ 碼點、emoji 與特殊符號，如何用 ToolBox 查詢字元的 Unicode 編碼。

目錄
  • 什麼是碼點
  • 常見用途

什麼是碼點

Unicode 給每個字元分配一個編號，記作碼點，如 U+0041 是字母 A。一個 emoji 可能由多個碼點組成（如帶膚色的表情）。

常見用途

排查「亂碼/問號」時，檢視字元的真實碼點能定位是編碼不一致還是字元本身不存在；特殊符號（如 © ✓ ❤）也靠碼點引用。

在 ToolBox 中查詢

輸入字元或碼點（如 U+1F600）即可雙向查詢，並顯示 UTF-8/UTF-16 位元組，便於除錯傳輸與儲存問題。

常見問題

一個 emoji 為什麼顯示成兩個方框？
可能是系統字型缺該碼點，或所用字型不含該 emoji 的字形；碼點存在但無字形就會顯示成豆腐塊。
U+ 和 &#x 有什麼區別？
U+1F600 是書寫約定；😀 是 HTML 數字實體寫法，二者指向同一碼點。
中文也是 Unicode 嗎？
是。中文常用碼點位於 U+4E00 起的 CJK 統一表意文字區，同樣適用碼點查詢。
