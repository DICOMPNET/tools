Amsler 阿姆斯勒方格表

注視方格中心圓點，用單眼觀察網格線是否平直、有無扭曲、空缺或變暗。Amsler 表是篩查黃斑變性等黃斑病變的簡易自測工具，異常變化應及時就醫。

核心功能

  • 標準方格網格，中心固定注視點
  • 支援單眼/雙眼切換
  • 可標記你看到的扭曲或缺損區域
  • 提供使用示意與記錄
  • 適配手機與桌面
  • 純前端展示

適用場景

  • 黃斑自檢：定期留意視物變形
  • 慢病隨訪：糖尿病/高齡人群居家監測
  • 科普瞭解黃斑功能

使用步驟

  1. 戴日常眼鏡，距離約 30cm
  2. 遮一隻眼，盯住中心圓點
  3. 用餘光看整片網格是否平直
  4. 發現扭曲或暗區就在圖上標出
  5. 換另一隻眼重複，定期對比

實用技巧

  • 務必單眼測，雙眼會互相補償掩蓋問題
  • 固定距離與光線，結果才可比
  • 線條一變形就記錄並就醫，別等加重
  • 不能替代眼底檢查，僅作預警

常見問題

網格看起來彎就是生病嗎？
可能是黃斑問題的訊號，尤其新近出現或單眼，建議儘快眼科就診。
多久自測一次合適？
高風險人群（糖尿病、高齡、家族史）可每週一次，作趨勢監測。
