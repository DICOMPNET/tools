.gitignore 生成器 使用指南

不同技術棧要忽略的檔案不同（node_modules、__pycache__、.env 等）。本工具勾選後生成合並的 .gitignore。本地生成不上傳。

核心功能

  • 按語言/框架勾選
  • 合併常用規則
  • 包含金鑰檔案忽略
  • 標準模板
  • 本地處理

適用場景

  • 新倉庫初始化
  • 多語言專案合一
  • 防止誤提交金鑰

使用步驟

  1. 勾選所用技術棧
  2. 點選生成
  3. 複製 .gitignore

實用技巧

  • 務必忽略 .env
  • 已跟蹤檔案需 git rm --cached
  • 全域性忽略用 git config

常見問題

已提交的檔案還能忽略嗎？
需先 git rm --cached 取消跟蹤。
