人員安全疏散時間估算（流量法） 使用指南

人員安全疏散時間估算器（流量法）。輸入人員密度、出口寬度與流量係數，按流量法估算疏散所需總時間，用於建築消防疏散設計與安全評估。

計算公式與原理

T = L/v + P/(W×F) + Tpre

將行走時間、出口排隊時間和預動作時間相加，估算人員完成疏散所需時間。

典型使用場景

  • 疏散設計中，由人數、出口寬度、人流速度與行走距離估算總疏散時間。
  • 預案編制時，把行走時間、出口排隊時間與預動作時間疊加得到總耗時。
  • 出口能力不足會形成排隊瓶頸，是疏散時間的主要來源。

算例參考

  • 算例：100 人、出口寬 2m、流量 1.5 人/(s·m)、距離 30m、速度 1.2m/s、預動作 30s：行走 = 30/1.2 = 25.0 s；排隊 = 100/(2×1.5) = 33.3 s；總疏散 = 25.0 + 33.3 + 30 = 88.3 s（≈1.47 min）；出口能力 = 2×1.5 = 3.00 人/s。
  • 算例：瓶頸識別：總時間 = 行走 + 排隊 + 預動作，其中『排隊 = 人數/(出口寬×單位寬度流量)』對結果最敏感。加寬出口或分流可顯著壓降排隊時間。

注意事項

本工具純前端執行，輸入內容不上傳伺服器；結果為按上述口徑得到的理論估算值。實際應用受裝置引數、測量條件與當地規範影響，請以裝置銘牌、檢測報告與現行標準為準，重大決策建議諮詢專業人士。

單位寬度人流流量取多少？
常見設計取值約 1.3–1.5 人/(s·m)（水平出口），樓梯略低。實際受人員構成、熟悉度影響，本工具以輸入為準，取值應參考現行疏散設計規範。
預動作時間是什麼？
指人員發現火情到開始撤離的反應時間（察覺、判斷、廣播、起身），通常 30–60 s 量級。它不依賴出口能力，但佔疏散總時長的相當比例，演練可顯著縮短。
