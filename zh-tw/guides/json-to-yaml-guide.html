JSON 轉 YAML 使用指南

YAML 是 JSON 的超集，用縮排表達層級、更適合人讀。輸入 JSON 即得等價的 YAML，本地轉換不上傳。

核心功能

  • JSON→YAML 轉換
  • 保持層級與型別
  • 支援縮排配置
  • 可雙向校驗
  • 本地處理

適用場景

  • 寫 Kubernetes / Docker Compose 配置
  • 把介面 JSON 轉可讀文件
  • 配置檔案格式遷移

使用步驟

  1. 貼上 JSON
  2. 點選轉換檢視 YAML
  3. 複製或下載

實用技巧

  • YAML 用縮排表示層級，別用 Tab
  • 字串含特殊字元會加引號
  • YAML 是 JSON 超集，可轉換回去

常見問題

YAML 和 JSON 能互轉嗎？
能，YAML 是 JSON 超集，本工具專注 JSON→YAML。
能給個例子嗎？
{"a":1,"b":[2,3]} → "a: 1\nb:\n - 2\n - 3"。
