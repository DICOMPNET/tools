遺址探方計算 使用指南

根據遺址範圍與探方規格計算探方數量、發掘面積與各探方座標（西南角為原點，北為 X 正向、東為 Y 正向）

功能說明

根據遺址範圍與探方規格計算探方數量、發掘面積與各探方座標（西南角為原點，北為 X 正向、東為 Y 正向）

典型使用場景

  • 布方時按遺址範圍與發掘計劃確定探方規格（常用 5×5m 或 10×10m），計算所需探方數量與總髮掘面積，並編排探方編號。
  • 建立統一座標網格：以遺址西南角為原點，北為 X 正向、東為 Y 正向，將每個探方西南角座標（如 T0503 = X50 Y30）標註於探方登記表。
  • 矩形遺址用取整加邊界法：行數=ceil(南北長/規格)、列數=ceil(東西寬/規格)，再扣掉完全落在遺址外的邊角探方。

算例參考

  • 100m×60m 遺址布 5m 探方：列數=ceil(100/5)=20，行數=ceil(60/5)=12，探方總數=20×12=240 個，發掘面積=240×25=6000 m²。西南角首方記為 T0000（或 T0101 依慣例），向東列號遞增、向北行號遞增。

注意事項

本工具純前端執行，輸入內容不上傳伺服器；結果為按上述口徑得到的理論估算值。實際應用受裝置引數、測量條件與當地規範影響，請以裝置銘牌、檢測報告與現行標準為準，重大決策建議諮詢專業人士。

探方編號 T0503 是什麼意思？
常見約定中 T 後四位或兩位數字分別表示 X、Y 座標的十米/五米格。例如 5m 探方下 T0503 指西南角位於 X=50m、Y=30m 處；具體位數與原點以該遺址《發掘方案》為準。
為什麼探方要統一規格？
統一規格便於層位、遺物出土單位（context）橫向對比與面積統計，也方便後期用座標回放 GIS。規格不同會導致層位劃分與遺物密度不可比。
