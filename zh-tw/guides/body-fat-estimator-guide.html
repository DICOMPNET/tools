體脂率估算 使用指南

輸入身高、體重、年齡與性別，使用 Deurenberg 公式估算體脂率，提供身體成分的大致參考，用於健身減脂過程中的體脂變化追蹤（僅供粗略估算）。

計算公式與原理

BF% = 1.2·BMI + 0.23·年齡 − 10.8·性別(男1) − 5.4

輸入身高、體重、年齡與性別，使用 Deurenberg 公式估算體脂率，提供身體成分的大致參考，用於健身減脂過程中的體脂變化追蹤（僅供粗略估算）。

典型使用場景

  • 體成分跟蹤：由 BMI、年齡、性別估體脂率，輔助減脂
  • 健身參考：看脂肪而非僅體重，避免"輕但胖"
  • 科普：理解年齡性別對體脂的影響

算例參考

  • 方法：演算法（Deurenberg）：體脂% = 1.2×BMI + 0.23×年齡 − 10.8×(男 1 / 女 0) − 5.4；BMI = 體重 ÷ 身高²。要求各值>0。屬粗略估算，誤差約 ±3.5%。
  • 算例：例1（65kg / 170cm / 30 歲 / 男）：BMI = 22.5，體脂 = 1.2×22.5 + 0.23×30 − 10.8 − 5.4 = 17.7%。例2（55kg / 160cm / 40 歲 / 女）：BMI = 21.5，體脂 = 1.2×21.5 + 0.23×40 − 0 − 5.4 = 29.6%。

注意事項

醫療健康類結果為按公式得到的估算值，不能替代醫生診斷與處方。給藥劑量、補液速度、抗凝與溶栓決策必須以藥品說明書、臨床指南和主治醫師判斷為準；出現胸痛、呼吸困難、意識改變等急症請立即就醫。

估算準嗎？
公式法誤差較大，僅作趨勢參考；較準方法為皮褶厚度、生物電阻抗(BIA)、DXA（雙能 X 線）。健身者肌肉多會被高估體脂。
男女公式為何不同？
同 BMI 下男性基礎脂肪低於女性，公式用 −10.8（男）/0（女）修正性別差異；女性健康體脂通常高於男性。
