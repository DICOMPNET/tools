簡譜與五線譜對照查詢 使用指南

選擇調號（如 C 調、G 調、F 調），檢視該調下簡譜數字（1–7）、五線譜位置與唱名/音名對照表。用於簡譜與五線譜互譯、視唱與樂理速查。

功能說明

選擇調號（如 C 調、G 調、F 調），檢視該調下簡譜數字（1–7）、五線譜位置與唱名/音名對照表。用於簡譜與五線譜互譯、視唱與樂理速查。

典型使用場景

  • 選調號（C/G/F 等）查該調下簡譜 1–7 對應音名與唱名
  • 簡譜轉五線譜或反之，視唱練耳速查
  • 教學時對照唱名 do-re-mi 與音名 C-D-E

算例參考

  • C 調對照：C 大調：簡譜 1=C(do)、2=D、3=E、4=F、5=G、6=A、7=B；頻率按十二平均律 1=C4=261.63 Hz、5=G4=392 Hz。
  • 移調對照：G 大調（1 個升號 #F）：1=G、2=A、3=B、4=C、5=D、6=E、7=#F；同一簡譜數字在不同調對應不同音名與音高。

注意事項

本工具純前端執行，輸入內容不上傳伺服器；結果為按上述口徑得到的理論估算值。實際應用受裝置引數、測量條件與當地規範影響，請以裝置銘牌、檢測報告與現行標準為準，重大決策建議諮詢專業人士。

簡譜數字和唱名怎麼對應？
簡譜 1–7 固定對應唱名 do–si；調號決定 1(do) 落在哪個音名，移調即把整列數字平移到新主音。
五線譜位置怎麼從簡譜來？
先定調號與譜號（如高音譜號下加一線是 C4），按音階級數把簡譜數字落到對應線/間；加臨時變音記號處理調內升降。
