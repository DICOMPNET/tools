數學表示式求值器 使用指南

數學表示式求值器讓你像用計算器一樣直接輸入表示式即可得出結果，支援 + - * / % ^ 等運算子與 sin/cos/sqrt/ln 等函式，還會自動儲存最近 20 條計算歷史，方便複用。

核心功能

  • 支援 + - * / % ^ ( ) 運算與優先順序
  • 內建 sin/cos/tan/sqrt/abs/ln/log/floor/ceil/round/min/max 函式
  • 百分比速算：15% * 200 自動按 0.15×200 處理
  • 白名單字元校驗，拒絕指令碼注入，安全可靠
  • 自動儲存最近 20 條歷史，一鍵複用
  • 結果超出常規範圍自動切換科學計數法

適用場景

  • 學生/工程師做日常數值計算
  • 資料分析前快速驗證公式
  • 把歷史計算結果一鍵回填繼續計算

使用步驟

  1. 在輸入框輸入表示式，如 2^10 + sqrt(144)
  2. 點選「計算」或按回車鍵
  3. 結果即時顯示，歷史記錄自動儲存
  4. 點選歷史中的「複用」可把表示式填回輸入框
  5. 使用上方按鈕快速插入函式與 π

實用技巧

  • ^ 表示冪運算（2^10 = 1024）
  • 百分號按"除以 100"處理：15% = 0.15
  • sqrt 與 ln 需要括號：sqrt(144)、ln(e)
  • π 可通過按鈕插入，也可直接輸入 pi

常見問題

為什麼提示"表示式無效"？
可能含非法字元（如中文、@、#），或括號不匹配；本工具僅接受數字、運算子與白名單函式。
結果太長顯示成科學計數法？
數值極大或極小時會自動使用科學計數法，如 1.5e+15。
