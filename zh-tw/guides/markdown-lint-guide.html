Markdown 檢查器 使用指南

Markdown 渲染依賴約定（如標題#後空格、列表縮排）。本工具按常見規範提示可疑寫法，幫助你寫出更一致的文件。本地處理不上傳。

核心功能

  • 標題層級檢查
  • 列表與縮排提示
  • 連結格式校驗
  • 程式碼塊圍欄檢查
  • 本地處理

適用場景

  • 寫 README 前自查
  • 統一團隊文件風格
  • 排查渲染異常

使用步驟

  1. 貼上 Markdown
  2. 點選檢查
  3. 按提示修正

實用技巧

  • 標題 # 後留空格
  • 列表項對齊縮排
  • 程式碼塊用成對圍欄

常見問題

會改我的內容嗎？
不會，僅給出提示。
能給個例子嗎？
"#標題" 建議改為 "# 標題"。
