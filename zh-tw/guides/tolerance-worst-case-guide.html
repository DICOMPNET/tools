公差疊加計算器（最差） 使用指南

公差疊加計算器（最差情形）求線性尺寸鏈在最差情況下的總公差累積，適合機械裝配的公差設計與間隙風險預估。

計算公式與原理

0.2 = 0.45。 最差情況偏保守。

線性尺寸鏈在最差情況下的總公差。

使用步驟

  1. 填寫「公差1 t₁」。
  2. 填寫「公差2 t₂」。
  3. 填寫「公差3 t₃」。
  4. 結果區會即時更新；可一鍵複製結果用於記錄或彙報。

典型使用場景

  • 安全關鍵、單件或小批次裝配中，用最壞情況（Worst Case）疊加估算總公差上界，保證 100% 不超差。
  • 與 RSS 工具對照，評估『為絕對安全加嚴公差』帶來的成本代價，輔助公差分配決策。
  • 合同/法規要求的極限尺寸校核，必須按極值法給出保證值。

算例參考

  • 公式：總公差 T = t₁ + t₂ + … + tₙ，直接把各組成環公差線性相加（假設全部同向取極值）。該法不依賴分佈假設，給出的是保守上界。
  • 算例：同段尺寸鏈公差 0.1、0.15、0.2 mm 按最壞情況疊加：T = 0.1 + 0.15 + 0.2 = 0.450 mm。這比 RSS 的 0.269 mm 大得多——意味著若按 WC 保證 100% 合格，每個零件都得控得更嚴（或留更大設計間隙），成本更高；大批次場景通常改用 RSS 取典型值。

注意事項

本工具純前端執行，輸入內容不上傳伺服器；結果為按上述口徑得到的理論估算值。實際應用受裝置引數、測量條件與當地規範影響，請以裝置銘牌、檢測報告與現行標準為準，重大決策建議諮詢專業人士。
