提示詞 Token 成本 使用指南

LLM Token 成本估算器，輸入輸入輸出 token 數與單價估算 API 費用，按 1 USD≈7.2 CNY 折算人民幣，輔助呼叫預算。

計算公式與原理

輸入費用 = 輸入 tokens / 10⁶ × 輸入單價；輸出費用 = 輸出 tokens / 10⁶ × 輸出單價；人民幣 ≈ 美元 × 匯率

大模型 API 普遍按輸入與輸出分別計價，且輸出單價通常高於輸入，因此壓縮提示詞與控制生成長度都能直接省錢。換算人民幣時匯率按當期取值，另需考慮批次/緩存摺扣與最低計費粒度。

使用步驟

  1. 填寫「輸入 Token 數」。
  2. 填寫「輸出 Token 數」。
  3. 填寫「輸入單價 $/1M」。
  4. 填寫「輸出單價 $/1M」。
  5. 結果區會即時更新；可一鍵複製結果用於記錄或彙報。

典型使用場景

  • 費用=輸入 token×輸入單價+輸出 token×輸出單價，按模型計費口徑估算。
  • 支援按 1 USD≈7.2 CNY 折算人民幣，輔助呼叫預算與成本對比。
  • 不同模型分詞器差異大，token 數需以對應模型為準，本估算為量級參考。

算例參考

  • 成本估算：輸入 10k token($0.01/1k)、輸出 2k token($0.03/1k) → 費用=10×0.01+2×0.03=0.16 USD≈1.15 元。批次呼叫前用此預判賬單。

注意事項

結果為按上述公式得到的理論估算值，實際表現受資料分佈、實現細節與執行環境影響，落地決策請以實測為準；本工具純前端執行，輸入不上傳伺服器。
