密碼生成器 使用指南

弱密碼是賬號被盜的首要原因。ToolBox 密碼生成器在瀏覽器本地用強隨機數生成密碼，不聯網、不上傳，可自定義長度、是否包含大小寫/數字/符號。

核心功能

  • 可調長度（建議 12 位以上）
  • 獨立開關：大寫、小寫、數字、符號
  • 排除易混淆字元(如 0/O/1/l)可選
  • 一鍵複製，不落地儲存
  • 基於瀏覽器密碼學安全隨機源

適用場景

  • 為新賬號生成高強度主密碼
  • 為不同網站生成不重複的獨立密碼
  • 生成 API Key、臨時令牌的隨機串
  • 團隊協作時分配一次性訪問口令

使用步驟

  1. 設定密碼長度，重要賬號建議 ≥16 位
  2. 勾選需要的字元型別，預設全選最安全
  3. （可選）開啟"排除易混淆字元"避免抄寫出錯
  4. 點選生成，預覽密碼
  5. 點選複製並立即存入密碼管理器

實用技巧

  • 每個網站使用不同密碼，配合密碼管理器最穩妥
  • 不要用生日、地名、連續數字等弱組合
  • 生成後立刻儲存，不要在多處明文貼上
  • 開啟雙重驗證(2FA)比單純加長密碼更有效

常見問題

生成的密碼安全嗎？
使用瀏覽器原生強隨機數源，且在本地生成不聯網，安全性高。
為什麼建議用密碼管理器？
人腦難記大量強密碼，管理器可加密保管並自動填充。
