基頻（f₀ = 1 / T） 使用指南

傅立葉級數基頻計算器：輸入週期 T，按 f₀ = 1/T 求週期訊號基頻，用於訊號頻域分解與諧波分析。

計算公式與原理

f₀ = 1 / T

週期訊號的基頻為其週期的倒數。

使用步驟

  1. 填寫「週期 (s)」。
  2. 結果區會即時更新；可一鍵複製結果用於記錄或彙報。

典型使用場景

  • 週期訊號週期 T 求基頻 f0。
  • 傅立葉級數展開的頻率基準。
  • 諧波頻率為基頻整數倍。

算例參考

  • T=0.02s（50Hz 週期）：基頻 f0 = 1 / 0.02 = 50 Hz；二次諧波 100Hz、三次 150Hz。
  • 週期變長：若 T=0.04s，則 f0=25Hz，基頻降一半、諧波同步下移。

注意事項

本工具純前端執行，輸入內容不上傳伺服器；結果為按上述口徑得到的理論估算值。實際應用受裝置引數、測量條件與當地規範影響，請以裝置銘牌、檢測報告與現行標準為準，重大決策建議諮詢專業人士。
