採購（成本/節約額）分析 使用指南

錄入採購價與基準價計算節約額與節約率，按品類彙總，用於降本考核與供應商比價，純前端統計不出境。

功能說明

錄入採購價與基準價計算節約額與節約率，按品類彙總，用於降本考核與供應商比價，純前端統計不出境。

典型使用場景

  • 彙總多家供應商的報價後，用描述統計看分佈：均值判斷市場均價、標準差看報價離散度、極差看最高最低報價差距，輔助議價。
  • 統計某品類近 N 次採購單價，觀察均值與波動，識別異常高價批次或價格趨勢。
  • 將每次談判的節約額（原基準價−實際成交價）彙總成數列，用均值/中位數評估整體降本效果、用標準差看節約的穩定性。

算例參考

  • 以「8 次採購單價（元）」為例：輸入 10,20,30,40,50,60,70,80（逗號、空格或換行分隔均可）→ 資料量 n=8，總和=360.00，平均值=45.00，中位數=(40+50)/2=45.00，最小值=10，最大值=80，極差=70.00，方差=525.00，標準差=22.91。說明這組單價的離散程度（標準差約 22.91）較大，議價空間可能較寬。

注意事項

本工具純前端執行，輸入內容不上傳伺服器；結果為按上述口徑得到的理論估算值。實際應用受裝置引數、測量條件與當地規範影響，請以裝置銘牌、檢測報告與現行標準為準，重大決策建議諮詢專業人士。

這些指標分別怎麼解讀？
均值反映集中趨勢；中位數對極端值更穩健；極差是最大最小之差，快速看波動範圍；方差/標準差衡量離散程度，越大說明供應商報價或批次資料越分散；標準差為 0 表示所有資料完全一致。選型時低標準差往往意味著成本更可控。
工具算的是「節約額」嗎？
本工具只做基礎描述統計，直接對輸入的數字序列計算均值/標準差等；「節約額」需你先自行算出每筆（基準價−成交價）再貼上進來。它不讀取任何外部資料，全部在瀏覽器本地完成。
