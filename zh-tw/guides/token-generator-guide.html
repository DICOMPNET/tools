隨機 Token 生成器 使用指南

基於瀏覽器加密級隨機數 crypto.getRandomValues 生成高強度令牌，可自定義長度、字元集與數量，顯示資訊熵，適合 API Token、邀請碼、金鑰等場景。

核心功能

  • crypto.getRandomValues 加密級隨機源
  • 自定義長度（4-256）與字元集（大小寫/數字/符號）
  • 批次生成最多 20 個
  • 顯示資訊熵（bit），量化強度
  • 逐個或全部一鍵複製

適用場景

  • 生成 API Token / 金鑰
  • 生成邀請碼、啟用碼、優惠券碼
  • 生成測試用的隨機憑據

使用步驟

  1. 設定長度（預設 32）與數量（預設 1）
  2. 勾選字元集：大小寫、數字、符號
  3. 點選「生成」，檢視熵值
  4. 點選「複製」使用

實用技巧

  • 符號集能顯著提升熵值，敏感場景建議勾選
  • 生成結果請立即安全儲存，本工具不儲存任何令牌
  • 瀏覽器關閉後令牌不會保留，重新開啟需重新生成

常見問題

Token 會被上傳嗎？
不會，隨機數在瀏覽器本地生成，不上傳任何伺服器。
什麼是資訊熵？
衡量隨機性強弱的指標，位數越高越難被暴力破解；128 bit 以上視為強令牌。
