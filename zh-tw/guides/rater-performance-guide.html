物業績效考核評分體系 使用指南

六大維度加權評分，可自定義權重並展示歸一化權重、配置 A/B/C/D 評級閾值；權重為 0 的維度不參與得分與排序，優先改進按分差×權重列出。

計算公式與原理

綜合得分 = Σ(維度得分 × 歸一化權重)；歸一化權重 = 該維權重 ÷ 非零權重合計

得分必須在 0–100、權重必須在 0–100 且不得為負；超出範圍或留空會點名報錯並停止計算，不會靜默截斷。權重為 0 的維度不參與綜合得分、等級判斷和改進排序。改進優先順序按「(100−得分)×歸一化權重」排序，同時體現分差與權重，取前 3 項。

使用步驟

  1. 逐維填寫得分（0–100）與權重（0–100）；保留觀察項可將權重設為 0，但至少一個維度權重大於 0。
  2. 按公司制度配置 A/B/C/D 四個等級下限，預設 90/80/70/60，要求嚴格遞減；低於 D 下限為 E 級。
  3. 生成後核對歸一化權重表：每個維度的原始權重、歸一化百分比和對綜合分的貢獻應能對上。
  4. 檢視「優先改進」的加權提升空間，並結合合同條款與公司考核制度決定整改或複核；工具建議僅供參考。

典型使用場景

  • 物業專案經理按月對各崗位評分，各維度權重按崗位職責差異化配置
  • 公司自定義 A/B/C/D 等級閾值，按合同或制度複核績效等級
  • 設定零權重維度以保留觀察資料，但不讓其影響綜合得分與優先改進排序

算例參考

  • 加權評分與歸一化：客戶滿意度 90（權重20）、設施維護 85（20）、響應時效 90（15）、收費率 88（15）、安全合規 92（15）、環境品質 85（15）→ 權重合計 100，歸一化後分別為 20%/20%/15%/15%/15%/15%；綜合 = 0.20×90 + 0.20×85 + 0.15×90 + 0.15×88 + 0.15×92 + 0.15×85 = 88.25 分。
  • 零權重維度：環境品質得分 10、權重改為 0，其餘權重合計 85；該維度不參與得分與排序，歸一化權重變為 23.5%/23.5%/17.6%/17.6%/17.6%，綜合 = (85×20 + 80×20 + 90×15 + 88×15 + 92×15) ÷ 85 = 86.5 分。
  • 可配置評級閾值：預設 A≥90、B≥80、C≥70、D≥60、E<60；若改為 A≥85、B≥75、C≥65、D≥55，則 86.3 分由 B 級變為 A 級。

注意事項

得分超 100、低於 0、為空或非數字，以及權重為負或超過 100，都會點名報錯並保留輸入框原值。評級閾值須嚴格遞減；合同複核提示隨當前等級給出，但是否複核仍以合同條款和公司制度為準。本工具純前端執行，輸入不上傳伺服器；結果為管理參考，不替代正式考核檔案。

超出 0–100 的分數會被截斷嗎？
不會。超範圍、為空或非數字都會點名報錯並停止計算，輸入框保留原值，便於核對後改正。
權重為 0 的維度參與考核嗎？
不參與。權重為 0 的維度不進入綜合得分、等級判斷和優先改進排序，頁面會單獨標註「不計入」，並展示其餘維度的實際歸一化權重。
改進優先順序為什麼不是直接看最低分？
低分但權重很小的維度，即使拉滿對總分影響也有限。工具按「(100−得分)×歸一化權重」計算加權提升空間，同時體現分差和權重。
評級閾值可以按公司制度調整嗎？
可以。A/B/C/D 四個下限均可配置，要求嚴格遞減；低於 D 下限為 E 級。評級和合同複核提示僅供參考。
