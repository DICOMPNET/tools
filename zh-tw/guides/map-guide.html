MAP 平均動脈壓 使用指南

MAP 平均動脈壓計算器。輸入收縮壓與舒張壓，按 MAP ≈ 舒張壓 + (收縮壓−舒張壓)/3 估算平均動脈壓，反映器官灌注壓力，用於迴圈監測參考。

計算公式與原理

MAP ≈ 舒張壓 + (收縮壓 − 舒張壓) / 3

MAP 平均動脈壓計算器。輸入收縮壓與舒張壓，按 MAP ≈ 舒張壓 + (收縮壓−舒張壓)/3 估算平均動脈壓，反映器官灌注壓力，用於迴圈監測參考。

典型使用場景

  • 器官灌注：MAP 反映心腦腎等平均灌注壓
  • 休克監測：MAP<65 常需升壓維持灌注
  • 血壓管理：結合收縮壓/舒張壓看整體

算例參考

  • 方法：演算法：MAP ≈ 舒張壓 + (收縮壓−舒張壓)/3；脈壓 = 收縮壓−舒張壓；分級：MAP≥70 正常、65–69 臨界、<65 偏低。要求血壓>0。
  • 算例：例1（120/80）：MAP=80+(120−80)/3=93.3mmHg，脈壓 40mmHg，正常。例2（100/60）：MAP=73.3mmHg，正常。例3（90/55）：MAP=66.7mmHg，臨界。

注意事項

醫療健康類結果為按公式得到的估算值，不能替代醫生診斷與處方。給藥劑量、補液速度、抗凝與溶栓決策必須以藥品說明書、臨床指南和主治醫師判斷為準；出現胸痛、呼吸困難、意識改變等急症請立即就醫。

MAP 比收縮壓重要嗎？
MAP 更代表器官平均灌注，尤其麻醉/ICU 關注 MAP 是否≥65；但收縮壓過低也影響冠脈灌注，需綜合判斷。
為什麼除以 3 不是 2？
舒張期佔整個心動週期約 2/3，故權重 2/3 給舒張壓、1/3 給脈壓，即 DBP+PP/3，是經驗近似。
